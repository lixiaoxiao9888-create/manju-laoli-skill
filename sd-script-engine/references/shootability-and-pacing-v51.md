# 剧本视听可拍性门禁与爆款节奏升级（V8.2.0-SLIM · 融合 short-drama-factory v5.1）

> 归属技能：`sd-script-engine`（剧本引擎）｜用于从源头消灭「下游分镜拍不出来、开局慢热、中后段注水、优化误改原稿」四大顽疾。

---

## 一、 剧本视听可拍性四门禁（`E37~E40` · 进分镜前必清）

1. **`E37` 禁否定式伪动作（硬拦截）**：严禁在 `△` 中写 `非但没跪 / 非但没退 / 看都没看一眼 / 连眼角都没扫` 等摄影机拍不出来的否定句，一律改写为正向可见动作（如 `△ 负手立于堂中，下巴微抬，目光越过众人落在主位`）。
2. **`E38` 道具交接来源闭环**：`△` 凡出现「接过 XX」，必须写清从哪位在场角色手中接过或从何处取出，严禁凭空接物导致下游分镜乱配递物人。
3. **`E39` 禁台词未提先知（幽灵反问）**：前文未出现且角色未在场得知的专名，严禁后句突然反问 `什么XX？`，必须先由对手抛话头或先亮物证。
4. **`E40` 禁同空间假切场**：相邻两场空间、时间、人物完全相同且无真实位移或时间跳转词，严禁硬拆场次。

---

## 二、 爆款开局与长剧防注水骨架

1. **第 1 集「极速进场五步拍点」**：`0~3s` 强视觉砸脸 ➔ **前 5 句台词内大白话挑明反派具体利益算盘/金额/死线** ➔ 反派加码逼死角 ➔ **第 1 集半场（35~65s）主角必亮首张实质反制牌**（查封/冻卡/撤资/收信物） ➔ 当场见血 + 破门断章。
2. **女频清算 A/B 双轨**：A 轨「当场掀桌·剥皮清算型」（第 3 集只结表层账，必留深层死账火种防 3 集演完大结局） vs B 轨「蓄力刀人·证据回放型」（第 1 集不可逆切割，第 2 集物证回放 3 笔血泪账，第 3 集公开抽底牌）。
3. **L1~L4 四级被看见圈层阶梯**：`L1 内宅/基层 ➔ L2 行业/城际 ➔ L3 权贵/名流 ➔ L4 中枢/天下`，单矛盾单元 ≤30 集必闭环并升维更换更高阶裁判与【质疑者配角】。
4. **立项六项《世界规则卡》**：写前锁定①权力上限 ②利益链条 ③空间壁垒 ④核心物证 ⑤**金手指代价锁** ⑥称谓阶梯，排除贬妻为妾/私拆御匾/撕自己手里原契等降智雷区。

---

## 三、 长剧防崩与「优化 ≠ 改编」路径消歧

1. **抗上下文压缩滚动快照**：批量连写每 5~10 集运行 `python sd-script-engine/scripts/rolling_checkpoint.py <剧本目录> --out rolling-state.md`，卸载旧集正文，只携状态包与最近 1~2 集尾态续写。
2. **「优化 ≠ 改编」路径消歧铁律**：用户拿**自己已有成稿**要求润色优化时，**严禁改剧名、严禁改主角姓名、严禁推翻原世界观外壳**；仅对标外部作品仿写时才执行剥壳换壳与第一性原理降维外化。

## ★ 剧本推进力与 AI 可拍性强化框架（吸收 R7.6 生产控制门）

1. **每场必推「剧情状态账本」+ 高潮后只升维**：
   - 每场结束必须至少改变 1 项状态：**主角处境 / 核心困难 / 刚刚的决定 / 已验证结果 / 对手认知 / 影响范围**；若聊完一遍六项全未变，该场并入前后场或删除。
   - 连续升级型故事层级**只进不退**（不先全球震动后退回某小团队当新危机）；**高潮核心打脸一旦成立，后续只保留「影响扩大 + 对手被迫改变行为 + 一句主题收刀」**，严禁再把前面讲过的数据或方法重新上课复习一遍。
2. **事件先于解释 + 角色认知账本**：
   - 优先「真实问题先发生 → 人物发现、判断、争执与决定」，**严禁角色刚问一句“会不会出事”，下一秒就刚好出事配合演出**。
   - 内部登记各主要角色“已知 / 亲眼见过 / 尚未知”，**严禁两个本来都知道内情的角色互相科普给观众听**；角色不能说出当下不可能知道的未来预言。
3. **AI 生产倒逼「可见证据」与说话人精简**：
   - 关键证据必须让 AI 视频画面一眼看得懂（如“零件装不上、卡死、封条二次热封痕”），**不把剧情押在“偏差 2 毫米”或需要 AI 稳定生成复杂小字表格/报告上**；
   - 正文单场优先控在 **2 个核心说话人**（第 3 人仅作短信息补位），降低多人口型与切镜成本；长对白场必须插入可见状态变化（送物、响铃、停机、起身等）。
4. **改稿防回滚：A/B/C 锁定分级 + 反馈作用域判定**：
   - **A 级绝对锁死**（已生成视频/已定镜一字不改，除非用户点名局部解锁）；**B 级含义锁**（核心事实与节点不动，仅修措辞）；**C 级方向锁**（允许重构实现方式）。
   - 收到修改意见先判清作用域——**单点 / 同类 / 阶段 / 全局**，绝不把“开头节奏再狠点”误推广成“全篇碎短句”。
5. **史实骨架 vs 戏剧表现层双层施工（仅真实人物 / 企业史 / 纪实逆袭题材按需启用）**：年份、成绩、商业/赛事结果与真实人物贡献归属属于事实骨架，严禁为爽感篡改；允许用匿名/复合功能角色承载真实存在的行业质疑或群体压力。
