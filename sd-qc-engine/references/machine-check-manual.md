# 出稿机检使用手册（C1~C26 / C14n / H1~H12）

> 本文档编写遵循总控 C1~C26 / H1~H12 机检体系；子检查码与触发门口径见下。

## 〇、定位

- 出稿机检脚本 **`validate_prompt.py`** 位于**总控** `scripts/` 目录（本引擎不复制、不改动脚本本体），是稿件级结构自检门禁：只查可机械判定的结构/版本问题；空间/遮挡/轴线/动作物理/视线仍由 AI 语义推演（总控 `short-drama-director/references/spatial-topview-camera.md` 与 `short-drama-director/references/quality-gate-review.md`），脚本不越权。
- 术语口径与总控完全一致：`--model 2.5 / 2.0` → **C1~C26**（Seedance 侧）；`--model h3` → **H1~H12**（MiniMax H3 格式支线，规程见总控 `short-drama-director/references/h3-adapter.md`）；`--track 1|2|3|4` → **赛道分流**（〇·0 强制分流锁），仅影响 C14 系列。
- **`--track`（赛道分流）**：赛道 ③ 解说叙事类走 **C14n 解说专线**——C14 三项篇幅 WARN 整体豁免、C14 三项 FAIL 照旧。理由与口径唯一权威在 `sd-jieshuo-engine/SKILL.md` §八。
- **`--combat`（打戏护栏触发门）**：C21 只对**打戏稿**生效（`on` 强制 / `off` 关闭 / 默认 `auto` 自动探测打戏信号词，文戏稿自动跳过）。规则权威在 `sd-combat-engine/references/combat-intensity-guardrails.md` §二。
- **C22 共用同一触发门**（未新增独立参数）：C22 规则权威在 `sd-combat-engine/references/combat-rhythm-and-load-guardrails.md`，与 C21 **共用 `--combat on|off|auto`**。二者分工——**C21 管激烈度（下限型·不许躺平），C22 管渲染负载与节奏（含上限型·不许过载）**，缺一则打戏必在「呆板站桩」与「小孩打架」两档之间摆动。
- **`--c23` 与 `--style-source`（画风锁机检触发门）**：C23 只对**启用 I 画风锁的稿**生效（`on` 强制 / `off` 关闭 / 默认 `auto`——稿内存在【STYLE/【PERFORMANCE 行首段标记或 `--style-source` 登记来源即启用，未启用画风锁的旧稿不追溯）。规则权威在总控 `short-drama-director/references/style-bible/director-to-prompt-protocol.md` §六；判据速查与实拍复盘教训见 `short-drama-director/references/style-bible/style-bible-spec.md` §四/§五。
- **`--aspect`（画幅任务锁回填）**：传入本次任务的画幅三选一（`16:9` / `9:16` / `21:9`），供 **C6b** 做「`aspect_ratio=` 字段 ↔【画幅风格】行声明 ↔ 任务锁」**三处互校**；并据此判「横竖构图词越界」。**多段稿建议逐段跑并带上本参数**（画幅锁是 B 锁，全片一致，漏传仅少一道比对）。
- **逐段判定（多段稿 · 2026-10-10 六维审计并入）**：脚本以 **`【画幅风格】`行**为界把稿件切成 N 段（真实交付稿＝「提示词组 × N 组」，3 分钟剧 ≈14 段，每段从 00:00 起、≤15s）。**C1 / C2 / C3 / C4 / C17 / C24 按段独立判定**——此前的「单段假设」会把合规多段稿全线误报、且**第 2 段起的人物遗漏抓不到**（"B 在下一镜不见了"的结构性盲区）。单段稿行为不变。**投喂正文口径**：含 ```` ``` ```` 围栏时只取围栏内容（C11/C12/C12b），避免稿件自带的说明散文/自检表被当成投喂正文误报。

## 一、命令行用法

```bash
python scripts/validate_prompt.py <提示词文件.md|.txt> [--model 2.5|2.0|h3] [--mode new|extend] [--track 1|2|3|4] [--combat on|off|auto] [--c23 on|off|auto] [--style-source 导演名] [--aspect 16:9|9:16|21:9] [--json] [--self-test]
```

| 参数 | 说明 |
|---|---|
| `<提示词文件>` | 待检的投喂稿（md/txt，UTF-8），通常为七段式或 H3 格式投喂稿 |
| `--model 2.5` | Seedance 2.5 侧检查（C1~C26），段上限 30s |
| `--model 2.0` | Seedance 2.0 侧检查（C1~C26），段上限 15s |
| `--model h3` | MiniMax H3 格式支线检查（H1~H12），硬区间 4–15s |
| `--mode new\|extend` | new=完整新稿；extend=续写稿 |
| `--track 1\|2\|3\|4` | **赛道分流**（〇·0：1 国内剧 / 2 海外剧 / 3 解说叙事 / 4 其他），默认 `1`。**仅赛道 3 改变判定**：C14 篇幅卡口豁免、改判 C14n；其余赛道口径不变 |
| `--combat on\|off\|auto` | **C21 打戏护栏触发门**，默认 `auto`：打戏信号词达阈值即启用 C21，文戏稿自动跳过；`on` / `off` 为强制开关 |
| `--c23 on\|off\|auto` | **C23 画风锁机检触发门**，默认 `auto`：稿内存在行首【STYLE/【PERFORMANCE 段标记即启用（I 锁已启用），未启用画风锁的旧稿不追溯；`on` / `off` 为强制开关（`on` 时缺段8/9 即报 C23a） |
| `--style-source 导演名` | **STYLE_BIBLE 来源风格登记**（如 `徐克`/`王家卫`）：登记后启用 C23d② 转译丢失与 C23e 题材越界判据；名字本身是选项层信息，**不得出现在稿内**（出现即 C23d1） |
| `--aspect 16:9\|9:16\|21:9` | **画幅任务锁回填**（B 锁）：供 **C6b** 做「`aspect_ratio=` 字段 ↔【画幅风格】声明 ↔ 任务锁」三处互校；与稿内声明不符即 FAIL。格式须形如 `16:9`（含全角冒号亦可），否则退出码 2 |
| `--json` | 以 JSON 输出结果（含 `track`、`c14_exempt`、`combat_checked`、`c23_checked`、`style_source` 字段） |
| `--self-test` | 脚本自带自检（验证机检器本身健康） |

> **赛道③ 稿件必带 `--track 3`**：解说类是「全片 VO」，若漏传 `--track 3`（默认按剧情赛道跑），C14 会把整篇旁白判为超配额，产出大量误报 WARN。这不是稿件缺陷，是**参数缺失**——先确认赛道再判 WARN。

**退出码与交付铁律**：脚本发现 FAIL 类问题退出码 1，无问题退出码 0。**FAIL 清零才交付**；WARN 逐条修复或在交付说明中写明判定依据，禁止带 FAIL 出稿。

## 二、C1~C26 门禁清单（Seedance 侧）

### 结构与预算（FAIL 级为主）

| 项 | 名称 | 内容 |
|---|---|---|
| C1 | 时长预算 | 段时长 ≤ 模型上限（2.5=30s / 2.0=15s） |
| C1b | 分段粒度 | 2.5 默认 25~30s 吃满上限；<12s 或 16~24s 碎段区告警 |
| C2 | 切镜上限 | 镜头数 ≤ ceil(段长/3s)；单镜 <3s 告警 |
| C3 | 时间轴 | 相邻镜头无断档/重叠；time 倒挂拦截 |
| C4 | 字符预算 | **单文件** ≤4500 字符（篇级工程兜底 · 按整份投喂稿文件的字符数计；段级字数上限**按模型分档**——2.0 ≤1900 字 / 2000 硬上限、2.5 ≤2600 字 / 3000 硬上限，由 `sd-feed-engine/scripts/gate_check.py`「闸门3」逐投喂单元判） |
| C5 | 版本语法 | 2.0 禁 [SFX:] 与顿挫词；2.5 建议 [SFX:] |
| C6 | 画幅回填 | 含 aspect_ratio= 或含画幅的【画幅风格】栏（**段名独立成行亦认**：`【画幅风格】` 换行后下一行写画幅值——2026-10-12 修复，此前官方示例 storyboard-example.md 用该写法必 FAIL） / **b** 画幅自相矛盾或不一致（① `aspect_ratio=` 字段出现互斥多值；② 字段值与【画幅风格】行声明不符；③ 与任务锁 `--aspect` 不符 → 均 **FAIL**）；构图词越界（**16:9·21:9 稿**写「垂直安全区／竖向安全区／上下叠压／上下对峙／纵向落差」，或 **9:16 稿**写「三分线左右站位／左右对峙／横向位移／左右推进／水平展开」→ **WARN**——横竖画幅的构图语汇不可混用）※2026-10-10 六维审计并入 · P2-A |
| C7 | 七段式 | 核实七段式核心栏齐备（【画幅风格】【场景资产】【核心人物】【站位声明】【时间轴分镜】【音效】【强制禁止项】）段7 可由前置【强制禁止项｜前置】**等价满足**（禁项单点二选一） / **b** 镜行解析失效 → FAIL（2026-10-11 新增 · **元检查**：时间轴行存在但无一能解析出镜行头「`[镜头N]` 景别 · 视角 · 运镜」→ 说明镜级判据〔C18g~l 运镜门 / C13 镜长 / C11b 末镜定格 / C2 单镜时长〕**全部未生效、本次 PASS 不可信**；解析率 <60% → WARN。治「检查器静默失效仍报绿灯」——假 PASS 比假 FAIL 危险一个量级） / **c** 站位人物账解析失效 → **FAIL**／WARN（2026-10-11 新增 · **元检查**：【站位声明】里一个人名都解析不出〔规范为 `@人名（画面位置 · …）`〕→ C17 摆位必入画／C17b 关系镜／C17c 背景锚点／C17d 跨段站位漂移／C19c 首镜主体优先 **五条判据全部未生效、本次 PASS 不可信**；解析为空但**宽松兜底解析成功**〔写成 `A（…）` 漏 `@`〕→ WARN，判据仍生效但请补 `@`。治「检查器静默失效仍报绿灯」） |
| C8 | 首尾帧禁用 | 2.0 出现 首帧:/尾帧:/参考图绑定/Start Frame/End Frame 即拦截（2.0 全面禁用） |
| C9 | 平台高危词 | 血腥/断肢/裸露/自伤/违法等高危词 → 拦截，走 platform-safety 替代表 |

### 对白与人物账（WARN 级）

| 项 | 名称 | 内容 |

出稿按以下顺序双门联审，**两门都过才交付**：


## 八、解析口径备忘：时间轴格式（C1~C30 / 闸门 / 看板全链路统一）

| 格式 | 样例 | `TIME_RE`（`validate_prompt.py` 全门禁用） | `COMBAT_RANGE_RE`（C21/C22 用） | `gate_check.py` / `build_board_lite.py` |

- 打戏三引擎（`sd-combat-engine` / `sd-xuanhuan-engine` / `sd-real-engine`）的分镜稿惯用 `0-3秒` 或 `[镜头1] 0-3秒` 整数秒；**自 2026-10-14（`◑15` + 全链路统一）起，`TIME_RE`、`parse_time_ranges`、`_c27_shot_span`、`_shot_head`、`C19c`、`C23_SHOT_LINE`、`gate_check.py`、`build_board_lite.py` 全部原生支持该格式**，不再出现「打戏稿跳过时间轴检查直接假 PASS」的盲区。
- **散文防误判守卫**：`TIME_RE` 第三形态要求行首或紧跟空白/括号（`[\s\[【\]】]`）且 `秒` 字紧贴数字（不接受 `1~2 秒` 带空格的散文写法），单段秒数上限 59s。
- **C21 不受影响**：它自带解析器（`COMBAT_RANGE_RE`），三种格式全认——这正是 C21 能对打戏分镜稿**直接生效**的前提。
- **C23 亦不受影响**：画风锁镜块解析器（`C23_SHOT_LINE`）三种格式全认（`0s-3s` / `0-3秒` / `00:00-00:04`），且**兼容小数秒**（`0s-2.5s`）——小数秒漏判曾导致 C23b/c/f 全线静默失效（自检第 1 轮抓到后修复）。
- 另：C21 的区间解析会**自动排除说明文字行**（如「三轮攻守：0-6 秒…」）并对**重复时间轴去重**（分镜稿 + 投喂稿同稿时），防止片长被算成 2~3 倍。
- **逐段解析（2026-10-10 六维审计并入 · 修「单段假设」）**：脚本以 `【画幅风格】` 行为界把稿件切成 N 段；**C1（段时长）/ C2（镜数上限）/ C3（时间轴连续性）/ C4（字符预算）/ C17（摆位必入画）/ C24（禁项单点）按段独立判定**。切口成因：真实交付稿是「提示词组 × N 组」（3 分钟剧 ≈14 段），而旧实现把整份文件当**一段**读——后果是① 合规多段稿被误报（C1 段时长按全篇累加、C2 镜头数按全篇比、C4 字符按全篇算、C24 看到 N 处禁项即判重复）；② **第 2 段起的人物遗漏、站位漂移全部漏检**（正是用户反复反馈的"B 在下一镜不见了"）。单段稿行为不变；`tr` 的行号仍为**全篇全局行号**，故 C15 的镜行回溯不受影响。
- **投喂正文口径（`_feed_body`）**：稿件含 ```` ``` ```` 围栏时，**C11（接续状态残留）/ C12（规则词混入）/ C12b（跨项目污染）只扫围栏内的投喂正文**，不扫围栏外自带的说明散文/自检表（否则文档里"无 palette 默认化""强制换机位"这类**自我描述**会被当成稿件污染误报）。无围栏稿按整篇为正文（旧行为）。
