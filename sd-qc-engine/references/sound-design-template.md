# 声音设计模板（音效/人声/环境音/BGM 层级）

> 精编自《灵境AI漫剧制作流 V3.9.0》manju-sound-design-director

## 〇、定位与边界

- **目的**：根据锁定台词、角色音色与剪辑分段，设计对白、画外音、环境声、拟音、音乐与静默；逐段复核台词、换气、停顿和反应时长，保证跨段长台词不漏字、不重字。
- **边界**：不改台词，不虚构已生成音频，不重新设计角色声线（只写场次声学与情绪调制），不在未授权时复刻真实人物声音。

## 一、声音层级与混音电平（与总控同一口径）

$$\text{第一层：对白清晰度 (0 dB)} > \text{第二层：动作物理音效 SFX (-6 dB)} > \text{第三层：环境声景与 BGM (-14 dB ~ -18 dB)}$$

- 对白永远处于最高清晰度优先级；动作音效（骨裂/破风/撞击）不得遮盖人声。
- BGM 在激烈打斗或对白爆发时自动避让（Ducking）。
- 使用声音桥连接合理镜头；使用静默突出决定、真相或冲击（`SILENCE` 也是一层设计）。

## 二、人声分类（严禁互换）

| 类型 | 规则 |
|---|---|
| 画内对白 | 台词逐字不改；写时间、角色、语气、重音、停顿、口型可见度和听者反应 |
| 画外音（OS 内心独白 / VO 旁白） | **声画分离红线**：OS 发声时画面角色必须闭口，禁用 `{}` 锁口型通道；VO 冷漠审视、不复述画面；一律走"声音："段，台词字段只装画内开口对白（机检 C14 兜底）；配额：VO+OS 占声音容量 ≤30%、60~80 字/分钟，防广播剧化 |
| 电话音 / 系统音 | 非画内人物，不绑定口型 |
| 旁白 | 不复述画面已呈现信息 |

## 三、与总控 Seedance 原生音效标记体系的衔接（★必读，防冲突）

本模板是**设计与复核层**；投喂提示词中的声音写法唯一权威是总控：

| 总控体系 | 衔接说明 |
|---|---|
| **[SFX:] 标记**（Seedance 2.5 原生音效标记） | Seedance **2.5 建议**使用 `[SFX:]`（机检 C5）；Seedance **2.0 禁用** `[SFX:]` 与顿挫词。本模板的 `PROP_SFX/AMBIENCE/FOLEY` 设计条目落到投喂稿时，2.5 走 `[SFX:]`，2.0 融入镜行画面/声音描述，禁混写版本语法 |
| **【音效】栏**（七段式核心栏之一） | 分层结果回填进总控七段式【音效】栏；栏名与段数以总控 `short-drama-director/references/model-adapters.md` 为准，本模板不另立格式 |
| **语气位**（`台词：【角色（语气）："…"】`） | 对白必须带语气位（2.0/2.5 同规格必写，机检 C16）：声音词只进语气位禁进画面段；语气按四维写（情绪色/力度/音质/节奏），禁空泛结果词（开心/难过/愤怒）；道具动作与语气一致（强情绪禁把玩类动作） |
| **音色锁** | 仅 2.5 且可选增强（投 `reference_audio` 并在【核心人物】行尾标注"锁定音色"）；不做资产体系、不设前置门禁 |
| **声音词豁免反形容词规则** | 语气位/声音段/【音效】豁免"形容词必须可画"规则（声音没有肌肉动作可写），但同样禁空泛结果词 |

## 四、环境声 / 拟音 / 音效写法

1. **环境声（AMBIENCE）**：保持空间连续——同一场内环境底噪不断层；跨段环境状态与连续性台账的场景账一致。
2. **拟音（FOLEY）**：证明接触、重量和材质——脚步声配地面材质，衣物声配动作幅度。
3. **道具音效（PROP_SFX）**：关键声音精确落在动作帧（声画同步点写明）；与语气位不冲突（C16d）。
4. **音乐（MUSIC）**：默认作为后期独立层。若目标视频模型提示词要求无背景音乐，明确隔离不写；需要配乐时输出音乐功能、进入/退出点与强度，不让其遮盖对白。
5. **战斗段「只要音效、禁 BGM」选项**：一镜到底的高动态战斗段，BGM 会与连续音效抢频、削弱打击感与压迫感。**战斗段可显式声明"只生成对应音效、不生成任何背景音乐"**——音效按招式/接触点逐条列清（出鞘、金属咬合脆响、低频轰鸣、音爆、介质崩解碎光、火柱腾起等），**BGM 完全不进该段**（既不写进模型提示词、也不做后期铺底，除非用户另行要求）。**这是战斗段的优先选项、不是全片默认**——文戏/情绪段照走总控 BGM Cue Sheet（`post-music-sound-design.md`）。**与投喂层衔接**：sd-feed-engine 默认不出 BGM，本节是"战斗段连后期也不铺"的强化声明，需在交付说明里对用户讲清。


- `layer` 取值：`DIALOGUE / VOICE_OVER / AMBIENCE / FOLEY / PROP_SFX / MUSIC / SILENCE`（裁定：不再强制 V3 公共信封根字段与 actor_profile_id 引用，角色音色以总控资产口径的 character_id/voice_id 表达；其余字段语义不变）。
- `segment_timing_validation`：逐段复核对白秒数 + 换气停顿 + 反应时长 ≤ 段长；不为容纳声音私自改台词或拉长生成段。
- 跨段台词：核对同一 `dialogue_id/voice_id`、前段结束字词、后段起始字词和呼吸连续，确保不漏字、不重字。
- 口头禅只有在锁定对白已有对应文本时才标记 `catchphrase_id`；声音岗位不得新增或替换台词。

## 六、质量门

- 全部锁定台词和声音标签被覆盖；每个说话角色引用当前音色版本。
- 每段声音时长不超过模型上限且与剪辑分段一致（C1）；跨段台词逐字连续。
- 声线未被场次情绪替换；环境底噪连续；无台词角色明确闭口。
- 画外声配额与声画分离合规（C14 / H9 / H10）。
- 缺少精确时码时形成待对齐 cue，不伪造已同步音频。
