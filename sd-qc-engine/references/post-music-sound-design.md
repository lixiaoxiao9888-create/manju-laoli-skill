> **本文档是质检交付层规则库 · 权威文件**
> 融合来源：script-writing-studio 07 模块
> **衔接声明（★必读）**：本文件承接 `sound-design-template.md` 的 **MUSIC 层 cue**，负责**落地执行**（找曲 / 生成 / 版权）。`sound-design-template.md` 是**设计与复核层**（声音分层/电平/声画分离/SOUND_PLAN），本文件是**后期执行层**。两层不重复、不打架。

## 〇、定位与边界

### 本模块负责

1. 为已生成视频/粗剪版/定稿分镜设计全片 **BGM 情绪曲线**。
2. 输出 **BGM Cue Sheet**：每段音乐从哪进、哪出、哪里淡入、哪里突停、哪里完全不要音乐。
3. 输出**音乐搜索关键词**（中文 / 英文 / 素材库标签）。
4. 输出 **AI 音乐生成提示词**（适配 Suno / Udio / ElevenLabs Music / Stable Audio / 剪辑软件 AI）。
5. 设计**声音层次**：对白、环境声、关键音效、转场音、低频铺底、静默点与音乐的关系。
6. **检查**音乐是否抢台词、过度煽情、破坏节奏、有版权风险。
7. 为短视频平台提供**音乐节奏建议**：前 3 秒 / 反转点 / 情绪爆点 / 结尾钩子。

### 本模块不负责

1. 不替代专业作曲、混音、母带或版权律师。
2. 不承诺任何音乐素材一定可商用；**只能提醒用户检查授权**。
3. **不生成或仿写**具体歌曲、歌手、影视原声、平台热门 BGM 的可替代版本。
4. **不把 BGM 强行加到所有段落**——静默、环境声和无音乐也是设计。
5. 不处理视频画面提示词；**不把 BGM 写回投喂稿**（投喂稿只含环境声、对白原声、同步音效）。

## 一、什么时候调用

**触发词**：配 BGM / 后期音乐 / 哪里该有音乐 / 音乐情绪递进 / 音乐 Cue Sheet / 我该搜什么音乐 / Suno 提示词 / Udio 提示词 / 剪辑音乐怎么进怎么出 / 台词下面铺什么 / 要不要突然静音 / 成片声音设计。

**提前做**：用户还没生成视频但已有分镜/投喂稿时，可提前做"**预配乐方案**"，但**必须标注时间点为暂定**，最终以实际剪辑时长为准。

---

## 二、输出模式（4 种）

| 模式 | 适用场景 | 输出内容 |
|---|---|---|
| **A 快速找音乐版** | 用户只想知道搜什么音乐 | 音乐功能、中文搜索词、英文搜索词、筛选条件、版权提醒 |
| **B 全片 Cue Sheet 版** | 用户已有视频或粗剪，要进剪辑 | 全片时间轴、BGM 进出点、静默点、音量、音效、情绪递进 |
| **C AI 音乐生成版** | 用户准备用 AI 音乐工具生成 | 每段 AI 提示词、时长、结构、乐器、节奏、禁止项 |
| **D 声音体检版** | 用户已有成片但觉得情绪不对 | 检查音乐是否抢戏/过满/过煽情/节奏不对/版权风险 |

**默认推荐**：已有粗剪 → B；只有剧情或分镜 → A + C；要上架发布 → B + 版权检查；音乐已放但不满意 → D。

## 三、核心原则（9 条）

| # | 原则 |
|---|---|
| 1 | **音乐服务叙事，不服务炫技**：每段 BGM 必须说明功能（铺底/推进/压迫/反转/催泪/喜剧停顿/结尾钩子/转场桥）。 |
| 2 | **对白优先**：有重要对白时，音乐低存在感、少旋律、无歌词或弱旋律，并给压混建议。 |
| 3 | **静默是武器**：惊吓/反转/难堪/压迫/强忍情绪时，静默或只保留环境声可能比 BGM 更有效。 |
| 4 | **不要从第一秒铺满到最后一秒**：必须有起伏、留白和断点。 |
| 5 | **情绪不要一上来满格**：悲伤/燃/悬疑/浪漫都要有递进。 |
| 6 | **音乐配合平台节奏**：前 3 秒可用音色钩子或节奏钩子；反转点用突停/低频/冲击音；结尾用悬而未决的尾音。 |
| 7 | **搜索词必须可执行**：不能只写"伤感 BGM"，必须给中文+英文+筛选条件。 |
| 8 | **AI 提示词必须写结构**：时长、是否无歌词、乐器、节奏、情绪曲线、进入退出、禁止项。 |
| 9 | **版权优先**：不使用具体歌名/歌手/影视原声/热门 BGM/"某某同款"作为生成目标。 |

## 六、AI 音乐生成提示词结构

**必含 9 项**：时长 / 是否无歌词 / 音乐功能 / 乐器与音色 / 情绪曲线 / 节奏速度或 BPM / 进入与结束方式 / 禁止项 / 使用场景。

**通用模板**：
```
生成一段 [时长] 的无歌词背景音乐，用于 [剧情场景/情绪功能]。
整体情绪是 [情绪]，不要一开始就爆发。
主要乐器/音色：[乐器1]、[乐器2]、[氛围音色]。
节奏：[慢速/中速/逐渐加速]，约 [BPM范围]。
结构：[0-X秒] 低存在感铺底；[X-Y秒] 情绪轻微递进；[Y-Z秒] 达到小高潮；
```

## 七、剪辑与混音建议

### 对白下方
- 音乐音量低于对白，保持低存在感。
- 优先无歌词、弱旋律、长音、氛围 pad、稀疏钢琴。
- 情绪强台词落点前，可短暂降低或抽掉音乐。
- 不要让鼓点踩在每个字上，除非喜剧或快节奏剪辑。

### 情绪爆点
- 爆点前渐弱，让观众注意角色表情或对白。
- 爆点瞬间用突停、低频冲击、短促 stinger。
- 爆点后**不要立刻铺满大音乐**，给 0.5-2 秒反应空间。

### 静默点（适用情况）
```
① 角色强忍情绪    ② 反转前一秒      ③ 难堪、尴尬、无法回应
④ 观众需要读表情  ⑤ 恐惧压迫        ⑥ 喜剧包袱落点
```

### 转场桥
- 跨场景硬切可用**音乐尾音、环境声桥或转场音**连接。
- 平行剪辑可用**同一 BGM 节奏**统一两个空间。
- 回忆/梦境/闪回要用**音色变化**区分现实。

## 八、版权与商用检查（★ 必读）

输出任何音乐方案时都要提醒：

1. 商用发布前**必须确认音乐素材授权范围**。
2. **保存授权页面、购买记录、下载记录或平台授权说明截图**。
3. 不要使用未授权影视原声、热门歌曲、歌手作品、平台爆款 BGM。
4. 不要要求 AI 音乐工具"模仿某歌手 / 某歌曲 / 某电影原声"。
5. 用素材库时，检查是否覆盖**短视频平台、商业广告、信息流投放、影视节、海外平台**等用途。
6. 用 AI 音乐工具时，检查**当前账号套餐是否允许商用**，以及生成作品的归属和限制。
7. 客户项目/品牌项目/付费投放项目，版权风险**默认按高标准处理**。

**固定提示语**：
```
版权提醒：以下搜索词和 AI 音乐提示词只用于寻找或生成原创/可授权音乐。发布前请确认素材库或
AI 音乐平台的商用授权，不要直接使用未授权歌曲、影视原声、热门 BGM 或具体歌手风格。
```

## 九、声音体检（用户说"音乐不对/太吵"时）

| 检查维度 | 常见问题 | 处理 |
|---|---|---|
| 是否抢台词 | 音乐盖过对白，鼓点踩字 | 降低音量、去旋律、去鼓点 |
| 是否过满 | 从第一秒铺到最后一秒 | 加留白、加断点、加静默 |
| 是否过煽情 | 第一秒就大旋律，情绪没递进 | 改为递进结构，降低起始强度 |
| 节奏是否匹配 | 快节奏画面配慢音乐 | 按平台节奏调整速度 |
| 是否需要静默 | 反转/难堪处有音乐反而稀释冲击 | 改为静默或只留环境声 |
| 是否有版权风险 | "某某同款"、影视原声、具体歌手风格 | 替换为原创/可授权素材 |
