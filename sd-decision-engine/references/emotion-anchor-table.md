# 情绪锚点表（Emotion Anchor Table · 6 列标准格式）

> **本文档是决策层核心输出格式 · 权威文件**
> 融合来源：script-writing-studio 04-core-workflow Phase 4.5
> 定位：**决策层 → 分镜层的交接凭证**。分镜引擎拿到锚点表后，每个镜头必须能对应到某个节拍。

---

## 〇、这是什么 / 解决什么问题

**问题**：直接从剧本跳到分镜，中间没有"情绪依据"。结果是分镜设计靠 LLM 当场发挥 → 不稳定、跨段不一致、情绪曲线没规划。

**解法**：在分镜前插入**情绪锚点表**，把"这段戏的情绪怎么走"先钉死，再设计镜头。

---

## 一、标准格式（6 列）

```
【大分镜 #B01 · 情绪锚点表】

| 节拍 # | 情绪关键词 | 服务的剧本动作 | 情境 ID | 核心组合摘要（80%定死） | 解锁雷区 |
|---|---|---|---|---|---|
| 节拍 1 | 闲聊试探 | 花十假装随口问"你等会去哪" | E07 | 长焦+大光圈+过肩静态 | — |
| 节拍 2 | 害羞犹豫 | 露夏低头搅奶茶不敢直视 | E08 | 过肩+长焦+手持微动 | — |
| 节拍 3 | 鼓起勇气 | 露夏抬头说出邀请 | E09 | 长焦+仰拍+缓推 | — |
| 节拍 4 | 决断接受 | 花十掐烟起身答应 | E11 | 微距标点+静切动 | — |
```

**列说明**：

| 列 | 填写要求 |
|---|---|
| **节拍 #** | 该段戏的情绪节拍序号（3-5 个） |
| **情绪关键词** | 4-6 字，如"闲聊试探""害羞犹豫"（禁空泛词如"复杂""微妙"） |
| **服务的剧本动作** | 一句话说清"这个节拍里角色在做什么"（必须有具体动作） |
| **情境 ID** | 来自 `context-mapping.md` 的 E01-E15（或用户自定义 EX01） |
| **核心组合摘要（80%定死）** | 从 ID 表**直接复制**，分镜层不允许修改 |
| **解锁雷区** | 若该 ID 解锁 A 类雷区则标注（如"A1 正面居中"），否则填 "—" |

---

## 二、硬约束（违反即重做）

| # | 约束 | 说明 |
|---|---|---|
| 1 | **每段大分镜节拍数 3-5 个** | 少于 3 = 戏不够；多于 5 = 该拆成两段 |
| 2 | **节拍数 × 每节拍承担镜头数 ≈ 段内总镜头数** | 便于与分镜数量对齐 |
| 3 | **每个节拍必须能用一句话说清"角色情绪/动作"** | 含糊的节拍写不出有效镜头 |
| 4 | **节拍之间必须有变化** | 4 个"害羞"节拍 = 戏没推进，违反核心原则 |
| 5 | **情境 ID 必须从三处之一获取** | 基础表 / 进阶表 / 用户自定义；**禁止 LLM 编造** |
| 6 | **同段内 ID 可重复** | 但核心组合的"动态变化"必须由辅助锚点承担（避免连续多镜完全一样） |

---

## 三、锚点表在管线中的作用（三层位置）

```
① 生成前 —— 每个镜头在设计时必须明确对应到某个节拍 + 该节拍的情境 ID
② 生成中 —— 内部四问的 Q1（为什么用这个镜头）+ Q4（解锁理由）答案直接来自锚点表
③ 生成后 —— 成片预演验证三件事：
     · 实际情绪曲线 = 锚点表预设曲线？
     · 每个节拍至少 1 个主镜头满足 ID 的 80% 核心组合？（辅助镜头允许偏离）
     · 解锁雷区是否合法？（A 类有白名单理由 / B 类不允许出现）
```

## 四、用户友好版输出（情境对照表）

> 锚点表是**工程化版本**（6 列表格）。给用户看时，另出一份**用户友好版**——一眼看清每个节拍用了哪个情境思路。

**输出格式**（在分镜本体之前打印）：

```
【本段情境对照】
- 节拍 1：闲聊试探 → E07 暧昧试探
- 节拍 2：退缩犹豫 → E08 内向退缩
- 节拍 3：鼓起勇气 → E09 突破内心
- 节拍 4：动作标点 → E11 干脆决断
```

**含解锁雷区时**：

```
【本段情境对照】
- 节拍 1：仪式肃穆 → E10 仪式威严（解锁 A1 正面居中 · 白名单 ② 仪式感）
- 节拍 2：转身亮相 → E02 反派登场变体（解锁 A1 · 白名单 ⑥ 权力凝固）
```

**含用户自定义时**：

```
【本段情境对照】
- 节拍 2：扭曲过渡 → ★ EX01 VR 入境扭曲（用户自定义 · 本会话内有效）
```

**注意**：节拍号与情境 ID **不写进分镜本体**，全部归集到此表（分镜稿保持干净）。

## 七、与总控体系衔接

| 机制 | 关系 |
|---|---|
| 情绪节拍曲线（`short-drama-director/references/emotion-beat-curve.md`） | 锚点表是**段落级细化版**——曲线管全片，锚点表管单段（3-5 节拍） |
| 分镜设计八重筛选 | 锚点表的"情境 ID + 核心组合"作为筛选的第一重"情绪匹配"依据 |
| 15 秒完播率结构 | 锚点表在 15 秒结构内分配节拍，不改变结构 |
| 机检 C 系 | 锚点表不参与机检（机检针对投喂稿），但**分镜层自检须核对锚点表落实率** |

---

## 八、快速调用语

- "这段戏做情绪锚点表" → 输出 6 列表格 + 情境对照表 + 数量说明
- "帮我看情绪曲线对不对" → 核对锚点表节拍变化是否合理
- "这段分镜有没有落实锚点表" → 逐镜核对情境 ID 对应关系
