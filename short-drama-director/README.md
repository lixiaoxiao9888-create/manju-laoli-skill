# 漫剧老李 AIGC 创作全流程 Skill · V7.4.20 多技能套装版（Short-Drama Director Suite）

面向 **AIGC 视听创作** 的工业级全流程创作技能包，供 AI 助手 / LLM 调用——从创意立项、剧本、资产、分镜到视频模型投喂提示词与独立质检。
典型场景为 AI 短剧 / 漫剧 / 短视频剧集；管线与题材解耦，同样适用于 AI 广告片 / 宣传片、分镜预演（PREVIS）、武打动作设计、微表情专项等一切需要跨镜头一致性的 AIGC 视频生产。

> 🔑 **核心理念：本包不持有图，交付的是"提示词 + 接线说明书"。**
> **图由用户在外部平台（即梦 / Seedance / 豆包等）自行生成并持有**——本包默认只出提示词，不代用户出图（用户明确下"出图口令"才执行）。因此"素材"按**存在形态**分三档，**每次交付首行必须声明**：
> - **M0 纯提示词**：稿件内**不出现任何图号**；跨镜一致性由**文字锁**承担（外观档案复述块五要素：发/服装/体态/年龄感/标志物，**禁写"同上"**）。
> - **M1 编号占位（默认）**：稿件保留 `图N` 槽位，并**必附《素材接线单》**——用户只需在平台的素材区按单子把图挂上，**不需要把图交回本包**。
> - **M2 已入库**：用户主动交回图并登记台账，此时**才**可做图像级核验。
>
> ⚠️ **四铁律**：**不索要图片**（不得把"把图发我"当作继续条件）· **不因缺图阻塞**（门禁按形态改判，"没有图"本身永不构成阻断）· **不假装**（禁止写不存在的图号；**禁止声称"已核验/与资产图册一致"而实际从未见过图**）· **要声明**（首行写明形态）。权威 = `references/asset-delivery-modes.md`。
>
> 📌 **A 轴与 M 轴正交**：`A0~A3` 管"要不要走资产链"（任务复杂度）；`M0~M2` 管"图在不在手里"（门禁怎么判）。**A 轴判不清按 A3；M 轴按用户实际条件，不取最高档**——用户手上没图就 M0，不为了"合规"逼用户出图。
