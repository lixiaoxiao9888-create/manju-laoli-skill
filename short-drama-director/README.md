# 漫剧老李 AIGC 创作全流程 Skill · V6.9.8 轻量版（Short-Drama Director Suite）

面向 **AIGC 视听创作** 的工业级全流程创作技能包，供 AI 助手 / LLM 调用——从创意立项、剧本、资产、分镜到视频模型投喂提示词与独立质检。
典型场景为 AI 短剧 / 漫剧 / 短视频剧集；管线与题材解耦，同样适用于 AI 广告片 / 宣传片、分镜预演（PREVIS）、武打动作设计、微表情专项等一切需要跨镜头一致性的 AIGC 视频生产。
覆盖：**Asset-First 六阶段管线**（立项锁定 → 五阶门控剧本 → 数字资产包 → 分镜 → 视频提示词渲染 → 独立质检）。

> 🔑 **核心理念：资产图先于分镜。** 角色/场景/道具在 P2 数字资产包阶段完成**出图并锁定**（非文字描述），成为《资产图册》唯一权威事实来源，分镜/投喂一律引用已锁定 @资产图。

> **品牌**：漫剧老李 AIGC 全流程 Skill
> **版本**：V6.9.8 轻量版（Lite）Multi-Agent（**V6.9.8 · 2026-09-20 新增 MiniMax H3 格式支线**：A 锁并列第三选项，只做「七段式→H3 原生格式」转换（两 checkpoint 路由 / 9 图取材策略 / 出稿机检 H1~H12），上游全流程、资产链、语气位、人物账、首镜锚定等照旧；**V6.9.7（2026-09-19）**：新增**首镜单主体锚定与具象化**（§5.0.2 续增单主体铁律 + §5.0.4 续增抽象形容删除纪律 + 法则 23 + 机检 **C20**——① **首镜锚定句只许一个具名主体**，**禁「X 与 Y 同框」类并列主体句式**（实测段1 镜1「首帧即这只手与她的脸同框」→ 出片**两张脸**，用户拉片："总共生成了两张脸，最大的祸首就是这儿"）；② **指代词必须带归属**（「这只手」无先行词 → 模型自补一个主体/一个头）；③ **抽象形态·程度副词一律删**（成线/成串/如注/轻蜷/微蜷——模型无法命名过程形态：「漏雨成线砸在手背上」→「雨滴砸在手背上溅开」，「手指轻蜷」→ 删）；④ **反光道具零光效描写**（C20d：光斑/受光/照射/照在/亮起类从句与「举到油灯旁」类动作一律不写——V6.9.5 的"光斑语言"实测仍出片**玉佩像打火机点了一簇火**，只写材质本色「玉面呈青玉原色」/「哑光金属本色」；旧建议「举到油灯旁侧受光」「光斑语言」已全部废止）；⑤ **道具动作与语气一致**（机检 **C16d**：把玩/摩挲类闲适动作只配慢悠悠语气，宣判/嘶吼/质问等强情绪语气必须换攥紧/捏住/垂手握着——实测段1 镜4 宣判台词配"直起身把玩玉佩"出戏，用户："他已经在俯视了，你还在那儿玩？"））；旧示范句已在 §5.0.4 标注废止）；**V6.9.6（2026-09-19）**：新增**禁止项栏目纪律**（§5.0.4 续增 + 法则 22 + 机检 **C19e**——**【强制禁止项】只装负面清单**（画面/文字/音频三类），**正向执行指令禁入该栏**（模型把该栏当"规避清单"读，写进去既不当禁令也不当指令——实测段1 该栏的「全片首帧即镜1的人物近景画面」「道具保持日常石质与金属质感」两条等同废纸），**否定式禁令同样禁入该栏**（被禁词根＝画面词，「玉佩/银镯不发光、不透光」写进禁止项也是废纸，段5/6/7/8/9/12 已全部改为镜行正向材质描写「哑光金属本色」）；正向指令一律回落【时间轴分镜】镜行/【画幅风格】/【站位声明】）；V6.9 基座 + 2026-09-18 定向修订：**〇节新增 D·段缝衔接方式三选一锁**（治"段落间衔接生硬"）/ **旁白·独白视听编织规程**（OS 声画分离红线·VO 配额）/ **时长守恒·禁拉伸凑满**（法则 17 修订：总时长由内容倒推，允许比剧本标注短至 -25%；C15 门）/ 出稿机检升 C1~C15，40 份规则库）；**V6.9.3（2026-09-19）**：新增**对白语气位规范**（官方对白三要素之三 HOW THEY SOUND——`台词：【角色（语气）："…"】` **2.0/2.5 同规格必写**；音色锁仅 2.5 且可选、不做资产体系；新增 `model-adapters.md` §5.2 + 机检 **C16**）；**同日续：人物账连续·摆位必入画**（§5.0.1 + 法则 20 + 机检 **C17**）；**V6.9.4（2026-09-19）**：新增**首镜锚定·景别一致·姿态延续·视线指派**（§5.0.2 + 法则 21 + 机检 **C18**——段首镜必带站位人物、特写不装全屋事件、撑起后禁无声躺回、举道具说话必须写明视线归属；病灶实测：「重生70」EP01 段1 出片空床无人/视线黏玉佩/清月躺回）；**V6.9.5（2026-09-19）**：新增**禁令失效三改法**（§5.0.4 + 法则 22 + 机检 **C19**——**视频模型对否定不敏感、对词根敏感**：被禁概念的词根（发光/笑/空镜）留在提示词里就会被当画面词渲染，实测三条否定式禁令两轮全部被无视；高关联视觉概念改写为「换词/主体优先句式/触发器移除」），出稿机检升至 **C1~C20**

## 🚀 快速开始（给 AI 助手）

1. 读取 `SKILL.md`，按“六步工作法”执行——**先完成 A 锁（模型版本 Seedance 2.5/2.0 强制二选一，或 MiniMax H3 格式支线）与 B 锁（画幅 16:9/9:16/21:9）才动笔，未指定不动笔**；
2. 先定**动作强度档**：`R1 写实克制` / `R2 商业高燃（默认）` / `R3 玄幻大招`；
3. 有对白 → 先过 `dialogue-speed-check` 语速自检；
4. 查 `model-adapters` 当前平台能力；
5. 直投公开平台 → 走 `platform-safety-compliance-guide` 安全默认档转译；
6. 交付前过 `quality-gate-review`。
