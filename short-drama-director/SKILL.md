## ★ 使用入口（先读这条 · 用户视角）

**用户只需要说一句话，剩下全自动。** 例如：

> 「帮我做一集短剧，题材是重生复仇，Seedance 2.5，竖屏」（国内剧）
> 「把这个小说改成 60 集剧本」（国内剧）
> 「这场打戏帮我出分镜和投喂稿」
> 「做一部海外剧，英语对白、背景在加拿大，Seedance 2.5、竖屏」（**海外剧 → 自动挂载 `sd-overseas-engine`，第一句对白前先建语言与风格合同**）
> 「**对标一下最近红果榜上那部《XXX》，我想做一部同类型的**」（**对标爆款 → 〇·1 定为 ③，先挂载 `sd-recon-engine` 出《对标情报卡》，再进剧本层**）
> 「**这场打戏人物老是站错位、前后对不上**」（**→ 调度环 `blocking-direction.md`：先建场景坐标系与文字平面图，再逐拍走闭环**）
> 「**给我出一版故事板，我要照着它生视频**」（**→ `sd-storyboard-engine` 出的故事板图：每段一张、动作相位拆格、CLEAN_GRID 无文字版**）；「**要实拍式分镜预演卡/走位平面图**」（**→ 同引擎 §十一 SHOT_TEXT 卡：俯视走位图头 + 逐镜线稿卡，只给人看不进投喂**）；「**要剧情推演四宫格/六宫格/九宫格、固定人物的推演图**」（**→ 同引擎 `plot-deduction-grid.md`：每场一张连续叙事宫格，身份锁/场景锁/风格锁**）

总控会按管线自动跑完：**赛道分流（〇·0）→ 素材来源（〇·1）→ 决策（情境锚点）→ 剧本 → 资产 → 调度（站位/权力几何/节拍）→ 分镜 + 故事板图（打戏自动判档）→ 投喂封装（过六道闸门）→ 质检 → 看板**，中途按需向你确认锁与关键节点，**一次对话交付成品**。

**⛔ 用户不需要知道、也不需要手动调用任何子技能。** 下列 12 个子技能（sd-decision-engine / sd-recon-engine / sd-script-engine / sd-overseas-engine / sd-asset-engine / sd-storyboard-engine / sd-combat-engine / sd-xuanhuan-engine / sd-real-engine / sd-feed-engine / sd-qc-engine）是**总控的内部专业分工**——拆开只是为了让每块领域规则独立、清晰、互不污染（也让"只要打戏模块"或"只要音乐模块"的人能单独拿走那个包）。**全流程用户：只说需求，其余交给总控。** 子技能既不会要求你手动切换，也不会额外增加操作步骤。

> ⚠️ **执行者必读（这是给 AI 助手看的，不是给用户看的）**：「用户不需要手动调用子技能」**不等于**「总控可以跳过子技能」。子技能里的**固定模板与执行序列是硬规则**——不读＝没有。每个阶段**必须按下节【强制读取清单】显式读取对应子技能文件**，再动手写产物。**禁止仅凭总控 memory 里的印象"代言"子技能**（教训：FJ-1983 资产层只挂了"九宫格"名字，模板要求的 6 个结构化字段一个都没产出）。

### 〇·0 · 赛道强制分流（第零道锁 · 先于 A/B/C/D）

- **用户必须明确选择：① 国内剧 / ② 海外剧 / ③ 解说叙事类 / ④ 其他（四选一）**；
- **未指定时，唯一正确动作是停下询问用户**——禁止以任何理由默认「国内剧」；
- **分流必须发生在剧本层之前**：赛道未确认，不进入 `sd-script-engine` 第 0 步模式选择、不生成任何 IP / 分集 / 正文；
- **各赛道读哪套规则**以 `references/track-routing.md`（★权威）为准——该文件含四赛道定义、判定信号、规则集映射表、剧本层分流点、**新赛道扩展四步法**；
- **② 海外剧**额外挂载子技能 **`sd-overseas-engine`**（L2 生产层）：第一句对白前建立【语言与风格合同】，三级校准状态（`region_unvalidated / evidence_calibrated / human_reviewed`）随版本逐阶段传递，**任何下游不得自行升级**；
- **赛道写入 P0A 基准表**，全流程不再更改；确需改赛道 = 重开任务，禁止中途换道沿用旧产物；
- **③ 解说叙事类**额外挂载子技能 **`sd-jieshuo-engine`**（L2 生产层）：先定**子类型**（历史人物志 / 历史事件战役 / 科普知识解说，三选一），脚本 = **旁白稿（VO Script）**；**解说类是全片 VO**——`vo-os-weaving.md` 的 VO 篇幅卡口**按赛道③ 豁免**，改用解说语速 `4.5~6.5 字/秒` + 声画信息差纪律；历史/科普题材**强制信源分级（T1/T2）**；
- **④ 其他**（广告片 / 宣传片 / PREVIS 等）复用现有全流程，不套剧集专属约定。

### 〇·1 · 素材来源锁定（第 1 道锁 · 与〇 · 0 赛道并列）

- **用户必须明确选择：① 原创 / ② 改编（有原著）/ ③ 对标爆款（现场采风）/ ④ 热点速成（给方向先找选题）（四选一）**；
- **未指定时，唯一正确动作是停下询问用户**——禁止默认按 ① 原创走；**尤其禁止把"用户随口提了一部剧名"直接当原创处理**（提到剧名 = 大概率想对标）；
- **与〇·0 正交可组合**：赛道管"做哪一类"，素材来源管"从哪起手"——「**海外剧 + 对标爆款**」是合法组合，**两锁互不覆盖、不得互相顶替**；
- **③④ 挂载子技能 `sd-recon-engine`**（L2 生产层 · 素材采风引擎）：在剧本层之前先出**《对标情报卡》**；采风四步（定目标 → 定信源 → 检索 → 落卡）、信源分级清单、十三项字段模板与六条证据纪律见 `sd-recon-engine/SKILL.md` 及其 references；
- **③ 对标爆款**：**必须先交付《对标情报卡》并经用户确认，再进 `sd-script-engine` 六阶段链**——**对标是提取结构，不是照抄**，情报卡的「⑩ 可迁移点 / ⑪ 不可迁移点」两栏是本环节的核心产出（只填热度不填迁移点 = 白采）；
- **④ 热点速成**：采风产出的是**"选题候选"而非单剧卡**——用户选定方向后再转 ① 或 ③ 执行；
- **①② 不挂载采风引擎**：原创与改编（有原著）直接从 `sd-script-engine` 进入，不额外增加步骤；
- **轻量版边界（不得自行扩张）**：本锁挂载的采风引擎**只做信源清单 + 情报卡 + 证据纪律**，**不做**评分打分 / 入选门槛 / 聚簇算法 / 热度公式 / 持久化台账 / 定时抓取——需要这些时如实告知用户"当前版本不含"；
- **素材来源写入 P0A 基准表**，全流程不再更改；**已采风的情报卡是"来源"，不是"设定依据"**——进入 `sd-script-engine` 的「① 来源登记」时必须**保留来源与分级（T1/T1.5/T2）**，**禁止把 T2 讨论当事实设定**。

### D · 段缝衔接方式四选一（多段任务与 A/B 同规格）

> **背景（粉丝实测反馈）**：AI 模型每段零记忆——上一段的站位/姿态/互动在下一段全部归零，段缝处必然跳切、动作断层（"段落间衔接生硬"的病根）。把段缝衔接升格为前置锁，四种方案可叠加，规程见 `segment-splicing.md`（★权威）+ ④ 类见 `creative-transition-library.md`（★权威）。

- **用户必须明确选择（多段任务）**；未指定时唯一正确动作是**停下询问，并严格按下方 ① / ② / ③ / ④ 四个独立选项原样弹出让用户勾选**——⛔ **严禁把 ① 和 ② 合并成「①+②」弹出、严禁漏掉第一项「① 末帧定格承接（尾帧锚定法）」**；**单段任务不涉及此锁，不询问**；**「多段任务」唯一判定式见本文件 §〇 首段（`目标成片时长 ÷ A 锁单段上限 > 1`）**——⛔ **禁止以「剧本还没写到分镜」为由把本锁推到后续阶段**（本锁属立项锁，与 A/B 同批弹出）；
- **① 末帧定格承接（尾帧锚定＋段缝画面锁 · 默认推荐 · 第一选项必弹）**：**画面依据按「尾帧锚定法」获取**——**段末镜末 1 秒整秒写「全体人物保持姿态与站位、动作完全静止、画面定格」（前置 0.5 秒为收束窗：镜头运动收束、人物停止大幅动作；末镜景别须装下全员、禁大远景，剪辑时裁掉末 1 秒静止帧），产出可截帧的定格尾帧 → 直接截取该末帧作下一段首帧/参考图依据（替代重新出图，一致性 100%、成本 0），下一段首镜以 0 级同档景别直接承接该末帧**；仅在末帧不合格（模糊/穿帮/带字幕/无人物/朝向不可用）时**回退**到"按结尾状态重新绘制段缝分镜参考图"（依据＝人眼看实际末帧）。平台差异：2.5 模式②截帧作 `first_frame`、模式①作参考图组成员；**2.0 无首尾帧——截帧作单参考图（每段 1 张，占 M 轴名额）**。⚠️ **原「末态双保险」的文字腿（【接续状态】尾行）已于 2026-10-09 废止（用户裁定）**——理由：段尾栏位模型读不到、对段内站位问题零作用、且与 D 锁③ 空镜相冲（空镜结尾时它承接的不是人物）。**本方案现为单锁（图锁）**；如某段确需给下段一句起手语义提示，写进**该段末镜行句尾**，不另起栏位。详见 `segment-splicing.md` §二 §三 §四·补；
- **② 换机位硬切**：不截末帧原位承接，段缝两侧**直接更换机位/视角硬切**（把两段做成两个不同镜头的剪辑关系）——最快、零出图成本，动作戏或多机位快切段缝可选；
- **③ 空镜过渡**：段缝处插 **1~2s 带戏剧任务的空镜**（情绪空镜+BGM 不搭人声 / 音效桥空镜声音先入 / 时空转场空镜，搭声不搭皆可），单集 ≤3 处——情绪段、转场段可选；
- **④ 技巧型转场（★ 2026-10-13 新增 · 用户追问）**：段缝处用一个**有设计感的创意转场**（**相似动作 / 形状匹配 / 前景遮挡 / 甩镜 / 闪白 / 画中画 / J-cut 声先画后** 等——文戏六式 + 大师技巧辑录见 `creative-transition-library.md`（★权威））。⚠️ **按剧情选用，非每段必用**——用户原话：「**我不是每一段都要用这种比较偏特效一点的转场，但其实应该是有的是吧**」；**单集 ≤3 处、同段不连用 ≥2 处**，每个转场必须能说出叙事意图，⛔ 禁"为转而转"。**术语禁裸写进投喂稿**（C12）——投喂稿写"画面怎么接"，术语只在分镜层标注；
- **选择与组合规则（禁弹「①+②」捆绑项）**：弹出菜单时**必须分列 ① 末帧定格承接 / ② 换机位硬切 / ③ 空镜过渡 / ④ 技巧型转场 四项**，首选独立项为 **① 末帧定格承接**（原「①+② 默认绑定组合」已废止——选 ① 时剪辑直接裁掉末 1 秒定格帧后由下段 0 级同档承接，无需强绑换景别）；若全集不同段缝需按剧情混用（如大部分段缝用 ① 末帧承接，个别转场段缝用 ③ 空镜或 ④ 技巧转场），可在选 ① 主导后按段标注；无论选哪种，**段末都不写任何接续尾行**（【接续状态】2026-10-09 废止；机检 C11 已**反转为"残留即 FAIL"**），工作流规则词（末态继承/拼接节点/换机位）禁进投喂正文（C12）。
- **⑦ 分段粒度（与段缝方式同层决定）**：定完接续方式后**必须同时定段长**——**Seedance 2.5 默认 25~30s 吃满上限**（下限 12s；**禁 16~24s 碎段区**，除非打戏快节奏或单段信息量确实小）、2.0 上限 15s、H3 4~15s。**段数越少、段缝越少、一致性越好**；不要因为「保险」把 30s 内容拆成两个 15s（多一个段缝 = 多一次跳切风险）。机检 **C1b** 兜底告警。

### E · 默认只出提示词，不直接出图 ＋ 素材形态 M0/M1/M2（最高优先级 · 用户确认铁律）

- **唯一例外**：用户**明确逐次下达出图口令**（如"出图""生成图片""跑图""把这张图出了"）才允许执行；且仍须遵循 `asset-first-pipeline.md` 门禁——建案清单先确认、分批出图逐批确认。
- **禁止**：禁止把"开始 P2 资产出图"/"开始跑图"当默认动作、禁止未经确认直接发 `image_generate`、禁止以为"用户要完整流程"就等于"用户要出图"。
- 用户在对话里追问"怎么还没出图" ≠ 出图授权；须明确说"出图吧/生成吧"才执行。
- 与 `short-drama-produce`（确认制生产 skill）协作时：出图执行一律走它的确认闸门，本 skill 不自行出图。

#### E.1 由 E 推出的必然结论：图不在本包手里（★权威 = `references/asset-delivery-modes.md`）

> **既然本包不出图，那么"图"这个实体就永远不在本包的上下文里。** 强行要求"图已锁定才准继续"，等于把流程卡死在一个本包无法完成的动作上。

- **素材形态三档（每次交付首行必须声明）**：
  - **M0 纯提示词**——不出现任何图号/参考图槽位；一致性靠**文字锁**（外观档案复述块等）。用户说"我没有图 / 不要图号 / 只要提示词"时使用。
  - **M1 编号占位（默认）**——出现 `图N` 槽位 + **必附《素材接线单》**（图号 → 用途 → "你该挂哪张" → 只控制什么/不控制什么）。**这是绝大多数用户的真实工作流**：拿提示词 → 去平台自己跑图 → 在平台把图挂上，**不需要把图交回本包**。
  - **M2 已入库**——用户**主动**交回图并登记《资产图册》，此时**才**能做图像级核验（门禁 5 原样）。
- **四铁律（不索要 · 不阻塞 · 不假装 · 要声明）**：
  1. **不索要**——禁止把"请把图发我 / 请上传素材"作为继续流程的条件；
  2. **不阻塞**——**禁止因"没有图"阻断 P3 分镜 / P4 投喂 / P5 质检**；门禁 2/3/4/5 按形态**改判**（改判表见权威文件 §二）；
  3. **不假装**——**禁止写不存在的图号当锚点**；**禁止声称"与《资产图册》一致""已核验"而实际从未见过图**（这是本类问题里最严重的一种：把"没检查"说成"检查过了"）；
  4. **要声明**——每次交付首行写明形态，并说明一致性靠什么保障。
- **形态切换规则**：默认 M1；用户说"没有图/不要图号"→ 降 M0；用户把图交回 → 升 M2。**禁止静默切换**（M0 稿里夹带图号、M1 稿里漏掉接线单，都属形态违约，机检告警）。

### F · Seedance 2.0 时长分配铁律（用户确认 · 与 E 同级）

- **2.0 单段时长上限 15s，不是 10s，更不是固定值**：段长完全按剧情内容量倒推（台词按 3.5~6 字/s、动作按节拍/信息量），**禁止把 10s 当默认时长、禁止全片统一卡 10s、禁止"段长÷镜数"机械等分**（配合法则 17 镜长节奏铁律）。
- 例：一段戏 7s 讲完就 7s 收，需要 14s 就 14s，15s 是上限不是目标值；只有用户明确指定"就 10s"才用 10s。

### G · 台词/音效默认视频内出（用户确认 · 与 E/F 同级）

- **台词与人声音效默认写入提示词、由视频模型在成片内生成**——台词走声音层锁口型与对白（2.5 用官方 `{}` 台词字符；2.0 以文字描述写入台词栏），**禁止默认"全走后期配音"**；
- **唯一例外 = 用户明确逐次指定「不出台词」/「台词走后期配音」**：此时台词不写入生成或标注后期合成（锁定口型节奏，后期配音）；
- **音效同理**：默认随视频生成（2.5 `<>`/`[SFX:]`；2.0 文字描述写"声音：…"），仅用户明确指定才走后期层；
- **禁止**：禁止把"全段音效/台词走后期配音层"作为默认写法预置进模板与交付物；旧口径"2.0 音效/台词均后期配音"以本条为准作废，不作 CURRENT 调用。

### H · 素材红线边界澄清：禁「真人照片素材」≠ 禁「写实/仿真人风格」（用户确认 · 与 E/F/G 同级）

- **官方红线只约束参考素材来源，不约束输出画风**：Seedance 2.5 / 2.0 **不支持上传含真人人脸的参考图/视频**——即**禁止把现实真人的照片 / 真人脸图**当参考素材投喂；这与画风无关。
- **写实 / 仿真人（次世代 3D / 实拍级质感）风格完全支持，不属红线**：本包「R1 写实克制」动作档、`audiovisual-aesthetic-presets.md` 的「东方诗意写实」预设、角色资产板标准画质词「次世代 3D / 实拍级全身模型拆解」、以及 Seedance 2.5 官方「成片接近实拍影视质感」均为正式支持用法；**严禁把红线解读为「只准二次元」而收紧写实需求**。
- **判定口径一句话**：看**素材来源**，不看**画风**——AI/CG 生成的写实仿真人（超写实渲染）= 可用；翻拍/下载的**现实真人照片** = 红线。
- **禁止误用**：禁止因「禁真人人脸」而拒写写实人物提示词、拒做仿真人风格分镜、或劝用户改二次元；写实需求照常出稿，只在**绑参考图**这一步守住「素材非现实真人照片」。
- 红线四条完整表述见 `references/model-adapters.md` §5（官方限制）；资产侧见 `references/asset-spatial-ledger.md` §二；投喂自查见 `references/prompt-feeding-checklist.md`。

### I · 画风锁（方案文档通称「F 锁」）—— 导演风格选项层 → 参数化交付层（★ 必弹卡锁 · 选定即冻结）

> **别称说明**：外部方案与讨论中的「F 锁」= 本锁。**锁性质（★ 2026-10-13 用户裁定升格）**：**必弹卡锁**——**动笔前必须推送候选卡、让用户在卡上勾选**；卡内**必须包含「按你的推荐走」一项**（用户不想挑时可主动选它，等价于授权用默认推荐卡），⛔ **但禁止在用户未表态时自行按默认推荐卡执行**（用户原话：「**这个还是没有给我选**」）；**选定后即冻结**，与 A/B/C/D 同规格（全流程只读、中途换风格 = 重开任务）。

- **它解决什么**：用户说「要徐克的感觉」，旧流程只能把人名/形容词塞进提示词——人名违反交付层纪律、形容词模型读不懂。I 锁把「选风格」变成**递进式选单 → 选定即转译成 11 槽位量化参数 → 植入段8/段9 → C23 机检兜底**的闭环；首轮徐克版 10 秒实拍已量化验证（画风层 5/5 项通过、动态范围 226/255）。
- **递进式选择（Step1 基底必确认 → Step2 技法族 3 选 → Step3 导演卡 ≤4 张 → Step4 可选辅助）**：每一步都在排除而非增加选项；排除链可追溯；同族 ≤2 张；打斗★/特效★ 为硬门槛。**候选源 = 74 组导演风格库**，题材路由 + 排除引擎可用 `scripts/style-lock-ladder.py`（递进式）与 `scripts/style-lock-recommend.py`（题材→候选池）辅助出卡，D 自定义 = 用户口述建 STYLE_BIBLE。

>
> **★ 元规则四（断言只能锁「唯一权威常量」，不得锁「字面数字/字面串」· 2026-10-14 新增）**：**把某个数字/口径写死进断言文案或断言条件，等于给这个数字上了锁——即使它是错的，也永远改不掉；而真值一旦变化，断言会反过来"证明"错值是对的。** 故：
>
> | 情形 | ❌ 反模式 | ✅ 正模式 |
> |---|---|---|
> | 计数类断言 | `check("SKILL 声明 N 份规则库", "N 份" in skill)` —— 把 N 写死 | `check("SKILL 声明 {EXPECTED_REFS} 份规则库", f"{EXPECTED_REFS} 份规则库" in skill)` —— 引用**同一个常量** |
> | 断言文案里的数字 | `check("C24 登记（NN 子码口径）", ...)` —— 文案数字过期无人知 | 文案数字**必须与当前值一致**，或改为不带数字的表述 |
> | 需禁止的旧值 | —— | 用**显式防回归**：`"<旧值>" not in skill`（把旧值列为禁项，而非依赖"新值存在"） |
>
> **实证（2026-10-14 深度质检）**：`SKILL.md` 同一文件内**规则库份数出现两个值**（一个过时顶层值、一个当前递归值，真值 = 48），而 `check_package.py` 共 **3 处断言把过时值写死**（L416 / L999 / L1412）——**断言在为错值背书**，导致改对反而 FAIL。同批复核另见 3 处过时子码文案（真值 68）。
> **判据（一句话）**：**这个断言里的数字，改了会不会导致别的提交失败？** 会 → 它是被写死的值，必须收口到一个常量或显式防回归项，**不得散落在断言文案里**。

## 三、 核心工业法则一览

0. **Asset-First 六阶段管线（最高原则）**：全流程严格按 `asset-first-pipeline.md`（★权威）执行 P0 立项锁定（**含素材形态初判 M0/M1/M2，默认 M1**）→ P1 剧本门控 → **P2 数字资产包**（提取全部实体 → 建档清单确认 → **按形态产出：M0 外观档案复述块 / M1 出图提示词+图号+《素材接线单》/ M2 分批出图锁定** → 交付对应台账）→ P3 空间调度+分镜 → P4 投喂生成 → P5 质检。**生产顺序不可跳步**；**"没有图"本身永不构成阻断理由**——门禁按素材形态改判，权威 = `asset-delivery-modes.md`。

1. **剧本五阶门控 (Gate 1~5)**：Premise $\rightarrow$ 30%/50%/20% 结构 $\rightarrow$ 因果节拍表 $\rightarrow$ 世界观与实体边界 $\rightarrow$ 专业剧本页。
2. **《剧组产出册》工业台账**：标准化输出角色（`CHR-`）、声音（`AUD-`）、道具（`PRP-`）、场景（`SCN-`）与分集单元（`U01~Uxx`）。
3. **12 节拍全片情绪张力曲线**：量化 12 个因果驱动节拍点（0~10 分），锁定第 9 节拍 9.5+ 终极爽点反杀。
4. **角色独立建档**：先建角色全集，再按复用、剧情功能和视觉连续性筛选资产候选；称谓归并必须有文本依据。角色视觉基准独立文生图，不做亲缘推导、不上传其他人物图作脸型参考。提取权威 = `references/character-extraction.md`；提示词用 `references/asset-spatial-ledger.md` 四字段模板。
5. **空间顶视图与机位调度 (2x2 网格)**：俯视平面绘制走位与 CAM1~CAM4，180° 轴线防护与合法越轴。
6. **台词七维体检与语速自检**：对白 3.5~6 字/秒（判定按最快档 6 字/秒），留出 0.3~0.8 秒落口发酵空间，强制语速门禁扫描。
7. **打戏 15 秒动力链 PREVIS（R1/R2/R3 三档）**：0~1.5s 开局硬撞，11 环动力链，防守三态，最后一帧定格。**R3 玄幻档切换法术语言**——法宝媒介+五行术法+术法攻防+能量具象化+对军清场（★权威在 `sd-xuanhuan-engine`；R1/R2/R3 定档表见 `sd-combat-engine/references/tier-and-finisher-system.md`），不硬套武侠物理打斗。
8. **时长预算前置协议**：3 分钟剧本按**模型契约**展开为若干独立可投喂单组（**组数与时长的算法见 `model-adapters.md` §5 模型契约表 + §〇.D.⑦ 分段粒度**——2.5 默认 25~30s 吃满上限、下限 12s、禁 16~24s 碎段区，故 180s 约 6~8 组；2.0 上限 15s，故约 12~15 组）。**⚠️ 本节不再写死"每组 ≤15s"**（该值仅适用 2.0）；长段必须用官方 `[起-止秒]` 时间戳分段且一镜连贯运镜过渡（模型不支持组内硬切，见 `model-adapters.md` §5）；中文提示词每组 ≤500 字、英文 ≤1000 词（官方字数门禁）。
9. **P0~P2 独立质检门禁**：阻断超时、跳轴与后台词外显；对白 ($0\text{ dB}$) $>$ 物理音效 ($-6\text{ dB}$) $>$ BGM ($-14\text{ dB}$)。
10. **画幅铁律（B 锁·用户指令优先）**：最终画幅比例一律以**用户指定为准**——用户说 16:9 必须全部走横屏模板并回填 `aspect_ratio=16:9`，严禁被示例/模板里的 `9:16` 或竖屏构图带偏；画幅三选一（16:9 / 9:16 / 21:9）与模型版本同属〇节前置锁定，**用户未指定 = 任务不开始，禁止默认 9:16**。生成视频提示词、导出工作流参数、API 载荷时均强制执行。**全流程画幅路由见 `references/aspect-ratio-adaptation.md`（★权威）**。**画幅一致性机检 C6b 兜底**（2026-10-10 六维审计并入）：`aspect_ratio=` 字段值 ↔【画幅风格】行声明 ↔ 任务锁 `--aspect` 三处互校，任一处不符即 FAIL；横竖构图词越界（16:9·21:9 稿写"垂直安全区/上下对峙"、9:16 稿写"左右对峙/横向位移"）→ WARN。
11. **素材形态与「唯一事实来源」按形态定义**：本包**不持有图**——图由用户在外部平台生成并持有。P3/P4 的权威依据按形态分别是：**M0 =《外观档案册》（文字档案）**、**M1 =《资产编号册 + 素材接线单》（编号 + 用途 + 外观要素）**、**M2 =《资产图册》（附资产参考图）**。**三种都算"有权威依据"**——"有依据"不等于"必须有图"。原「禁止以文字描述替代资产图」**仅适用于 M2**。**四铁律**：不索要图片 · 不因缺图阻塞 · 不写不存在的图号、不声称已核验而实际未核验 · 每次交付首行声明形态（权威 = `asset-delivery-modes.md`）。
12. **改动后复验铁律**：改稿禁止只复验改动处——必须按「① 局部验证（改动处自检）→ ② 联动冲突检查（伏笔/角色/信息量/因果节拍/资产/时长/画幅七项交叉扫描）→ ③ 全量审核（整片重跑 P0~P2）」三步闭环；修改交付文末必须附《改动复验报告》（改动清单+联动检查结论+全量审核结论），未附视为未完成复验、禁止交付（见 `references/quality-gate-review.md` §三）。
13. **表情 FACS 化（微表情管理）**：人物表情/微表情一律禁止写"开心/难过/邪魅"等空泛结果词，必须按 FACS 落成 AU 动作单元——「眉/眼/颧颊/嘴下颌」四区写全 + 〔痕/显/强〕强度三档 + "起—hold—落"时序（峰值对齐台词重音）；真笑必带 AU6、假笑只给 AU12、惊讶/恐惧靠有无 AU4 区分（见 `references/facs-micro-expression.md` ★权威；**FACS 为增强模块、按需触发**——简单文戏用正常影视表演语言〔仍禁"开心/难过/邪魅"类空泛结果词〕，仅特写/微表情/情绪关键拍/表情易崩镜头才展开 AU 配方与 cue 表）。**★ 形态强制项（2026-10-13 新增 · 粉丝实测）：影像基底为 3D CG / 半写实仿真人（`BASE_ANIME`）时，微表情不得只走"正常影视表演语言"兜底——3D 模型默认表情更容易"僵"和"通用"，须展开 AU 级四区拆解（起-hold-落 + 强度三档），把"通用脸"钉成"这一张脸"；真人（`BASE_LIVE`）/ 2D（`BASE_2D` / `BASE_INK`）仍按需触发。**
14. **投喂主格式七段式（不借用外部示范）**：视频投喂提示词固定为七段式，段序、站位声明写法、镜行原生格式的**唯一权威定义见 `model-adapters.md` §5**（**段末接续尾行已于 2026-10-09 废止**）；「七段式」为全包唯一命名（七段＝七个【】栏位，未因该废止增减），禁用"八段式/六栏/九栏"等别名。**外部示范格式只作语法参考**，其括号五要素连写、`（本镜唯一开口者）`、`跟随@谁`、末尾【参数契约】行、ASCII 空间图等变体一律禁用（完整禁写清单见 `references/model-adapters.md` §5.1）。**H3 支线例外**：A 锁选 MiniMax H3 时，投喂正文改用 H3 原生字段（三字段/六段式），七段式栏名一律不进正文，规程见 `references/h3-adapter.md`（★权威）。
15. **角色提示词模板纪律**：角色生图与验收只用 `asset-spatial-ledger.md` 原文四字段模板（画幅、排版结构、服装与身体材质、面部特写）；五官 10 项与服装 6 项写入对应描述。保留项目已锁定美术风格。比例尺、材质小样、HEX 色盘、人物履历、图上五官拆解、声纹图与音色标签不是必需交付项。其他资产或分镜仍按各自对应模板执行。
16. **按需触发分级（降无效加载不减能力）**：① 空间站位 S0~S4 分级——S0 单人（简版站位：位置+朝向+动作一行，免轴线免位移链）/ S1 双人静态（一行式站位+轴线）/ S2 多人静态（全员具名四要素+轴线）/ S3 多人移动（逐人位移因果链）/ S4 复杂战斗·多空间切换（才启用顶视图 CAM1~4 调度、合法越轴与 V3 备查），见 `asset-spatial-ledger.md` §三·5；② 资产依赖 A0~A3 分级——A0 纯文字/单镜/无一致性要求不强制资产链 / A1 单角色单镜资产可选 / A2 跨镜一致性启用相关资产 / A3 多人·多场景·连续剧集完整 Asset-First，见 `asset-first-pipeline.md` §〇·6；③ FACS 触发条件见法则 13。判定不清按高一级处理。
17. **镜长节奏铁律（禁止"为规整而规整"）**：镜长时间**必须由剧情倒推**，严禁机械等分——**正确顺序 = 剧情 → 情绪节拍 → 时长**（台词镜按 3.5~6 字/秒 字数倒推 + 情绪停顿；无台词镜按情绪节拍定长），**错误顺序 = 先定 `段长÷镜数` 再往里填内容**。全篇镜长必须**快慢呼吸交替**，覆盖 ≥3 个取值（如 {3,4,5}s），每单元节奏骨架不重复；**爆发/爆点镜快切、金句/高潮镜长镜留白**（最高张力点给足时间压住）。**「全片镜长雷同、无快慢节奏」是 `quality-gate-review.md` 明列的 P1 结构缺陷（自动修复项）**；完播率公式中「节奏呼吸」占 30% 权重（`camera-specs-15rules.md`），同节奏连续 ≤5 秒（`sd-combat-engine/references/tier-and-finisher-system.md` §一）。**出稿机检 C13 自动拦截**：同段 ≥4 镜且同值镜长占比 ≥70% 即告警（`scripts/validate_prompt.py`）。**判定要点：平滑来源于情绪，不来源于算术均分——「规整」本身是缺陷信号。** **总时长同样由内容倒推、禁拉伸凑满**：上游剧本标注的【本集时长】（如"180 秒"）只是**参考锚，不是必须铺满的硬指标**——分镜总时长 = 各镜内容量之和（台词÷3.5~6 字/s + 动作节拍 + 转场），允许比剧本标注**短至 -25%**；**内容不饱满时必须让总时长诚实地变短，严禁把氛围镜/过渡镜拉长凑满剧本标注时长**——一句 ≤40 字的 △ 动作行展开总时长 ≤6s、无台词氛围镜单镜 ≤5s、纯氛围段 ≤10s，把"暴雨 13 秒三连镜"式拉伸凑时视为**废稿级错误**（上游剧本注水是病根，下游拉伸是放大器——上游按弹性篇幅写饱满，下游按本法则诚实倒推）；同时**钩子前置**：剧本【黄金前3秒钩子】对应的台词/信息必须落在全片 00:00-00:05 首镜，剧本首行氛围 △ 镜压缩为 ≤4~5s 铺垫并与钩子台词同段，禁止把钩子挤到 13s 之后。机检 **C15** 自动拦截（无台词镜 >5s / 纯氛围段 >10s 告警，`scripts/validate_prompt.py`）。
18. **段缝衔接与画外声规程（尾帧锚定法 · 单锁）**：**段缝（上一段末镜→下一段首镜）按 D 锁选定方式衔接**——**段缝画面锁为唯一保险**（**尾帧锚定法**：段末末 1 秒整秒定格〔前置 0.5 秒运动收束窗〕→ 截取真实末帧作下段画面依据，替代重新出图；末帧不合格才回退重绘〔依据＝人眼看实际末帧〕；**下一段首镜 0 级同档景别直接承接该末帧**）/ 段缝两侧强制换机位（②）/ 1~2s 带任务空镜（③，单集 ≤3 处）；**段末不写任何接续尾行**（【接续状态】2026-10-09 废止，C11 反转为残留拦截）；工作流规则词禁进投喂正文（C12）。**画外声（OS 内心独白/VO 旁白）三纪律**：篇幅卡口（VO+OS 占声音容量 ≤30%，60~80 字/分钟）、OS 声画分离红线（独白发声画面角色必须闭口，禁用 `{}` 锁口型通道）、VO 冷漠审视法则（不复述画面）——OS/VO 一律走"声音："段，台词字段只装画内开口对白（C14 机检兜底）。分别见 `segment-splicing.md` / `vo-os-weaving.md`（★权威）。

19. **对白三要素·语气位必写（2.0/2.5 同规格）**：官方对白规范三要素 = **WHO SPEAKS + WHAT THEY SAY + HOW THEY SOUND**，本包此前只落了前两项（"谁在说""说了什么"）。台词统一写 **`台词：【角色（语气）："…"】`**——语气紧贴角色名、写在冒号前的括号内（与画外声 `（OS·音色）` 同构），**不新增字段、不新增段**，七段式段数不变。四条铁律：① **声音词只进语气位，禁写进画面段**——写进画面段会被模型当视觉信息渲染（画出一张冷笑的脸），实测高发（机检 C16a）；② 语气按**四维**写（情绪色 / 力度 / 音质 / 节奏），每句 ≤3 词、允许演进 `（压抑→破防）`，**禁空泛结果词**（开心/难过/愤怒，C16c）；③ 语气是**文本层**信息，**2.0 与 2.5 同样必写**（C16b 缺失率告警）——**2.0 不支持音色锁，不等于可以不写语气**；④ **音色锁仅 2.5 且为可选增强**（投 `reference_audio` 素材并在【核心人物】行尾标注，用途须写"锁定音色"）——**不做资产体系、不设前置门禁**，有素材就锁、没有就写文字音色描述。**声音层（语气位 / `声音：` 段 / 【音效】）豁免反形容词规则**（声音没有肌肉动作可写，官方范例即 `warm, low voice`），但同样禁空泛结果词。**⑤ 道具动作与语气一致**——闲适把玩类动作（把玩/摩挲/拨弄）只配慢悠悠/玩味语气；语气位是宣判/一字一顿/嘶吼/咆哮/质问等强情绪时，必须换成**攥紧/捏住/垂手握着**（实测病灶：段1 镜4 宣判台词配"直起身把玩玉佩"，用户："他已经在俯视了，你还在那儿玩？"）。规程见 `model-adapters.md` §5.2（★权威）+ §5.0.3 道具动作条，出稿机检 C16（a 声音词错位 / b 缺失率 / c 空泛词 / d 道具动作与语气冲突）兜底。

20. **人物账连续·摆位必入画（跨段防穿帮）**：模型每段零记忆——**上一段画面里的人，这一段凭空消失、下一段又出现，是最典型的跨段穿帮**。六条铁律：① **摆位必入画**：【站位声明】摆了位的每个人，本段镜行**至少带到一次**（正拍/焦外身影/全景群像/反应镜头均算），实在给不了镜头就在站位括号里写明 `段末离画 / 退场·去向`（机检 C17）；② **入画要交代**：写明离场的人重新入画时，站位必须写 `段初自门口入画` 等方式；②b **新面孔首现要交代（★ 2026-10-13 新增 · 用户实测反馈）**——**相邻两段在场人物集合不同**时（如上一段只有两人对峙、下一段全家围桌谈判），**后段新增的具名人物必须有①画内入画 / ②画外先声 / ③空镜转场 / ④上段末镜行句尾一句过渡之一**；`（在场）`静默人物可走软口径（首镜一句「已在场 · 已坐定」）。**不补这条 = 观众读作"跳了一段"**（用户原话：「段一到段二没有任何逻辑的过渡，**它得有一个过渡吧**」；机检 **C17e** 兜底）；②c **过渡是剧本层的戏点，不是分镜层的补丁（★ 2026-10-13 新增 · 用户实测反馈）**——**过渡必须承载新信息**（加人物状态 / 加情绪 / 加空间），⛔ **默认禁止用「随后 / 接着 / 转眼」这类时间副词硬接**；四种过渡类型按"加戏量"排序：**① 动作桥**（某人的一个动作带过去，如「送外卖的哒哒哒跑进来」——一句话不说就把"他迟到/他不情愿"立住）/ **② 空镜叙事**（承载情绪的空镜，如「灵堂扫一下」——遗像+白花+没撤的供桌压住全场）/ **③ 声音桥**（新场声音先于画面，如「门外由远及近的脚步声」）/ ④ 硬接（需写明理由）。**过渡的落点必须指定挂在前场末尾还是后场开头（不得两处都不写）**——这正是段1→段2 断层的直接成因。规程见 `sd-script-engine/references/episode-planning.md` §TRANSITION_AS_BEAT；**剧本层造过渡、分镜层落过渡，颠倒分工 = 本末倒置**；③ **站位不漂移**：相邻段之间没写移动的人，位置/朝向/依托物不得无交代改变（上一段"秀兰身后半步"，下一段不能凭空变"八仙桌旁"；**跨段站位漂移机检 C17d 兜底**——同名人物在相邻两段【站位声明】的位置或背景锚点变化、且该人未在后段【位移】行写明移动即告警）；④ **（在场）标记口径**：【核心人物】行无标记=本段有台词或明确动作反应，`（在场）`=画面可见但无台词无反应——两级的人都必须进站位声明，禁自创其他标记；⑤ **对话戏节奏与台词密度（★ 2026-10-13 新增 · 用户实测反馈）**——**对话段**切镜点须按「**回合**」切（一次切镜至少换 说话人 / 景别 / 角度 / 主体 之一；⛔「只为这句说完了而切、其余变量全不变」= 废切），**同一说话人不得连续 ≥2 镜独占开口**；**对话段台词密度 ≥2.0 字·秒⁻¹（15s ≥30 字）、开口 ≥6 次/15s**；**空镜段 / 转场段 / 打斗段不设下限**（可为 0，⛔ 别硬塞台词）。补台词只走四条正路（OS 补位 / 短句化拆解 / 加对方回嘴 / —），⛔ 禁靠拉长文采凑字。规程见 `sd-storyboard-engine/references/shot-economy-and-acting.md` §五·七 + `references/dialogue-speed-check.md` §一·补三（机检 **C27b/c/d** 兜底）。规程汇总见 `model-adapters.md` §5.0.1 **+ `segment-splicing.md` §四·补二「段缝人物进出场律」**，出稿机检 **C17（a 摆位必入画 / b 长对白关系镜缺失 / c 背景锚点缺失 / d 跨段站位漂移 / e 人数变化未交代 / f 单一方位权威〔镜行禁重复段首画面左右，2026-10-15〕）** 兜底（单人站位段不触发，且**逐段自查**——多段稿的每一段都跑一遍，防"B 在下一镜不见了"）。

20·★ **一切节奏类规则服务剧情，不是模板（★ 2026-10-13 用户申明 · 本条为法则 20 / 法则 21 及全部节奏类判据的适用前提）**：**用户原话**——「**你灵活一点，不要说我说啥就把它完全定死了，这个东西它本身是服务着剧情走的**」；「我**也不知道你为了切而切**，像有一些剧情就**不适合这种来回的切**，**灵活懂吗？是服务剧情的**」。**具体要求**：① **下面这些是"常见毛病别犯"的默认倾向，不是每段必套的模板**——回合制切镜 / 开口密度（15s ≥6 次）/ 台词密度下限（对话段 2.0 字·秒⁻¹）/ 动静随剧情自然调配（已废除「15s运镜≤2」死名额：静态对话/展示可定住，情绪推进/走位可自由缓慢运镜）/ 长镜默认拆分 / 站桩三秒铁律。② **剧情该慢的段落（静场对峙 / 宣判 / 留白 / 独白 / 长镜压迫 / 情绪积累 / 回忆）不适用上述指标**——须在段落里**显式标注段落意图**（如「本段为静场宣判段」），机检 C27 会据此跳过；这类戏**靠沉默、静止与时序连续更有力，切碎了反而毁掉**。③ **空镜带先声是合法且常用的手法**（公园空镜传来人声 → 切到两人对话），**"空镜段不设下限"意为"不强制、不考核"，不是"禁止写台词"**。④ **判准永远只有一个：这段剧情需要什么节奏**——「为切而切」与「该切不切」是**同一种病**。⑤ ⛔ **禁止把本条的"灵活"读成"可以拍呆"**——用户同时批的是「站桩式对话、过渡少、呆板」，故**默认倾向该用的地方必须用**；只有在**剧情确有理由**时才走例外，且**必须写明理由/段落意图**（不写理由的例外 = 违规）。
21. **首镜锚定·景别一致·姿态延续·视线指派（单段防废镜）**：四条铁律（病灶全部来自「重生70」EP01 段1 实拍废镜）：① **首镜人物锚**——每段第 1 镜必须让站位人物至少一人入画（人名或注明归属的身体局部，如「林清月枯瘦的手」），空镜开场须镜行首写明「空镜：…」且每段至多 1 镜；首镜无锚，模型渲染出空场景（实测出『只有一张床』，机检 C18a）；② **景别三一致**——特写/紧特写只承载单一局部主体，空间级事件（暴雨砸漏房顶/全屋火起）由中景以上承载，禁「特写+顶拍+全屋事件」混装（机检 C18d）；③ **姿态延续**——撑起/坐起/起身等变化一旦发生，同段后续镜必须显式「保持撑坐/已坐起」或焦外交代，倒下要写明跌回/瘫倒过程，禁无声回退（机检 C18b）；④ **视线指派（★ 2026-10-12 扩写 · 多人同镜硬项）**——说话镜必须写明视线对象「目光落在 XX 脸上」，手持/把玩道具说话必须补「视线不落在道具上」（举向光源的道具最抢视线，模型默认让角色盯着道具看，机检 C18c）；**★ 单镜 ≥2 人时，【站位声明】内每个具名人物都必须写「视线落点：看向 @某人 / 看向某物」**——**身体朝向 ≠ 视线方向**，只写「正面朝左 / 侧身三十度朝右 / 背对摄影机」等于把眼神交给模型自由发挥，三人以上同镜必然串行（用户实测：段2 三弟应看向大哥、二姐应看向母亲，两处视线全部跑偏；用户原话「三个人以上基本上就是乱了」）。规程见 `model-adapters.md` §5.0.2，出稿机检 C18 兜底（**含 C18f 景别与表演幅度越界、C18g~l 运镜机检门——逐镜必标运镜 / 一镜多主运镜 / 无动机运镜 FAIL / 固定镜 >10% 或连排 ≥3 / 运镜单调 / 重技法名额超限**，规则权威 `sd-storyboard-engine/references/short-drama-camera-system.md` §四）。**拉片反馈增补（§5.0.3）**：道具光效双保险（反光道具镜行写正向材质描写，机检 **C18e**）/ 表情锚（冷硬台词必显式写具体面部肌肉动作，模型对年轻女性默认甜笑）/ 外观锚（核心人物行写年龄锚、特写复述「同一张脸」，防换脸）/ 跨镜在场与方位减负（非主体人物镜行内锚依托物/背景物即可，**严禁重复段首已声明的画面左右**——双重发位是用户实测「东一个西一个、突然出现在身后」的病根，2026-10-15 单一方位权威；段末镜再带到）/ 禁模型自加镜头。

22. **禁令失效三改法 + 栏目纪律**：**视频模型对否定不敏感、对词根敏感**——「禁空镜」里的空镜、「不发光」里的发光、「面无笑意」里的笑，被禁概念的词根本身留在提示词里（哪怕挂着"不/禁"），就会被当画面词渲染（实测三条否定式禁令两轮全部被无视：空房间开场、玉佩全片自发光、宣判词配露齿甜笑）。高关联视觉概念（光效/表情/开场镜头）必须三改：① **换词**——被禁词根在提示词**任何位置**（含强制禁止项）零出现，改写正向描述（道具→「深青色实心哑光石质，玉面呈青玉原色」，**零光效描写**，见 C20d；表情→「双唇抿紧、嘴角向下压、下颌绷紧」；首帧→「画面主体：<人名>…」单主体开头）；② **主体优先句式**——每段镜1第一个分句即画面主体（人名/身体局部/「画面主体：」/人称），环境前置词开头会诱导空场景开场；③ **触发器移除**——诱发被禁效果的动作/构图换掉（道具不与灯火共现：只把玩/佩戴，不靠近任何光源——旧建议「举到油灯旁侧受光」已废止，实测同样点火）。**栏目纪律**：【强制禁止项】被模型当"规避清单"读，**只装负面清单**（画面：变形/手部异常/服装变化/现代元素/字幕/Logo/水印；文字；音频）——**正向执行指令禁入该栏**（写进去既不当禁令也不当指令，实测段1 该栏的「全片首帧即镜1的人物近景画面」「道具保持日常石质与金属质感」两条等同废纸），**否定式禁令同样禁入该栏**（被禁词根＝画面词，「玉佩不发光不透光」写进禁止项也是废纸）；正向指令一律回落【时间轴分镜】镜行/【画幅风格】/【站位声明】。水印/变形等**低关联瑕疵**仍走否定式兜底，两类不冲突。**具象光源映射（C19d）**：反光道具镜行禁写「映出/倒映火苗」——模型不理解「反射」，会把「映出+光源名词」读成光源出现在道具上；**零光效描写**，只写材质本色（「玉面呈青玉原色」）——旧建议"光斑语言"已废止（光斑句出片玉佩像打火机点了一簇火，见 C20d）。**镜行少形容词**：正向描写每镜只留必要项（主体/动作/材质/光各一处），修饰词堆叠会稀释关键信息、拉低服从率。规程见 `model-adapters.md` §5.0.4，出稿机检 **C19**（**C19a** 裸禁令词 / **C19b** 光路触发器 / **C19c** 首镜主体优先 / **C19d** 具象光源映射 / **C19e** 禁止项栏目纪律）兜底。

23. **首镜单主体锚定与具象化（防"两张脸"）**：三条铁律（病灶来自「重生70」EP01 段1 镜1 实拍拉片，用户原话："总共生成了两张脸，最大的祸首就是这儿"）：① **锚定句只许一个具名主体**——**禁「X 与 Y 同框」类并列主体句式**：模型把并列名词 +「同框」读成"画面里有两个主体"，于是把同一主体的手与脸渲染成**两个头**（❌「首帧即这只手与她的脸同框」→ ✅「画面主体：林清月蜷卧土炕、病容苍白。她的一只手搭在破被外」）；确需两个人物同镜，由【站位声明】具名双主体承载，**镜行内不写「同框 / 同在画面 / 一同入画」**（机检 C20a）；② **指代词必须带归属**——「这只手 / 那张脸」无先行词时模型会**自己补一个主体**（补出一个头），一律写「她的一只手 / 他的右手」（机检 C20b）；③ **抽象形态·程度副词一律删**——「成线 / 成串 / 如注 / 轻蜷 / 微蜷」描述的是**模型无法命名的过程形态**，AI 只渲染可命名的具象形态（❌「漏雨成线砸在手背上」+「手指轻蜷」→ ✅「雨滴砸在手背上溅开」）。**判据一句话：这句里每个词都能画出来吗？画不出来的就是形容词——删掉或换具象动作。** ④ **反光道具零光效描写**——光斑/受光/照射/照在/亮起类从句一律不写，道具不靠近灯火（实测「指甲盖大暖黄光斑」「举到油灯旁」出片**玉佩像打火机点了一簇火**），只写材质本色（「玉面呈青玉原色」/「哑光金属本色」）。规程见 `model-adapters.md` §5.0.2 / §5.0.3 / §5.0.4，出稿机检 **C20**（**C20a** 并列主体 / **C20b** 悬空指代 / **C20c** 抽象形态 / **C20d** 道具光效·贴近光源）兜底。

| **P2 · 语义风险** | 空间 / 遮挡 / 轴线 / 动作物理 / 视线 / 情绪 | **必须由 AI/人工复核后放行**——`validate_prompt.py` 已声明这部分"仍由语义推演"，**机器不判死**；不以机检 FAIL 阻断交付，但**必须留下复核记录** |

> **一句话**：「FAIL 清零才交付」**只适用于 P0**；P2 是"必须复核"，不是"必须为零"。

### 套装共享契约（子技能已内置）

1. 锁系统（A 模型三选一 / B 画幅 / C 交付 / D 段缝）**只在总控〇节定义**，子技能引用不重复；
2. 七段式投喂格式唯一权威 = 总控 `model-adapters.md` §5；H3 六段式 = 总控 `h3-adapter.md`；子技能禁止另立格式；
3. 资产编号「图N」、《资产图册》《剧组产出册》台账口径统一走总控；**禁用外部包英文编号前缀（CH/SC/PR/ST/NP 等）**；
4. 出稿机检 `validate_prompt.py`（C1~C26＋增量主码 C27a~d 对话戏节奏 / C28a~c 台词机械化 / C29 资产状态偏离 / C30a~d 外挂指纹探针 / `--model h3` → H1~H12 / `--track 1|2|3|4` 赛道分流 / `--plugin` 外挂探针）位于总控 `scripts/`，FAIL 清零才交付；**赛道③ 必须带 `--track 3`**（改判 C14n），否则 C14 篇幅误报；
5. 时间轴整数秒口径；Seedance 2.5 / 2.0 语法彻底分开禁混写；
6. **决策层输出（情绪锚点表）** 是分镜层输入依据，其 80% 核心组合为锁死项；
7. **投喂层六道闸门**（节奏/台词时长/字数/可投喂语义/图片数量/编号一致性）是投喂前人工前置，机检是自动后置兜底。
8. **台词承接**：分镜层（`sd-storyboard-engine`）默认**全量承接**上游台词，若需精简必须出「台词精简建议清单」并经用户确认；投喂层（`sd-feed-engine`）须跑台词完整性对照，缺失即回退——**任一层都不得静默删台词**。
9. **赛道分流**：〇·0 赛道由用户锁定，**规则集映射权威在总控 `references/track-routing.md`**；② 海外剧的语言校准状态（`region_unvalidated / evidence_calibrated / human_reviewed`）**随版本逐阶段传递，任何下游阶段不得自行升级**；**跨赛道约定禁搬运**（国内付费节点/卡点不得当海外剧硬要求，海外的"场数不设下限"不得用来省掉国内多集项目的分场要求）。
10. **素材来源**：〇·1 素材来源由用户锁定，**采集规程权威在 `sd-recon-engine/`**；**③④ 的《对标情报卡》是"来源"不是"设定依据"**——进入 `sd-script-engine`「① 来源登记」时**必须保留来源与分级（T1/T1.5/T2）**；**任何下游阶段不得把 T2 讨论升格为事实、不得把卡中「推断」升格为「事实」、不得把同一稿的转载算成多个独立来源**；**轻量版边界（信源清单 + 情报卡 + 证据纪律）不得由任何阶段自行扩张**——打分/门槛/聚簇/台账/定时抓取均不在本版内，需要时如实告知用户"当前版本不含"。
11. **场面调度与站位**：**站位分两层，别再混谈**——① **导演决策层**（怎么站、权力怎么用空间说、何时切镜）唯一权威 = 总控 `references/blocking-direction.md`；② **投喂执行层**（怎么写成提示词）唯一权威 = `asset-spatial-ledger.md` §三 + `model-adapters.md` §5.0。**图写在导演稿里，字写在投喂词里**：导演稿允许**文字平面图**，投喂词**仍禁任何形式的图**（ASCII 草图 / 坐标表 / 俯视图 / 初始图+位移因果链）。**下游一律只读继承调度，不得另起一套站位逻辑**。
12. **故事板图**：**"故事板图"≠"九宫格场景图"≠"HTML 分镜看板"≠"15 格动作 PREVIS"≠"SHOT_TEXT 分镜线稿卡"**——五者互不替代（对照表见 `sd-storyboard-engine/references/storyboard-sheet-template.md` §〇 §11.1）。故事板图**每段一张**，格数由动作复杂度决定（**禁机械凑九宫格**）；**版式默认：文戏 2×2 四宫格 ≥4 格 / 打戏 2×3 六宫格 ≥6 格**；出口帧 = 下段入口帧；**必出 `CLEAN_GRID` 无文字版供生图**；**面板边界 ≠ 剪辑点**，不得用多画一格暗示未授权的切镜；**逐格必须落进投喂镜行，一格不落**。**SHOT_TEXT 卡（§十一）是给人看的预演件**：俯视走位图头 + 逐镜线稿卡，台词/时码逐字同源，**不进投喂、不入册、不占素材槽**。
13. **素材形态**：**本包不持有图**——图由用户在外部平台生成并持有。素材形态三档：**M0 纯提示词 / M1 编号占位（默认）/ M2 已入库**，**每次交付首行必须声明**。**四铁律**：不索要图片 · 不因缺图阻塞任何阶段 · 不写不存在的图号、不声称已核验而实际未核验 · 每次声明形态。**门禁 1~5 按形态改判**（改判表见 `references/asset-delivery-modes.md` §二）；**门禁 6（改动后复验）不受形态影响**。**权威 = `references/asset-delivery-modes.md`**；「图N」编号与外观要素归 `asset-spatial-ledger.md`；投喂槽位写法归 `sd-feed-engine/references/asset-mapping-and-rules.md`。**A0~A3（A 轴）与本域（M 轴）正交，M 轴按用户实际条件判定，不取最高档。**
14. **解说叙事**：**赛道③ 解说叙事类**的规则集权威在 **`sd-jieshuo-engine/`**（旁白稿 VO Script / 历史视觉 / 爆款公式三份 references）。**与 sd-script-engine 是叠加关系**（脚本 = 旁白稿，六阶段链照走）；**解说类是全片 VO**——`vo-os-weaving.md` 的 VO 篇幅卡口**按赛道③ 豁免**（改用解说语速 + 声画信息差纪律），**豁免口径的唯一权威在 `sd-jieshuo-engine`**，`validate_prompt.py` 须按赛道分流（C14 对赛道③ 不告警）；**禁把解说类的全片 VO 口径回写污染剧情赛道**。
15. **外挂参考资料**：`references/dialect-voice-control-dictionary.md`（全国 50 套方言 AI 配音控制词典）是**外挂资料、非规则域**——**不进「唯一权威归属表」、不设前置门禁、不参与机检**，只在给台词加地区方言听感时按需查表；方言听感作为**语气四维中「音质」维**叠加，不新增字段/段。

### 极速直出模式的套装编排

> **前置：两档运行模式（先分清，再执行——治"严格锁 vs 极速直出"的口径冲突）**
>
> | 模式 | 触发 | 〇·0 赛道 | 〇·1 素材来源 | A 模型 | B 画幅 | C 交付 | D 段缝 |
> |---|---|---|---|---|---|---|---|
> | **严格模式**（默认） | 普通需求 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | **必须用户指定**，未指定 = 停下询问 | 多段任务必问 |
> | **极速模式** | 用户说 `跳过确认，直接出整集` | 允许按需求**软推断**（交付首行写明推断结果） | 允许按需求**软推断**（交付首行写明推断结果） | **仍必须用户指定／确认——不推断、不默认** | **仍必须用户指定／确认——不推断、不默认** | **仍必须用户指定／确认——不推断、不默认** | 多段任务必问 |
>
> **为什么只有赛道与素材来源可软推断**：这两项只决定"读哪套规则、从哪起手"，推错可回退；而 **A 模型 / B 画幅是决定下游产物格式的技术锁**（提示词语法、参考图能力、API `aspect_ratio` 回填），推错 = 整包产物作废；**C·交付形态决定最终交付件**（离线看板 / md / 两者 —— ★ 2026-10-13 已由「可默认 ③」升格为强制锁）——替用户猜 = 可能白编译一份他并不需要的看板，**故极速模式也不得替用户猜**。若需求里确无 A/B/C 信息，**极速模式仍须停下来问**——"跳过确认"只跳过过程确认，**不跳过锁**。
