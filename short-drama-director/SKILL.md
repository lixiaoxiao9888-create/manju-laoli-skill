## 〇、 任务前置强制锁定：A·模型版本 / B·画幅 / C·交付形态（最高优先级 · 每个任务第一步）

> **每个任务动笔前必须先完成 A、B 两道创作锁。任一项用户未指定 = 任务不开始，禁止默认跳过。C·交付形态未指定时默认「③ 两者都交付」，不阻塞创作（见下）。**

### A · 模型版本强制二选一
- 用户必须明确选择：**Seedance 2.5** 或 **Seedance 2.0**；
- 未指定时，唯一正确动作是**停下询问用户**，禁止以任何理由默认选版；
- 锁定后全流程（提示词语法 / 投喂封装 / 参考图 / 音效 / 首尾帧）一律按该版本契约执行，两版语法彻底分开，禁止混写；
- **锁定 2.5 时追加一步「任务模式二选一」（2026-09-15 新增）**：① **全能参考模式**（默认推荐）——投喂参考图组（角色 4 View / 场景母板，上限 30 张）锁定形象，短剧/漫剧一致性生产的标准路线，支持 B 锁画幅；② **首尾帧模式**——仅投 `first_frame`+`last_frame` 双图精准锁定动作起止（与参考图**互斥**、不可混用，画幅随首尾帧自适应）。未表态时按默认①执行并告知；选②时提醒首尾帧需按 B 锁画幅比例出图。用户不想要首尾帧就完全不涉及它。

### 2.5 vs 2.0 硬差异对照表

| 维度 | Seedance 2.5 | Seedance 2.0 |
|---|---|---|
| 原生能力 | 官方原生音效/台词字符 + Hit-Stop 顿挫 + 首尾帧 | 无原生音效标记、无顿挫感支持 |
| 单段时长 | 15s 单段高动态直出 | 10s 单段直出无压力（长叙事可多轮延长） |
| 运镜语法 | 可写复杂连续运镜与转场 | 每镜一条简单运镜，禁一镜多转折 |
| 打击感写法 | 允许 Hit-Stop 三件套（微停顿+火花+震颤声） | 禁顿挫词，打击感靠接触瞬间画面本身 |
| 蓄力 | 可写压缩收束蓄力 | 边打边蓄，禁静止蓄力段 |
| 参考图 | 两种模式二选一：**全能参考**（参考图组锁形象·默认）或**首尾帧**（Start/End Frame，与参考图互斥） | 无首尾帧，参考图仅锁定形象 |
| 文戏 | 微表情+金句发酵可用 | 简化表演指令，逐拍分解须极简 |
| 出片哲学 | 单段完整成片 | 单段直出为主，可自行决定是否拆段快剪 |

### 投喂封装差异
- **2.5**：声音标记走官方字符（音效 `<>`、台词 `{}`、音乐 `()`、字幕 `【】`；社区兼容 `[SFX: ...]` 亦可）+ Hit-Stop 写法；首尾帧**仅限任务模式②**（默认全能参考模式不涉及，见〇节 A）；
- **2.0**：无 `[SFX:]`、无顿挫词、音效走后期配音（末尾参数行已废止——模型/画幅/时长由【画幅风格】行与 A/B 锁承载）。

### B · 画幅强制三选一（与 A 同规格铁律）
- 用户必须明确选择：**16:9 横屏** 或 **9:16 竖屏** 或 **21:9 宽幕**（官方另支持 1:1，仅用户明确指定时采用）；
- 未指定时，唯一正确动作是**停下询问用户**，禁止以任何理由默认跳画幅（旧版"未指定默认 9:16"规则自 V6.7 轻量版起废止）；
- 锁定后全流程（资产构图 / 分镜机位 / 提示词模板 / API `aspect_ratio` 回填 / 质检）一律按该画幅版本执行，禁止混用、禁止被示例或模板带偏；画幅细则路由见 `references/aspect-ratio-adaptation.md`（★权威）。

### C · 交付形态三选一（A/B 锁定后顺带确认；未指定默认 ③，不阻塞创作）
- **① 只要离线看板**：项目 md 照常创作（它是看板的唯一编译源，不写 md 就没有看板），但最终**只交付看板 HTML**，md 留作工作底稿；
- **② 只要 markdown 文档**：交付 md，不编译看板；
- **③ 两者都交付（默认）**：md + 编译好的单文件离线看板。
- **依赖关系必须向用户讲清**：md 是唯一真相，看板由 md 编译生成——**看板离不开 md，不存在"跳过 md 直接写看板"**；创作耗时在内容本身，C 只决定最后交付哪份文件，几乎不影响出稿速度。
- 交互口径：与 A、B 同一句话问清（"模型版本？画幅？要看板、要 md、还是都要？"），用户未答 C 不追问，按 ③ 执行并在交付时说明一句即可。

> **A、B 两锁齐备才动笔**：A·模型版本 与 B·画幅 全部锁死，才允许进入 P1 之后的任何环节；C·交付形态可后置（默认 ③）。详见 `references/model-adapters.md` 〇节。

## 二、 核心特性：多平台 Agent 与多模型深度兼容

### 1. 多 Agent 运行平台适配
- **WorkBuddy 适配**：支持 P0 立项锁定 → P1 剧本门控 → **P2 数字资产包（资产图先于分镜）** → P3 空间调度 → P4 投喂 → P5 质检六阶段会话流转，自动挂载《剧组_资产图册.md》与 2x2 顶视图；
- **豆包智能体 / 扣子 (Coze) 适配**：支持输出结构化 JSON 块，自动分块（Chunking）防止对话上下文截断；
- **OpenClaw 适配**：原生 CLI 部署与 Tool-Call 完整兼容；
- **Dify / 通用大模型适配**：支持单文件 Prompt 独立运行模式。

### 2. 闭源视频模型适配（主推 Seedance 2.5 / 2.0 · 强制二选一）
- **版本前置锁定**：每个任务第一步先与用户二选一锁定 Seedance 2.5 或 2.0（见「〇、模型版本强制锁定」），两版语法/契约彻底分开，未指定不动笔；
- **Seedance 2.5**：单次生成官方上限 **30 秒**（`duration=4~30`）并支持多轮延长（本包仍推荐每组 ≤15s 质量实践）；全模态参考上限 50 个（30 图+10 视频+10 音频，素材必须标注用途）；双图首尾帧（与参考图互斥）；Hit-Stop 物理碰撞顿挫感；声音标记官方字符（音效 `<>`、台词 `{}`、音乐 `()`、字幕 `【】`）；480p~4K、24~60fps；**不支持真人人脸参考图**（官方红线）；
- **Seedance 2.0**：单段直出（10s 无任何问题）；支持单参考图绑定、5s~15s 提示词解耦与运镜控制参数映射；无 `[SFX:]`、无顿挫词、音效走后期配音（末尾参数行已废止）；
- **即梦（次选 / 历史兼容）**：支持单参考图绑定、5s~15s 提示词解耦与运镜控制参数映射；**不参与 A 锁强制二选一**，仅用户明确点名时按 `model-adapters.md` §二 特性行执行；
- 🗄️ **LEGACY·可灵**：自 V6.8 起不再作为本包正式支持模型（历史版本曾支持，相关契约已移除）。

## 三、 核心工业法则一览

0. **Asset-First 六阶段管线（最高原则）**：全流程严格按 `asset-first-pipeline.md`（★权威）执行 P0 立项锁定 → P1 剧本门控 → **P2 数字资产包**（提取全部实体 → 资产清单确认 → 角色/场景/道具分批出图锁定 → 交付《资产图册》）→ P3 空间调度+分镜 → P4 投喂生成 → P5 质检。**资产图先于分镜，无图不进分镜**（P2/P3 硬门禁）。

1. **剧本五阶门控 (Gate 1~5)**：Premise $\rightarrow$ 30%/50%/20% 结构 $\rightarrow$ 因果节拍表 $\rightarrow$ 世界观与实体边界 $\rightarrow$ 专业剧本页。
2. **《剧组产出册》工业台账**：标准化输出角色（`CHR-`）、声音（`AUD-`）、道具（`PRP-`）、场景（`SCN-`）与分集单元（`U01~Uxx`）。
3. **12 节拍全片情绪张力曲线**：量化 12 个因果驱动节拍点（0~10 分），锁定第 9 节拍 9.5+ 终极爽点反杀。
4. **角色资产板与亲缘推导**：A/B 级 16 项锁，T1（男女主）至 T2（亲属配角）40%~60% 骨相与五官关联遗传推导。
5. **空间顶视图与机位调度 (2x2 网格)**：俯视平面绘制走位与 CAM1~CAM4，180° 轴线防护与合法越轴。
6. **台词七维体检与语速自检**：对白 3.5~5 字/秒，留出 0.3~0.8 秒落口发酵空间，强制语速门禁扫描。
7. **打戏 15 秒动力链 PREVIS（R1/R2/R3 三档）**：0~1.5s 开局硬撞，11 环动力链，防守三态，最后一帧定格。**R3 玄幻档切换法术语言**——法宝媒介+五行术法+术法攻防+能量具象化+对军清场（见 `xuanhuan-magic-combat.md` ★权威），不硬套武侠物理打斗。
8. **时长预算前置协议**：3 分钟剧本强制展开为 14~15 组（每组 $\le 15$ 秒，单组独立可投喂生成）。Seedance 2.5 官方单段上限 30s 且支持多轮延长——本包仍按 ≤15s/组执行（质量实践）；15s 以上长段必须用官方 `[起-止秒]` 时间戳分段且一镜连贯运镜过渡（模型不支持组内硬切，见 `model-adapters.md` §5）；中文提示词每组 ≤500 字、英文 ≤1000 词（官方字数门禁）。
9. **P0~P2 独立质检门禁**：阻断超时、跳轴与后台词外显；对白 ($0\text{ dB}$) $>$ 物理音效 ($-6\text{ dB}$) $>$ BGM ($-14\text{ dB}$)。
10. **画幅铁律（B 锁·用户指令优先）**：最终画幅比例一律以**用户指定为准**——用户说 16:9 必须全部走横屏模板并回填 `aspect_ratio=16:9`，严禁被示例/模板里的 `9:16` 或竖屏构图带偏；画幅三选一（16:9 / 9:16 / 21:9）与模型版本同属〇节前置锁定，**用户未指定 = 任务不开始，禁止默认 9:16**。生成视频提示词、导出工作流参数、API 载荷时均强制执行。**全流程画幅路由见 `references/aspect-ratio-adaptation.md`（★权威）**。
11. **资产图册唯一事实来源**：《剧组资产图册》（CHR/SCN/PRP 全附资产参考图）是 P3/P4 的唯一权威事实来源；分镜/投喂引用的 `@锚点` 必须指向已锁定资产图，禁止以文字描述替代资产图。
12. **改动后复验铁律**：改稿禁止只复验改动处——必须按「① 局部验证（改动处自检）→ ② 联动冲突检查（伏笔/角色/信息量/因果节拍/资产/时长/画幅七项交叉扫描）→ ③ 全量审核（整片重跑 P0~P2）」三步闭环；修改交付文末必须附《改动复验报告》（改动清单+联动检查结论+全量审核结论），未附视为未完成复验、禁止交付（见 `references/quality-gate-review.md` §三）。
13. **表情 FACS 化（微表情管理）**：人物表情/微表情一律禁止写"开心/难过/邪魅"等空泛结果词，必须按 FACS 落成 AU 动作单元——「眉/眼/颧颊/嘴下颌」四区写全 + 〔痕/显/强〕强度三档 + "起—hold—落"时序（峰值对齐台词重音）；真笑必带 AU6、假笑只给 AU12、惊讶/恐惧靠有无 AU4 区分（见 `references/★ facs-micro-expression.md` ★权威；**FACS 为增强模块、按需触发**——简单文戏用正常影视表演语言〔仍禁"开心/难过/邪魅"类空泛结果词〕，仅特写/微表情/情绪关键拍/表情易崩镜头才展开 AU 配方与 cue 表）。
14. **投喂主格式七段式（不借用外部示范）**：视频投喂提示词固定为七段式，段序、站位声明写法、接续状态尾行、镜行原生格式的**唯一权威定义见 `model-adapters.md` §5**；「七段式」为全包唯一命名，禁用"八段式/六栏/九栏"等别名（V6.8 统一）。**外部示范格式只作语法参考**，其括号五要素连写、`（本镜唯一开口者）`、`跟随@谁`、末尾【参数契约】行、ASCII 空间图等变体一律禁用（完整禁写清单见 `references/model-adapters.md` §5.1）。
15. **交付满额铁律（不许漏执行项目）**：契约要求的字段/模板段落必须逐条写满才算完成——角色出图必须走**4 View 资产板（头部近景/面部特写 + 无头正面/90°侧面/背面三联全身）+ 五官 10 项 + 服装材质 6 项**，战斗场景必须用**战斗角色站位版**（占位/轴线/禁入画/空中高位预留），分镜必须逐镜带到场名单 + 站位声明 + 行内声音台词 + 接续状态。**示例与演示产物同样按满血标准写**，禁止两三条简笔交差；交付前自查缺项。
16. **按需触发分级（V6.8·降无效加载不减能力）**：① 空间站位 S0~S4 分级——S0 单人（简版站位：位置+朝向+动作一行，免轴线免位移链）/ S1 双人静态（一行式站位+轴线）/ S2 多人静态（全员具名四要素+轴线）/ S3 多人移动（逐人位移因果链）/ S4 复杂战斗·多空间切换（才启用顶视图 CAM1~4 调度、合法越轴与 V3 备查），见 `asset-spatial-ledger.md` §三·5；② 资产依赖 A0~A3 分级——A0 纯文字/单镜/无一致性要求不强制资产链 / A1 单角色单镜资产可选 / A2 跨镜一致性启用相关资产 / A3 多人·多场景·连续剧集完整 Asset-First，见 `asset-first-pipeline.md` §〇·6；③ FACS 触发条件见法则 13。判定不清按高一级处理。
