## 一、 物理硬约束与时长预算协议

1. **单单元时长约束**：每个独立生成单元严格控制在 **4 ~ 15 秒**（单镜 3~5 秒，一组 3~4 镜）；⚠️ 官方上限：Seedance 2.5 单次可生成 **4~30s** 并支持多轮延长——本包仍推荐每组 ≤15s（质量实践：节奏更可控、废片成本更低）；若用 15s 以上长段，必须用官方 `[起-止秒]` 时间戳分段且一镜连贯运镜过渡（`model-adapters.md` §5）。
2. **时长前置预算公式**：
   $$\text{目标视觉单元组数} = \frac{\text{预估成片总时长（秒）}}{12\sim 15 \text{ 秒 / 单元}}$$
   * 3 分钟（180 秒）成片必须拆解为 **14~15 组** 独立提示词，严禁场景 1:1 机械压缩！
3. **单组即成品交付**：每组自带时间轴（从 `00:00` 开始）、画幅风格、资产短锚点、分镜详情与负面词，用户可直接整组复制投喂。

## 二、 三层信息解耦框架 (3-Layer Decoupling)

* **Layer 1 全局不变量**：画幅比例（16:9 横屏 / 9:16 竖屏）、模型版本（`Seedance 2.5` / `Seedance 2.0` 强制二选一；即梦次选，不参与锁定）、美术渲染风格、色调基调、核心角色/场景资产短锚点。
* **Layer 2 空间与镜头变量**：秒级时间轴（官方原生 `[起-止秒]` 分段，见 `model-adapters.md` §5）、镜头规格五要素、主体物理发劲动作、接触点受力（Hit-Stop 顿挫感）、台词与声音标记（官方字符：音效 `<>`、台词 `{}`、音乐 `()`、字幕 `【】`；社区兼容写法 `[SFX: ...]` 仍可被识别）。
  * **Hit-Stop 三件套（打击硬度必写）**：兵刃/肢体相碰瞬间 = ①1~2 帧微停顿（打破平滑插值，杜绝“滑步/空气假打”）+ ②接触点微观火花迸射（枪尖红宝石与剑刃相交处火星）+ ③双刃咬死高频震颤声（Metallic Screech）。三件缺一，打击感发飘。
* **Layer 3 分层负面排除**：画面防崩 + 题材专项排除 + 镜头动态排除。

> ⚠️ **组内过渡铁律（官方限制）**：模型**一镜生成、不支持硬剪辑切换镜头**——一组内的 3~4 镜必须写成连续运镜衔接（推/拉/摇/移/穿透/遮挡过渡），真硬切必须拆成多段独立生成、后期剪辑拼接。

## 二·五、 微步进时间轴切片四要素公式（长段高动态专用）

> ⚠️ **画幅铁律（B 锁·高于一切模板）**：最终画幅以**用户指令为准**。画幅强制三选一——16:9 / 9:16 / 21:9（1:1 仅明确指定时采用），用户未指定 = 停下询问，**禁止默认 9:16**。用户指定 16:9 → 一律走横屏模板，禁套竖屏模板、禁示例里的 `aspect_ratio=9:16`；用户指定 9:16 → 走竖屏模板。**每条提示词/每个 API 参数都必须回填用户指定的画幅，禁止默认回落。**
>
> 📐 **全流程横/竖屏构图路由、时间轴模板选择、API 参数回填 → 以 `aspect-ratio-adaptation.md`（★权威）为准**。

单段 15s（或 30s 连续打斗）内若动作密度高，为避免模型“动作抽搐、四肢变形、换脸漂移”，时间轴描述强制采用 **0.5s~1.0s 微步进切片**，每片四要素齐全：

$$\text{切片} = [\text{时间区间}]: [\text{运镜机位动词}] + [\text{主体力学动作}] + [\text{双色对冲粒子特效}] + [\text{环境物理介质破坏与受力反馈}]$$

### 1. 常用切片动词表
* **运镜动词**：极微距锁焦、无人机超广角暴力快推、贴身平行极速横移、碰撞点微环绕、低角度仰跟上摆、360° 环绕急推（≤180°）、垂直拉升至鸟瞰。
* **力学动作动词**：轻推刀镡、反手拔刀出鞘、正面突破音障冲刺、机枪高频对攻、滑步下潜、侧蹬反关节格开、拔地暴起凌空反切。
* **粒子特效**：赤红流光拖尾、幽蓝燃烧烈焰、缠绕黑烟、自发光火星微观纤维、空气激波环形扩散。
* **环境受力**：成排竹木拦腰震断、碎石浮空、地面犁开深沟、漫天枯叶卷成海啸漩涡、雨水受高温汽化。

### 2. 微步进示例（居合拔刀斩 5s）
```text
0s-1.0s [极微距锁焦] 角色A指尖抵住刀镡轻推，剑身震颤低鸣，狂风掀起衣袂发丝，漫天飞叶扑向镜头。
1.0s-2.0s [超广角暴力快推] 角色A反手拔剑拖出红色流光，角色B化作蓝焰黑烟正面冲刺，突破音障带出空气激波。
2.0s-3.0s [碰撞点半环绕] 双剑正面相撞火星四溅，红雾与蓝焰对冲爆燃，冲击波横扫压弯两侧竹林。
3.0s-4.0s [贴身平行横移] 密集机枪拆招对攻，剑气撕裂成排竹竿，竹屑碎片飞溅，碎石浮空。
4.0s-5.0s [正面命中定格→鸟瞰遮挡] 终极对斩白光爆燃，命中瞬间 1~2 帧微停顿（Hit-Stop），镜头极速拉升至鸟瞰，漫天竹叶席卷遮挡镜头收尾。
```
> 定格仅限命中瞬间 1~2 帧微停顿（Hit-Stop）；禁“角色静止站立/悬停蓄力/对峙”类静止段（总纲铁律，2026-09-02）。
> 适用：长段连续打斗 / 高密度动作 / 大招释放段。普通文戏或简单对招无需微步进，按标准 15s 四镜分镜即可。

### 3. 双实体色彩与材质锚定（混战防混淆·必写）
> 双人/多人对峙打斗，严禁只给双方各一个颜色。必须为**每一方建立一整套锚定**（粒子色 + 材质 + 光效 + 轨迹），双方高反差互补；远全对撞时观众靠这套锚定分清谁是谁。

$$	ext{锚定} = \text{角色}：\text{粒子色/光效} + \text{护甲材质} + \text{招式的轨迹形态}$$

* **锚定必须成体系**：每个角色 = 主色 + 材质 + 专属特效轨迹，整套贯穿全程；
* **双方互补对冲**：冷色系 vs 暖色系、光系 vs 暗系，在极速混战与远景对撞中保证视线清晰，杜绝画面混杂与面孔混淆；
* **对照模板**（学自 35s 玄幻秒级拆解）：
  * 黑发剑客 → 冷银剑气 / 水墨黑白 / 玄青轻甲 / 月牙弧光与霜刃拖尾（纯粹剑道·极速穿透）；
  * 白发神将 → 金红烈火 / 熔岩重铠 / 阴阳双龙 / 战戟犁地火线（神魔伟力·重击霸体）；
  * 双方对冲：金红熔岩流火拖尾 vs 银白冷冽霜刃拖尾，左右分流。
* **能量贴附物理载体（能量禁悬浮·2026-09-04 吸收）**：一切能量特效必须**贴附在物理载体上**——刀刃、手臂、服装边缘、运动轨迹、骨甲、法器内部结构，禁止无附着物的悬浮光团/光雾；
  * **频率分层**：高频短电弧（贴附刃缘/指尖，细密噼啪）vs 低频脉冲（贯注臂膀/躯干，缓慢鼓胀），两类叠加出能量"活性"；
  * 示例写法：`青金电弧沿刀刃螺旋缠绕（高频短弧），臂膀经络间金色脉冲缓缓鼓胀（低频灌注）`。

### 4. 常用音效词库（SFX 可投喂清单）
> 音效标记：官方原生写法用 `<>` 包裹（如 `<Sub-bass Drop 沉闷低频超重音脉冲>`，台词 `{}`、音乐 `()`），社区兼容写法 `[SFX: ...]` 亦可被识别；音效叠在时间轴对应秒段，必须具体，禁空泛“震撼音效”。以下词来自已验证样例，可直接投喂：

|---|---|
| 神魔觉醒/蓄能 | Sub-bass Drop 沉闷低频超重音脉冲 + 高频电流滋滋声 |
| 拔剑/擦剑 | Sword Ring 清脆冷兵器擦鸣 + 节奏鼓点进场 |
| 破空斩击 | Air-cut Whoosh 重型风刃破空呼啸 |
| 音障突破/硬撞 | Sonic Boom 音障爆炸 + 金属交击爆鸣 |
| 兵刃死锁 | Metallic Screech 双刃咬死高频震颤 |
| 连击攻防 | Metal Clashes 密集金属连续碰撞 + 战气爆裂 |
| 冲击波/震退 | Shockwave Blast 重磅气浪爆破 |
| 万剑齐发 | Supersonic Barrage 密集机枪破空尖啸 + Sword Swarm Hum 万剑蜂鸣共振 |

> ⚠️ 台词（人声对白）永远走声音层单独生成/合成，不写进画面提示词当口型；官方写法台词用 `{}`、音效用 `<>`；音效可留 `[SFX:]`（社区兼容）。

### 5. 声音事件时间线（音效排布规范·2026-09-04 吸收）
- 音效不按"氛围堆砌"，按**事件排时间线序列**——每个动作事件对应一个音效事件，先后成链：`拔剑鸣（0.5s）→ 破空呼啸（1.2s）→ 交击爆鸣（2.0s）→ 冲击波爆破（2.5s）`；
- **空间纵深音**：远层事件用低频闷响+混响，近层事件用高频脆响+干声，靠声场层次强化画面纵深；
- **死寂转余响收尾**：绝杀命中后先留 0.3~0.5s 死寂（抽掉全部音层），再放环境余响（碎石滚落/风声/耳鸣），比全程轰鸣更有打击重量；
- ⚠️ 本节仅适用于 Seedance 2.5（`[SFX:]` 原生标记）；Seedance 2.0 音效全部后期配音，提示词内不写任何音效标记。
