## 一、 完播率黄金公式与核心铁律

$$\text{完播率} = \text{开局冲击 (20%)} \times \text{节奏呼吸 (30%)} \times \text{运镜丰富度 (25%)} \times \text{情绪拐点 (25%)}$$

### 1. 核心铁律
* **铁律 1（无铺垫法则）**：15 秒打戏前 1.5 秒内必须发生攻防接触，开局 0.5 秒内出现冲突最烈点（两招硬撞 + 微定格）。第一帧必须是双人同框中近景，禁止全景风景慢铺垫。
* **铁律 2（近景对招法则）**：15 秒内必须有至少 1 段（2~3 秒）上半身近景对招。必须用**招式序列化机枪节奏**（逐击写清招式名、落点与防守反馈，包含拳/掌/肘/指/膝变化，且必须含肘击），禁止抽象频率参数。
* **铁律 3（防守三态法则）**：防守被破必须经历 `完整态 (桩架稳固) -> 崩防线 (双臂被震开) -> 狼狈过渡态 (0.3~1s 闪避拍打)`。
* **铁律 4（闪避大幅化法则）**：闪避严禁小幅平移，必须是下潜贴地、铁板桥大后仰 $\ge 45^\circ$、侧身空翻或大步滑移等大幅动作。
* **铁律 5（高潮收尾法则）**：15 秒最后一帧直接延伸至终结技命中最炸裂瞬间（冲击波/骨碎/碎石/嵌墙），不设 0.5 秒平静收尾帧。
* **铁律 6（多人混战独立攻击逻辑法则）**：多人战斗（≥3 人）严禁站桩挨打/排队单挑，也不可让多人围一攻击目标同时出招。**每个作战单位必须有独立攻击逻辑 + 主动位移**：
  * 每个角色写清自己的目标、招式与位移轨迹（A 攻击 B 同时 C 从侧翼插入或绕后）；
  * 画面内任何人都不允许原地不动等接招，挨打方也必须写反击/闪避/位移；
  * 配合双实体色彩锚定（`seedance-render-engine.md` §二·五）区分参战方，避免模型把多人搅成一团；
  * 适合单人/多人混战通用。
* **铁律 7（1v1 穿梭感法则·防站桩）**：1v1 打斗模型默认坏习惯是“两人原地出招”即站桩式打斗。**严禁只写“穿梭交击/对打”等抽象动势**，必须写清**具体位移路径**：
  * **交叉换位**：两人从两侧对冲、擦肩而过、交换位置（如“银白流光自左向右、黑红流光自右向左，画面中央交叉换位”）；
  * **每个镜头必须有位移动词**：冲锋 / 追击 / 后撤 / 翻越 / 升空 / 下坠 / 绕背，禁止两人同框原地挥武器；
  * **运镜跟随路径**：镜头跟随角色完整移动路径（穿过画面），不只跟随角色本体；
  * **垂直穿梭**：地面冲锋 + 蹬地升空 + 空中错身 + 下坠砸地，天上地下反复拉锯；
  * 示例：`两人迎面冲刺，在画面中央交叉换位、擦肩而过，随即回身对撞`。
* **铁律 8（对撞反震两段式法则，2026-09-04 吸收）**：正面硬撞后**严禁原地停留**——必须写「接触爆发 → 双向反震分离 + 多层贯穿破坏」（接触点爆闪、地面放射状龟裂、后方介质被贯穿撕开），且撞出后必须立刻接新动作，禁止两人在撞击点僵持。
* **铁律 9（能量在介质内部交击法则，2026-09-04 吸收）**：弃剑/弃兵 → 双掌扣刃 → 能量灌入兵刃**内部**与对方能量交击 → 兵刃锯齿龟裂——能量走介质内部交击，比表面对波力量密度更高，禁两人隔空对波。
* **铁律 10（错位交叉首碰法则，2026-09-04 吸收）**：首碰禁普通正面对撞，改为**刀锋擦过护甲**并带属性弧光爆闪——首碰即错位交叉，破坏正面对撞的呆板对称。
* **铁律 11（怪物环境支点位移 + 单场战斗节拍弧法则，2026-09-04 吸收）**：
  * 巨型/怪物单位必须借环境支点变向：墙面蹬踏、梁柱借力、桥底潜行偷袭——禁止怪物只会直线冲锋；
  * 单场战斗按节拍弧推进：接敌 → 试探 → 大招 → 败退 → 潜行偷袭 → 反杀 → 追击，禁止从头到尾同一强度平推。

## 二、 镜头规格五要素与画幅空间铁律

### 1. 镜头规格五要素（每次必写）
格式：`[景别] · [拍摄视角+角度] · [运镜方式] · [跟随目标]`
* **景别**：全景 / 中景 / 中近景 / 近景 / 特写
* **视角**：正面(0°) / 侧面(90°) / 斜角(30°-60°) / 俯视 / 仰视
* **运镜**：跟拍跟镜 / 环绕(≤180°) / 急速推镜 / 急速拉镜 / 升降 / 慢动作跟镜 / 定格定镜 / 甩镜闪切
* **跟随目标**：跟随角色、肢体或具体接触点

### 2. 16:9 横屏与 9:16 竖屏双画幅构图法则
* **16:9 横屏电影级构图（默认与大银幕标配）**：
  * 充分利用横向画幅展开**中长焦空间纵深与环境压迫**；
  * 双人对峙采用三分线左右站位，攻防推进利用对角线动势；
  * **空间感铁律**：中景及以上（看到两人完整身形）**严禁 90° 侧面正拍**（格斗游戏扁平感），必须采用 **30°~60° 斜角拍摄** 营造前后空间纵深。
* **9:16 竖屏构图**：强调垂直高度落差，腾空下劈、贴地滑行与冲镜特写。

## 三、 动作动力链 11 环与空气动力反馈

1. **11 环动力链**：意图锁定 $\rightarrow$ 起手抱桩 $\rightarrow$ 重心沉移 $\rightarrow$ 后足蹬地 $\rightarrow$ 腰胯转拧 $\rightarrow$ 脊柱如大弓 $\rightarrow$ 肢体传导 $\rightarrow$ 毫米级接触点 $\rightarrow$ 骨肉受力形变 $\rightarrow$ 收招惯性 $\rightarrow$ 下一击继承。
2. **空气反馈四层级**：
   * 路径反馈：拳风切开空气微弱扭曲，腿风如鞭横扫割出可见弧线；
   * 命中气爆：轻击微气爆（空气波纹荡开），重击明气爆（环形气浪炸裂碎石弹起），终极击冲击波；
   * 速度证据：快速留半透明残影，瞬速形成锥形音爆气穴。
