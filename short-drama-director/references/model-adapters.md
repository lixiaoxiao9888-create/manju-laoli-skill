# 闭源视频模型适配层规范 (Seedance 2.5 / 2.0 主推 · 即梦次选)

本规范详细定义了闭源主流云端视频模型（**Seedance 2.5 主推**、Seedance 2.0，即梦 2.0/3.0 为次选/历史兼容）的提示词语法、参考图绑定、时长规则与平台特性适配契约。**强制二选一只在 Seedance 2.5 与 2.0 之间进行；即梦仅用户明确点名时按 §二 特性行执行，不参与前置锁定。**

---

## 〇、 任务前置强制锁定：A·模型版本 / B·画幅 / C·交付形态（最高优先级 · 与 SKILL.md 〇节联动）

> **每个任务动笔前必须完成 A（2.5 / 2.0 二选一）与 B（画幅三选一）两道创作锁。任一项用户未指定 = 任务不开始，禁止默认跳过。C·交付形态未指定时默认 ③（两者都交付），不阻塞创作。**

### A · 模型版本强制二选一
- 用户未指定模型版本 = 任务不开始，禁止默认跳版本；锁定后按下方对照表分语法执行。

### B · 画幅强制三选一
- 用户必须明确选择：**16:9 横屏 / 9:16 竖屏 / 21:9 宽幕**（官方另支持 1:1，仅明确指定时采用）；未指定 = 停下询问，禁止默认 9:16；
- 每条提示词 / 每个时间轴分镜 / 每个 API 载荷的 `aspect_ratio` 都回填锁定值；画幅构图细则路由见 `aspect-ratio-adaptation.md`（★权威）。

### C · 交付形态三选一（未指定默认 ③，不阻塞创作）
- **① 只要离线看板**：项目 md 照常创作（唯一编译源），最终只交付看板 HTML；**② 只要 markdown 文档**：不编译看板；**③ 两者都交付（默认）**：md + 单文件离线看板；
- 依赖关系：md 是唯一真相、看板由 md 编译生成，**看板离不开 md，不存在"跳过 md 直接写看板"**；C 只决定交付哪份文件，几乎不影响出稿速度——与 A、B 同一句话问清即可，未答不追问。

### 1. 2.5 vs 2.0 投喂法则对照表

| 语法项 | Seedance 2.5 | Seedance 2.0 |
|---|---|---|

| 台词 | 台词走声音层，不写进口型 | 同左；音效与台词均后期配音 |

## 一、 Seedance 2.5 专属适配与核心特性

### 1. Seedance 2.5 升级特性（2026-09-14 按火山方舟官方文档校准）
- **长叙事与时长**：单次生成时长提升至 **30 秒**（API `duration=4~30`），支持**多轮延长**；⚠️ 本包时长预算仍推荐每组 ≤15s（质量实践），超 15s 单段必须用官方 `[起-止秒]` 时间戳分段且一镜连贯运镜过渡（见 §5）；
- **全模态参考**：单次参考素材上限 **50 个**（30 图 + 10 视频 + 10 音频），支持**纯音频参考生视频**（无需图/视频）；每份素材必须标注用途（锁定外貌/动作/音色/运镜），禁只丢图不说明；
- **原生多语言**：中/英/西/印尼/葡/日/马来/泰/阿/越/韩共 11 种；非中文台词须在台词前明确语言；
- **画面质感**：成片接近实拍影视质感；微表情生理递进（0.3s 眼神颤抖、咬牙、瞳孔缩放）连续性提升，单段零变形动作；
- **物理碰撞（Hit-Stop 顿挫感）**：硬核招式打击瞬间的接触面形变、阻尼停顿与反作用力弹开，杜绝"滑步"与"空气假打"；
- **精准编辑**：提供基于时间戳的精准编辑控制；
- **输出规格**：MP4 / MOV（H.264 + PCM，色彩保真更高）；480p / 720p / 1080p / **4K**；帧率 24~60fps；单文件 ≤200MB；
- **首尾帧**：支持同时输入起始帧（Start Frame）、结束帧（End Frame）与角色 4 View 资产板，精准锁定动作起止态；⚠️ **首/尾帧与参考图为互斥任务类型**（官方限制：首尾帧模式画幅仅 `adaptive` 自适应；`last_frame` 不可单独使用，必须配 `first_frame`）。
  > 📌 来源核验（2026-09-15，多平台官方接口文档交叉确认：Vercel AI Gateway / Runware / reAPI / hiapi / Segmind）：`first_frame`/`last_frame` 为 2.5 官方素材角色；首尾帧与参考图互斥、adaptive 画幅、last 需配 first、时长 4~30s、参考图上限 30 张均与官方一致。

### 1.5 参考模式二选一（**仅锁定 2.5 后必答** · 2026-09-15 新增）

> ⚠️ **仅 2.5**。**Seedance 2.0 / 即梦无首尾帧**（禁止投喂 `first_frame`/`last_frame`），只有模式①（单参考图绑定）。

2.5 的参考素材走**两条互斥路线**，A 锁锁定 2.5 后必须让用户二选一，未表态默认①并告知：

| | ① 全能参考模式（默认推荐） | ② 首尾帧模式 |
|---|---|---|
| 投喂素材 | 参考图组（角色 4 View / 场景资产图组〔母版+机位调度版或站位版+拼接图〕/ 道具，上限 30 张，逐张标注用途） | 仅 `first_frame` + `last_frame` 双图（成对，缺一不可） |
| 画幅 | 遵循 B 锁（16:9 / 9:16 / 21:9） | `adaptive` 自适应——**首尾帧图必须按 B 键画幅比例出图**，否则成片画幅跑偏 |
| 适配场景 | 短剧/漫剧一致性生产（多角色跨镜、场景锚定）＝本包主流程 | 精确转场、动作起止态锁定（如招式收势定格、场景无缝过渡） |
| 与本包流程关系 | 完整走 P0~P5（资产→分镜→投喂） | 资产链照常（首尾帧图本身按分镜另行出图，见 §4 首帧约束），但 P4 投喂封装改为双帧模式 |
| 禁止 | — | 与参考图混用（官方互斥）；拿参考图直接当首帧 |

选②时 P4 投喂词仍为七段式，【画幅风格】行尾追加 `mode=first_last_frame` 声明；【核心人物】改为「首帧＝…起手态，尾帧＝…收势态」的画面描述。用户明确说"不用首尾帧"即完全走①，流程中不得再出现首尾帧相关写法。

### 3. 逐实体参考图锁定公式（多参考图场景）
- 多参考图（角色+服装+场景混投）时，必须**逐实体**写绑定关系，公式=「严格保持 X，只改变 Y」；
- 示例：`严格保持 @CHR-A 的脸型与发型（参考图1），只改变服装为战损态玄青轻甲（参考图2）`——每个实体单独一句，禁止笼统写"参考以上图片"。

### 4. 首帧约束（防参考图污染首帧 · **仅 Seedance 2.5 首尾帧模式②适用**）
> ⚠️ **版本限定**：本节只服务 **2.5 参考模式②（首尾帧模式）**。**Seedance 2.0 无首尾帧**（参考图仅锁定形象），本节不适用 2.0；2.0 一律走单参考图绑定。
- **严禁直接把参考图当作首帧**投喂生成——参考图仅用于形象锁定，直接作首帧会导致动作僵死、构图复刻；
- 需要精确首帧控制时，首帧必须**另绘全身近景图**（按分镜起手动作单独出图），再与尾帧组成首尾帧对。

### 5. 官方原生提示词语法（2026-09-14 官方文档摘录校准）

> 来源：火山引擎方舟官方文档（教程页 docs.volcengine.com/docs/82379/2607688 · 创建任务接口 docs.volcengine.com/docs/82379/1520757，模型全称 `doubao-seedance-2-5-260628`）。
> 📌 **主格式声明（2026-09-15 用户裁定·三修）**：官方长文示例（如 30s 蒸汽朋克散文体）**仅作语法参考**。本包主格式 = **七段式结构化分段格式**：`【画幅风格】→【场景资产】→【核心人物】→【站位声明】→【时间轴分镜】→【音效】→【强制禁止项】`。官方条目中仍必须遵守的只有硬约束：字数门禁、素材标注用途、红线四条、声音字符（2.5 走官方 API 时）。**命名统一（V6.8）**：「七段式」为唯一命名；【接续状态】是【时间轴分镜】段强制尾行（末镜后必带），不单列成段、不计段数；禁用「八段式/六栏/九栏」等别名。

### 5.0 站位声明（文字版人物站位控制 · 每段必写 · 一行式）

> 站位是老大难问题——模型每段零记忆，不写站位 = 位置随机。**保持极简：一句话声明，禁止画图、禁止坐标表、禁止ASCII布局**（V3 空间图体系已废止为日常格式，`spatial-reference-system-V3.md` 仅留作超复杂群像场景的备查参考，默认不用）。

```text
【站位声明】：@角色A（画面左 · 背靠断裂石柱 · 侧身45°朝右 · 右手垂剑）、@角色B（画面右 · 依托残枪堆 · 正面朝左 · 长枪斜扛）；轴线锁定：左A右B，全段禁越轴；位移仅限本镜声明路径（A: 石柱→中央对决区；B: 残枪堆→中央对决区）。
```

- **四要素**（每人一段括号）：位置（画面左/右/中）+ 依托物（空间锚点）+ 朝向 + 姿态；
- **轴线行**：多镜同场景必写 `左A右B`（或对调后全段保持），声明后全段禁越轴；
- **位移行**：本镜要发生的移动逐人写 `起点→终点`，每步有动作原因（攻击/闪避/击退），**禁瞬移**——与"每镜必有位移动词"配套，防站桩同时防乱跑；
- 静态/对话段：位移行写 `全员原位，无位移` 即可，其余同格式；
- 与【核心人物】分工：核心人物锁"是谁"，站位声明锁"在哪、朝哪、怎么动"；
- 第二人（远景/背景）同样进声明，写法 `@B（远景·画面右后·断桥尽头·背身而立）`——与主次同框四件套共用。

**七段式完整顺序**（2.0 版示例骨架）：
```text
【画幅风格】16:9 横屏, <风格/光影/色调/质感一句话>（2.0 版在句尾写 `model=seedance-2.0`）
【场景资产】@SCN-xxx（外观以场景参考图锁定，不另写文字描述）
【核心人物】@CHR-xxx（外观以人物参考图锁定）× N 人
【站位声明】（一行式四要素+轴线+位移，见上文）
【时间轴分镜】
00:00-00:05 [镜头1] 景别 · 视角角度 · 运镜。动作与受力。声音：音效描述。台词：无（或【谁："…"】）
00:05-00:10 [镜头2] …
【接续状态】：角色动作与空间位置严格继承（终段按档位写终帧定格，如：全段终帧定格最高潮画面，无平缓收势帧·R3 档强制）
【音效】环境音列举（2.0 注明全段音效走后期配音层）
【强制禁止项】画面：…；文字：…；音频：…
```
> ⚠️ **末尾参数行已废止（2026-09-15 用户裁定）**：不再在提示词末尾加【参数契约】行——模型版本写在【画幅风格】句尾 `model=`，画幅/时长由项目头 A/B 锁与各镜时间轴承载，无需重复。
- 镜行格式沿用本包原生写法：`00:00-00:05 [镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`——**每镜行尾必须带行内 `声音：` 与 `台词：`**（无台词写"台词：无。"），2.5 可用官方声音字符，2.0 写后期配音用音效描述；**镜行不写"跟随@谁"**（跟随目标属运镜策略，需要时自然融进动作描述，如"镜头随其位移横移"）；不采用外部示范的"括号五要素连写 + 本镜唯一开口者"变体；
- **【接续状态】**：时间轴分镜末镜后必带——默认 `角色动作与空间位置严格继承`（多段接续）；终段按档位写终帧（R3 档强制"终帧定格最高潮画面，无平缓收势帧"）；
- 与本包规则的关系：**格式用七段式 + 一行式站位声明；打斗/去水/Hit-Stop/在场声明等规则仍按本包各权威文件执行**；
- 空间连续性铁律（`asset-spatial-ledger.md` §三）继续有效：180°轴线、上一镜被击退到哪下一镜从哪继续、真实场景位置≠画面位置（运镜可改变观察，不可改变真实空间）。

### 5.1 格式禁写清单（2026-09-15 用户裁定集 · 防回归）

> 以下写法在 2026-09-15 会话中被用户逐条否决，**任何情况下不得出现在交付产物中**。写提示词/改规则前先过一遍这张表。

| # | 禁写项 | 说明（否决缘由） | 正确做法 |
|---|---|---|---|

| 3 | 提示词末尾【参数契约】行 | 用户：放最后干嘛，删掉 | model 写进【画幅风格】句尾 `model=`；画幅/时长由 A/B 锁与镜行时间轴承载 |
| 4 | 站位用 V3 俯视 ASCII 空间图 / 初始图+位移因果链 / 坐标表 | 用户：太复杂，模型理解不了 | 一行式【站位声明】：四要素+轴线行+位移行 |
| 5 | 默认跳版本或默认画幅（如写"未指定默认 9:16"） | 用户：要有同规格强制项 | A·模型版本 / B·画幅 未指定 = 任务不开始，停下询问 |
| 6 | 画面提示词写电影感装饰性长散文（\<UserQuery>官方 30s 蒸汽朋克示范那类） | 用户：只作语法参考 | 七段式结构化分段；只吸收官方硬约束（字数/红线/时间戳） |
| 7 | 简笔版出图提示词（两三句打发） | 用户：别漏执行项目 | 角色=4 View 资产板+五官 10 项+服装 6 项；战斗场景=战斗角色站位版 |
| 8 | 投喂正文写 FACS 内部标注：`（AU12）〔显〕`、`English kernel: lips roll in…` | 用户：这是啥？视频提示词里没有这个东西（2026-09-15） | 只写肌肉动作的画面语言（哪块肌肉+可见动作+幅度+秒数）；AU 编号/强度档/kernel 只进内部 FACS cue 表·QC 表（见 `★ facs-micro-expression.md` §二·分层铁律） |

> 一句话总纲：**格式用本包七段式 + 原生镜行 + 一行式站位；站位不画图、镜行不带跟随、末尾不带参数行、版本与画幅不默认、交付不缩水。**

- **官方基础公式**（顺序组织，不需要的部分可省略）：`主体 + 动作/事件 + 场景与环境 + 视觉风格 + 运镜/切镜 + 声音`；
- **声音标记官方原生写法**（与社区 `[SFX:]` 写法并存，投喂官方 API 优先用官方字符）：音乐用 `()`、音效用 `<>`、台词用 `{}`、字幕用 `【】`；非中文台词在台词前明确语言；
- **时间戳分段（官方原生支持）**：提示词内用 `[起始秒-结束秒]` 分段描述镜头时序，如 `[0-10秒]：古董黄铜钟面微距特写……`；**一镜连贯叙事，模型不支持硬剪辑切换镜头，组内画面过渡一律靠运镜**——组内多镜（3~4 镜）必须写成连续运镜衔接，真硬切要拆成多段独立生成、后期剪辑拼接；
- **字数硬约束**：中文提示词 ≤500 字、英文 ≤1000 词——字数过多信息分散，模型会忽略细节、丢元素；
- **官方限制（红线）**：
  1. Seedance 2.5 / 2.0 系列**不支持上传含真人人脸的参考图/视频**（角色资产参考图必须为动漫/CG/绘画风格）；
  2. 提示词禁矛盾描述，不同时写多种冲突美术风格；
  3. 参考素材必须标注用途（锁定角色/场景/运镜/音色），不能只丢图不说明；
  4. 多模态参考生视频、首帧生视频、视频编辑为**互斥任务类型，不可混用**；
- **@CHR/@SCN 属性澄清**：官方文档**没有** `@CHR`/`@SCN` 标记、180° 轴线、世界朝向锁定语法——这套是国内漫剧创作者社群沉淀的工程化扩展写法（模型可识别解析，用于防角色漂移/越轴/穿帮）。本包继续沿用，但投喂官方 API 时必须同时满足官方规则（素材用 `@图片1/@视频1/@音频1` 指代并逐个标注用途）。

### 6. 官方 API 契约（创建任务请求体）

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    { "type": "text", "text": "……草莓味参考@图像1……" }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 15,
  "output_format": "mov"
}
```

| 参数 | 取值与说明 |
|---|---|
| `model` | 固定 `doubao-seedance-2-5-260628` |
| `ratio` | `16:9` / `9:16` / `1:1` / `21:9`；编辑/首尾帧模式用 `adaptive` 自适应 |
| `duration` | **4~30 秒** |
| `generate_audio` | 布尔值，是否生成原生音频 |
| `content` | 数组，可混合 `text` / `image_url` / `video_url` / `audio_url` 多模态素材 |
| 素材 `role` | `reference_image` / `reference_video` / `reference_audio`；首帧 `first_frame`、尾帧 `last_frame`（**仅 2.5 模式②；首/尾帧与参考图互斥**；2.0 不适用） |

## 三、 投喂前自检清单 (Pre-Flight Checklist)

1. **时长与组数核对**：单组提示词必须标注目标时长（Seedance 2.5 推荐 12~15s、官方上限 30s；Seedance 2.0 上限 15s；即梦推荐 5~10s）；
2. **资产短锚点检验**：必须使用 `@CHR_name` 或 `[CHR-xxx]` 明确对应资产图，严禁无主代词（如“他/她/神秘人”）；同时按官方要求为每份参考素材标注用途（外貌/动作/音色/运镜）；
3. **字数门禁**：中文提示词 ≤500 字、英文 ≤1000 词（官方约束，超字模型丢细节）；
4. **真人脸红线**：角色/场景参考图严禁含真人人脸（官方限制），资产图一律动漫/CG/绘画风格；
5. **任务互斥核对**：多模态参考生视频 / 首帧生视频 / 视频编辑三选一，不可混用；
6. **安全合规转译**：血腥、断肢等动作必须按 `platform-safety-compliance-guide.md` 转译为“气浪震碎/光效消散/重创定格”，避免平台审核封禁。
