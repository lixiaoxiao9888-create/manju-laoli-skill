# 轻量离线分镜看板（Storyboard Board Lite）

> ⭐ **定位**：把项目 md（唯一真相）一键编译成**单文件离线 HTML 看板**——双击浏览器即开，零依赖、零数据库、零端口。形态与 6.8.3 完整版（模块 K）**同构**：创作蓝图层 + 分镜生产层双层区块全保留；**只砍** N1~N11 深度检查层、`validate_prompt.py` 依赖与 board_state.json 快照。
>
> 🔗 配套脚本：`scripts/build_board_lite.py`

---

## 一、 四条轻量铁律（K-lite 1~4）

| 编号 | 铁律 | 说明 |
|---|---|---|
| **K-lite-1** | **md 是唯一真相，看板只读** | 看板是产物不是工作面。⛔ 禁止"在网页里改分镜再同步回 md"；改稿改 md，然后**重编译**看板。 |
| **K-lite-2** | **缺字段降级不中断** | md 是用户手改的文件。任何章节缺失 → 该区块显示"未解析到"并记 **WARN**，**看板永远出得来**，绝不因一处格式不标准整板崩掉。 |
| **K-lite-3** | **拆解视图与原文并存** | 每段必须同时给：① 逐镜拆解（泳道 + 镜头卡，定位问题用）+ ② ` ```text ` 围栏原文照录（直接复制投喂用，不改写）。只做其一 = 看板残废。 |
| **K-lite-4** | **⑤ 出图提示词与 ③ 投喂提示词必同板** | **P2.5 资产出图提示词与 P4 分镜投喂提示词必须同时出现在看板上**——一边出资产图、一边投视频，缺 P2.5 → WARN 并在 ⑤ 区提示补齐。 |
| **K-lite-5** | **宽容识别，不为看板改写 md** | 章节名 / 段标题 / 资产表列序 / 镜行时间码一律按关键词宽容匹配（见 §三）。遇到不识别的新格式，**优先扩编译器**，不许要求用户把 md 改成契约标题——那会制造"为出看板而生的第二份 md"，直接违反 K-lite-1。 |
| **K-lite-6** | **信息零丢失** | md 里写下的每一样东西都必须出现在看板上：剧本区收**正文 + 表格**（表头/数据按 markdown 分隔行切表、保持原文顺序）；未被归区的章节（双锁表 / 内部 QC / API 模板 / 生成顺序等）原文照录进「⑦ 其他章节」。看板出现"未解析到"仅限该章节在 md 里本来就不存在。 |

---

## 二、 用法

```bash
python scripts/build_board_lite.py <项目.md>              # 输出 <项目名>_分镜看板.html（同目录）
python scripts/build_board_lite.py <项目.md> --out 看板.html
```

## 三、 输入 md 契约（章节名与 6.8.3 对齐，存量项目档可直接编译）

```markdown
# 项目标题                      ← 一级标题 = 看板标题
【画幅】：16:9                  ← A/B 双锁回显（未声明 → WARN"未锁定"）
【模型版本】：2.5

## P0A · 创作基准               ← 表格: 项 | 内容 → Ⅰ 区
## P1 · 剧本                    ← 正文照录 → Ⅱ 区
## P1 · 视听圣经                ← 表格或正文 → Ⅲ 区
## P2 · 资产清单                ← 表格: 编码|名字|视图|@图片N → ④ 区（自动算引用段）
## P2.5 · 资产出图提示词        → ⑤ 区（K-lite-4 必同板）
### CHR-001 · 林越 · 主角 4 View 资产板
```text
（资产图出图提示词——生成人物/场景/道具图用，不是视频投喂词）
```
## P4 · 投喂提示词             → ③ 区
### 段1
【核心人物】：…                 ← 段级栏（可选，渲染为标签）
【站位声明】：…                 ← 段级栏·一行式文字站位（四要素+轴线+位移，禁止画图，见 model-adapters.md §5.0）
```text
（该段完整视频投喂提示词，照录）
```
[0-3秒] 逐镜拆解行             → ① 泳道 + ② 镜头卡
## P6 · 发布文案               ← 可选：【标题】【封面文案】【正文】【话题标签】→ ⑥ 区
```

**解析规则（宽容识别 · K-lite-5）**：上面是**推荐契约**，不是硬性要求。编译器按关键词归区，自定义标题照样能编译：

| 维度 | 宽容规则 |
|---|---|
| 章节名 | 按关键词归区，**不要求照抄标题**：`资产清单/资产表/P2`→④、`出图提示词/资产出图/P2.5/P2c`→⑤、`投喂提示词/分镜提示词/P4`→③、`剧本/故事/梗概`→Ⅱ、`视听圣经/风格圣经`→Ⅲ、`创作基准/P0A`→Ⅰ、`发布文案/P6`→⑥。所以 `## 二、 资产清单（P2b）`、`## 三、 P2c 出图提示词`、`## 四、 P4 投喂提示词组` 都能直接编译 |
| 段标题 | `### 段1` / `### U01 · …` / `### 第1段` 都认 |
| 资产出图子标题 | `### 1. \`@CHR-沈砚\` · 4 View 资产板` —— 自动去前导序号与反引号，按 `·` 拆成 编码 / 名字 / 说明 |
| 资产表列序 | 按**表头名**映射（编码·名字·视图/出图·@图片N），兼容 `类\|编码\|类型\|出图\|复用单元` 这类自定义列序；未映射的列收进「附加信息」，信息不丢 |
| 镜行时间码 | 三种都认：本包原生 `00:00-00:05 [镜头1] …`、`[00:00-00:05] …`、`[0-3秒] …`；段外无拆解行时自动从围栏原文兜底提取；检测时间码回跳 |
| A/B 双锁 | 除 `【画幅】：` / `【模型版本】：` 行外，**还能从任意表格兜底**（如双锁表里 `**B · 画幅** \| **16:9 横屏**`、`**A · 模型版本** \| **Seedance 2.0**`） |
| 时间轴 | 各段独立计时（每段都从 0 起）时，泳道按累计偏移铺成整片时间轴（15+15+12+15 → 标尺到 57s），总时长＝**累加**而非取最大值 |

## 四、 看板区块（自上而下 · 双层结构）

| 层 | 区块 | 内容 |
|---|---|---|
| **创作蓝图层** | Ⅰ 创作基准 | P0A 表格项 |
| | Ⅱ 剧本层 | P1 正文照录 |
| | Ⅲ 视听圣经 | P1 锁定项（一次锁定全片继承） |
| **分镜生产层** | ① 时间轴泳道 | 每段一条泳道，逐镜按秒定位色块 + 时间刻度 |
| | ② 镜头卡矩阵 | 逐镜卡（段/镜号/时间码/内容）——拆解视图 |
| | ③ 投喂提示词原文 | 每段折叠框 + **复制投喂原文**按钮 + 段级栏标签——成品视图 |
| | ④ 资产总表 | P2 表 + @图片N 徽标 + **自动算出每个资产被哪些段引用** |
| | ⑤ 资产出图提示词 | 每资产折叠框 + **复制出图提示词**按钮（与 ③ 必同板） |
| | ⑥ 发布文案 | P6 四件套（可选） |
| 顶部 | 统计条 + 段筛选 | 模型/画幅/段数/镜数/总时长 + 按段过滤 + **只看告警**开关 |

## 五、 与 6.8.3 完整版的取舍

| 项 | 6.8.3 完整版 | 本轻量版 |
|---|---|---|
| 编译器 | build_board.py（约 1900 行，import validate_prompt.py） | build_board_lite.py（约 450 行，零依赖） |
| 检查 | CLI 层 + N1~N11 看板层 | 轻量 WARN：缺围栏原文 / 缺时间戳 / 时间码回跳 / 缺 P2.5（K-lite-4）/ A·B 锁未锁定 |
| 状态快照 | board_state.json（:memory:） | 无 |
| 校验一致性对照（⑦） | 有 | 无（深度质检走 P0~P2 质检门禁与改动后复验铁律） |
| 双层区块 / 泳道 / 镜头卡 / 原文复制 / 资产引用段 | ✅ | ✅ 同构保留 |
| 共同点 | **md 唯一真相只读 · 单文件离线 HTML 双击即开 · 拆解+原文并存 · 缺字段降级** | |
