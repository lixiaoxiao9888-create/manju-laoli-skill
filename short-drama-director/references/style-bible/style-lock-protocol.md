# 画风锁规程（I 锁 · 方案文档通称「F 锁」）—— 推荐式选单 → 选定即冻结

> **本文件是 I 画风锁的唯一权威**。
> 编号说明：〇节 E~H 已被既有用户确认铁律占用（E 只出提示词 / F 2.0 时长分配 / G 台词音效默认内出 / H 素材红线），本锁编号顺延为 **I**；方案文档与外部讨论中的通称「F 锁」= 本锁。
> **锁性质（★ 2026-10-13 用户裁定升格）**：与 C·交付形态同级的**必弹卡锁**——**动笔前必须推送候选卡、让用户在卡上勾选**；卡内**必须包含「按你的推荐走」一项**（用户不想挑时可主动选它，等价于授权用默认推荐卡），⛔ **但禁止在用户未表态时自行按默认推荐卡执行**（用户原话：「**这个还是没有给我选**」）；**选定后即冻结**，与 A/B/C/D 同规格（全流程只读、中途改 = 重开任务）。
> 配套文件：`style-archetype-taxonomy.md`（六原型与七个NOT）· `director-style-catalog-74.md`（74 组候选源）· `style-fit-and-combat-matrix.md`（题材适配矩阵）· `director-to-prompt-protocol.md`（转译植入）· `director-param-library.md`(11 槽位参数) · `style-prefix-blocks.md`（成品块）· `style-bible-spec.md`（交付规范）。

## 一、设计原则（用户口径 · 逐条对应）

| 用户要求 | 落地设计 |
|---|---|
| 「在前面做成一个选项」 | 插在 **P0 锁区**（D 锁之后、E 铁律之前），与各锁同一句话问清 |
| 「类似于固定锁」 | 选定后与 A/B/C/D 同规格：全流程只读、禁止中途改、中途改 = 重开任务 |
| 「尽量让他们前面先多选一些」 | 每次给 **4 张候选卡**（含「D 自定义」位），每张卡**必带易跑偏警告** |
| 「选完那个类型之后给他推荐」 | 候选卡由 **题材 × 素材来源** 交叉推荐，命中题材有**默认推荐卡**（标「默认推荐」） |
| 不能变成拦路虎 | **卡上必带「按你的推荐走」一项**（一键授权，跳过零成本）；⛔ 但**未表态 ≠ 已表态**——未表态 = 停下询问（★ 2026-10-13 修订） |

## 二、触发时机与位置

```text
〇·1 素材来源 → A 模型版本 → B 画幅 → C 交付形态（强制锁）
        → D 段缝衔接（多段任务）→ ★I 画风与视觉风格（本锁 · P1 剧本之前推送候选卡）
```

- 〇·1 + A/B 锁定后、**进入 P1 之前**推送候选卡；
- 与 A/B/C 同一句话问清（「模型版本？画幅？交付形态？画风想要哪一种？」）——⛔ **禁止说「不指定我就按默认卡走」**；改用「**这几张卡请挑一张；不想挑就回「按你的推荐走」**」（★ 2026-10-13 用户裁定）；
- **写入 P0A 基准表**，P2/P3/P4/P5 只读；确需改 = 重开任务（与 A/B/C/D 同纪律）。

## 三、四步递进（每次只收窄、不平铺）

> 74 组按国籍平铺是把检索负担甩给用户。本锁按**技法**递进收窄，每一步都在排除。

### Step 1 · 影像基底（★ 2026-10-13 用户裁定：**必须确认** · 形态 = 必问项）

| 基底 | 判定依据 | 默认落点 |
|---|---|---|
| **真人实拍质感** | 都市悬疑 / 警匪 / 年代怀旧 / 写实向 | 真人写实原型 |
| **2D 手绘动画** | 知识科普 / 童话 / 青春 / 古风抒情 | 手绘水彩 → 厚涂赛璐璐 |

> ★**铁律**：基底不匹配的风格**整体不可选**，且直接在卡上说明原因（例：真人基底却推 MAPPA → 卡上标注「与真人基底冲突」，不出卡）。
>
> ⛔ **2026-10-13 用户裁定（形态必问 · 不得自动判定）**：**影像基底不得由执行者"自动带出"**——必须**明确向用户确认**（真人实拍质感 / 2D 手绘 / 3D CG / 水墨二维），确认后再出卡。理由：用户原话「**我这个是真人的哈，什么动漫什么开发，这不是动漫 IP 啊**」——形态一旦被自动判走，**全片画质词 / 形体骨相 / 候选池 / 打戏档位全部跟着错**，且错在源头、下游无从纠正。**本节判定表只用于"给建议"，不作为"直接结论"**；用户未表态 = **停下询问**。真人项目同步改写 `STYLE_PROFILE.md` 四处（`动漫化程度 = 0` / 6.5~7.5 头身·真人质感 / 实拍级画质词 / 硬排除 T8 动画质感派全族 + 网红脸 + 磨皮过度）。

### Step 3 · 导演卡（每族 1~2 张 · 最多 4 张）

**排序键 =（题材亲和度, 打斗★ + 特效★）——亲和度优先，能力总分次之。**

> ★**通用教训（实测三轮抓出）**：推荐排序**永远不能只看能力维度**。能力（打斗★/特效★）是**门槛**（用于排除），**不是排序键**。排序键必须是**题材亲和度**——否则都市情感场景会把朴赞郁（打斗★★★）顶上 A 卡。引擎 v1/v1.1 两代都栽在这里，v2（现行）五用例 A 卡全对。

**收卡规则（一条都不能少）**：
1. **同族不超过 2 张**——4 张卡里同族占 3 张等于没给选择；
2. **必带能力标签**——打斗★ / 特效★ 缺任一 → 不得进候选池；
3. **必带易跑偏警告**——「我选了它，最可能出什么错」是用户最需要的信息；
4. **必标 AI 落地度**——A 直接用 / B 系统自动补写法约束 / **C 必须同时给降级方案**（不得只提示风险不给路）；
5. **自动排除清单要明示**——「本次已排除 17 组不适合打戏的风格」，让用户知道系统替他做了什么；
6. **禁出基底冲突卡**——与 Step 1 基底冲突的风格直接不上卡。

**次级操作**（用户没选中时）：看全部该族 / 换一批 / 按技法筛 / **D 自定义**（用户描述 → 按 11 槽位建 STYLE_BIBLE）。

### Step 4 · 可选辅助质感（选完主风格后才问 · 可跳过）

只给能叠加的族（2 个选项 + 「不叠加」）；**未指定 = 不叠加，按主风格执行，不追问不阻塞**。互斥的 6 对见 Step 2 表，不得出现在辅助选项里。

## 六、四条硬规则（选定即冻结）

- **F-1 一套主原型 + 至多一个辅助原型**（辅助须承担明确独立功能，如「主体水墨 + 特效手绘化」）；
- **F-2 多时空走「公共底层 + 明确分支」**，**禁止同一时空串风格**；
- **F-3 选定即冻结**：写入 P0A 基准表，P2/P3/P4/P5 只读；确需改 = 重开任务（与 A/B/C/D 同纪律）；
- **F-4 第三方作品名禁入最终提示词**：参考只作内部解析，须转译为可见参数（灵境铁律第 8 条；判据见 `director-to-prompt-protocol.md` §六 C23d）。

## 七、推荐引擎硬约束（与 `scripts/style-lock-ladder.py` 互为镜像）

```text

2. 若【含打斗】→ 候选池 = style-fit-and-combat-matrix.md §二 打戏可用 24 组

4. 生成 4 张卡时，每卡必须带：打斗★ / 特效★ / 题材锁定 / 易跑偏警告

   剔除「声音：/音效/禁止项/严禁/不得」语境行，且只向上回溯 1 行；
```
