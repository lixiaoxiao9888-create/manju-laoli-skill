# 画幅自适应路由规范 (Aspect-Ratio Adaptation Router)

> ⭐ **全局总控路由（★权威）**：本 skill 所有环节的画幅都由此文件统一裁决。**第一步永远是锁定画幅**，锁定后全流程（资产→剧本分镜→镜头构图→模板→API 参数→质检）一律使用该画幅版本，禁止混用、禁止被示例/模板带偏。

---

## 〇、 画幅锁定流程（任何任务开始前强制执行）

1. **B 锁·强制三选一**：用户必须明确选择 **16:9 横屏 / 9:16 竖屏 / 21:9 宽幕**（官方另支持 1:1，仅明确指定时采用）；
2. **用户未指定 → 停下询问**（与〇节 A·模型版本锁同规格），禁止默认 9:16、禁止默认回落（旧版"未指定默认 9:16"规则已废止）；
3. **锁定后**：在任务产出物开头显式声明 `【画幅】：16:9 横屏 / 9:16 竖屏 / 21:9 宽幕`，全流程沿用；
4. **回填**：每条提示词、每个时间轴分镜、每个 API 载荷的 `aspect_ratio` 都写锁定值，禁止默认回落。

## 二、 横屏 / 竖屏构图对照细则

### 横屏 16:9（用户指定横屏时全模块启用）
- **空间纵深**：中长焦拉开前后层次，利用走廊/街道/广场纵深感；
- **站位**：双人对峙走三分线左右站位，攻防沿对角线推进；
- **位移展示**：腾空横飞、撞墙横飞、贴地滑行等横向轨迹优先；
- **大招**：广角+低仰蓄力，环形冲击波横扫、左右对称对峙；
- **景别阶梯**：极微距→超广角→宏观全景→鸟瞰（横向铺展环境破坏）；
- **禁**：竖屏式"垂直安全区""上下叠压构图"写法混入。

### 竖屏 9:16（默认/用户指定竖屏时全模块启用）
- **垂直纵深**：高低位落差（高位俯瞰/低位仰视）、前后景叠压遮挡；
- **站位**：上下对峙、冲镜特写（攻击部位直冲镜头）；
- **位移展示**：下劈、跳起下砸、贴地滑行、腾空上冲等纵向轨迹优先；
- **大招**：垂直拉升+俯冲、法相压顶、腾空爆发、地面放射状裂纹向上延伸；
- **景别阶梯**：垂直方向的推进与拉升（俯冲跟随、拉升俯瞰）；
- **安全区**：人物占屏比控制，避免关键信息（面部/台词）被裁切。

---

## 三、 强约束清单（违反即返工）

1. 用户说 `16:9` → 任何环节出现 `aspect_ratio=9:16`、竖屏构图词（垂直安全区/冲镜特写/上下叠压）均属违规；
2. 用户说 `9:16` → 不得套横屏模板或横屏构图词；
3. 模板/示例里的画幅**不是默认值**，只是"参考写法"，最终以锁定的画幅为准；
4. 每份交付物（提示词组、工作流载荷、分镜表）顶部必须声明 `【画幅】`，质检时核对一致。
