# P5 后期：剪辑、剪映草稿、音效与配乐（V7.0 · 2026-10-05）

> **V7.2 起整集剪辑以 `pro-editing-packaging.md` 为准**（每集最低标准、九步流程、字幕/人声原速/人名条/冲击帧/破框）。本文件保留工具细节与 V7.0~V7.1 经验。

> 来源：《实测玄幻漫剧》EP01 后期实测。H3 生成的原片普遍"每镜落定 + 结尾落定"，**生成 15 秒、剪辑保留 10~13 秒**是标准做法，所有剪辑版动作均值可到 8.7~11.6。

## 一、工具（`scripts/h3_tools/`，复制到项目的 `P4任务/工具/` 使用；`音效库/` 放在 `P4任务/` 下）

| 脚本 | 作用 | 用法 |
|---|---|---|
| `动态检测.py` | 每 0.5 秒统计相邻帧运动量，标出"定格"（连续 1 秒低于阈值）和"冲一下就停" | `python 动态检测.py [--动作] 视频.mp4`；默认文戏标准（合格 3/定格 2），`--动作` 为动作段标准（合格 6/定格 3/均值≥8） |
| `动作剪辑.py` | 分段变速、关键帧猛推、冲击震屏、砍尾，跑完自动做动作检测 | `python 动作剪辑.py 输入 输出 0.3-6@1.2 6-7.5@1.8 7.5-8.9@1+推 8.9-10.8@1+震 ...` |
| `生成剪映草稿.py` | 把同样的分段方案写成剪映时间线（变速、推镜关键帧、冲击特效轨、音效轨、压低原声） | `python 生成剪映草稿.py 草稿名 输入.mp4 段... "音效:6.98=重低音冲击.wav*1.3" "静:5.6-6.5"` |
| `拼接草稿.py` | 一份 JSON 剪辑方案写多段（素材/分段/音效/压低原声/背景音乐），生成整集草稿 | `python 拼接草稿.py EP01_剪辑方案.json` |
| `渲染整集.py` | 用同一份 JSON 方案直接渲染成片 mp4（变速/推/震/冲/闪/局部放大、压低原声、音效、配乐，末端 loudnorm -14 LUFS / TP -1.5） | `python 渲染整集.py 方案.json 输出.mp4` |
| `合成配乐.py` | 按"配乐提示表"合成与剪辑点对齐的预告片式临时配乐（低音铺底/太鼓/铜管轰鸣/蓄力/弦乐震音/台词让位） | `python 合成配乐.py 提示表.json 输出.wav` |
| `合成音效.py` | 用 ffmpeg 生成 7 个基础合成音效（重低音冲击、甩镜嗖、蓄力上扬、水花炸裂、低吼震颤、水晶叮、入水闷响） | `python 合成音效.py 输出目录` |
| `合成音效v2.py` | 分层合成 + 洞穴混响：声浪轰鸣、岩壁龟裂、碎石滚落、风啸上冲（峰值在 1.45s，放在 剪点−1.45s）、巨物砸水、压迫低鸣（3s 渐强，结尾对准下一句台词前切断） | `python 合成音效v2.py 输出目录` |

依赖：ffmpeg/ffprobe 在 PATH；numpy、scipy（配乐）；`pip install pyJianYingDraft`（草稿）。

## 二、剪辑方法
1. **先检测再剪**：`动态检测.py --动作` 找出低于 6 的分桶，逐帧确认是"主体定姿"还是"正常读图"。
2. **分段写法**：`起-止@倍速[+推][+震]`（源视频时间）。
   - 主体定姿段 1.5~1.8 倍；动作好的段 1.0~1.1 倍保留流畅；**台词/独白段保持 1 倍**（不压语速）。
   - `+推`：段内由慢到快放大到 1.25 倍，补"猛推"（特写、面具、台词推近）。
   - `+震`：段首 0.2s 闪白 + 0.35s 色散冲击 + 衰减震屏，只给真正的冲击点。
   - `+冲`（V7.0.1）：曲线加速——该段切成四小段，倍速依次 0.75/1.0/1.4/2.0（乘段倍速），先慢后快冲进下一刀，模拟剪映"曲线变速"的蓄力→爆发；匀速加速只会"变快"，曲线加速才"变狠"。不与 `+推` 同用。
   - `+闪`（V7.0.1）：冲击闪帧——段首 2 帧由白闪入，给命中瞬间。
   - 不写的时间段直接丢弃（开头空镜、结尾落定、串进来的无关画面）。
3. **验收**：剪辑版动作均值 ≥ 8（动作段）、无定格；同时逐镜看主体与节奏，过度加速会发飘、震屏过多会晕。
4. 文戏段不加震屏；独白段宁可保留原速。

## 二点五、抽卡拼接（V7.0.1 · E01-6 实测）
同一分镜、同一写法下，**哪一处定姿、哪一处拍好已主要由抽卡随机决定**（E01-6：00171 坠落翻转好但撞顶未入画；00172 撞顶入画、闪避残影好，但 S 形与坠落定姿）。标准做法：
1. 同提示词多抽 2~3 条（只换种子），逐镜标记"好/定姿/穿帮"。
2. 在**镜头边界或动作接缝**处拼接（如"坠石下落 → 撞击闪帧 → 岩台崩裂"），不在同一个连续动作中途换片。
3. 分辨率不同的片子统一缩放到较高者再拼，最终整体超分。
4. 拼接后再跑 `动态检测.py --动作`，并重点看接缝前后主体位置、光色是否跳。
（剪映侧可用 `拼接草稿.py`：同一段写成多个"段落"条目、各引用不同素材。）

## 二点六、超分（V7.0.2 · E01-5 实测）
- **超分的是原片，不是剪辑版**：时长、帧率不变，剪辑方案的源时间点可直接复用（先用 `select='gt(scene,0.08)'` 核对剪点是否一致）。
- **超分会重新生成音轨**（00173→00174：包络相关 0.97、波形相关仅 0.69，台词可能变样）：用户已确认过台词的，用"高清画面 + 原片原声"重新封装（`-map 0:v -map 1:a`），再加回声等处理。
- 统一超分到 1088×1952（H3 高清档），整集拼接不会忽清忽糊。

## 二点七、穿帮抢救与整集定稿（V7.0.2 · EP01 实测）
- **局部放大**：分段写成 `{"段": "2.0-2.6@1.5+震", "放大": 1.6, "焦点": [0.6, 0.22]}`，把焦点移到画面中心——裁掉穿帮区域（E01-4 蛇身"红布"）、把全身站桩改成半身+推近（E01-5 开场）。剪映草稿用 scale+transform 实现，渲染用 crop。
- **跳切 + 闪白**：穿帮持续较长时直接剪掉中段，在接缝处 `+闪` 掩盖跳切。
- **静止段**：无台词 → 2 倍速；有台词 → 原速 + `+推`（不压语速）。
- **首帧残影**：H3 片头常有 1~2 帧上一镜残影，起点从 0.15s 开始。
- **整集流程**：拼接预览 → 逐段 2fps 联系表找穿帮/静止 → 改方案 → 按最终时间线写配乐提示表（让位=台词区间，静默=冲击前 0.4~1s）→ 渲染成片 + 生成同名剪映草稿 → ebur128 验收（I≈-14 LUFS，TP≤-1.5）。

## 二点八、整集组装与段间转场（V7.1 · EP01/EP02 实测）
- 每段定稿的剪辑方案 JSON 保留（素材、分段、音效），整集用一个组装脚本按顺序拼段落、统一 `画面填充`，再交 `拼接草稿.py`（剪映）与 `渲染整集.py`（成片 mp4，-14 LUFS）。
- **段间转场五法**（按上下段的画面关系选）：
  1. 视线动机切：上段末人物仰望/回头 → 下段他看到的东西；切点前 0.6s 先进下段的声音（声桥）+ 切点闪白。
  2. 满屏色擦除：上段末满屏红雾/尘浪/水花 → 下段开场，用这片颜色当擦除，加闪白。
  3. J-cut：下段第一声（蝠群尖啸、地裂）提前 0.3s 进上段末尾。
  4. 黑场衔接：上段末进入黑暗（隧道）→ 0.5s 黑 → 下段从黑里亮起；起点前移保留"黑暗中转身"一类动作，别裁成跳切。
  5. 段间锁连续段：两段本来连续，只需查首帧是否穿帮（上段末帧状态是否被带偏）。
- **片尾钩子**：剧本标"黑场卡点"的，最后硬切黑 1~1.2s，黑里给一个声音钩子（心跳、闷沉搏动、远处呼名）。
- **低清/高清混剪**：选中条超分到 1088×1952；超分会重生成音轨，一律"高清画面 + 原片原声"重新封装后再进方案；未超分的段混入高清段会看出清晰度差。
- **临时配乐提示表**按整集时间线写：段落起点由组装脚本算出，台词区间自动"让位"，段间转场处放轰鸣/鼓点，片尾黑场静默。

## 三、剪映草稿（pyJianYingDraft · 剪映专业版 11.6 实测可打开）
- **草稿目录自动识别**：从 `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft\root_meta_info.json` 里已有草稿的路径推断（用户可能把草稿位置改到别的盘）。
- **永不覆盖**：同名草稿存在时另存 `名字_v2/_v3`。剪映打开中的草稿有 `.locked` 锁，强行覆盖会失败且可能丢用户手改。
- **剪映保存过的草稿会加密**（draft_content.json 变密文）：生成后用户在剪映里改了什么，脚本读不回来——改动以"告诉我→改方案 JSON→重新生成新版本"的方式回流。
- **素材先复制进项目目录**再引用，避免下载文件夹被清理后草稿丢素材。
- 剪映时间线倍速标签只显示一位小数（1.15 显示 1.2X），属显示精度。
- 片段时长以库实际写入值累加（浮点取整会造成"片段重叠"报错）。
- 能做：变速、关键帧（缩放/位置/旋转/透明度/亮度/对比度/饱和度/音量）、画面特效（闪白、色散冲击、震动等 1000+）、滤镜、转场、蒙版、本地音效与配乐、音频场景特效（洞穴回声/山洞/超重低音等，作用于音频片段）。
- 不能做：曲线变速（蒙太奇/子弹时间需用户手动套）、调用剪映在线曲库/音效库（只能用本地文件）。

## 四、音效与配乐
- **剪映缓存里的音效没有名字**（`Cache\music\` 全是哈希文件名，查不到映射）：按时长 <8s、低频占比/高频占比筛候选再给用户试听；用户以前没在剪映用过影视音效时，缓存里基本只有提示音和人声。
- **专业音效（V7.0.2）**：Sonniss GDC 免费包（免版税可商用、无需署名，禁 AI 训练；网站有 Cloudflare 验证，需用户浏览器下载，下完移出 C 盘）。每个库只含 2~4 个样品，需切段：按包络找起止 → 截取、48k 立体声、峰值 -1dB、尾部淡出 → 放 `音效库/专业/` 并写 `索引.md`（时长/峰值位置/用途）。剪辑方案引用 `专业/文件名.wav`，放置时间 = 命中点 − 峰值位置。合成音效保留用于心跳、风啸等专业库缺的。
- **合成音效只是占位**：冲击、低吼的低频尚可，"嗖"和水花偏电子。高质量做法：用户在剪映音效库试听挑选，加到任意草稿后剪映会缓存到 `JianyingPro\User Data\Cache\music\`（文件名为哈希，按修改时间找最新的），再由脚本对齐卡点。
- **"先静再炸"**：冲击前 0.5~0.9 秒把原声压到 12%（`静:` 参数）+ 蓄力上扬，命中点重低音 1.3~1.4 倍——这是最有爽感的一处。
- **剪辑单**：每段交付时附"时间线位置 / 画面 / 建议音效与处理"表，方便用户在剪映补音效、曲线变速、字幕。
- **临时配乐**：`合成配乐.py` 的提示表按整集时间线写段落（暗底/清冷/脉冲/震音）、鼓点、轰鸣、蓄力、静默、让位（台词区间自动压到 35%）。只有氛围与打击、无旋律，定位是确定"在哪静、在哪炸"；正式版用 AI 作曲（写明时长与关键爆点时间）或剪映可商用曲库。
- 洞穴等场景的对白可在素材音轨上加轻度回声（`ffmpeg -af "aecho=0.85:0.75:70|160:0.32|0.18"`），或在剪映给音频片段加"洞穴回声"。

## 五、单集时长
不设硬性下限：加速与砍尾后单集 70~90 秒均可（EP01 规划 95 秒，前四段 55 秒剪后 41.4 秒）。以节奏为准。
