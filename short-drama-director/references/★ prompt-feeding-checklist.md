## 〇、 执行铁律

1. **A·模型版本锁定（未指定不动笔）**：写任何提示词前，先完成 Seedance 2.5 / 2.0 强制二选一（见 `model-adapters.md` 〇节）；用户未指定 = 任务不开始，禁止默认跳版本；
2. **B·画幅锁定（与 A 同规格）**：先完成画幅强制三选一——**16:9 / 9:16 / 21:9**（1:1 仅用户明确指定时采用）；用户未指定 = 停下询问，禁止默认 9:16；锁定后全流程沿用（见 `aspect-ratio-adaptation.md`）；
3. **双锁齐备才过检（多段任务加 D 锁）**：A、B 两道锁全部锁死，才允许进入下方 6 步序列；**多段任务另锁 D·段缝衔接方式三选一**（末态双保险/换机位硬切/空镜过渡，见 SKILL 〇节 D 与 `segment-splicing.md`），未指定停下询问；
4. **按序过检**：以下 6 步按顺序执行，每步产出对应校验结果，全部通过才允许出稿；
5. **语速卡不入正文**：语速自检卡是内部 QC 附件，默认不写入投喂正文（避免污染提示词），但必须随交付物一并输出；
6. **战斗档二选一**：R3 玄幻 → `xuanhuan-magic-combat.md`；武侠/现代格斗 → `action-previs-15grid.md`；两者不混用；
7. **交付满额铁律（不许漏执行项目）**：契约要求的字段/模板段落必须逐条写满才算出稿——出图提示词按满血模板（角色 4 View 资产板+16 项锁定 / 战斗场景站位版）、分镜逐镜带在场名单+站位声明+行内声音台词+接续状态；**示例与演示同样满血**，禁止简笔交差（见 SKILL.md 法则 15）；
8. **出稿机检门（硬性·2026-09-15 新增 / V6.9.7 扩容至 C20 四判据）**：提示词写完后，**必须跑一遍 `scripts/validate_prompt.py <稿>.md --model 2.5|2.0`**，`[-] FAIL` 项清零才允许交付（脚本查 C1~C20：时长/切镜/字符/版本语法/画幅回填/七段式/2.0 禁用首尾帧/高危词/接续状态/**套话告警**/规则词混入/镜长雷同节奏门/**画外声 OS·VO 声画分离与配额**/**拉伸凑时**/**对白语气错位与缺失**/**摆位必入画·人物账连续**/**首镜锚定·姿态回退·视线黏道具·特写承载空间事件·反光道具光效**/**裸禁令词·光路触发器·首镜主体优先·具象光源映射·禁止项栏目纪律**/**首镜单主体锚定·并列主体句式·悬空指代·抽象形态形容·道具光效·道具贴近光源**）。机检兜底，人读规则先行，两者不互相替代；
9. **禁用清单先行**：出稿前照 `model-adapters.md` §5.1「格式禁写清单」扫一遍（禁外部括号五要素连写 / 禁镜行"跟随@谁" / 禁末尾参数行 / 禁 ASCII 站位图 / 禁默认版本与画幅 / 禁装饰性长散文 / 禁简笔出图词）——命中任一条即返工。
10. **对白语气必写（V6.9.3 新增 · 2.0 / 2.5 同规格）**：**有台词的镜行，`台词：` 字段必须是 `【角色（语气）："…"】`**——语气是官方对白三要素之三（HOW THEY SOUND），缺失会让声音与表情一并扁平（官方原文点名 `tone_qualifiers`）。**语气词只进语气位、禁写进画面段**（写进画面段会被当视觉信息渲染成"一张冷笑的脸"）；**道具动作与语气一致（V6.9.7 续增 · C16d）**：把玩/摩挲类闲适动作只配慢悠悠语气，宣判/嘶吼/质问等强情绪语气必须换攥紧/捏住/垂手握着（实测宣判时刻"把玩玉佩"出戏）；**音色锁仅 2.5 且为可选增强**（2.0 无音频参考通道，只做语气，不做音色锁不算缺陷）。规范见 `model-adapters.md` §5.2，机检 C16 兜底。
11. **人物账连续·摆位必入画（V6.9.3 续）**：**站位声明摆了位的每个人，本段镜行必须至少带到一次**（正拍/焦外身影/全景群像/反应镜头均算），给不了镜头就写明 `段末离画/退场·去向`；重新入画要写明方式；相邻段没移动的人站位不漂移。多段任务逐段自查（尤其"背景工具人"：抽烟的爹/缩在身后的妹妹最容易整段蒸发）。规范见 `model-adapters.md` §5.0.1，机检 C17 兜底。
12. **首镜锚定·景别一致·姿态延续·视线指派（V6.9.4 新增 · 单段防废镜）**：① 每段第 1 镜必须带站位人物（人名或注明归属的身体局部），空镜开场写明「空镜：…」且每段至多 1 镜；② 特写只装单一局部主体，暴雨砸漏/塌方/全屋事件由中景以上承载；③ 撑起/坐起之后，后续镜必须「保持撑坐」或写明跌回过程，禁无声躺回；④ 说话镜写明「目光落在 XX 脸上」，把玩/举向道具说话必须补「视线不落在道具上」。规范见 `model-adapters.md` §5.0.2，机检 C18 兜底。
13. **禁令失效三改法 + 栏目纪律（V6.9.5 新增三改法 / V6.9.6 续增栏目纪律）**：**视频模型对否定不敏感、对词根敏感**——被禁概念的词根（发光/笑/空镜）哪怕挂着"不/禁"也会被当画面词渲染（实测三条否定式禁令两轮全部被无视）。高关联视觉概念必须：① **换词**——被禁词根在提示词任何位置（含强制禁止项）零出现，改正向描述（道具→「实心哑光石质，玉面呈青玉原色」**零光效**；表情→「双唇抿紧、嘴角向下压」；首帧→「画面主体：<人名>…」单主体开头）；② **主体优先**——每段镜1第一个分句即人名/身体局部/「画面主体：」，禁环境前置词开头；③ **触发器移除**——道具不与灯火共现：只把玩/佩戴，不靠近光源（⚠️ 旧建议「举到油灯旁，火光从侧面照」已废止——实测同样点火）。**栏目纪律（V6.9.6）**：【强制禁止项】只装负面清单（画面/文字/音频三类）——**正向执行指令禁入**（该栏被当规避清单读，写进去两头不生效），**否定式禁令同样禁入**（被禁词根＝画面词）；正向指令一律回落镜行/【画幅风格】/【站位声明】。水印/变形等低关联瑕疵仍走否定式兜底。**具象光源映射（C19d）**：反光道具镜行禁写「映出/倒映火苗」，**零光效描写**只写材质本色（⚠️ 旧建议"光斑语言"已废止——V6.9.7 实测光斑句出片玉佩像打火机点了一簇火，见铁律 14④）。**镜行少形容词**：正向描写每镜只留必要项（主体/动作/材质各一处），修饰词堆叠稀释关键信息。规范见 `model-adapters.md` §5.0.4，机检 C19（a~e 五判据）兜底。
13. **道具光效·表情锚·外观锚·跨镜在场（V6.9.4 增补 / V6.9.5—V6.9.7 按禁令失效三改法修订）**：① 玉佩/银镯/镜面类反光道具：**零光效描写**——只写材质本色（「玉面呈青玉原色」/「哑光金属本色」），光斑/受光/照射/照在/亮起类从句与「举到灯旁」类动作一律不写（⚠️ 旧写法「仅表面反射/映出 X 光」「受光处泛光斑」全部废止——「映着火苗」→ 玉佩变自发光魔法道具；「指甲盖大暖黄光斑」→ 玉佩像打火机点了一簇火，见铁律 14④ / 机检 C20d；⚠️ 【强制禁止项】里的「XX 不发光、不透光、不悬浮」同样废止——被禁词根＝画面词，见 §5.0.4 改法一 / 机检 C19e-b）；② 冷硬/宣判台词必显式写**面部肌肉动作**「双唇抿紧、嘴角向下压、下颌绷紧、眉梢下压」（模型对年轻女性默认甜笑；⚠️ 写「面无笑意、唇线平直」已废止——被禁词根＝画面词，见 §5.0.4 改法一 / 机检 C19a）；③【核心人物】行写年龄锚，特写镜复述「与镜N同一张脸」（防跨镜换脸）；④ 非主体人物镜行内复述方位词（"画面右后门边阴影"）、段末镜再带到；⑤ 首镜锚定靠**镜行内单主体正向声明**「画面主体：<人名>…」（⚠️ 禁止项里的「禁自行增加镜头或空镜开场」已废止，「空镜」词根本身会污染画面；也禁「X 与 Y 同框」并列主体句式——见铁律 14）。规范见 `model-adapters.md` §5.0.3/§5.0.4，机检 C18e/C19/C20 兜底。
14. **首镜单主体锚定与具象化（V6.9.7 新增 · 防"两张脸"）**：① **首镜锚定句只许一个具名主体**——**禁「X 与 Y 同框」类并列主体句式**（实测段1 镜1「首帧即这只手与她的脸同框」→ 出片**两张脸**，用户原话："总共生成了两张脸，最大的祸首就是这儿"——模型把并列名词 +「同框」读成画面里有两个主体）；身体部位一律以「她的/其 + 部位」从属出现，确需两人同镜由【站位声明】具名双主体承载（机检 C20a）；② **指代词必须带归属**——「这只手 / 那张脸」无先行词 → 模型自补一个主体（补出一个头），一律写「她的一只手 / 他的右手」（机检 C20b）；③ **抽象形态·程度副词一律删**——成线/成串/成股/如注/轻蜷/微蜷，模型**无法命名过程形态**（「漏雨成线砸在手背上」→「雨滴砸在手背上溅开」；「手指轻蜷」→ 直接删）。**判据一句话：这句里每个词都能画出来吗？画不出来的就是形容词。** ④ **反光道具零光效描写**——光斑/受光/照射/照在/亮起类从句与「举到灯旁」类动作一律不写（实测「指甲盖大暖黄光斑」「举到油灯旁」出片**玉佩像打火机点了一簇火**），只写材质本色（「玉面呈青玉原色」/「哑光金属本色」）（机检 C20d）。规范见 `model-adapters.md` §5.0.2/§5.0.3/§5.0.4，机检 C20 兜底。

## 一、 六步必查序列（缺一不可）

### Step 1 · 模板与时长预算
- [ ] 读 `seedance-render-engine.md`（★主模板）
- [ ] 时长预算公式核对：目标组数 = 预估成片秒数 ÷ 12~15s
- [ ] 每组 ≤15s（单镜 3~5s，一组 3~4 镜）；高密度动作段改**微步进切片**（0.5~1.0s/片）；2.5 用 15s 以上长段必须官方 `[起-止秒]` 时间戳分段且一镜连贯运镜过渡（官方不支持组内硬切）
- [ ] **字数门禁**：每组中文提示词 ≤500 字、英文 ≤1000 词（官方约束：超字模型丢细节）
- [ ] 每组自带完整时间轴（从 00:00 开始）、画幅风格、资产短锚点、负面词
- [ ] 每份参考素材已标注用途（外貌/动作/音色/运镜），禁只丢图不说明（官方要求）；角色参考图无**现实真人人脸**（官方红线＝禁真人照片素材；**AI/CG 生成的写实/仿真人风格不受限**）
- [ ] **场景双图铁律（2026-09-15 用户裁决）**：每个达出图标准的 SCN 必须出**两张**——①功能图（文戏机位调度版或战斗角色站位版）+ ②**场景拼接图**（左 2/3 高空鸟瞰透视 + 右 1/3 正面/背面/左侧/右侧四向等高；模板见 `asset-spatial-ledger.md` §四）；**场景与道具出图一律 16:9 横版，与成片 B 锁画幅无关**（成片构图由投喂词【画幅风格】行承载）；只出功能图不出拼接图 = 回补后方可进 P3

### Step 2 · 画幅路由
- [ ] 读 `aspect-ratio-adaptation.md`（★权威）
- [ ] 交付物顶部显式声明 `【画幅】：16:9 横屏 / 9:16 竖屏`
- [ ] 每条提示词/每个 API 载荷回填 `aspect_ratio=锁定值`，零回落
- [ ] 构图按画幅套版：横屏=三分线左右站位/对角线动势/横向位移；竖屏=垂直落差/俯仰对峙/冲镜特写

### Step 3 · 镜头规格
- [ ] 读 `camera-specs-15rules.md`
- [ ] 每镜镜头头三要素齐全：`[景别] · [视角+角度] · [运镜]`——**镜行不写"跟随@谁"**（跟随目标属运镜策略，需要时融进动作描述，见 `model-adapters.md` §5.0）
- [ ] **镜行原生三尾缀**：每镜行尾必须带行内 `。声音：…。台词：…。`（无台词写"台词：无。"；2.0 无官方声音字符，`声音：/台词：` 写由模型生成的音效与对白描述——默认视频内出，不默认后期；仅用户明确指定"不出台词"才降级）——缺尾缀 = 镜行不完整，退回补写
- [ ] **接续状态（V6.9 口径）**：时间轴分镜末镜后必带 `【接续状态】：…`——**写具体末帧画面**（谁+在哪+姿态+关键道具/互动状态，下段自该画面起手；**禁"角色动作与空间位置严格继承"套话**，机检 C11 告警）；终段按档位写终帧定格，R3 强制无平缓收势帧；**跨段接续按 〇节 D 锁**（末态双保险=另出段缝分镜参考图 / 换机位硬切 / 空镜过渡）配齐段缝措施——缺此行退回补写（见 `segment-splicing.md`）
- [ ] 中景/全景严禁 90° 侧面正拍（必须 30°~60° 斜角）
- [ ] 连续镜头景别阶梯跃迁（极微距特写→超广角中景→宏观全景→鸟瞰/过肩定格），禁相同景别+机位连排
- [ ] 15s 高燃段：开局 0~1.5s 见肉、同运镜 ≤2s、以高潮定格收尾
- [ ] **在场名单**：同场景多镜的每一镜【核心人物】段必须点名本镜全部在场角色（动作主角+静止配角全列，写身份+位置+状态）；跨镜用承接链 `承接上镜：@B 仍在门口` 显式声明人员延续；无"来人/离开"默认全员原样在场（见 `asset-spatial-ledger.md` §三·5）
- [ ] **站位声明**：每段必带【站位声明】一行式文字站位（见 `model-adapters.md` §5.0）——每人一段括号四要素（位置=画面左/右/中 + 依托物 + 朝向 + 姿态），多镜同场景加轴线行 `左A右B·禁越轴`，位移行 `起点→终点` 逐人写、每步有动作原因禁瞬移（静态段写"全员原位，无位移"）；**禁止画 ASCII 空间图/坐标表**（V3 图仅超复杂群像备查，默认不用）——缺此行 = 位置随机，退回补写
- [ ] **主次同框**：第二人（含远景/背景人）必须具名+具象+定位+状态（`@B（远景·灰袍老者·断桥尽头·背身而立）`），禁"远处站着个人"弱指令；双主体关键同框镜用同框图锁定形象
- [ ] **时长守恒·禁拉伸凑时（V6.9 修订）**：剧本【本集时长】只是参考锚**不是必须铺满的硬指标**——分镜总时长由各镜内容量倒推（台词÷3.5~5 字/s + 动作节拍），允许比剧本标注短至 -25%；**内容不饱满就让总时长诚实变短，严禁拉长氛围/过渡镜凑满**：一句 ≤40 字 △ 动作行展开 ≤6s、无台词氛围镜单镜 ≤5s、纯氛围段 ≤10s；**钩子前置**：剧本【黄金前3秒钩子】的台词/信息必须落在全片 00:00-00:05 首镜，首行氛围 △ 压缩为 ≤4~5s 并与钩子台词同段，禁把钩子挤到 13s 之后——机检 C15 兜底

### Step 4 · 对白四查（有对白必过）
- [ ] 读 `dialogue-speed-check.md`（语速）+ `wenxi-micro-expression.md`（微表情/发酵）+ `model-adapters.md` §5.2（**语气**）
- [ ] **语气位必写（官方三要素之三 · 2.0/2.5 同规格）**：每条有台词的镜行写成 `台词：【角色（语气）："…"】`——语气按四维写（情绪色 / 力度 / 音质 / 节奏）且 ≤3 词，**禁空泛结果词**（开心/难过/生气）；**声音词只进语气位**，画面段出现"嘶哑/冷笑/低语"等即为错位（机检 C16a，实测高发）；慢档语气词（气音/一字一顿）须回改语速档（见 `dialogue-speed-check.md` §一·补）；**音色锁仅 2.5 且可选**（2.0 只做语气）
- [ ] 每条台词拆句→计数→套档（标准 3.5~5 字/s / 慢速 <3.5 / 快速 >5）→速算→判定
- [ ] 台词时长 ≤ 该镜预算（超时=🔴 P0，必须重构或拆镜）
- [ ] 单句 >24 字强制拆 2~3 镜（每镜 ≤18 字）
- [ ] 金句/高潮台词后预留 0.3~0.8s 无对白反应镜头（瞳孔骤缩/倒吸凉气/静场）
- [ ] 文戏微表情按六阶段生理递进（触发→初识→压抑→泄露→破防→余韵）
- [ ] **表情 FACS 化**：表演/表情位无"开心/难过/邪魅"等空泛情绪词，一律落成**肌肉动作的画面语言**（四区写全 + 幅度词 + 起落秒数）；真笑＝眼尾眯＋眼下隆起＋嘴角上提，假笑＝**只嘴角动、眼周零参与**，惊讶/恐惧按眉心是否拧住区分（见 `★ facs-micro-expression.md`，配方查 `facs-emotion-recipes.md`）
- [ ] **零 FACS 标注进正文**：投喂正文内不出现 AU 编号、`〔痕/显/强〕`强度标记、English kernel——这些是给创作者看的内部标注，只留在 FACS cue 表 / QC 表（见 `★ facs-micro-expression.md` §二·分层铁律）
- [ ] **有 OS/VO 必过画外声规程（V6.9）**：读 `vo-os-weaving.md`——OS/VO 一律写进"声音："段并标注画外身份，**"台词："字段只装画内开口对白**（"台词：无。"）；OS 镜画面段必含**闭口证据**（嘴唇紧闭/嘴角无波动），**禁用 `{}` 锁口型通道**；VO 删掉后画面信息量不减（不复述）；段内 OS ≤2 镜、VO ≤1 镜，VO+OS 总字数 ≤60~80 字/分钟（折算 15s 段 ≤20 字）——机检 C14 兜底

### Step 5 · 战斗档语法（战斗段必过）
- [ ] **R3 玄幻**：读 `xuanhuan-magic-combat.md`（★权威）
  - [ ] 法宝媒介施法（禁拳脚抽象"施法"词）：材质+施法动作+特效出口
  - [ ] 五行属性绑定+双色粒子（属性即视觉语言）
  - [ ] 术法攻防循环：祭防御→破防临界→**防守转攻**（高光必写）→瞬移残影
  - [ ] 能量具象化：光柱/具象生物/巨型化法相/领域道域
  - [ ] 蓄力前奏必写：天地灵气汇聚/能量漩涡成型
  - [ ] 对军清场：战场破坏反馈（沟壑/陨石坑/碎片）
- [ ] **武侠/现代**：读 `action-previs-15grid.md`（11 环动力链/防守三态/R1~R3 强度档）
- [ ] Seedance 2.5 特性：Hit-Stop 0.1s 打击阻尼停顿标注、声音标记官方字符（音效 `<>`、台词 `{}`、音乐 `()`、字幕 `【】`；社区兼容 `[SFX: ...]` 亦可）
- [ ] **版本二择一语法**（先锁版本再套语法，见 `model-adapters.md` 〇节）：
  - [ ] 2.5：可用 Hit-Stop 三件套 + 声音标记 + 首尾帧（**仅参考模式②**；首尾帧与参考图互斥）；单段官方上限 30s、支持多轮延长；**2.0 无首尾帧（禁用）**；
  - [ ] 2.0：**禁顿挫词、禁官方声音字符标记**（音效/台词以文字描述写入镜行、默认由模型生成，不默认后期）；单段直出，上限 15s（按剧情分配时长，不锁 10s）；末尾参数行已废止（model 写入【画幅风格】句尾）。

### Step 6 · 出稿质检
- [ ] 读 `quality-gate-review.md`
- [ ] P0：时长 ≤15s / 台词未篡改 / 无跳轴 / 画幅一致 / 锚点指向已登记资产
- [ ] P1：受力过程完整（非光污染对波）/ 节奏快慢变化 / 光源物理真实
- [ ] P2：空镜全部带戏剧任务（转场/情绪落地/时空锚，单集 ≤3 处；无任务空镜才算缺陷）/ 反形容词（**仅画面段约束，声音层豁免**，见 `cinematic-dramaturgy-rules.md` §四）/ 声音三层（对白 0dB > SFX -6dB > BGM -14dB）/ VO+OS 未超配额 / **对白语气位全覆盖**（有台词的镜全带 `（语气）`，声音词不在画面段，机检 C16）/ **摆位必入画**（站位每个人都被至少一个镜行带到或写明离画，机检 C17）
- [ ] 锚点全部指向《资产图册》已锁定资产图（无图=门禁 3/4 阻断，回补 P2c）
- [ ] **改稿必跑改动后复验**：修改类任务禁止只复验改动处——必须跑「局部验证 → 联动冲突检查 → 全量审核」三步闭环，并附《改动复验报告》（见 `quality-gate-review.md` §三）

## 二、 输出契约（交付物必须包含）

> 出稿前的最后一道防回归闸门：对照下表逐条扫，命中任一条即返工。
>
> | 判型 | 检查项 | 判型 | 检查项 |
> |---|---|---|---|
> | 主格式 | 是否为**七段式**（段序与各段定义以 `model-adapters.md` §5 为准） | 镜行 | 是否为原生 `[镜头N] 景别 · 视角角度 · 运镜。动作。声音：…。台词：…。`（无"跟随@谁"、无括号五要素连写） |
> | 机检 | 是否已跑 `scripts/validate_prompt.py` 且 `FAIL` 清零（2.0 禁用首尾帧/SFX/高危词/七段式/接续状态套话/镜长雷同/OS 声画分离由脚本兜底） |
> | 站位 | 是否**一行式【站位声明】**（四要素+轴线+位移），无 ASCII 空间图/坐标表 | 口径 | 版本/画幅已锁定且未被默认；未被外部示范格式带偏；社区锚点与官方素材标注并存 |
> | 语气 | **有台词的镜全带 `（语气）`**（2.0/2.5 同规格）；声音词不在画面段；音色锁仅 2.5 可选 | 声画 | 2.0 无声音标记、无顿挫词；2.5 用官方字符（`<>` `{}` `()` `【】`） | 交付 | 出图词满血（4 View 资产板+16 项 / 战斗站位版），非简笔；示例亦满血 |

```text
【投喂提示词组】× N 组
├── 每组（七段式）：【画幅风格（含 model=）】/【场景资产】/【核心人物】/【站位声明】/【时间轴分镜（含行内声音·台词；末镜后接续状态尾行）】/【音效】/【强制禁止项】
```

**标准负面词清单**（可直接回填各组"负面排除"段）：

- 字幕、Logo、水印、边框、分屏、黑边。
