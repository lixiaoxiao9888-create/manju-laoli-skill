## 一、 15 秒大招三段式节奏结构

一条标准的大招高燃提示词必须分为三大连续阶段，层层递进，音画共振：

```
┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
│ 阶段 1：大招蓄力 (0-3s)   │ 阶段 2：法阵展开 (3-8s)   │ 阶段 3：终极爆发 (8-15s) │
│ 特写微距 + 极速环绕升镜   │ 全景拉远 + 空间扭曲畸变   │ 巨型法相/火龙卷 + 爆音终帧│
└──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

### 1. 阶段一：大招蓄力与微距拉升（0~3 秒，抓眼球）
* **镜头运镜**：极低角度微推 $\rightarrow$ 特写极速环绕拉升 $\rightarrow$ 定格人物全身（⚠️ 定格仅指动作瞬间抓拍/命中 Hit-Stop，人物保持运动姿态，禁静止站立）。
* **微观动作**：手腕猛旋、指尖余火缠成暗角、掌心太古签纹极转、足尖点噬火浪、收焰聚于掌心、青筋暴突、眼眸神光爆绽。
* **特效细节**：掌心凝刃、“主色+副色”双色波涌燃炼、金羽凝结、空气扭曲、碎石浮空。
* **音效设计**：**开屏即爆音！** 尖锐火雷声/破空剑鸣 + 地面低频轰鸣，0.5 秒特写抖动蓄势，瞬间拉满压迫感。

### 2. 阶段二：法阵展开与空间异象（3~8 秒，造奇观）
* **镜头运镜**：低角度微推 $\rightarrow$ 全景平稳抬升拉远 $\rightarrow$ 俯瞰空间格局。
* **空间动作**：单手擎天/虚空悬浮、身姿沉稳傲慢、尊袍随狂风神风傲然扬动、俯视冷冽。
* **法阵与异象**：亿万符文如火龙盘旋漫天泼洒、空间随阵法剧烈扭曲崩折、千道法纹铺满夜空顶、地面龟裂透出熔岩/雷光。
* **音效设计**：弦乐拉满 + 重音震底，法阵展开伴随漫天雷鸣轰鸣，节奏持续攀升。

### 3. 阶段三：终极爆发与道域镇压（8~15 秒，情绪高潮）
* **镜头运镜**：大广角全景 $\rightarrow$ 极速推向爆发核心 $\rightarrow$ 冲击波定格终帧。
* **终结绝杀**：凝聚十道巨型火龙卷/万剑归宗/黑渊禁区，碾碎漫天虚空，天地恒压无极。
* **音效设计**：重低音音爆轰炸，余音回荡，绝不设平静收尾，以最高燃爆点定格收尾！

### 4. FPV 主观穿梭机位（万剑/弹幕级大招专用）
> 学自 35s 玄幻秒级拆解：大招释放段的“弹幕式”攻击（万剑齐发/箭雨/光弹），用**跟随第一排攻击的 FPV 主观俯冲**，比旁观全景更有代入感。
* **写法**：跟随第一排飞剑超高速向前俯冲，攻击如暴雨倾泻，呈地毯式火力压制；
* **配套**：极速运动模糊 + 攻击划破云雾/熔岩地面 + 密集机枪破空尖啸音效（Supersonic Barrage）。

### 5. 短蓄力仪式感（慢/滞段·慎用升格）
> ⚠️ 2026-09-02 实测：**升格慢镜破坏节奏，默认禁用**。大招蓄力/神魔显现/法相成型段，用**短促凝神 + 能量聚核**快速带过，保持节奏推进；除非用户明确要求慢镜，否则不写“升格/慢动作”。
* **写法（紧凑版）**：面部推镜 $\rightarrow$ 拉开仰视全身，能量急剧坍缩成核，阴阳双龙盘旋成太极图（黑龙盘暗黑旋涡 + 白龙绕光明风暴 + 中央持兵）；
* **配套**：沉浑龙吟 + 史诗交响最高潮，1~2 个镜头内完成蓄力，紧接爆发。

### 6. 天地级异象（神魔/法相终极形态）
> 玄幻天花板级大招：**通天神魔巨躯**拔地而起，半身烈日半身熔岩，背后神环轮转，手托擎天巨刃；下方山脉与人物如蝼蚁微尘。
* **能量坍缩**：狂暴雷火向枪尖急剧坍缩凝聚为一点，空间产生引力透镜扭曲（背景岩石被拉长、光带弯折）；
* **灭世收尾**：神兵直插大地，地核能量柱如核爆贯穿天穹，大陆板块断裂，金红光浪横扫大陆，天际照亮成白昼，终帧高斯模糊+震屏。

## 二、 双色粒子与高级质感配色铁律

1. **双色缠绕原则**：
   * 严禁单色涂抹，必须采用“主色 + 副色”高反差互补或渐变，例如：
     * `赤红 + 暗金`（熔岩尊者、烈阳神明）
     * `玄黑 + 幽紫`（暗夜深渊、魔道至尊）
     * `冰蓝 + 银白`（霜雪剑圣、寒月仙尊）
     * `苍青 + 鎏金`（太古道祖、东方修仙）
2. **UE5 级渲染与环境物理参数**：
   * 全局声明必须包含：`UE5 超写实真实光照，体积雾苍茫弥漫，8K 超高清，符文文字流动清晰、光芒微闪，材质细节极具真实感与颗粒感，开启低空碎石虚空漂浮宏景`。

## 四、 去水五律（粒子/光效防"水"铁律·2026-09-02 实测固化）

> 背景：多款模型默认把"粒子特效"渲染成均匀慢速的半透明彩色雾气，把"光柱/法阵"渲染成呆板发光软管或简笔柱子——观感"水"。以下五律为去水硬规则，写任何大招/法阵/能量特效前必须逐条自查。

1. **禁评价词**：顶级/神级/震撼/绝美/高动态范围——模型不识别评价，纯占字数。只写可见动作与材质。
2. **禁裸光效**：光柱/法阵/能量球/光束严禁裸写，必须具象化四件套——由什么构成（符文环/火流/铁屑）+ 边缘什么样（剥落/焦黑/白热光边）+ 怎么动（轮转/收束/分野）+ 密度层次（近实中厚远虚）。
3. **禁写"粒子"二字**：改写作材质比喻——燃烧的铁屑洪流（密度如蜂群）/ 水晶碎屑逆流 / 火星 / 余烬 / 符纸碎屑。模型对这些材质有物理经验，对"粒子"没有。
4. **必写方向与速度差**：全片一个速度=水。高速粒子带拖尾光迹（0.2s 划出画面），慢速余烬带沉降弧线（触地即灭）；禁"均匀漂浮"，写"下落/逆流/贴地游走"。
5. **生长三段论（压缩→爆发→余波）**：蓄力必须写"逆向收束"（粒子像磁吸铁屑向核心压缩，衣袂发丝被吸向能量场）——没有压缩就没有重量感，这是水不水的分水岭；爆发写核心破裂+冲击波环；余波写烟尘膨胀+余烬沉降。

## 六、 双属性对冲与绝杀收尾范式（2026-09-04 吸收）

### 1. 双属性对冲成太极图案炸散
- 两属性能量对冲时，禁写"两色光柱互推"——必须写**两股属性流旋拧交缠成太极图案，旋转加速至临界后整体炸散**；
- 写法要素：双色流体螺旋缠绕 → 图案成型（阴阳双鱼咬合轮转）→ 临界过载 → 图案崩裂炸散为漫天双色光屑；
- 对冲双方各自的色彩锚定遵循 `seedance-render-engine.md` §二·五·3（整套锚定+高反差互补）。

### 2. 能量吞屏切黑结尾（绝杀专用收束）
- 绝杀命中后：**能量光浪吞没全屏 → 切黑 → 环境余声收束**（碎石滚落/风声/耳鸣）；
- 三拍结构：命中爆闪（吞屏白/属性色）→ 纯黑 0.3~0.5s → 余响渐起；
- 禁止绝杀后直接跳平静全景——吞屏切黑给"重击消化时间"，余声收束给"余韵留白"，均不拖节奏。
