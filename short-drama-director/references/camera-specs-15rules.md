# 15 秒完播率镜头规格、空间斜角与防穿模铁律 (Camera Specs & 15-Sec Rules)

---

## 一、 15 秒完播率黄金公式

> 📐 **画幅路由**：横屏 16:9 / 竖屏 9:16 的构图、景别阶梯与运镜写法 → 以 `aspect-ratio-adaptation.md`（★权威）为准，按用户指定画幅切换。

$$\text{完播率} = \text{开局无试探 (20%)} \times \text{节奏呼吸 (30%)} \times \text{运镜丰富度 (25%)} \times \text{情绪绝杀 (25%)}$$

1. **开局无试探（0~1.5s 必须见肉）**：第一帧必须双人同框近景/中景，1.5 秒内必须爆发一次极端杀招正面硬撞，严禁远景慢热铺垫；
2. **同运镜 $\le 2$ 秒，同景别 $\le 3$ 秒**：15 秒内完成 5~8 次精准镜头切换；
3. **以高潮收尾，不设收尾帧**：15 秒最后一帧必须是终结技命中、气血炸裂、碎石飞溅或击飞倒地的最高潮定格，不设收腿平息画面。

## 二、 镜头规格五要素（每次必写）

格式：`[景别] · [拍摄视角+角度] · [运镜方式] · [跟随目标]`

* **景别**：全景 / 中景 / 中近景 / 近景 / 特写；
* **视角**：正面(0°) / 侧面(90°) / 斜角(30°-60°) / 俯拍 / 仰拍；
* **角度**：平视 / 仰视(N°) / 俯视(N°)；
* **运镜**：跟拍跟镜 / 急速推镜 / 急速拉镜 / 甩镜闪切 / 命中瞬间定格（Hit-Stop 微停顿，1~2 帧）/（⚠️ 慢动作跟镜、升格默认禁用，2026-09-02 实测破坏节奏）
* **跟随目标**：跟随角色、肢体或具体接触点。

> ⚠️ **镜行书写口径（2026-09-15 用户裁定）**：五要素是**设计检查表**，用于确保每个镜头都想清楚；落到【时间轴分镜】镜行时**只写三要素** `[镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`，**不写"跟随@谁"**——跟随作为运镜策略在动作描述里自然体现（如"镜头随其位移横移"）。见 `model-adapters.md` §5.0 / §5.1。

## 三、 空间感两大铁律

1. **中景及全景严禁 90° 侧面正拍**：中景和全景必须使用 **30°~60° 斜角拍摄**，建立前后遮挡与空间纵深，彻底杜绝街机横版感；只有近景/特写允许 90° 侧拍。
2. **景别与动作幅度绝对匹配**：大幅动作配全景/中景展示张力；小幅拳肘对招配近景/中近景放大密度。

## 四、 宏微观景别阶梯跃迁 (Shot Ladder Progression)

连续镜头的景别与机位严禁平铺重复，必须按阶梯跃迁制造视觉推进感：

$$\text{标准阶梯} = \text{极微距特写（发力微观）} \to \text{超广角/低角度中景（双人攻防位移）} \to \text{宏观全景（环境/法阵破坏）} \to \text{鸟瞰/过肩定格}$$

### 1. 阶梯跃迁铁律
* **严禁连续两个镜头使用相同景别 + 相同机位**；
* 动作高潮前插入**极微距特写**（指尖发力/剑身微颤/眼眸神纹），浅景深虚化背景制造张力；
* 大招释放用**宏观全景**展示环境破坏（法阵崩碎/山峰崩塌/竹海覆灭）；
* 绝杀收尾用**鸟瞰或过肩定格**，配合满天飞叶/烟尘扑镜实现自然遮挡转场（Occlusion Wipe）。

### 2. Eye-Trace 视线流引导
* 相邻镜头的主体高光/视觉焦点必须保持在屏幕**同一象限**或沿动势方向连续过渡；
* 例如：镜头1 右侧出鞘刀光 → 镜头2 自右向左冲刺的流光核心，避免观众视线满屏搜索。

### 3. 极限景别跳跃（Macro-Micro Jump）
> 长段高燃战斗/大招段，在**极微距特写（ECU）** 与 **极宏观大远景（EWS）** 之间极限跳跃，制造空间张力与视觉震撼（学自 35s 玄幻秒级拆解）。与下方单向阶梯互补：阶梯管顺序推进，极限跳跃管两极反差。

* **两极对跳**：ECU 双眼怒睁蓄能 → EWS 天幕分野异象（右半边天被金红火色染透，左半边铅灰雷云，云层分野滚动）；ECU 兵刃咬死 → EWS 通天神魔巨躯；
* **极端体量对比**：EWS 中下方山脉与人物如蝼蚁微尘，巨像背后神环轮转（体量对比本身就是奇观）；
* **适用**：神魔觉醒/大招释放/灭世收尾段；普通对招不强制。

## 四·五、 四阶动静呼吸律 (Rhythm Curve)

> 长段战斗（≥15s 或拆段成片）的节奏骨架：**静 → 极动 → 慢/滞 → 绝杀** 四阶段递进，缺一平淡（学自 35s 玄幻秒级拆解，对应 `action-previs-15grid.md` 的“快慢交替 ≤5s”）。

1. **静（暴风雨前肃杀）**：眼眸特写、平心擦剑、蓄势凝神，节奏压到最低；
2. **极动（节奏拉满）**：空斩、贯穿、地面犁地对冲、暴风骤雨多段拆招；
3. **慢/滞（短蓄力·不用升格）**：万剑蓄力、神魔显现、能量凝核——用 **1~2 个紧凑镜头快速带过**，保持节奏推进（⚠️ 2026-09-02 实测：升格慢镜破坏节奏，默认禁用，蓄力段只保留短促凝神+聚能）；
4. **绝杀定格**：法相举戈、贯穿灭世，最高情绪与视觉爽点释放，定格终帧。

> 适用：大招释放段 / 长段拆分成片。普通文戏对白按标准景别切换即可，不强制阶梯。

## 五、 受击镜头工具箱（挨打方怎么拍·2026-09-04 吸收）

> 受击不是"被打飞"三个字了事——按受击强度选用以下镜头手法，让挨打方也有镜头语言：

- **短促径向震动**：命中瞬间镜头沿受力方向短促震一下（1~2 帧），模拟冲击波击中摄影机；
- **轻微轴向受力**：镜头随受击方向小幅偏转/倾斜，传递"摄影机也被波及"的重量感；
- **瞬时焦点变化**：受击瞬间焦点从攻方急切到受击方面部（痛苦细节），或焦点随击飞目标快速转移；
- **动态模糊与速度匹配**：击飞/震退段加径向动态模糊，模糊方向与位移方向严格匹配，禁全屏均匀模糊；
- **Time Ramp 变速**：仅限极短受击瞬间（命中帧前后 0.2s 内的加速/减速切换），禁整段升格慢镜（2026-09-02 已默认禁用）。
