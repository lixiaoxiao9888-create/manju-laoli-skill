## 〇、 执行铁律

1. **A·模型版本锁定（未指定不动笔）**：写任何提示词前，先完成 Seedance 2.5 / 2.0 强制二选一（见 `model-adapters.md` 〇节）；用户未指定 = 任务不开始，禁止默认跳版本；
2. **B·画幅锁定（与 A 同规格）**：先完成画幅强制三选一——**16:9 / 9:16 / 21:9**（1:1 仅用户明确指定时采用）；用户未指定 = 停下询问，禁止默认 9:16；锁定后全流程沿用（见 `aspect-ratio-adaptation.md`）；
3. **双锁齐备才过检（多段任务加 D 锁）**：A、B 两道锁全部锁死，才允许进入下方 6 步序列；**多段任务另锁 D·段缝衔接方式四选一**（尾帧锚定+画面锁/换机位硬切/空镜过渡/**技巧型转场**——④ 见 `creative-transition-library.md`），未指定停下询问；
4. **按序过检**：以下 6 步按顺序执行，每步产出对应校验结果，全部通过才允许出稿；
5. **语速卡不入正文**：语速自检卡是内部 QC 附件，默认不写入投喂正文（避免污染提示词），但必须随交付物一并输出；
6. **战斗档先定档再取库**：先按 `sd-combat-engine/references/tier-and-finisher-system.md` 〇节定 R1/R2/R3，再取对应引擎完整库——**R1 写实 → `sd-real-engine`；R2 武侠/现代格斗 → `sd-combat-engine`；R3 玄幻 → `sd-xuanhuan-engine`**；**三者不混用**；
7. **交付满额铁律（不许漏执行项目）**：契约要求的字段/模板段落必须逐条写满才算出稿——出图提示词按满血模板（角色四字段模板+五官10项与服装6项 / 战斗场景站位版）、分镜逐镜带在场名单+站位声明+行内声音台词（**段末不写接续尾行**）；**示例与演示同样满血**，禁止简笔交差（见 SKILL.md 法则 15）；
8. **出稿机检门（硬性 · 2026-09-15 新增 / 2026-10-10 扩容至 C1~C26 · 子检查码共 98 条）**：提示词写完后，**必须跑一遍 `scripts/validate_prompt.py <稿>.md --model 2.5|2.0`**（画幅锁定时加 `--aspect 16:9|9:16|21:9` 供 C6b 三处互校），`[-] FAIL` 项清零才允许交付（脚本查 C1~C26：时长/切镜/字符/版本语法/画幅回填/**画幅一致性 C6b（字段↔【画幅风格】↔`--aspect` 互校 + 横竖构图词越界）**/七段式/2.0 禁用首尾帧/高危词/**接续状态残留拦截（C11 反转：出现即 FAIL）**/规则词混入/镜长雷同节奏门/**画外声 OS·VO 声画分离与配额**/**拉伸凑时**/**对白语气错位与缺失**/**摆位必入画·人物账连续·跨段站位漂移（C17d）**/**首镜锚定·姿态回退·视线黏道具·特写承载空间事件·反光道具光效·景别与表演幅度越界**/**运镜机检门 C18g~l（逐镜必标运镜·一镜多主运镜·无动机运镜·固定镜 >10% 或连排 ≥3·运镜单调·重技法名额超限）**/**段缝景别落差 C18m（相邻两段末镜终点景别 → 首镜起点景别：末镜做了收束动作的须同档〔反向收紧 ≥1 级即报〕、未做收束的 ≤1 级〔≥2 级即报〕，超出且无过渡手段即报）**/**站位人物账解析元检查 C7c（【站位声明】漏 `@` 时人名解析为空 → C17／C17b／C17c／C17d／C19c 五条判据静默失效，脚本却照报 PASSED）**/**裸禁令词·光路触发器·首镜主体优先·具象光源映射·禁止项栏目纪律**/**首镜单主体锚定·并列主体句式·悬空指代·抽象形态形容·道具光效·道具贴近光源**）。**多段稿（N 组提示词）逐段自查**——C1/C2/C3/C4/C17/C24 按段独立判定，防"第一段合规、第二段起人物蒸发"。机检兜底，人读规则先行，两者不互相替代；
9. **禁用清单先行**：出稿前照 `model-adapters.md` §5.1「格式禁写清单」扫一遍（禁外部括号五要素连写 / 禁镜行"跟随@谁" / 禁末尾参数行 / 禁 ASCII 站位图 / 禁默认版本与画幅 / 禁装饰性长散文 / 禁简笔出图词）——命中任一条即返工。
10. **对白语气必写（2.0 / 2.5 同规格）**：**有台词的镜行，`台词：` 字段必须是 `【角色（语气）："…"】`**——语气是官方对白三要素之三（HOW THEY SOUND），缺失会让声音与表情一并扁平（官方原文点名 `tone_qualifiers`）。**语气词只进语气位、禁写进画面段**（写进画面段会被当视觉信息渲染成"一张冷笑的脸"）；**道具动作与语气一致**：把玩/摩挲类闲适动作只配慢悠悠语气，宣判/嘶吼/质问等强情绪语气必须换攥紧/捏住/垂手握着（实测宣判时刻"把玩玉佩"出戏）；**音色锁仅 2.5 且为可选增强**（2.0 无音频参考通道，只做语气，不做音色锁不算缺陷）。规范见 `model-adapters.md` §5.2，机检 C16 兜底。
11. **人物账连续·摆位必入画**：**站位声明摆了位的每个人，本段镜行必须至少带到一次**（正拍/焦外身影/全景群像/反应镜头均算），给不了镜头就写明 `段末离画/退场·去向`；重新入画要写明方式；相邻段没移动的人站位不漂移。多段任务逐段自查（尤其"背景工具人"：抽烟的爹/缩在身后的妹妹最容易整段蒸发）。规范见 `model-adapters.md` §5.0.1，机检 **C17（a 摆位必入画 / b 关系镜缺失 / c 背景锚点缺失 / d 跨段站位漂移）** 兜底——**多段稿逐段跑，第 2 段起每段都要查**。
12. **首镜锚定·景别一致·姿态延续·视线指派（单段防废镜）**：① 每段第 1 镜必须带站位人物（人名或注明归属的身体局部），空镜开场写明「空镜：…」且每段至多 1 镜；② 特写只装单一局部主体，暴雨砸漏/塌方/全屋事件由中景以上承载；③ 撑起/坐起之后，后续镜必须「保持撑坐」或写明跌回过程，禁无声躺回；④ 说话镜写明「目光落在 XX 脸上」，把玩/举向道具说话必须补「视线不落在道具上」。规范见 `model-adapters.md` §5.0.2，机检 C18 兜底。
13. **禁令失效三改法 + 栏目纪律**：**视频模型对否定不敏感、对词根敏感**——被禁概念的词根（发光/笑/空镜）哪怕挂着"不/禁"也会被当画面词渲染（实测三条否定式禁令两轮全部被无视）。高关联视觉概念必须：① **换词**——被禁词根在提示词任何位置（含强制禁止项）零出现，改正向描述（道具→「实心哑光石质，玉面呈青玉原色」**零光效**；表情→「双唇抿紧、嘴角向下压」；首帧→「画面主体：<人名>…」单主体开头）；② **主体优先**——每段镜1第一个分句即人名/身体局部/「画面主体：」，禁环境前置词开头；③ **触发器移除**——道具不与灯火共现：只把玩/佩戴，不靠近光源（⚠️ 旧建议「举到油灯旁，火光从侧面照」已废止——实测同样点火）。**栏目纪律**：【强制禁止项】只装负面清单（画面/文字/音频三类）——**正向执行指令禁入**（该栏被当规避清单读，写进去两头不生效），**否定式禁令同样禁入**（被禁词根＝画面词）；正向指令一律回落镜行/【画幅风格】/【站位声明】。水印/变形等低关联瑕疵仍走否定式兜底。**具象光源映射（C19d）**：反光道具镜行禁写「映出/倒映火苗」，**零光效描写**只写材质本色（⚠️ 旧建议"光斑语言"已废止——光斑句出片玉佩像打火机点了一簇火，见铁律 15④）。**镜行少形容词**：正向描写每镜只留必要项（主体/动作/材质各一处），修饰词堆叠稀释关键信息。规范见 `model-adapters.md` §5.0.4，机检 C19（a~e 五判据）兜底。
14. **道具光效·表情锚·外观锚·跨镜在场（按禁令失效三改法修订）**：① 玉佩/银镯/镜面类反光道具：**零光效描写**——只写材质本色（「玉面呈青玉原色」/「哑光金属本色」），光斑/受光/照射/照在/亮起类从句与「举到灯旁」类动作一律不写（⚠️ 旧写法「仅表面反射/映出 X 光」「受光处泛光斑」全部废止——「映着火苗」→ 玉佩变自发光魔法道具；「指甲盖大暖黄光斑」→ 玉佩像打火机点了一簇火，见铁律 15④ / 机检 C20d；⚠️ 【强制禁止项】里的「XX 不发光、不透光、不悬浮」同样废止——被禁词根＝画面词，见 §5.0.4 改法一 / 机检 C19e-b）；② 冷硬/宣判台词必显式写**面部肌肉动作**「双唇抿紧、嘴角向下压、下颌绷紧、眉梢下压」（模型对年轻女性默认甜笑；⚠️ 写「面无笑意、唇线平直」已废止——被禁词根＝画面词，见 §5.0.4 改法一 / 机检 C19a）；③【核心人物】行写年龄锚，特写镜复述「与镜N同一张脸」（防跨镜换脸）；④ 非主体人物镜行内**锚依托物/背景物即可，严禁重复段首已声明的画面左右**（2026-10-15 单一方位权威：双重发位＝用户实测「东一个西一个/突然出现在身后」，旧写法「复述画面右后门边阴影」废止，且与 C20f 顶牛）；段末镜再带到；⑤ 首镜锚定靠**镜行内单主体正向声明**「画面主体：<人名>…」（⚠️ 禁止项里的「禁自行增加镜头或空镜开场」已废止，「空镜」词根本身会污染画面；也禁「X 与 Y 同框」并列主体句式——见铁律 15）。规范见 `model-adapters.md` §5.0.3/§5.0.4，机检 C18e/C19/C20 兜底。
15. **首镜单主体锚定与具象化（防"两张脸"）**：① **首镜锚定句只许一个具名主体**——**禁「X 与 Y 同框」类并列主体句式**（实测段1 镜1「首帧即这只手与她的脸同框」→ 出片**两张脸**，用户原话："总共生成了两张脸，最大的祸首就是这儿"——模型把并列名词 +「同框」读成画面里有两个主体）；身体部位一律以「她的/其 + 部位」从属出现，确需两人同镜由【站位声明】具名双主体承载（机检 C20a）；② **指代词必须带归属**——「这只手 / 那张脸」无先行词 → 模型自补一个主体（补出一个头），一律写「她的一只手 / 他的右手」（机检 C20b）；③ **抽象形态·程度副词一律删**——成线/成串/成股/如注/轻蜷/微蜷，模型**无法命名过程形态**（「漏雨成线砸在手背上」→「雨滴砸在手背上溅开」；「手指轻蜷」→ 直接删）。**判据一句话：这句里每个词都能画出来吗？画不出来的就是形容词。** ④ **反光道具零光效描写**——光斑/受光/照射/照在/亮起类从句与「举到灯旁」类动作一律不写（实测「指甲盖大暖黄光斑」「举到油灯旁」出片**玉佩像打火机点了一簇火**），只写材质本色（「玉面呈青玉原色」/「哑光金属本色」）（机检 C20d）。规范见 `model-adapters.md` §5.0.2/§5.0.3/§5.0.4，机检 C20 兜底。

- [ ] 每镜镜头头三要素齐全：`[景别] · [视角+角度] · [运镜]`——**镜行不写"跟随@谁"**（跟随目标属运镜策略，需要时融进动作描述，见 `model-adapters.md` §5.0）
- [ ] **镜行原生三尾缀**：每镜行尾必须带行内 `。声音：…。台词：…。`（无台词写"台词：无。"；2.0 无官方声音字符，`声音：/台词：` 写由模型生成的音效与对白描述——默认视频内出，不默认后期；仅用户明确指定"不出台词"才降级）——缺尾缀 = 镜行不完整，退回补写
- [ ] **段末无接续尾行**：⛔【接续状态】**2026-10-09 废止**，**不得写出该栏**（机检 C11 已反转为残留拦截，出现即 FAIL）；段末镜按 `segment-splicing.md` §二 写**末 1 秒整秒定格（前置 0.5 秒收束窗）**（人物全部在场、无遮挡、无字幕压屏，末镜景别禁大远景，确保末帧可截）；终段按档位在**末镜行内**写终帧定格，R3 强制无平缓收势帧；**跨段接续按 〇节 D 锁**（段缝画面锁＝末帧截图优先 / 末帧不合格才重绘 / 换机位硬切 ② / 空镜过渡 ③）配齐段缝措施——写了接续状态的稿退回删改
- [ ] 中景/全景严禁 90° 侧面正拍（必须 30°~60° 斜角）
- [ ] 连续镜头景别阶梯跃迁（极微距特写→超广角中景→宏观全景→鸟瞰/过肩定格），禁相同景别+机位连排
- [ ] 15s 高燃段：开局 0~1.5s 见肉、同运镜 ≤2s、以高潮定格收尾
- [ ] **在场名单**：同场景多镜的每一镜【核心人物】段必须点名本镜全部在场角色（动作主角+静止配角全列，写身份+位置+状态）；跨镜用承接链 `承接上镜：@B 仍在门口` 显式声明人员延续；无"来人/离开"默认全员原样在场（见 `asset-spatial-ledger.md` §三·5）
- [ ] **站位声明**：每段必带【站位声明】一行式文字站位（见 `model-adapters.md` §5.0）——每人一段括号四要素（位置=画面左/右/中 + 依托物 + 朝向 + 姿态），多镜同场景加轴线行 `左A右B·禁越轴`，位移行 `起点→终点` 逐人写、每步有动作原因禁瞬移（静态段写"全员原位，无位移"）；**禁止画 ASCII 空间图/坐标表**（V3 图仅超复杂群像备查，默认不用）——缺此行 = 位置随机，退回补写
- [ ] **主次同框**：第二人（含远景/背景人）必须具名+具象+定位+状态（`@B（远景·灰袍老者·断桥尽头·背身而立）`），禁"远处站着个人"弱指令；双主体关键同框镜用同框图锁定形象
- [ ] **时长守恒·禁拉伸凑时**：剧本【本集时长】只是参考锚**不是必须铺满的硬指标**——分镜总时长由各镜内容量倒推（台词÷3.5~6 字/s + 动作节拍），允许比剧本标注短至 -25%；**内容不饱满就让总时长诚实变短，严禁拉长氛围/过渡镜凑满**：一句 ≤40 字 △ 动作行展开 ≤6s、无台词氛围镜单镜 ≤5s、纯氛围段 ≤10s；**钩子前置**：剧本【黄金前3秒钩子】的台词/信息必须落在全片 00:00-00:05 首镜，首行氛围 △ 压缩为 ≤4~5s 并与钩子台词同段，禁把钩子挤到 13s 之后——机检 C15 兜底

### Step 4 · 对白四查（有对白必过）
- [ ] 读 `dialogue-speed-check.md`（语速）+ `wenxi-micro-expression.md`（微表情/发酵）+ `model-adapters.md` §5.2（**语气**）
- [ ] **语气位必写（官方三要素之三 · 2.0/2.5 同规格）**：每条有台词的镜行写成 `台词：【角色（语气）："…"】`——语气按四维写（情绪色 / 力度 / 音质 / 节奏）且 ≤3 词，**禁空泛结果词**（开心/难过/生气）；**声音词只进语气位**，画面段出现"嘶哑/冷笑/低语"等即为错位（机检 C16a，实测高发）；慢档语气词（气音/一字一顿）须回改语速档（见 `dialogue-speed-check.md` §一·补）；**音色锁仅 2.5 且可选**（2.0 只做语气）
- [ ] 每条台词拆句→计数→套档（慢速 2.5~3.5 / 标准 3.5~5 / 快速·高速 5~6 字/s；**判定念得完以最快档 6 字/秒为准**）→速算→判定
- [ ] 台词时长 ≤ 该镜预算（超时=🔴 P0，必须重构或拆镜）
- [ ] 单句 >24 字强制拆 2~3 镜（每镜 ≤18 字）
- [ ] 金句/高潮台词后预留 0.3~0.8s 无对白反应镜头（瞳孔骤缩/倒吸凉气/静场）
- [ ] 文戏微表情按六阶段生理递进（触发→初识→压抑→泄露→破防→余韵）
- [ ] **表情 FACS 化**：表演/表情位无"开心/难过/邪魅"等空泛情绪词，一律落成**肌肉动作的画面语言**（四区写全 + 幅度词 + 起落秒数）；真笑＝眼尾眯＋眼下隆起＋嘴角上提，假笑＝**只嘴角动、眼周零参与**，惊讶/恐惧按眉心是否拧住区分（见 `facs-micro-expression.md`，配方查 `facs-emotion-recipes.md`）
- [ ] **零 FACS 标注进正文**：投喂正文内不出现 AU 编号、`〔痕/显/强〕`强度标记、English kernel——这些是给创作者看的内部标注，只留在 FACS cue 表 / QC 表（见 `facs-micro-expression.md` §二·分层铁律）
- [ ] **有 OS/VO 必过画外声规程**：读 `vo-os-weaving.md`——OS/VO 一律写进"声音："段并标注画外身份，**"台词："字段只装画内开口对白**（"台词：无。"）；OS 镜画面段必含**闭口证据**（嘴唇紧闭/嘴角无波动），**禁用 `{}` 锁口型通道**；VO 删掉后画面信息量不减（不复述）；段内 OS ≤2 镜、VO ≤1 镜，VO+OS 总字数 ≤60~80 字/分钟（折算 15s 段 ≤20 字）——机检 C14 兜底
