# P4·补、跨段空间交接卡（Cross-Segment Spatial Handoff）· ★ 唯一权威

> **回灌来源**：多段成片逐帧复核回灌（V8.2.0-SLIM）。客户反馈「满 30 秒之后再切，站位有些错乱」。
> 成片实测：28.11 / 57.18 / 85.25 / 112.32 秒四次段缝**全部**出现人物左右重排、可见家具换位或倒地者复活。
> 而该稿 `validate_prompt.py` 是 **0 FAIL / 0 WARN**、`gate_check.py` G0~G7 全绿。
> **所以这不是「站位没写」，是「站位写在每一段里，却没有交给下一段」。**

## 一、病灶：旧规则管的是「逐段自洽」，缺的是「跨段坐标系」

本包站位体系已经很严：`G8-HANDOFF/C17d` 绝对方位双标、`G8-HANDOFF/C17d` 左/中/右扇区、`G8-HANDOFF/C17d` 扇区↔朝向自洽、`C60b-SOLOFACE` 单人镜面朝锁、`C17d/C17j/C17k` 跨段锚点与姿态继承、`C31/C32a` 跨段切景别 + 换机位硬切。四条实测漏洞：

| # | 漏洞 | 现有判据为什么拦不住 | 成片后果 |
|---|---|---|---|
| ① | **轴线锁定的「内容」跨段被改写** | `C17c-AXIS` 只判 `if "轴线锁定" not in block_sec`，判存在不判内容 | 段2「左沈炼／右雷老虎与陆红袖」（1v2 双区）→ 段3「左沈炼／中雷老虎／右陆红袖」（三扇区），57.4s 沈炼与雷老虎左右对调 |
| ② | **强制换机位，却不声明机位站在屋子哪一侧** | `C31/C32a` 只比景别与角度字符串，没有任何字段锁「机位所在半球」 | 每换一次机位，模型重新解释一次「画面左区／右区」；**越强调换机位，站位被重排的次数越多** |
| ③ | **可见固定锚没有跨段交接清单** | `C32b` 只查「背景锚点有没有写」，不查上段末镜与下段首镜的锚集合是否连续 | 段2 末镜是【西侧实木殿柱】+【雪窗】，段3 首镜变成【枯枝火堆】前景 + 佛像远景 → 57.4s 火堆凭空落到画面正中央，空间整体重建 |
| ④ | **只锁「人与人」，没锁「人与家具／家具在画面哪儿」** | `C17d` 的 `_parse_zw_anchors()` 只比【】锚点名与教室式「前排/后排」排位词，`画面左区/中区/右区` 不在判定范围 | 段2 沈炼在「殿西【西侧实木殿柱】北侧」、段3 变「殿中【青砖地面】中区」，两段都叫「画面左区」，物理上已换地方 |

> **一句话**：模型是无状态的，它靠**画面里看得见的固定物**重建空间，不靠「殿南／殿北」这类抽象方位词。
> 包把「谁在左、谁在右、谁朝哪」写死了，没把「摄像机站哪儿、屋子里的东西在画面哪儿」写死。

## 二、《跨段空间交接卡》格式（每段【站位声明】末尾追加一行）

```text
跨段空间交接：机位侧=<本段机位恒定所在半球与朝向>；画框映射=画面左·<绝对方位与固定锚>／画面右·<绝对方位与固定锚>；固定可见锚=<固定家具在画面里的恒定位置，逐项列出>；上段末镜可见锚=<上段最后一镜实际入画的锚，首段写「无（本集首段）」>；本段首镜可见锚=<本段镜头1 必须复述的锚>；<其余既有站位声明内容不变>。
```

**五个字段的作用**

| 字段 | 锁什么 | 缺了会怎样 |
|---|---|---|
| `机位侧=` | 摄像机恒定站在场景哪一侧、朝哪拍，**全段不换半球** | 模型每段重定「画面左」的含义 |
| `画框映射=` | 把「画面左/右」翻译成绝对方位 + 固定锚 | `G8-HANDOFF/C17d` 的绝对方位与 `G8-HANDOFF/C17d` 的扇区各说各话 |
| `固定可见锚=` | 佛像／火堆／殿柱／门窗各自在画面里的恒定位置 | 段缝换锚 → 空间重建（57.4s 火堆） |
| `上段末镜可见锚=` / `本段首镜可见锚=` | 段缝两侧可见锚必须有交集 ≥2 | 上段演完的家具在下段凭空消失／换位 |

**写法四条**

1. **只写正向白描**，不写「禁止重排／不要瞬移」——禁令仍集中【强制禁止项】一处，本卡不产生二次禁止。
2. **固定可见锚写「相对画面方位 + 景别裁切例外」**：`景别裁切可不全部入画，但入画时方位不变`。否则近景/特写镜会被卡逼着塞满家具，直接撞 `C66b-OVERLOAD` 回到糊帧。
3. **交接卡写在【站位声明】栏内，不进镜行正文**；台词、景别、焦段、运镜、主体动作一字不动。
4. 机位侧确需变更（如人物走向门外、转为背拍）时，写 `机位切换：<物理路径>`，且仍**不得越过 180° 轴线**；`G8-HANDOFF/C17d` 只对「无说明的机位侧跳变」判 FAIL。

## 三、轴线交接锁（与交接卡配套）

**死律**：同场景相邻两段 `轴线锁定：` 后的**内容必须逐字一致**。

确需变更的两种合法情形，必须在**下段**写 `轴线交接：`，且句子里要有**物理路径动作**（走／压／退／横步／切／旋身／抽刀／欺身／栽倒／离场…），不能只写「轴线调整」：

| 情形 | 合法写法示例 |
|---|---|
| 1v2 双区 → 左中右三扇区 | `轴线交接：承接上段 1v2 双区，@雷老虎 从右区前列抽刀旋身、贴【西侧实木殿柱】前横步压入中区，@陆红袖 顺势切至右区后列，全段机位不越过东西轴线` |
| 角色退场，三人 → 双人 | `轴线交接：承接上段三扇区，@雷老虎 已在【枯枝火堆】西侧仰面栽倒、此镜起不再入画，中区空出，左 @沈炼 右 @陆红袖 隔火堆对峙` |

> 只写「轴线交接：改为双人」而不给路径 → `G8-HANDOFF/C17d` 判 WARN（写了但没给动作，模型仍会硬翻）。

## 四、机检落点（G8-HANDOFF · `scripts/gate_check.py`）

| 子码 | 级别 | 判据 |
|---|---|---|
| `G8-HANDOFF/C17d` | **FAIL** | 每段【站位声明】必含 `机位侧=` 与 `画框映射=`；相邻段 `机位侧` 值必须一致（除非下段写 `机位切换：`） |
| `G8-HANDOFF/C17d` | **FAIL** | 相邻段 `轴线锁定` 内容必须一致；不一致时下段必须含 `轴线交接：`（无路径动作 → WARN） |
| `G8-HANDOFF/C17d` | WARN | 每段必含 `固定可见锚=` / `上段末镜可见锚=` / `本段首镜可见锚=`；相邻段 `固定可见锚` 内容必须一致；非首段「上段末镜可见锚」与「本段首镜可见锚」的【】锚名交集 ≥2 |

**为什么落在 `gate_check.py` 而不是 `validate_prompt.py`**：`validate_prompt.py` 的 45 项稿件机检与内嵌正反例标杆已通过实拍验证，塞入跨段状态判据会连锁扰动零告警基线。G8 作为投喂前第八道闸门独立运行，与 G7 挂载表并列，不改动任何既有判据口径。

**发布纪律**：`gate_check.py --self-test` 的正反例必须覆盖 ① 缺交接卡 → `G8-HANDOFF/C17d` FAIL；② 轴线改写无交接 → `G8-HANDOFF/C17d` FAIL；③ 固定可见锚跨段不一致 → `G8-HANDOFF/C17d` WARN。`compile_feed.py` 自编译标杆稿（`sd_core.default_project_state()`）必须自带交接卡，否则 self-test 会直接 FAIL。

## 五、 《段尾空间与手持物交接快照》（4 行结构化状态接力 · 专治段 2 站位与道具漂移）

> **痛点**：长文本写到段 2 时，AI 靠回忆段 1 正文极易把“谁站桌哪侧、脸朝哪、手里拿着什么”记串。每写完一段，必须在内部交接台账（不进最终纯净投喂块正文）落以下 **4 行结构化快照**；写下一段 `00:00` 首镜与【站位声明】时，**必须逐字段照抄继承**，严禁跳变：

```text
[HANDOFF-SNAPSHOT 段N → 段N+1]
1. 房间基准：北=〔门/墙〕 | 东=〔窗/柜〕 | 南=〔门/墙〕 | 西=〔家具〕 | 中心=〔主桌/焦点〕
2. 机位与锚：本段末机位侧=〔南侧朝北 / 反打北侧朝南〕 | 固定可见锚=〔至少 2 个背景物理锚点〕
3. 末态站位：@角色A=〔世界坐标+姿势+朝向〕；@角色B=〔世界坐标+姿势+朝向〕（下段 00:00 必严丝合缝承接）
4. 末态手持：@角色A=〔左手/右手所持物或空手〕；@角色B=〔左手/右手所持物或空手〕（下段无动作交代禁凭空消失或换手）
```

- **机检硬门升级（V8.2.0-SLIM-rev4）**：`sd-feed-engine/scripts/gate_check.py` 对多段投喂稿（≥2 段）已将 **段 2+ 缺失 `G8-HANDOFF`（`机位侧=` / `固定可见锚=`）** 与 **段 2+ 未复述房间物理坐标锚点（`G8-ANCHOR-REPEAT`）** 升格为硬阻断 **`FAIL`**（不再只是 WARN）。
- **跨段动线与白模同步自检（V8.2.0-SLIM-rev10）**：若段 N+1 开场承接段 N 末态的位移与拾物动作，段 N 末态快照须确认关键道具落在目标角色进场同侧，且段 N+1 挂载的更新白模（`图2B`）须采用「双地标夹心坐标」同步锁死新站位与道具落点。
