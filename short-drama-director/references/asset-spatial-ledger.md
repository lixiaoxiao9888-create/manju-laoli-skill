# 角色资产参考图与 3D 空间快照规范 (Asset & Spatial Ledger)

> 🔗 **流程位置：P2 数字资产包·分批出图（见 `asset-first-pipeline.md` ★权威）**。本规范是**资产参考图提示词与验收规范**。角色参考图的版式由四字段模板中的「排版结构」确定；场景与道具仍按各自模板。用户提供的图片按素材形态登记，供 P3/P4 引用。

> **当前角色提示词与验收格式（用户明确覆盖）**：角色生图与验收只用下方原文四字段模板：**画幅、排版结构、服装与身体材质、面部特写**。项目已锁定美术风格必须沿用；五官 10 项和服装 6 项填入对应字段。比例尺、材质小样、HEX 色盘、人物履历、图上五官拆解、声纹图、音色标签等配套物均非必需项，缺少不判不合格。角色基准独立文生图，不上传父母或其他人物图，不作亲缘推导；换装只参考本人已确认的基准图。本说明优先于本文件中与之冲突的旧版角色板细则。

## 一、 角色资产 16 项硬性锁定规范

### 1. 五官 10 项必写（杜绝脸部漂移）
1. 脸型骨相（方圆脸/冷艳瓜子脸/重颌方脸）；
2. 眉形细节（平直剑眉/微挑柳叶眉/断眉）；
3. 眼型与眼窝（狭长丹凤眼/深邃眼窝杏眼）；
4. 瞳色与反光（深褐琉璃瞳/赤金锐利高光）；
5. 鼻梁山根（高挺直鼻/小巧微翘驼峰鼻）；
6. 唇形与唇色（薄唇微抿/朱红饱满唇峰）；
7. 下颌线条与折角（下颌线清晰锐利/方正刚硬）；
8. 耳廓耳型（贴脑耳/白净分明耳廓）；
9. 标志性特征（眼角泪痣/眉心浅疤/断鼻骨）；
10. 面部肌肉与肤色（冷白无暇/古铜粗糙/刀削般体块）。

**性别锚点（必写·2026-09-15 实测补强）**：面部特写句必须以 `X~Y岁男性/女性（身份代称）` 收尾（如 `24~26岁青年女性`、`55~60岁老年男性（老将）`），性别词不可省略——只写"老将/文士/武将"等身份代称或只写年龄段，模型会自行推断性别导致漂移；所有下游投喂词（人物入场句）提及该角色时，性别指向必须与资产板一致（如女文士不可写成"青衫文士"）。

**★ 年龄锚 / 体型锚 / 身份外观三件套（必写·2026-10-12 新增 · 机检 C26c/C26d）**

> **由来（粉丝群实测反馈）**：「**人物年龄，人物身材比例都卡不到**」「人物也搞得像**协警**，和外卖员的特征没有关系」。
> **病根**：此前"年龄锚"只作为**投喂层**的一句建议（`model-adapters.md` §5.0.3），**没进资产板必写项、也没进机检**——规则写在散文里，执行时不生效。

| 项 | 要求 | 正例（外卖骑手 陈舟） | 反例（会被判不合格） |
|---|---|---|---|
| **年龄锚** | 必写年龄段，且**可换算**（`28~32岁`）；禁只写"青年/中年人" | `28~32岁男性` | `青年男性`、`他` |
| **性别锚** | 必写（既有铁律，不重复） | `男性` | 只写`骑手` |
| **体型锚** | **必须有数字或明确体型词**——身高 + 体型 + 上下身比例 | `178cm·精瘦，肩宽窄、腿长占比偏高` | `高大`、`身材不错` |
| **身份外观三件套 ①职业标识物** | 至少 1 个**可入画的硬标识** | `胸前橙色方形外卖箱 + 平台工牌` | 无 |
| **身份外观三件套 ②服装形制与材质** | 写形制 + 材质 + 磨损 | `橙色骑手冲锋衣·尼龙·袖口磨白·反光条掉漆` | `穿制服` |
| **身份外观三件套 ③气质体态** | 把职业写进身体习惯 | `常年骑车致含胸驼背、右肩低、手掌粗大` | 无 |
| **⛔ 反漂移清单** | 逐条写死"不能被画成什么" | `禁写成协警警服/公文包/对讲机` | 无 |

**四条铁律**：
1. **身份必须落到可画要素**——只写"外卖员"不算数；缺三件套任一项，模型就会给**邻近职业的泛化形象**（最高发：外卖员→协警、护士→白大褂医生、教师→制服群众演员）。
2. **年龄与体型必须可复述**——年龄段 + 身高体型，禁止"中年男性""高大"这类不可复述的概括词。
3. **⛔ 反漂移清单必写**——正向描述禁不住漂移，必须同时给出**禁止画成什么**。
4. **上游来源唯一**：本表数值一律从剧本层《人物锚卡》（`sd-script-engine/references/story-bible-and-ip.md` §1.11）抄录，**资产层禁另编一套**；改锚 → 资产/分镜/投喂稿逐级标 `STALE`。
5. **机检兜底**：**C26c**（年龄锚缺失）/ **C26d**（身份可渲染外观缺失）。

### 2. 服装材质 6 项必写（杜绝塑料感）
1. 面料类别（重磅斜纹棉麻/做旧哑光皮革/高密生丝）；
2. 编织与表面纹理（粗糙麻织肌理/皮革龟裂细纹）；
3. 垂坠受力与硬挺度（厚重硬挺垂坠/贴身流线）；
4. 战损污损与做旧细节（袖口磨损起毛/衣角泥水浸润/领口汗渍）；
5. 金属与扣具光泽（哑光拉丝古铜扣/冷银金属拉链反光）；
6. 缝纫与剪裁工艺（双排工整明线/暗青色提花刺绣）。

## 三、 3D 空间快照与 180 度轴线锁 (Spatial Ledger)

> 🔗 **上游**：本章是**投喂执行层**的站位规则（怎么写进提示词）。**先有导演稿**——场面的调度、权力几何、节拍闭环、镜头策略模式，唯一权威在 `blocking-direction.md`（★权威）；本章把导演稿的【人物初始位】+【位移】翻译成一行式【站位声明】。**跳步直接写站位＝凭感觉，站位必然漂。**

1. **绝对视角基准**：所有“画面左/右”严格指观众看画面的左/右。
2. **空间锚点固定**：确定场景中的核心固定参照物（门、窗、办公桌、立柱、擂台边缘）。
3. **180 度动作轴线法则**：在同一场戏中，摄像机必须始终在双方视线连线（动作轴线）的同一侧，严禁跨越轴线导致角色方位在镜头间无故反转。
4. **移动轨迹闭环**：角色移动必须具备 `起点 -> 可见运动路径 -> 终点`，上一镜在左侧的角色，下一镜严禁瞬间移动到右侧。
5. **空间站位风险分级（S0~S4）**：空间能力全保留，但按任务复杂度加载，低等级不加载高等级规则——**S0 单人**：简版站位一行（位置+朝向+动作），免轴线行免位移链；**S1 双人静态**：一行式站位声明（四要素）+ 轴线行（左A右B·禁越轴）；**S2 多人静态（3~4 人）**：站位声明全员具名（每人四要素）+ 轴线行；**S3 多人移动**：在 S2 基础上加逐人位移因果链（起点→终点·每步有动作原因·禁瞬移）；**S4 复杂战斗/多人空间切换**：全量空间规则——顶视图 CAM1~4 调度、合法越轴、V3 系统备查（`spatial-reference-system-V3.md`，LEGACY/备查）。判定不清按高一级处理。

6. **多角色在场声明铁律（2026-09-04 粉丝实测丢人问题修复）**：AI 视频模型每段独立生成、零记忆——谁在本镜出现完全取决于本镜提示词写了谁。有"空间连续性"还不够，必须补"人员连续性"：
   - **在场声明**：同场景多镜的每一镜【核心人物】段必须**点名本镜全部在场角色**（动作主角+静止配角全列，写身份+位置+状态）；无"来人/离开"描述时，默认全员原样在场；⚠️ **（2026-10-15 单一方位权威）此处的"位置"钉依托物/状态即可，画面左右一律以段首【站位声明】为准、不每镜重写**——双重发位是用户实测"东一个西一个/突然出现在身后"的病根（见 `model-adapters.md` §5.0）；
   - **人员承接链**：跨镜显式声明延续，如 `承接上镜：@B 仍在门口`；
   - **主次同框四件套**：第二人（含远景/背景人）必须**具名+具象+定位+状态**，写法 `@B（远景·灰袍老者·断桥尽头·背身而立）`；严禁"远处站着个人"类弱指令；被主体"看见"（视线/动作连接）的配角不会被省略；双主体关键同框镜用同框图锁定形象。
   - **画内/画外清单（2026-09-15 审计补强）**：每镜时间轴行内，**入画者逐个具名**（含只听不说的听话者——他们物理上就在取景半径内，不写模型就会自行决定删或加）；**画外者明写"×不入画"**，全部在画角色一个不漏、画外角色一个不混；道具支撑视线动作时（如"视线落在军牌上"）必须锚定道具入画方式（前景虚化等）并注明持有人不入画，防凭空长出手；
   - **跨段蒙太奇默认（2026-09-15 用户定案，修正当日早先"过渡走位"写法）**：段与段是**各自独立生成的剪辑关系，不是连续拍摄关系**——跨段位置/场景不一致时，**默认用蒙太奇直切**（前段终态→后段开场，剪辑点自然衔接），段缝只需按 D 锁配齐**画面锁与两端机位关系**（**段末不写接续尾行**，该栏 2026-10-09 废止）；**严禁为凑连续性把两个场景塞进同一个生成单元**去表现"连续走位"——双场景穿梭是穿帮高发源，蒙太奇才是零成本转场。**同段内**位置断层才需要走位声明或省略交代（同场景内"过渡走位不拍摄"合法，因为场景资产唯一）。判定口诀：**跨段切、同段连**——跨段蒙太奇，同段内才讲连续性。
   - **跨段锚点钩子（2026-09-15 实测补强）**：蒙太奇直切省了走位，但**前段收尾画面必须为后段核心登场元素埋钩子**——后段要登场的人物/物/景，在前段尾拍以远景剪影、视线指向、声音预告等方式提前入画（如段3 尾拍远处高台敌将剪影→段4 开战），否则后段登场元素无来由、观众跳戏；同时前段【禁止项】的人数锁定必须为该钩子元素**开单例豁免**（写明唯一豁免条件：何时/何处/剪影级/静止/仅一人），豁免要收窄到不会引发人数失控。
   - ✅ 已实测验证（2026-09-04）：修复后双镜（分镜1 林越+沈砚同框 / 分镜2 中心林越+远景老仆）投喂确认沈砚留住、老仆出现；修复前对照（只点名主角+"远处站着个老仆"）确认会丢人。

7. **单实例铁律与位移当前态锚点（2026-09-15 实测分身问题修复）**：
   - **单实例**：每个点名角色在画面中全程只有一个身体。凡【强制禁止项】必须含"单人单实例——每个点名角色全程只有一个身体，禁止同角色分身、复制人、同框重影"；人数锁定（仅 X 人）只防"多出陌生人"，防不了"点名人自己变两个"，两条都要写；
   - **位移当前态锚点**：站位声明里登记过位移的角色（如 `A 沙盘→帅案前半步`），在其后每一镜被点名时必须**带当前位锚点**（如 `@白珩（保持镜2进言位：帅案前半步·拱手而立·全程仅此一处）`），禁止悬空点名——已位移角色只写名字不给当前位置，模型会把起点实例和终点实例各渲染一次（拉镜/全景把全场拉进画面时尤其高发）；
   - **迁移非复制**：位移行注明"单实例迁移，旧位不得残留"。

8. **景别-取景半径匹配铁律（2026-09-15 实测分身根因二次修复）**：镜头能框住谁，由**景别 × 站位物理距离**共同决定，不由台词需要决定——
   - **可见动作必须在取景半径内**：点名做可见表情/动作（侧目、点头、回望）的角色，必须处在该镜景别能框住的物理距离内（中近景≈单人；中景≈相邻 2~3 人；全景≈同屋全员）。站位隔着沙盘/半个厅的角色与持镜主体不在一个取景半径里，却在提示词里被要求做可见反应——模型无法让画外人物入画，只能把人物**位移到主体身边渲染或复制分身**，这是分身/乱位的真正根因之一；
   - **三种合法处理**（按戏优先选）：① 升景别改全景，全场同框做反应；② **拆反应镜**——主体镜（中近景·画内仅主体，明确写"其余角色不入画"）+ 反应镜（全景·众人各归其位做反应）；③ 降级为画外音/声音反应，不入画；
   - **禁止**：中近/中景里点名远处角色做可见动作；"缓慢拉镜拉出全员"不算合法处理（拉镜只是景别渐变，改不了物理距离，模型照样补人）。

## 四、 场景出图执行规范（P2c·第二批）

**流程**：核心场景出空间资产图，每张确认锁定。

### ★ 场景出图产物分工表（治「同一场景被出成两套图」）

> **背景（必读）**：本包的场景出图长期存在**两套并行规范**——本节「场景母版 + 调度/站位版」与 `sd-asset-engine/references/scene-grid-template.md`「九宫格场景图」。两套规范**互不引用**（本节全文提「九宫格」0 次、九宫格模板全文提「母版/调度版/站位版」0 次），而**强制读取清单 P2 行同时点名了两份文件**。执行者读完只能二选一，或干脆每场景多出几张图。**明确分工——两者都要出，互不替代；并按出图顺序排定「先出母版、再出九宫格」。**

**场景出图顺序（2026-10-11 用户裁定）**：每个核心场景 = **先出 ① 场景母版 → 再出 ② 九宫格场景图 → 复杂场景才出 ③ 机位调度版 / 战斗站位版**。

| 顺序 | 产物 | 唯一权威文件 | 管什么 | 每场景产出 | 画幅 | 人物 | 何时出 |
|---|---|---|---|---|---|---|---|
| **①** | **场景母版** | **本文件 §四（即本节）** | **长相与空间锚点**（连续性与空间一致性基准件） | **1 张** | **16:9 横版** | **无人空镜** | **必出**（第一张） |

**四条硬规则**：

1. **都要出，不互替**——母版管「**这个场景长什么样**」、九宫格管「**这个场景有哪几个子区域、各区域从哪些机位看**」。**缺任一类 = 该场景资产不完整**（是否属必要出图场景按本节末「出图标准」判定：跨 2 镜以上 / 关键打斗 / 重场戏）。
2. **画幅分治**——九宫格是**多格网格件**（在模板内逐格落构图）；母版与调度/站位版**一律 16:9 横版**，与成片画幅解耦（见 `aspect-ratio-adaptation.md`）。
3. **人物口径分治**——**需要人物时只走战斗站位版**（带 `@锚点` + 轴线）；母版、九宫格**一律无人空镜**，不得在其它图内叠人。
4. **禁止合并**——不许把九宫格塞进母版单幅里，也不许用母版替代九宫格的区域/机位清单；两者**产物形态不同**（3×3 网格 vs 单幅横版），合并即丢信息（九宫格的 9 格区域分配会被压掉）。

> 九宫格模板侧的对接口径见 `sd-asset-engine/references/scene-grid-template.md` §一「与总控场景出图规范的对接」段（双向接线，两处任一处被改都会让另一处对不上）。

**① 场景母版（★必出 · 第一张 · 2026-09-15 用户裁定 · 2026-10-11 提为第一序位）**：纯场景基准图——空间布局 / 材质 / 光源 / 主色调 / 氛围，画面无任何标注与人物；**是后续所有分镜投喂的空间一致性锚点**——后续所有镜头的【场景资产】与站位/背景描述，均以本图为长相真相源交叉核对（原「场景四向长相配套图」所承担的「管长相」职能，自 2026-10-11 起**整体并入母版**，该配套图不再另出）。

**② 九宫格场景图（★必出 · 第二张）**：多机位合集件，1 张 = 9 视角 = 只占 1 个素材槽，管机位与子区域；模板见 `sd-asset-engine/references/scene-grid-template.md`。

**③ 机位调度版 / 战斗站位版（⛔ 仅复杂场景按需 · 非必出 · 2026-10-11 降级）**：由原「必出二选一」降为「**复杂场景专属**」——**日常文戏走一行式【站位声明】+ 空间站位 S0~S4 分级即可，不单独出调度图**。

### 场景空间事实五件事（治"场景一致性只靠出图、没有事实源"）

> 病根：此前场景一致性依赖"出一张好图 + 各镜文字描述对齐"，但**场景本身没有一套可复述的"空间事实"**——于是同一场景换个剧集、换个季候状态，就在细节上漂移。精编自《灵境AI漫剧制作流 V3.9.0》`manju-environment-art-designer`：**先把场景当"空间事实"记死，再谈出图。**

#### A. 场景空间坐标系（★与导演稿共用同一套）

场景资产必须携带一份**坐标系**，与 `blocking-direction.md` §一 的【场景坐标系】**同源共用**（同一场景只有一套坐标）：

```
【SCN-03 客栈大堂 · 空间坐标系】
  方位基：北 = 正对大门（临街）｜南 = 后院门｜东 = 柜台一侧｜西 = 楼梯一侧
  垂直层级：地面层 / 半层楼梯平台（+1.6m）/ 二层回廊（+3.2m）
  中央活动区：堂内方桌区（对峙/谈判场）
  主入口：北·大门｜次入口：南·后门 / 东·柜台内门
  固定物：北墙双扇木门、东侧杉木柜台、堂中四张方桌、西侧楼梯扶手、西南角酒坛架
  安全可拍区：堂内四桌之间通道 + 楼梯平台下方不阻挡区
  禁入区：后院门外（画外）/ 二层回廊（除剧情需要）
```

**铁律**：**同一 SCN 场景跨集复用时，坐标系一字不改**；只有**空间结构真的变了**（改建/坍塌/季节场景替换）才创建新 SCN 编号。别名合并（"客栈大堂 / 堂屋 / 前厅"指同一空间时）必须先合并再出图。

#### B. SET_STATE · 场景持续状态变体（带生效区间）

场景不是静态照片。**凡是"持续一段剧情时间"的场景状态**，一律登记为 `SET_STATE`，并写明**生效区间**：

| SET_STATE 类型 | 例子 | 必写 |
|---|---|---|
| **损毁类** | 火灾后焦黑 / 战损断墙 / 砸碎的柜台 | 损毁范围、残留物、烟熏/水渍痕迹、**从哪个节拍起生效** |
| **停工类** | 停电（只有应急灯/月光）/ 断电的霓虹 | 唯一光源来源与色温、暗部比例 |
| **天候类** | 大雨 / 积雪 / 大雾 / 沙尘 | 地面湿滑反光、积水、飘落物、**可见度** |
| **节庆类** | 挂灯笼 / 贴红纸 / 摆供桌 | 装饰清单、配色偏移、**是否只在本集有效** |
| **时序类** | 过去 / 现在（同一空间的闪回） | 陈设差异、人物服饰差异、**色调差异** |

**三条硬规则**：

1. **生效区间必写**：`SET_STATE: 损毁档 · 自 EP3 段2 起 → 持续至 EP5 结束`——**没写结束＝默认延续到明确解除**，禁"这一镜烧了下一镜又是好的"；
2. **变体之间必须同源**：同一 SCN 的母版 / 损毁版 / 雨夜版**共享同一坐标系与固定物位置**，只改变状态层，**禁止把两版画成两个空间**；
3. **变体必须出图**：跨 2 镜以上的状态变化，**状态版必须单独出图并登记《资产图册》**（母版 + 状态版并列），不得只靠投喂词文字描述。

#### B·补. CHAR_STATE · 人物持续状态变体（★ 2026-10-13 新增 · 用户实测反馈）

> **由来（用户实测）**：「外卖员的资产图里是**戴着头盔**的；提示词里让他坐在家里、**把头盔夹在怀里**——结果画面里**同时出现了两个头盔**：一个戴在头上（资产图带的），一个夹在怀里（提示词要的）。」

**病根**：`SET_STATE` 只服务**场景**，人物此前**没有任何状态变体机制**——角色身上的穿戴物被立绘模板写成「**配饰（固定不可变更·保留入图）**」（`sd-asset-engine/references/character-portrait-templates.md` §二），而"同一人物多造型换装"解决的是**跨造型**（A 造型 / B 造型各出一张图），**不是「同一场戏内的状态变化」**。
于是当剧情要求「摘下头盔」时：资产图锁着"戴着头盔"、提示词要"夹着头盔"，**两者没有优先级声明 → 视频模型把两个信号【叠加】而不是【替换】→ 长出两个头盔。**

> **★ 铁律（治本条）**：**资产图锁定的是「这个东西长什么样」，不是「它必须在身上」。**

**凡"持续一段剧情时间"的人物状态变化**，一律登记 `CHAR_STATE` 并写**生效区间**：

| CHAR_STATE 类型 | 例子 | 必写（缺一即未登记） |
|---|---|---|
| **穿戴增减类** | 摘下头盔 / 脱下外套 / 戴上或摘下眼镜 / 解开领带 | ① **脱离物去哪**（手持 / 夹在腋下 / 挂在臂弯 / 放在桌上 / 别在腰后）；② **脱离后本体的样子**（发型被压扁 / 只剩内搭 / 未被遮挡的脸） |
| **伤病类** | 脸上的血 / 淤青 / 包扎 / 绷带 | 位置、面积、**新伤还是旧伤**、是否持续恶化 |
| **污损类** | 一身泥 / 湿透 / 烧焦的衣角 | 范围、**干燥进度**、是否可逆 |
| **时序类** | 闪回中的年轻态 / 入狱前后 | 与主时间线的**差异清单** |

**三条硬规则**：

1. **生效区间必写**：`CHAR_STATE: 摘盔档 · 自 EP2 段3 起 → 持续至 EP4 结束`——**没写结束＝默认延续到明确解除**，禁"这一镜摘了下一镜又戴上了"；
2. **跨 2 镜以上的脱离态必须出图**：与场景 SET_STATE 同规格——**状态版单独出图并登记《资产图册》**（母版 + 脱离态并列）；**只跨 1 镜**的可用**文字偏离声明**替代（写法见 `model-adapters.md` §5「资产偏离声明」）；
3. **反"半途矛盾"**：写"摘下头盔"就必须同时写**物理后果**（发型被压扁 / 额前有压痕）——否则模型会给出"没戴头盔但头发仍是头盔形状"的诡异结果。同理，"脱下外套"要写内层衣物。

#### C. 空气介质层（有来源、有密度、有运动）

**"干净的空气"也是一个明确选择，不是默认留空。** 每个场景必须显式声明介质状态：

```
【空气介质】主介质：{清洁空气 / 湿度 / 雾 / 烟 / 尘 / 雨雪 / 蒸汽}
  来源：{灶火 / 香炉 / 战场扬尘 / 雨 / 地面积水蒸发 …}
  分布：{全屋均匀 / 集中于地面 0~0.5m / 靠窗一侧}
  密度与粒径：{稀薄可见 / 中等 / 浓重} · {细雾 / 粗颗粒}
  运动：{静止滞留 / 缓慢上升 / 随穿堂风横移}
  沉降与可见度：{无沉降 / 桌面薄灰} · 能见度{正常 / 略降 / 显著降低}
  光散射：{不明显 / 侧逆光可见光路 / 光柱明显} · 状态变化：{随剧情起止}
```

**两条禁令**（与 `sd-storyboard-engine/references/scene-space-adaptation.md` 的"物理雾双检"同源，此处为**登记口径**）：

1. **禁无源之雾 / 万能光柱**：空气介质**必须有来源**；场景只提供**介质事实 + 开口与遮挡事实**，**不为灯光岗位制造光柱**（光柱由光位决定，不由场景决定）；
2. **禁"什么都没写的空气"**：介质栏留空 = 执行者自由发挥；不确定时**写"清洁空气，无介质"**。

#### D. 尺度参照 scale_evidence（巨构 / 巨兽 / 异常尺度专用）

当场景或主体**尺度异常**（巨型殿宇、巨兽、深渊、千军阵列）时，**必须提供可验证的尺度参照**，否则模型会按常规比例渲染，巨构变小屋：

| 参照类型 | 写法 |
|---|---|
| **熟悉参照物** | 人物与建筑的比例（"门高约 6 人叠高"）、常见物件（马车/台阶/灯笼）作标尺 |
| **遮挡层** | 由近及远 3 层以上遮挡，建立纵深与体量 |
| **地平线 / 消失点** | 明确地平线高度，判断俯仰与体量 |
| **大气透视** | 远景降对比、偏冷、细节简化 |
| **接触面** | 主体与地面的接触范围、压痕、投影长度 |
| **物理后果** | 重量反馈：风压、扬尘、水浪、地面震裂、回声延时 |

**与既有规则的交界**：尺度四件套的**玄幻战力表现**（法相/剑阵的巨物化）归 `sd-xuanhuan-engine`；本章只管**场景侧的尺度事实登记**。
