# 场面调度与站位决策层（Blocking Direction）· ★权威

> 🔗 **流程位置：P3 分镜·调度第一环**（先于逐镜故事板，先于投喂封装）。精编自《灵境AI漫剧制作流 V3.9.0》`manju-blocking-director`，并与本包既有站位体系**分工不重叠**。

## 〇、定位与边界（先读这条，防与既有文件打架）

本文件解决的是**「为什么这样站、这样走、这时切不切」**——即**导演决策层**。

| 层 | 回答什么 | 唯一权威 |
|---|---|---|
| **导演决策层（本文件）** | 这场戏的人物**怎么调度**、权力关系怎么用空间表达、节拍怎么走、何时切镜 | **本文件** |
| **投喂执行层** | 站位**怎么写进提示词**（一行式四要素 + 轴线行 + 位移行） | `asset-spatial-ledger.md` §三 + `model-adapters.md` §5.0 |
| **分段/转场层** | 怎么切成 ≤15 秒的生成段、切点落哪 | `segment-splicing.md` + `sd-qc-engine/references/editing-transition-gate.md` |
| **图形化层** | 逐镜面板怎么画、面板边界≠剪辑点 | `sd-storyboard-engine/references/storyboard-sheet-template.md` |

**四条边界（越界即返工）**：

1. **不改剧本**：不改台词、不增删事件、不改人物动机；
2. **不选器材**：不指定正式焦段、摄影设备、精确轨迹、灯光器材——那些归 `sd-storyboard-engine` / `sd-decision-engine`；
3. **不写投喂词**：本文件的产物是**导演稿（内部）**，不是【站位声明】投喂栏内容；
4. **不确定就停**：入口状态（谁在场、在哪、手里有什么）不明确时**停止该场并询问**，**严禁重置人物与道具**、严禁靠猜继续。

## 一、场景坐标系与文字平面图（解禁 · 这是站位老大难的根因修复）

### 1.1 先讲清楚"解禁了什么、仍然禁什么"

> **历史冲突**：本包长期写「**禁止画图、禁止坐标表、禁止 ASCII 布局**」（`model-adapters.md` §5.0）。用户与实测的共同反馈是：**站位依然是最容易被诟病的环节**——因为禁令只砍掉了"投喂词里画图"这个错误做法，却**没有提供替代的调度手段**，执行者于是只能凭感觉写站位，站位自然不稳。
>
> **收窄口径（一句话）：图画在导演稿里，字写在投喂词里。**

| | 内容 | 判定 |
|---|---|---|
| ✅ **允许（新增）** | 在**导演稿内部**写**文字平面图**：用场景坐标系（北/南/东/西 + 垂直层级）、固定物、入口、行动区、人物初始位置与朝向，**以结构化文字**表达空间关系 | 本文件 |
| ❌ **仍然禁止** | 把任何形式的图**写进投喂提示词**：ASCII 草图、俯视 ASCII 空间图、坐标数值表、初始图 + 位移因果链、"画个九宫格示意站位" | `model-adapters.md` §5.1 禁写清单第 4 条 |

**为什么这样切**：AI 视频模型对"投喂词里的图形符号"解析能力极差（这是禁令的原始动机，依然成立）；但**导演自己需要一张空间图来保证站位前后不矛盾**——这张图是**思考工具**，不投喂，不进入七段式任何一段。

### 1.2 文字平面图写法（必须只用下面这几类要素）

```
【场景坐标系】（写一次，全场共用，后续所有调度引用它）
  方位基：以场景实际朝向为准 —— 北 = 正对主窗/主门 / 南 = 回望入口 / 东·西 = 两侧
  垂直层级：地面层 / 台阶层（+0.5m）/ 高台层（+2m）
  中央活动区：{剧情对峙/行动发生的核心区域}
  主入口：{门/缺口位置}　|　次入口：{位置或"无"}
  固定物（不可移动·可作依托）：{立柱 / 沙盘 / 长桌 / 擂台边缘 / 断桥石墩 …}
```

```
【人物初始位】（逐人一行，禁"画面左右"代替真实方位）
  @角色A：{北窗下·靠东墙} · 朝向{南·面朝室内} · 姿态{立·双手负后}
  @角色B：{中央活动区·沙盘南侧} · 朝向{北·面向A} · 姿态{俯身看图}
  群像开关：{A/B/C} —— A：逐人派事务；B：只写密度句；C：全段写「除 @XX 外无其他人物」
```

**三条硬规则**：

1. **绝对方位优先**：能用"北/南/东/西 + 固定物"就不用"画面左/右"——**画面方位随镜头翻转，真实方位不会**；
2. **每步有依托**：人物落位尽量绑定固定物（"靠东墙立柱"），**悬空站位是漂移的第一来源**；
3. **写一次、全段引**：坐标系建立后，后续节拍只写增量（`@角色A：北窗下 → 中央活动区`），**不重复抄坐标系**；
4. **群像开关逐段裁定（P7 新增）**：每段必须显式标 `群像：A/B/C`（判据见 §4.2），**禁沉默**——不裁＝模型自己猜，要么空场要么乱加人。

### 1.3 与投喂层的交接（这一步不能省）

导演稿的【人物初始位】**必须**被翻译成投喂层的**一行式【站位声明】**才能投喂：

```
导演稿（内部·真方位）           →   投喂词（七段式·画面方位）
@角色A：北窗下·靠东墙·朝南      →   @角色A（画面左 · 背靠东墙立柱 · 侧身45°朝右 …）
```

翻译规则与四要素语法见 `model-adapters.md` §5.0；**翻译后导演稿不进投喂词**。

## 二、权力几何（谁高谁低，用空间说，不用台词说）

**权力几何**＝用**站位差、高度差、遮挡、距离**表达人物关系变化。每一场至少明确一次：

| 维度 | 低权力 / 受压 | 高权力 / 压制 |
|---|---|---|
| **高度** | 坐 / 跪 / 俯身 / 处于台阶层以下 | 立 / 居高台 / 俯视 |
| **空间** | 被逼至墙角 / 退至门边 / 处于中央活动区边缘 | 占据中央活动区 / 背靠唯一出口 |
| **遮挡** | 被固定物遮去半身 / 被对方身影盖住 | 无遮挡、正对光源 |
| **距离** | 被迫后撤、距离被动拉大 | 主动逼近、压缩对方可移动范围 |
| **取景半径** | 需借"画外"承接 | 占据取景中心 |

**铁律**：**场末的权力几何必须与场初不同**（否则这场戏的空间没有参与叙事）。若剧本本身权力不变（如纯过场），**显式写明"本场为过场，权力几何不变"**，不允许默认省略。

**与既有规则的交界**：权力几何的**具体镜头实现**（大仰角/大俯角/侧面疏离）归 `sd-storyboard-engine`；本文件只负责**决定谁该在什么空间位置**。

## 三、节拍闭环：起势 → 路径 → 接触/阻挡 → 落点 → 接收者反应

每一个**动作节拍**必须五段闭合（缺段＝该节拍没完成）：

| 段 | 写什么 | 缺段的后果 |
|---|---|---|
| ① **起势** | 谁、在哪个坐标、做什么准备动作 | 动作无来由 |
| ② **路径** | 从哪走到哪（起点坐标 → 终点坐标），**必经点**在哪 | 瞬移 / 穿模 |
| ③ **接触 / 阻挡** | 动作落在谁/什么物上；被什么挡住 | 打空 / 动作悬空 |
| ④ **落点** | 结果状态：谁被推到哪里、道具到哪、谁失去平衡 | 下一节点失位 |
| ⑤ **接收者反应** | **被动作影响的对象**的可见反应（面部/体态/后退） | 动作没有戏剧价值 |

**节拍闭环的两条禁令**：

1. **禁瞬移**：角色从 A 到 B 必须有②路径，**除非剧本给出瞬移设定**（如玄幻身法），此时必须写视觉痕迹（残影/空间裂隙）；
2. **禁穿模**：路径**不得穿过固定物**；必须绕过或跨越，并写明方式。

**与既有规则的交界**：本闭环负责**动作的空间逻辑**；动作的**物理动力学**（11 环动力链 / 受力形变）归三个打戏引擎 `sd-combat-engine` / `sd-real-engine` / `sd-xuanhuan-engine`。

## 四、对话与群戏的调度链

### 4.1 双人对话：说话者 → 听者 → 反应者链

对话不是"你一句我一句给镜头"，而是**信息在三人链上的传递**：

```
说话者（发出）→ 听者（接收·必须可见）→ 反应者（第三方·把隐含态度外化）
```

- **听者必可见**：任何一句有分量的台词，**听者的接收状态必须给到**（否则台词没有落地）；
- **反应者可缺席但要说明**：无第三方时，**反应由听者兼任**，须写明"本场无第三方，反应挂在听者身上"；
- **反应优先于台词**：判断"这句要不要切镜"时，**看反应有没有价值**，而不是看谁在说话（与 `sd-qc-engine/references/editing-transition-gate.md` §三·切镜触发门同源）。

### 4.2 群戏：主焦点 / 次反应 / 背景行为 三级

三人以上同场时，**每个节拍只允许一个视觉主焦点**：

| 层级 | 数量 | 要求 |
|---|---|---|
| **主焦点** | 恰 1 个 | 本拍的动作或信息主体 |
| **次反应** | 1~2 个 | 对主焦点有可见反应，**必须具名 + 具体位置 + 具体状态** |
| **背景行为** | 其余 | 有稳定的背景活动（不抢动作），**禁"静止的人形立牌"** |

**铁律**：**严禁全员同时抢动作**（模型会把每个点名的角色都渲染一次完整动作，导致画面散架）。收束方式：只让主焦点做大动作，次反应做**小幅度**反应（转头/退半步/皱眉），背景行为做**循环性**动作（添茶/侍立/走动）。

> **★ 群像开关（第一层闸门 · 2026-10-24 P7 新增 · 本层裁定，投喂层只翻译）**
> §4.2 的「背景行为」此前只是**调度侧原则**，投喂层无槽位、机检无断言、且与 C35/C37/C20h 三条反向规则无裁决
> → 执行时必然选最省力的那条，背景人被按死。现在由本层**先裁开关**，把冲突消解在调度环：

| 开关 | 判据（命中任一） | 下游动作 |
|---|---|---|
| **A · 开·逐人写** | 公共/半公共空间且 ≥2 个无名可见人；剧本有围观/旁听/知情叙事；摆了 ≥2 个非主角点位；**台词需要"被听见"** | 每人派一件事务（R/P 型），见 `short-drama-director/references/crowd-behavior-direction.md` §三 |
| **B · 开·只写密度** | 场景有人但不承担叙事 | 只写密度句（S 型），不写个体 |
| **C · 关** | 密闭双人戏 / **打戏段** / 纯特写 / 四下无人 / 竖屏近景对话 | 全段写 `除 @XX 外无其他人物`（C20h 句式），**禁出现任何群像事务** |

- **C 类一票否决**：公共空间 + 打戏 = **打戏赢**（动作清晰度是刚性需求，背景真实感是弹性需求）；
- 开关标在**文字平面图**的场景头上（`群像：A/B/C`），一段一裁，同场景可切（教室走廊段 A，后门偷听特写段 C）；
- **沉默不是 C**——不裁开关 = 模型自己猜，结局要么空场、要么乱加人。三类都必须是显式声明。

## 五、关键道具：持有 / 转交 / 落点 / 左右手

剧情关键道具（信物、武器、证物、图册）在本层必须**逐节拍登记四项**：

```
【道具账】@玉佩：持有者{@角色A} · 手位{右手·虚握} · 状态{完好} · 本拍动作{无}
        节拍③后：持有者{@角色B} · 手位{左手} · 状态{完好·被夺}
```

**四必写**：

1. **持有者**（谁拿着）——换人必有交接动作；
2. **手位**（左/右手）——**跨镜换手是最隐蔽的穿帮**，换手必须有具体动作承接；
3. **落点**（离手后去哪）——**道具离手但未给落点＝下一镜必然随机出现**；
4. **状态**（完好/破损/沾血/入鞘）——状态变化必须有触发节拍。

**与既有规则的交界**：道具的**出图**（道具资产图）归 `sd-asset-engine/references/prop-template.md`；道具的**单实例锁与跨镜朝向**归 `asset-spatial-ledger.md` §三·7 与 `sd-asset-engine/references/continuity-and-crowd.md`；道具的**投喂层锚点**（`@PRP-道具名`）归 `model-adapters.md` §5【场景资产】栏——**本层【道具账】管"怎么决定"，投喂层【场景资产】栏管"怎么写进提示词"**，两者同源不重复（2026-10-13 补：此前【道具账】在投喂层无对应落位，道具只能写镜行括号夹注）。

## 六、镜头策略四模式：本层"决定"，分段层"执行"

本场必须在下面四种里**选唯一一种**，并写明**选择证据 + 被否决方案**：

| 模式 | 判据（互斥） |
|---|---|
| `TRUE_ONE_TAKE` 真一镜到底 | 禁切区非空；不得含任何切镜；跨段须保持同一镜头身份、轨迹、空间、焦点、光线连续 |
| `SIMULATED_ONE_TAKE` 伪一镜到底 | 只用导演批准的隐藏缝（遮满画面 / 快速掠过 / 暗部 / 同构运动）衔接 |
| `CUT_COVERAGE` 常规切镜 | 至少 1 个已批准切点；每个可见切镜必须带来新信息 / 新立场 / 新反应 / 时间压缩 |
| `HYBRID` 混合 | 以不可切连续段为骨架，只在规定事件点切镜 |

> ⚠️ **不重复定义**：四模式的**完整判据、字段、转场优先级、生成分段政策**，唯一权威在 **`sd-qc-engine/references/editing-transition-gate.md` §一~§三**（另有 `segment-splicing.md` 段缝规程）。本文件只做**决策入口**，字段一次都不重抄。

**本层必须额外交出的两份东西**（这是分段层拿不到的）：

- **决策证据六项**：`空间连续价值 / 表演连续价值 / 信息分布 / 视角变化需求 / 时空压缩需求 / 技术与生成可行性`；
- **被否决方案**：至少写一条"为什么不选它"（**"节奏更快、画面更丰富"不算理由**）。

## 八、一页速查

```
先建坐标系（北南东西 + 固定物 + 出入口）→ 摆人物初始位（绝对方位 + 依托物）
  → 每拍走闭环（起势→路径→接触/阻挡→落点→接收者反应）
  → 每场定权力几何（场末必须≠场初，过场显式声明）
  → 对话挂说话者-听者-反应者链；群戏分主焦点/次反应/背景行为
  → 关键道具记持有/手位/落点/状态
  → 最后选唯一镜头策略四模式 + 写证据 + 写被否决方案
  → 交付导演稿（图在稿里，投喂词里只有一行式站位）
```
