# 成片穿帮防治军规（Blooper Prevention Playbook）

> **版本**：P6 新增「段间衔接」章（2026-10-22，沿革见 CHANGELOG）· P6.4 加「画幅-剧型分档」（2026-10-23）
> **由来**：《三天》段1 成片拉片（25 帧逐格对稿）+ 长镜连续动作拆解，两条线共同实测总结。
> **本手册专治一件事**：**稿子没写死 → 模型自行补全 → 成片穿帮**。
> 本手册所有条目的根因都是这一句话——**穿帮不是模型随机发疯，是稿子把解释权留给了模型**。
>
> ⚠️ **执行前先分档（§十·10.0）**：**16:9 横屏（抖音半精品）与 9:16 竖屏（红果快节奏）不是同一套打法**——横屏要意境与唯美，空镜/留白/反应镜是加分项；竖屏节奏优先，空镜是负资产，衔接全靠台词钩与冲突。**把横屏那套套到竖屏，产出的就是一堆无意义镜头。**

---

## 〇、总纲：三条第一性原则（先背这个）

1. **模型不会让任何状态凭空消失。** 你建立了一个姿态（趴桌、拎球衣、外套搭肩），不写它的终结，它要么原样保留、要么**挂到画面里最近的另一个人身上**。
2. **模型不用方位词自洽，用位移自洽。** 你只写"东侧后门"没写"画右"，它把门放错侧之后，会让角色**走一大段路圆回来**——用一个穿帮补另一个洞。
3. **模型看不懂连续路径，只看终态。** "从门框一路摸到窗沿"它理解成"手在窗沿"这个结果，中间过程直接跳帧——这就是用户说的"敷衍"。

---

## 一、连续动作拆解军规（治「敷衍」）

**案例**：长镜（15 秒）里写"从门框一路摸到窗沿"，初版一句带过 → 成片上一秒手在门框、下一秒已在窗沿，中间瞬移。

> ⚠️ **适用面（P6 修订）**：本章治的是「**单镜装得下连续长路径**」的长镜（长镜承载）；**SD 2.5 单镜 3~5s 物理上装不下**「从A到B」的完整过程，写了也只会被压成硬切——这类稿按常规一镜一动作写即可，C36 机检对单镜 <6s **不触发**。

| # | 军规 | 反例（会穿帮） | 正例 |
|---|---|---|---|
| 1.1 | **连续动作必须切成带路径的离散镜**：一区一镜，路径上的每个空间落点单独成镜 | 单镜写"从门框一路摸到窗沿" | 门框→门板→墙裙→窗台→窗沿，每落点一镜 |
| 1.2 | **每镜三件套**：当前接触点（手/道具在哪）+ 主动方手位 + 被动方身体反应 | 只写"他摸过去" | "指尖落在门框边沿；左手扶着门板；她在门内半步外、肩膀微微一缩" |
| 1.3 | **被动方（或对手戏方）反应是模型的进度条**：缩肩、后撤半步、视线跟着手动、呼吸变浅——告诉它"动作真的在走"，也防整场拍成两块木头 | 对手方无反应 | "@女主 视线跟着他的手移了半格、肩膀微微一缩" |
| 1.4 | **禁止项必须点名禁跳帧**：正面描述 + 禁止侧双向夹 | 只正面写路径 | "禁止手部位置瞬移或跳跃（每一镜只准停在当前落点，一镜内禁止从门框直接到窗沿）" |
| 1.5 | **快慢节奏对比**：起手快切（手持 + 运动模糊），过程慢推（缓慢推进/横移），张力全在快慢切换 | 全程同速 | 大幅调度 4 秒快 → 贴身细部 8 秒慢 |
| 1.6 | **横屏禁纯垂直下移**（高度有限，两下出画）→ 主体**斜置**、镜头沿**斜轴**移动（画左上→画右下） | 竖屏写法照搬横屏 | "人物斜卧于房间中央·头朝画左上、脚朝画右下；镜头沿人物斜轴缓慢下移" |

> 📌 机检：**C36 连续动作一句带过**（见 machine-check-manual）——**单镜 ≥6s** 的镜行画面主体出现"从A摸/抚/蹭/拂/扫/划到B" → WARN。**单镜 <6s 不触发**（SD 2.5 单镜 3~5s 装不下长路径）。

## 二、姿态交接军规（治「姿态悬空甩锅」）

**案例**：沈甜在镜1/镜3 趴桌探身爆料；镜4（江野入场）画面主体只写江野，没交代沈甜下场 → 成片 15-16 秒**苏念趴在桌上**——模型把"趴桌"这个姿态从沈甜身上摘下来，挂到了画面里最近的另一个人身上。

| # | 军规 |
|---|---|
| 2.1 | **姿态三问**：每个标志姿态写稿时问——**谁建立 / 何时终止 / 终止时换上什么**。三问缺一，姿态就悬空 |
| 2.2 | **姿态终结必须显式交接**：正面写下场（"@沈甜 已坐直、双手收回桌上，背对镜头不再探身"），并点名"止于镜N、禁转移给任何其他人" |
| 2.3 | **只禁承接方 = 无效**：上轮修复只写"禁苏念趴桌"治标——禁了承接方没管放出方，模型下次把趴桌挂到周越身上。**必须放出方承接方两头都写** |
| 2.4 | **非主体人物也要交代姿态**：他人镜头里的配角，写明"保持X姿势不动（禁加戏）"——不交代，模型就给他加戏 |
| 2.5 | **站位声明是姿态宪法**：每个具名角色的姿态与切换点写在【站位声明】，镜行只写增量；跨镜不变的特征（左右关系、坐/站）只在这里说一次 |

## 三、背景人物军规（治「多人同动」）

**案例**：镜4 原文"@周越 与两个男生虚焦的侧影，只抬手起哄"——"只抬手"没限定人数 → 成片 12-13 秒两个男生**同时比划**。

| # | 军规 |
|---|---|
| 3.1 | **群体动作必须点到人头**："仅 @周越 一人抬手起哄，另两个男生静坐不动"——"只抬手"是人家的动作不是人数 |
| 3.2 | **C35 层次原则延伸到龙套**：多人物镜的"清晰主体 + 虚焦陪衬"不只管具名角色，背景群像同样适用——动作只能属于一个，其余静坐 |
| 3.3 | **背景一律虚焦 + 不给正脸 + 每格 ≤3 人**（已在禁止项，保持） |
| 3.4 | 起哄/反应镜头：**一个声音 + 一个动作**，其余是"静"——静才是主角的放大镜 |

> 📌 机检：**C37 背景多人同动未点名**——镜行画面主体含"两个/N个 + 同学/男生/人"群体词与动作词、却无"仅X一人"分配证据 → WARN。

## 四、状态锁定军规（治「模型自行补全」）

**案例**：CHAR_STATE 写"球衣→离身（拎于左手），外套仍穿着"——"仍穿着"没说里面穿什么、拉链什么状态 → 成片江野**光着上身只披外套，胸腹全露**。

| # | 军规 |
|---|---|
| 4.1 | **状态写到可执行级**：服装状态必须写"拉链拉到哪 / 内搭什么 / 手在哪 / 持什么"。"仍 / 依然 / 照旧"这类词 = 把解释权交给模型，**禁** |
| 4.2 | **CHAR_STATE 登记时同步写"防叠加"**：立绘里没有的件，镜行里出现必须登记为状态覆盖（"基准图 + 状态覆盖"两句并写） |
| 4.3 | **状态偏离要复述**：道具/服装在镜行里每次出现关键状态时复述一次（"被卷成筒握在右手→推向画左衣襟"），防模型回退默认态 |
| 4.4 | **禁止项补致命伤**：明显违和的形态（赤膊、透视、裸露类）直接在禁止项点名——但**禁用平台高危词**（见第八章） |

## 五、方位与轴线军规（治「放错侧」）

**案例**：镜4 只写"自东侧【教室后门】进场" → 门被放画左，而苏念在画右，模型让江野**横穿整间教室**自洽。

| # | 军规 |
|---|---|
| 5.1 | **镜行里方位必须写画左/画右**：模型对"画左/画右"敏感，对"东南西北"无感。场景锚点写方位，镜行画面主体必须落成画左画右 |
| 5.2 | **每段首栏给机位映射**："机位主朝向朝东北，画左=西北、画右=东南"——一句顶十句（已入《三天》段1【机位与轴线】，沿用） |
| 5.3 | **位移限定步数与终点**："自画右深处横向两步即停"，禁横穿；位移路径写进【站位声明】，镜行复用 |
| 5.4 | **轴线锁定跨段一致**：人物左右关系一段一锁，跨段不变；"机位反转 180°"只反机位不反人物关系 |
| 5.5 | **过肩方向规则**：越过 A **右肩** → A 在画面**左**前景；越过 A **左肩** → A 在画面**右**前景 |
| 5.6 | **关系词必须换成点名 + 画面位置**："越过同桌的肩" → "越过 @沈甜 右肩，同桌占画面右前景"——模型不知道"同桌"在哪侧 |

| # | 军规 |
|---|---|
| 6.1 | **画幅先锁再写构图**：9:16 竖屏 / 16:9 横屏在【画幅风格】首栏声明，构图基准随栏末给出 |

## 七、台词军规（治「怪」）

**案例**（用户实测"还是有点奇怪"）：

| 病 | 反例 | 修法 |
|---|---|---|
| 尬语（军事/公文化） | "野哥，目标已锁定" | 高中生起哄味："野哥，正主在这儿呢！" |
| 逻辑不清 | "谁先追到，钱归谁"（局是赌江野追不追到，没有"谁先"） | "一个月为期，追到了三千归你！" |
| 拗口 | "还嫌三千少" | "还嫌三千不够" |
| 两个修辞打架 | "你脸上写着三千呢，别装了" | "你脸上就写着俩字，三千" |

**通则**：① 口语化、短句、一次一个信息；② 语气标签三件套（情绪·语速·功能）必须与内容匹配；③ 赌约/交易类台词先把规则写对再写味儿；④ 尾钩句是全剧魂（文件名级），禁改。

## 九、拉片-改稿闭环方法论（AI 助手执行）

用户拿成片来复盘时，按此流程：

1. **抽帧**：`ffmpeg -i 成片.mp4 -vf fps=1,scale=640:-1 f_%03d.jpg`（25s 视频 = 25 帧，逐格对稿）
2. **对账**：每帧标注对应稿内哪一段哪一镜，输出三列——**照稿执行 ✅ / 小瑕疵 / 真穿帮 ❌**。除逐镜对外，**段缝处单独看一眼**：上一段末帧到下一段首帧之间，内容上断没断（接力棒/反应者/声音桥/时间锚）——这类「跳脱」在逐镜对稿里看不出来，它是段与段之间的病
3. **根因归类**：每个穿帮必须归到"稿子哪一句没写死"，**不接受"模型问题"这个归类**——归到模型问题就等于没归
4. **三明治改稿**（顺序不能反）：
   - 第一层：**画面主体**补状态（接触点/姿态/位移/人数分配）
   - 第二层：**站位声明**补宪法（姿态切换点、位移路径、轴线）
   - 第三层：**禁止项**夹致命伤（禁瞬移/禁串角色/禁多人同动/禁高危词）
5. **复跑机检**：`validate_prompt.py --by-segment` + `audit_contract.py`，FAIL/WARN 清零才交付
6. **记录**：新军规沉淀回本手册（本条本身就是第 6 步的产物）

## 十、段间衔接军规（治「跳脱」）

> **本章跳脱于任何具体剧本**：治的是多段稿的通用病——**每段内部都写死了，段与段之间却是两段各生成各的**。
> 段内管「这一秒发生什么」，段间接管「观众凭什么走到下一秒」。后者不写，模型不会补。

**病的样子**：上一段话音落下，下一段主角直接空降开讲/开打——情绪断在半空、动作没有由来、空间说换就换。用户看完的原话是这种感受：「太跳脱了」「连个空镜都没有」「前后的关联性有点差」。

### 10.0 先分档：横屏半精品 ≠ 竖屏快节奏（**本节优先于下面所有条目**）

> **「要不要加空镜」不是风格偏好，是画幅决定的。** 同一套衔接规则套到两种剧上，横屏会显得「没接住」，竖屏会显得「多了很多没意义的镜头」——两档必须分开执行。

| 维度 | **16:9 横屏（抖音剧情 / 半精品剧）** | **9:16 竖屏（红果类快节奏短剧）** |
|---|---|---|
| 节奏 | 允许停顿、允许留白，情绪要有「落点」 | 节奏堆得极快，**每 3~5 秒必须有一个钩子**，不能停 |
| 空镜 | ✅ **该用的表现手段**：教室空镜、天光、走廊尽头、无人物入画的窗——用来卸情绪、立意境、做唯美留白 | ❌ **基本是负资产**：观众在手指上，一停就划走；空镜＝拖节奏 |
| 段间衔接 | 空镜起手 / 反应者一拍 / 声音先入 / 时间锚 —— **都要看得见** | **主要靠台词与冲突**：一句抢白、一个钩子问句、一个动作被打断、矛盾直接升级 |
| 台词密度 | 可以低，允许沉默；台词之间留呼吸 | 高密度，几乎没有沉默；一句话不推进就删 |
| 语速与停顿 | **3.5~5 字/秒**（标准对白），句间可留 0.5~1s 停顿做情绪落点 | **5~6 字/秒**（快念，短剧常态），几乎不停顿；停顿只在"憋住/被打断"时出现。基准见 `sd-feed-engine/references/feed-mode-and-gates.md` |
| 唯美镜头 | ✅ 允许（服化道质感、光影、构图本身就是卖点） | ⚠️ 只在**极短**（≤1s）且**不中断动作**时可用，不做独立停留 |
| 判据取向 | 缺衔接 = 断；缺意境 = 平 | 缺钩子 = 走人；加空镜 = 加速流失 |

**执行口径（写稿时先问一句「这是几比几」）**：

1. **横屏稿**：§10.1~10.8 全量执行，空镜/反应镜/声音桥都算加分项。
2. **竖屏稿**：只执行**内容接力**（10.1 接力棒、10.2 段尾三问、10.3 禁空降），**手段一律换成台词与冲突**：
   - ❌ 不加空镜起手、不加纯意境镜、不加无信息量的反应镜；
   - ✅ 用「上一段的话没被答完」直接切进来（一句抢白：*"我话还没说完。"*）；
   - ✅ 用**动作被打断**跨段（敲门声、有人拽住手腕、手机响）；
   - ✅ 用**信息升级**跨段（上一段的疑问，这一段第一句就答/就否）；
   - ✅ 时间跳就靠**一句台词交代**（"三小时后"由人物说出来），不要给天色空镜。
3. **两档共通、不可省的那一条**：**段与段之间必须有人接过上段的棒**——竖屏省的是「镜头」，不是「因果」。省了因果，观众照样觉得跳。
4. 确需在竖屏里放空镜的（比如一个关键道具的特写空镜），在该镜标注「**刻意空镜**」并压到 ≤1s——机检 C39 认这个标记放行。

| # | 军规 |
|---|---|
| 10.1 | **接力棒原则**：每段结尾必须向下一段**交出**一样东西——一句没被回应的问句 / 一个刚发起了一半的动作 / 一条刚到场的信息 / 一团没散去的情绪；每段开头必须**接住**上段交出来的东西。交不出或接不住 = 跳脱 |
| 10.2 | **段尾三问**（每段写完必问，答不上就补镜）：① 这段结束时，场上留着什么**没解决**的东西？② 下一段的发起方是谁，**为什么是此刻**发起？③ 观众靠什么从上个空间/情绪走到下一个？ |
| 10.3 | **禁空降**：下一段的主要行动不能凭空发起——它必须是上段某句台词/某个动作的**直接后果**。确实要跳（时间跳/空间跳）时，用一个**反应者一拍**或一个**动因镜**（铃响、广播、来人、一个目光）把因果补上 |
| 10.4 | **反应者缓冲**：段间最便宜的衔接是**场内第三者的反应镜头**——上段主角话音落下，先给反应者一拍（捅肘、对视、吸口气、笔停在半空），再切下段发起方。一两秒，承接一整段。主角的话需要有人"接"，观众的情绪需要有人"替自己反应"。**竖屏例外**：反应不单独成镜、压进同一镜的同一拍（一个眼神／一句"啊？"），绝不独立停留——见 10.0 |
| 10.5 | **声音桥梁**：换场用**先入的声音**搭桥（铃、广播、脚步、环境声由远及近），下一段首镜从该声音的延续开始。声音比画面更能缝合空间裂缝——观众的耳朵会替画面圆场。**这条两档通用**：声音不占时长，竖屏同样该用 |
| 10.6 | **时间锚点**：段间跳跃超过「即刻」时，必须给**时间/事件锚点**（铃响、天色变化、广播、来人），否则模型和观众都默认「紧接着」，动机断裂、动作无由来——「她为什么突然冲出去」这类疑问全是这么来的。**竖屏例外**：时间锚交给台词（"都放学了"／"三小时后"由人物说出来），不给天色空镜 |
| 10.7 | **转场是后期的事，接力是稿子的事**：闪白、空镜、叠化可以由剪辑后期加，但「内容上谁接了谁的棒」稿子里不写，**生成端不会补**——两段各生成各的，断的是叙事不是技术。别用「我后期加转场」安慰自己，那是遮羞不是衔接。**竖屏同理**：你省掉的是**镜头**，不是**因果** |
| 10.8 | **段缝声明必须写桥接**：段缝说明不能只写机位跨度（景别/焦段/换轴——那是 `segment-splicing.md` 的技术参数），必须同时写**内容桥接方式**：承接什么 / 反应者是谁 / 什么声音先入 / 什么时间锚。**竖屏写「台词钩/抢白/打断/矛盾升级」同样算桥接**。机检 **C38** 查的就是这个声明 |

> 📌 机检：**C38 段间缺桥接声明**——相邻两段之间（非首段）的段缝说明/段首行内，既无桥接词（承接/反应镜/先入/时间锚/话头/递进/因果/台词钩/抢白/打断…），也未显式声明「硬切跳」→ WARN。声明即放行：真跳切就写「硬切跳（刻意跳切）」，机检不拦刻意，只拦**没想过**。
>
> 📌 机检：**C39 竖屏空镜冗余**——稿内锁定 **9:16** 且某镜标了「空镜／无人物入画」→ WARN（竖屏节奏里空镜＝拖节奏，见 10.0）；该镜标注「**刻意空镜**」放行。**16:9 / 21:9 稿永不触发**——横屏的空镜是表现手段，不是问题。

> **与 `segment-splicing.md` 的分工**：那份管段缝的**技术参数**（景别跨度/机位角度/定格帧/接口余量），本章管段间的**内容桥接**。两件事都要写，写在段缝说明的同一行里。
