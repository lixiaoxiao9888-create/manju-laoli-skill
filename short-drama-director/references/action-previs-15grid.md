# 通用打戏动作动力学与 15 秒 PREVIS 导演系统 (Action Previs & Combat Engine)

> 📐 **画幅路由**：横屏 16:9 / 竖屏 9:16 的空间感铁律与构图写法 → 以 `aspect-ratio-adaptation.md`（★权威）为准，按用户指定画幅切换（横屏走三分线/对角线，竖屏走垂直纵深/冲镜特写）。

## 〇、 动作强度三档（先定档再套规则）

> ⚠️ **总纲铁律（2026-09-02 实测二次翻车后固化）：AI 视频没有“静止表演”能力。** 任何“对峙 2 秒/蓄势待发/留白/悬停/站立/特写定格”类静止段，模型都渲染成角色呆立几秒、节奏拖沓。**一切情绪与蓄力必须在运动中完成**：边打边蓄、上升途中蓄、后撤中蓄；神态挂载在动作瞬间（甩剑转身时冷笑），不单独成段。唯一允许的“定格”是**命中瞬间 1~2 帧微停顿（Hit-Stop）**，其余静止段默认禁用。

## 一、 15 秒打戏完播潜力评分（启发式，非平台预测模型）

$$\text{完播潜力评分} = 0.20 \times \text{开局吸引力} + 0.30 \times \text{节奏呼吸} + 0.25 \times \text{运镜丰富度} + 0.25 \times \text{情绪拐点}$$

> 说明：该公式是创作者自检用的**加权启发式评分**，用于衡量“完播潜力”而非真实完播率预测。R1 档可选择性满足。

| 维度 | 权重 | 执行硬指标（R2/R3 档） |
|---|---|---|
| **开局吸引力** | 20% | **0~1.5 秒内必须发生攻防接触**（R2/R3 档：开局 0.5 秒内出现两种对立招式的正面硬撞 + 命中瞬间微停顿）。第一帧建议双人同框中近景，避免远景风景慢热铺垫。 |
| **节奏呼吸感** | 30% | 快慢交替，同节奏连续 $\le 5$ 秒。前面极速密集的连打，用**命中瞬间 1~2 帧微停顿（Hit-Stop）**或瞬间加速制造反差，**禁用慢镜/升格**（2026-09-02 实测破坏节奏）。 |
| **运镜丰富度** | 25% | **同运镜 $\le 2$ 秒，同景别 $\le 3$ 秒**。重磅终结招式采用三段式运镜（低仰蓄力 $\rightarrow$ 俯冲跟随 $\rightarrow$ 碰撞定格）。 |
| **情绪拐点** | 25% | 在 8~12 秒区间必须出现一次局势逆转、破防爆发或破绽抓取，让观众情绪剧烈反弹。 |
| **以高潮收尾** | 核心 | **R2/R3 档**：禁止 0.5 秒平缓收尾帧（如收腿落地/发丝飘落/气焰消散）。最后一帧停留在终结技命中、重创失衡、冲击波炸裂、碎石掀飞或倒地嵌墙的最高潮定格。**R1 档**：允许克制收势或悬念收尾。 |

### 开局硬撞新变体：零帧瞬移起手 ＋ 弹射迎击（2026-09-04 吸收）

- **攻方零帧瞬移贴脸**：第一帧即瞬移至对手面门前出招（残影/空间撕裂作瞬移痕迹），省略冲刺过程，开局冲击力拉满；
- **守方弹射迎击对冲**：守方不是原地挨打——弹射起跳/蹬地迎击，与攻方在空中或近身位对冲碰撞；
- 仍守开局铁律：0.5 秒内出现对立招式硬撞 + 命中瞬间微停顿；瞬移必须有视觉痕迹（残影/黑色空间裂隙/空气扭曲），禁无来由跳切。

## 二、 动作动力链 11 环 (The 11-Link Kinetic Chain)

严禁写“挥拳打去”、“放光波对轰”等缺乏物理依据的抽象描述。**关键重击**必须由 11 环推导；连接招/过渡招只需写清起点、受力点与状态继承，不强制逐环展开：

1. **攻击意图 (Intent)**：明确锁定目标受力点（如颌下、心口、太阳穴、两肋、膝关节）。
2. **起手蓄力 (Preparation)**：三体式/防守架/深蹲沉身，筋膜紧绷，肢体蓄势。
3. **重心位移 (Center of Gravity)**：重心前后/高低转移（如前倾下压或后撤沉马）。
4. **后足蹬地 (Foot Propulsion)**：后脚掌抓地跺地，力从地起，脚底产生物理推力与地面微尘反馈。
5. **腰胯转拧 (Torso/Hip Torque)**：腰胯如大轴转动，将地面反作用力放大并传导至躯干。
6. **脊柱传导 (Spine Transmission)**：脊椎如大弓崩弹，将力量贯通至肩、肘、腕或髋、膝、踝。
7. **肢体攻击轨迹 (Limb Trajectory)**：直线穿刺、弧线横扫、垂直下砸或螺旋钻击的明确几何空间轨迹。
8. **精准物理接触点 (Contact Point)**：拳峰击中下颌骨、肘尖砸入肋骨缝隙、剑尖刺入手腕破绽、脚跟钉踩膝关节。
9. **力道渗透与受力形变 (Impact & Deformation)**：
   * 肌肉凹陷波纹化、受力闷响、受击方下颌线受力紧绷；
   * 受击方头部剧烈侧偏/后仰，躯干弓成虾形，双脚离地向后横飞。
10. **收招惯性与空气回填 (Inertia & Recoil)**：脚步换位稳住支撑，衣摆发丝因自身拳风向前吹拂后自然回落。
11. **下一击继承状态 (Chained State)**：借旋转惯性或反作用力，零间隔顺势切入下一段连招或防御。

## 三、 镜头规格五要素强制体系 (Camera Specs Standard)

每次出现镜头描述时，必须提供完整的 5 维参数，不给模型任何自由脑补的空间：

$$\text{格式：}[\text{景别}] · [\text{拍摄视角}+\text{角度}] · [\text{运镜方式}] · [\text{跟随目标}]$$

| 要素 | 标准选项 | 正确写法示例 |
|---|---|---|
| **① 景别** | 特写 / 近景 / 中近景 / 中景 / 全景 | `近景` / `特写` / `中景` |
| **② 拍摄视角** | 正面 (0°) / 侧面 (90°) / 斜角 (30°-60°) / 俯拍 / 仰拍 | `45°斜侧` / `正面0°` / `30°仰视` |
| **③ 角度** | 平视 / 仰视 (N°) / 俯视 (N°) | `平视` / `30°仰视` / `60°俯视` |
| **④ 运镜方式** | 跟拍跟镜 / 急速推镜 / 急速拉镜 / 甩镜闪切 / 慢动作跟镜 / 升降运镜 / 定格定镜 | `急速推镜` / `跟拍跟镜` / `定格定镜` |
| **⑤ 跟随目标** | 跟随角色、肢体或具体接触点 | `跟随右拳推进至心口接触点` / `跟随双臂攻防交错` |

### 空间感两大铁律 (Critical Spatial Laws)
* **铁律 1（中景/全景禁 90° 侧拍）**：中景及全景（看到双人全身或大半身）**严禁使用 90° 侧面正拍**（会产生街机横版平面的廉价感）。必须使用 **30°~60° 斜角拍摄**，借助前后人物遮挡与背景纵深产生强烈对决压迫感！
  * **例外：仅在近景/特写（胸部以上或手部细节对招）时允许使用 90° 侧拍。**
* **铁律 2（景别与动作幅度匹配）**：
  * 大幅动作（腾空/大步崩拳/飞踢/过肩摔投/轻功腾挪） $\rightarrow$ 必须配 **全景/中景**，展现舒展身形与空间位移；
  * 小幅动作（短桥寸劲/指探面门/卸力擒拿/肘击） $\rightarrow$ 必须配 **近景/特写**，放大击打密度与受力细节。
* **16:9 横屏构图**：充分利用横向画幅展开中长焦空间纵深与环境压迫；双人对峙采用三分线左右站位，攻防推进利用对角线动势。
* **9:16 竖屏构图**：强调垂直高度落差，腾空下劈、贴地滑行与冲镜特写。
* **运镜节奏**：同运镜 $\le 2$ 秒，同景别 $\le 3$ 秒。15 秒内完成 5~8 次精准镜头切换。

## 四、 上半身近景对招：机枪节奏 (Machine-Gun Rhythm)

R2/R3 档打戏中必须包含 1 段（2~3 秒）上半身中近景对招，写清连续招式链：
* **招式序列化**：禁止写“每秒打N拳”或“快速连击”等抽象词，必须逐击写清：`攻击部位 -> 招式名 -> 防守方具体反应`（至少包含拳/掌/肘/指/腕等多种手法；R2/R3 档建议包含肘击）。
* **机枪节奏三模式**：
  1. **3轻1重**：3 次极速拳掌试探逼防 $\rightarrow$ 1 次崩拳/顶肘重击慢放定格；
  2. **封-破-杀**：一格挡封中线 $\rightarrow$ 二分桥破防线 $\rightarrow$ 三寸劲贯穿制胜；
  3. **左右交替加速**：左-右-左-右出拳间隔越来越短，像打鼓加速。

## 五、 防守三态与闪避大幅化 (Defense 3-States & Evasion)

### 1. 防守三态溃败链条
防守方被破防后，必须经历真实的失衡过渡过程，严禁瞬间原地复原：
```
┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐
│  1. 完整态 (Full) │ ───>  │ 2. 崩防线 (Break) │ ───>  │ 3. 过渡态 (Mess)  │
│ 桩步稳固,架桥封门 │       │ 招式被破,双臂弹开 │       │ 狼狈侧闪,零碎抵抗 │
└──────────────────┘       └──────────────────┘       └──────────────────┘
```
* **过渡态（0.3~1 秒）**：来不及架起完整防守，只能靠本能做出零碎反应（侧身闪、大幅后仰躲、单臂仓促拍开、碎步后撤、缩身下潜）。

### 2. 闪避大幅化法则
* **严禁小幅微移**：禁止写“微微侧身一让”、“轻轻偏头”。
* **必须是大幅度身体运动**：
  * **极低位下潜**：身形骤降贴地，重拳擦着头皮削过削断发丝；
  * **铁板桥大后仰**：腰身向后折叠 $\ge 45^\circ$，腿风自面门上方两指处呼啸而过；
  * **翻转/空翻闪避**：侧手翻、阿乌空翻或360°旋转跳开，闪避即位移、位移即蓄力。

## 六、 真实物理碰撞与空气动力反馈 (Air & Impact Feedback)

**原则：轻≠弱，轻=快而重。** 每一击都应尽量有空气与物理反馈（R1 档可弱化气爆，以真实受力为主）：

| 攻击类型 / 烈度 | 空气动力表现 | 接触点气爆与物理破坏 |
|---|---|---|
| **轻击 / 快速刺击** | 拳风/腿风使空气轻微扭曲泛白，发丝被气浪吹动 | 接触点荡开肉眼可见的空气波纹，微震后退 |
| **重击 / 崩拳 / 扫踢** | 拳面形成锥形音爆气穴，腿风如利刃割开可见弧线气刃 | 空气被撕裂出沉闷音爆，环形气浪向外扩散，脚下碎石被震起弹开，受击方双脚擦地滑行留痕 |
| **终结技 / 绝杀大招** | 蓄力时周身气流向出招点疯狂聚拢压缩，空气产生热扭曲/冷凝震颤 | 接触点轰然炸开大范围环形冲击波，地面呈放射状裂纹崩塌，受击者后背衣服爆开并被掀飞撞塌墙面 |

## 七、 劲气与特效绑定系统 (Combat Aura & Energy Rules)

1. **特效服从角色主色**：角色主色是什么，所有招式特效必须统一为该色系（如太极=黑白阴阳，红茶=橙红爆烈，白鸽=紫黑弧刃，凛羽=银白霜雾，雷电=纯紫电弧，剑神=红紫锐光）。
2. **特效四要素**：
   * **① 起源点**：拳面/脚尖/肘尖/剑尖；
   * **② 流动形态**：直线穿刺型 / 弧线切割型 / 螺旋扩散型 / 垂直坠落型；
   * **③ 终点爆散**：冲击波 / 碎石炸裂 / 气浪横扫；
   * **④ 余韵残留**：地面焦痕 / 冰晶霜痕 / 蛛网裂纹 / 碎尘回填。
3. **特效生长三段论与段落分配**：
   * **前段 (0-3s)**：一招一炸，开局冲击亮眼即收；
   * **中段 (3-12s)**：连打过程零特效保持干净清晰，收尾重击带特效给出节奏感；
   * **后段 (12-15s)**：特效生长全开（萌芽 $\rightarrow$ 壮大 $\rightarrow$ 巅峰绽放），冲击波轰然炸裂收尾。
