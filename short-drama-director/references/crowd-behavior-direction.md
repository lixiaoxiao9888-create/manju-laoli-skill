# 群像行为调度（Crowd Behavior Direction · ★权威）

> **本文档是总控共享权威文件**（群像行为层唯一权威 · 2026-10-24 P7 新增）
> **为什么放在总控**：本文件的权威横跨**资产层**（`GRP-N`）、**调度层**（`blocking-direction.md`）、
> **分镜层**（`short-drama-camera-system.md` §六）、**表演层**（`acting-direction.md` §十一）、
> **投喂层**（`model-adapters.md` §5）与**质检层**（C40）——按本包「跨阶段共享权威留在总控」的惯例置于此。
> **管什么**：画面里**每一个可见的人**在**干什么**、**什么时机动**、**动到什么幅度**。
> **不管什么**：群像的**长相一致性**（资产层 → `sd-asset-engine/references/continuity-and-crowd.md` §3.1 `GRP-N`）、
> 群像的**站位点位与轴线**（调度层 → `references/blocking-direction.md`）、
> 群像的**景别与机位**（`sd-storyboard-engine/references/short-drama-camera-system.md` §六）。**四层分工，不互相替代。**

## 〇、为什么需要这份文件（缺口由来 · 三条病根全部核实过）

**病灶（2026-10-24 用户实测）**：男女主对话时，背景人物「呆滞、站着不动、一点反应都没有」；
教室戏里后排同学「像僵尸一样在那儿看着」；闹市里一男一女走过，「背后的人不知道在干嘛」。

**核验结论：原则层不缺，缺的是「槽位 + 裁决 + 机检」三件事。**

群像行为的**正确原则**在包内其实已经存在三处：

| 出处 | 已有内容 |
|---|---|
| `short-drama-director/references/blocking-direction.md` §4.2 | 「背景行为」三级之一：有稳定的背景活动（不抢动作），**禁"静止的人形立牌"**；循环性动作（添茶/侍立/走动） |
| `short-drama-director/references/acting-direction.md` §十一 | 群体反应成波不成排；焦外听者非静止蜡像；常态是人群微动，威胁来临全体冻结 |
| `sd-asset-engine/references/continuity-and-crowd.md` §3.2 | 人群调度卡①~⑦（分布维度） |

**但它们全部止步于原则层，从未进入执行链**，原因是三件事同时缺位：

1. **投喂层无槽位**——七段式四个既有槽位没有一个能承载"每个人在干什么"：【核心人物】的 `（在场）` 明文允许无反应，【站位声明】只有位置/依托物/朝向/姿态四要素（无"手头事务"项），【时间轴分镜】无群像事务句范式，【场景资产】不承载人物行为；
2. **无冲突裁决**——原则要求"背景要有活动"，而 C35（禁写独立动作）/ C37（示范句"其余是静"）/ C20h（必写"无其他人物"）三条**反向规则**没有任何裁决说明。执行者面对冲突时，必然选**最短最省力**的那条 → 按死背景人；
3. **机检零断言**——`C25b` 只禁同步反应词（众人同时/齐声/异口同声），这是**反面**；正面（"必须要有事务"）一条机检都没有。

**准确表述**：**禁止一群人"齐动"（C25b）≠ 允许一群人"齐不动"。** 前者有规则、后者没有，缺口就在这个不对称上。

**本文件补的正是这三件事**：§六 给三个投喂槽位、§五 给冲突裁决（不打碎 C35/C37/C20h）、§七 给 C40 正面对偶机检。

## 一、总纲

**核心口诀：画面里每个可见的人都在干一件自己的事；静止只能是被事件打断的结果，不能是默认底色。**

**三层闸门**（缺一层必跑偏）：

| 层 | 决定什么 | 判据 | 阶段 |
|---|---|---|---|
| **第一层** | 本段**要不要**群像 | 场景属性 + 剧本功能 | 导演稿（调度环） |
| **第二层** | 有群像时**写到哪一型** | 景别 × 距离 | 分镜稿 |
| **第三层** | 机检**怎么判**（不越界） | 条件触发，无全局默认 | 出稿机检 |

⚠️ **沉默是最贵的代价**：既不说"有人"也不说"没人"，模型就自己猜——结局要么空场、要么乱加人。
**三种结局（有 / 只要密度 / 没有）都必须是显式声明。**

## 二、第一层闸门：本段要不要群像（A / B / C）

> 本层在**导演稿调度环**（`blocking-direction.md`）建坐标系时一次性标定：
> `群像：开（A/B）/ 关（C）`。**投喂层只翻译，不重新决策。**

### 2.1 判据表

| 类 | 判据（命中任一即入） | 强制句式 |
|---|---|---|
| **A · 要写群像** | ① 公共/半公共空间且同镜 ≥2 个无名可见人（教室、食堂、闹市、朝堂、客栈、车站、商场）<br>② 剧本有围观/旁听/知情者的叙事功能<br>③ 导演稿摆了 ≥2 个非主角点位<br>④ **台词需要"被听见"的证据**（秘密、宣判、丑闻、退学通知） | 逐人写事务（§三 R/P 型） |
| **B · 只要真实感** | 场景天然有人但不承担叙事（远景街面、食堂背景、走廊人流过场） | 只写密度句（§三 S 型），**不写个体** |
| **C · 不要群像** | ① 密闭双人戏（车内、密室、走廊尽头、电梯）且剧本未写第三人<br>② **打戏段**（群像行为撕碎动作清晰度）<br>③ 特写/大特写（B 档景别装不下）<br>④ 剧本写明「四下无人/空无一人」<br>⑤ 竖屏 9:16 的近景对话（画面窄，背景人会被压成畸形） | 显式写 `除 @XX 外无其他人物` |

⚠️ **C 类判据具有一票否决权，优先级高于 A 类。** 否则「公共空间 + 打戏」会打架——**打戏赢**。
理由：动作清晰度是刚性需求，背景真实感是弹性需求，刚性永远先于弹性。

### 2.2 三类各自必须显式声明（沉默 = 未通过）

- **A 类**：本段必须有 ≥1 条群像事务句（§三），且人数与 §三 的字数预算匹配；
- **B 类**：必须写一句密度句（`前景 N 名…中景 N 名…人流自左向右，不遮挡主角面部`）；
- **C 类**：**必须写** `除 @XX 外无其他人物`——这正是 **C20h 已验证有效的句式**，直接复用，不新增字段。

⚠️ **C 类句式禁在 A / B 类出现**：写了 `无其他人物` 却又安排了群像事务，是自相矛盾的指令，模型会二选一，必崩一边。

## 三、第二层闸门：写到哪一型（R / P / S）

> 判据是**镜头装得下多少细节**（景别 × 人物与主体的距离），**不是剧情重不重要**。
> 景别越紧、人离主体越近 → 越要写到 R 型；远景一律 S 型封顶，一个字也不许多写。

| 型 | 谁 | 必写三件套 | 字数预算 | 禁 |
|---|---|---|---|---|
| **R · 反应人** | 同处一室、能听见台词的人（教室同学、邻座、同桌、围观者） | ① 手上事务 ② 被台词/事件**打断的时机** ③ 反应幅度 | 每人 **15~25 字** | 集体同步转头、开口抢戏、起身走近主体 |
| **P · 事务人** | 公共空间、不承担叙事功能的路人 | ① 具体事务（动词+宾语） ② 穿画方向 ③ 与主角最近距离 | 每人 **8~15 字** | 停下来盯主角、看镜头、与主角产生交互 |
| **S · 密度人** | 远景、焦外、虚化人群 | 只写密度 + 人流方向 + 一个整体倾向 | **一句 20 字封顶** | 写任何个体、写个体五官 |

### 3.1 事务句三件套（所有型通用）

```
① 手上事务 = 具体动词 + 具体宾语（抄板书 / 拧瓶盖 / 把纸箱往摊后码 / 转笔 / 低头刷手机）
             ❌ 禁「站着 / 看着 / 在旁 / 围观 / 发呆」——这是状态词，不是事务词
② 幅度 = 原地 · 小幅 · 可重复（翻一页 / 转半圈 / 顿一下 / 停住笔）
③ 视线归属 = 事务优先，事件其次（「低头看卷子，未注意到讲台」/「被『退学』二字打断才抬眼」）
```

**分界线（本文件与 C35/C37 的接法 · 务必守住）**：
✅ **允许**：原地、小幅、循环、不抢焦、不与主体交互的事务；
❌ **仍禁**：位移（走近/绕到/走到）、与主体产生交互（递东西/拍肩/搭话）、抢焦大动作（挥手/起哄/大幅度转身）。
——**判据一句话：这个动作会不会把观众的注意力从主体身上抢走？不会就写，会就禁。**

## 四、停顿—恢复曲线（对话戏的核心，也是他最缺的一环）

**铁律：群像静止只允许出现在事件高潮的那一拍，且必须写出"被什么打断"。**

| 阶段 | 群像状态 | 写法 |
|---|---|---|
| ① 事件前 | **全员事务态** | 每人一件不同的事（禁"都在做同一件事"） |
| ② 事件抛出 | **最多 1~2 人先反应**，写 0.3~0.5 秒秒差 | 「@甲 先停笔抬眼；0.4 秒后 @乙 才转头」 |
| ③ 事件高潮 | **全体停下手中事**（此刻静止合法） | 「全班笔尖同时停住，无人说话」 |
| ④ 事件后 | **各自恢复，不许同时** | 「靠窗那人继续转笔，前排两人已低头继续抄，最后一排仍望着讲台」 |

⚠️ ③ 的「全体停」**每段至多一次**，且必须紧邻事件；**禁把 ③ 当段的默认底色**（那是僵尸的温床）。
⚠️ ② 的秒差与 `acting-direction.md` §十一·补 第 3 条（错峰反应律）同源；③④ 与 §十一「威胁来临全体冻结」同源。

## 五、与既有规则的边界（不打碎 C35 / C37 / C20h / C25b）

| 既有规则 | 治什么 | 本文件怎么接 |
|---|---|---|
| **C35** 多人物镜未标层次 | 两个主体被平铺成并排 | **不动**。层次照标；陪衬者的**虚焦形态照写**，只是在虚焦形态之外**追加一句原地事务** |
| **C37** 背景多人同动未点名 | 群体动作没主 → 全员一起动 | **不动**「动作点到人头」；只把示范句从「其余是静」升级为「其余各自有事」（见 §八） |
| **C20h 死律 4** | 群像横向互看 + 镜像克隆 | **加例外口径**：`无其他人物` **只在 C 类写**；A/B 类禁写，改为写人数 + 各人事务 |
| **C25b** 群演反应同步词 | 整齐划一的假反应 | **不动**。本文件 §四 的错峰就是它的正面对偶 |
| **C32** 画面段最低三要素 | 背景全空、模型自配背景 | **不动**。C32 的「背景元素」指**物件/环境行为**；本文件补的是**人物行为**，两者叠加不冲突 |

## 六、投喂层三个槽位（七段式不增段 · 不新增字段）

### 6.1 槽位一：【核心人物】的 `（在场）` 升级

| 写法 | 判定 |
|---|---|
| `@同学甲（在场）` | ❌ C40a WARN（旧僵尸许可证） |
| `@同学甲（在场·事务：低头抄板书）` | ✅ 合规 |
| `@同学乙（在场·事务：转笔，被「退学」二字打断才抬眼望向讲台）` | ✅ 合规（R 型完整三件套） |

括号内事务词 **2~6 字**封顶（R 型可放宽到 12 字以内，须含打断时机）。**M0 无图形态照写**，逐段复述。

### 6.2 槽位二：【站位声明】四要素 → **五要素**

```
旧（四要素）：位置 + 依托物 + 朝向 + 姿态
新（五要素）：位置 + 依托物 + 朝向 + 姿态 + 手头事务
```

```
【站位声明】：@周越（画面右 · 倚课桌 · 正面朝左 · 坐姿 · 手头事务：抬手起哄）、
@同学甲（画面左后 · 伏桌 · 侧身朝右 · 坐姿 · 手头事务：低头抄板书）、
@同学乙（画面中后 · 靠窗 · 背身侧朝 · 坐姿 · 手头事务：转笔望窗外）；
轴线锁定：右前左后，全段禁越轴；位移仅限本镜声明路径（周越: 课桌→过道）。
```

- 五要素对 **R / P 型必填**；主角可写 `手头事务：无（全神注视对手）`；
- **S 型不进站位声明**（无个体、无点位），只走密度句；
- 第 5 项**不引入新方位信息**——只写手在干什么，不写画面左右（§五 单一方位权威不受影响）。

### 6.3 槽位三：【时间轴分镜】A 档群像镜

A 档景别（大远景/远景/全景/中全景/中景）且同镜 ≥3 人时：

- 必须写**每人各异**的事务分配（一条事务句可覆盖 2~3 人，但**事务必须不同**）；
- **禁**「众人围观 / 大家在旁 / 周围人群 / 同学们看着」这类聚合词（聚合词 = 模型自由发挥 → 同步僵尸）；
- B 档景别（中近景及以下）**不写个体事务**，背景人物写「虚化」即可（`short-drama-camera-system.md` §六 不变）。

## 七、机检 C40（条件触发 · 无全局默认值）

> 编号占用核对：C1~C39 已占用，**C40 空**。
> 规则权威：`sd-qc-engine/references/machine-check-manual.md` C40 条目；实现在
> `short-drama-director/scripts/validate_prompt.py` `finalize_checks()`。

**触发门（命中任一才判；两者都不命中 = 安静通过，一声不吭）**：

- **开（A/B）**：【核心人物】出现 ≥1 个 `（在场` **或** 画面段出现 ≥3 个可见人
  **或** 场景词命中公共空间词表（教室/食堂/街/市/广场/朝堂/客栈/车站/商场/礼堂/食堂）
  ——且**非打戏档、非纯特写段**；
- **关（C）**：密闭双人 / 打戏档 / 纯特写段 / 声明「四下无人」。

| 子码 | 判据 | 级别 |
|---|---|---|
| **C40a** | 开门下，`（在场）` 未带 `·事务：` → 逐个点名 | WARN |
| **C40b** | 开门下，画面段出现「众人/大家/围观/在旁/周围人群/同学们看着」聚合词且同行无事务动词 → 逐镜点名 | WARN |
| **C40c** | 开门下，【站位声明】摆位 ≥3 人，五要素「手头事务」缺失率 ≥50% | WARN |
| **C40d** | 关门下，既未写 `无其他人物`、也未写任何群像事务（沉默） | WARN |

⚠️ **C40 不是全局开关**：它**不要求每段都有群像**。C 类段只查 C40d 一句声明，群像行为一条都不查。
把 C40 写成全局默认 = 把病从"全静"搬到"全动"，两头都错。
