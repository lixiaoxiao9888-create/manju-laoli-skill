# AI 短剧全流程 Asset-First 六阶段生产管线 (Asset-First Pipeline)

> ⭐ **全局总控流程（★权威）**：本文件定义本 skill 从立项到成片的**唯一生产顺序**。所有模块（剧本/资产/分镜/渲染/质检）都挂载在这六阶段上，禁止跳步、禁止以文字描述替代资产图。
>
> 🔗 联动：画幅/风格/平台锁定 → `aspect-ratio-adaptation.md`；剧本门控 → `screenplay-gate-engine.md`；资产图执行 → `asset-spatial-ledger.md` / `character-lineage-and-sheets.md` / `production-ledger-handbook.md`；分镜 → `spatial-topview-camera.md` / `action-previs-15grid.md`；渲染 → `seedance-render-engine.md` / `model-adapters.md`；质检 → `quality-gate-review.md`。

## 〇、 核心原则（铁律）

1. **资产图先于分镜**：任何跨镜/跨集复用的角色、场景、道具，必须在分镜前完成**出图并锁定**；
2. **"名字+装扮"不是资产**：文字描述只是索引标签；**资产 = 可直接投喂模型的资产参考图**（角色 4 View 资产板 / 场景资产图（母版+机位调度版或站位版+拼接图） / 道具图）；
3. **无图不进分镜**（P2 硬门禁）：分镜里引用的 `@CHR` / `@SCN` / `@PRP` 锚点，必须指向已锁定的资产图，否则阻断；
4. **画幅、风格、平台在 P0 一次锁定**，全流程沿用（见 `aspect-ratio-adaptation.md`）；
5. **分批出图 + 逐批确认**：资产不一次性堆砌，按 角色→场景→道具 分批产出，每批锁定后才进下一批；
6. **资产依赖分级（A0~A3 · V6.8）**：Asset-First 能力全保留，但按任务复杂度触发——**A0** 纯文字/单镜/无角色一致性要求：不强制资产链，文字描述可直投（禁用 @锚点 即不受门禁3/4约束）；**A1** 单角色单镜：资产可选（有参考图更稳）；**A2** 跨镜角色/场景一致性：启用相关角色/场景资产出图；**A3** 多人/多场景/连续剧集/高一致性项目：完整执行 Asset-First 六阶段（默认档）。判定不清按 A3 处理（宁全勿缺）。

## 一、 六阶段总览

```text
P0 立项锁定（画幅 / 风格 / 平台 / 时长）
  ↓
P1 剧本五阶门控（前提 → 结构 → 节拍 → 实体 → 专业剧本页）
  ↓
P2 【数字资产包】（本 skill 核心阶段）
  ├─ 2a 实体提取：从剧本自动提取全部 角色(CHR)/场景(SCN)/道具(PRP)/声音(AUD)
  ├─ 2b 资产清单：全量编码 + 16项五官 + 6项材质 + 亲缘推导表(T1→T2→T3) + 用户确认无遗漏
  ├─ 2c 分批出图：①角色(A/B级 4 View 资产板) ②场景(核心场景资产图（母版+机位调度版或站位版+拼接图）) ③道具(关键道具图)，每批确认锁定
  └─ 2d 交付《资产图册》：CHR/SCN/PRP 全部附资产参考图 + 短锚点 @名，成为唯一权威事实来源
  ↓
P3 空间调度 + 分镜（每个镜头引用已锁定 @资产图，CAM1~4 / 180°轴线）
  ↓
P4 投喂生成（Seedance 2.5 / 2.0 强制二选一，每单元 ≤15s，三层解耦提示词）
  ↓
P5 质检（P0/P1/P2 + 资产一致性：画幅/脸型/服装与资产图一致；**修改稿另须跑改动后三步复验并附《改动复验报告》，见门禁 6**）
```

## 二、 P2 数字资产包执行细则

### 2a 实体提取（从剧本自动派生）
- 扫描定稿剧本，提取全部**有跨镜复用**的实体：
  - 角色 CHR：A（核心）/ B（常驻）/ C（群众，仅需文字描述）；
  - 场景 SCN：核心场景（多集出现 / 关键打斗 / 重场戏）必须出图；一次性过场场景可仅文字；
  - 道具 PRP：剧情关键物证 / 多镜出现 / 有防穿模风险的道具必须出图；
  - 声音 AUD：OS / 对白 / SFX / BGM 四类，进产出册声音资产表。
- **判定标准**：该实体是否在 2 个以上镜头/场景出现，或在后续剧情中复用 → 是则出图。

### 2b 资产清单（用户确认门禁 1）
- 输出《完整资产清单》：所有实体编码 + 角色 16 项五官 + 6 项材质 + 亲缘推导表（T1→T2→T3 骨相继承 40%~60%）+ 场景空间属性 + 道具特征；
- **必须让用户确认"无遗漏、无错位"后才进入出图**，禁止直接出图。

### 2c 分批出图（每批确认门禁 2）
- **第一批·角色**：T1 男女主先出（建立脸模与画风基准）→ T2 亲属/反派按亲缘推导直接出图 → T3 功能配角按需出图；全部采用 4 View 资产板（`asset-spatial-ledger.md` §二）；
- **第二批·场景**：核心场景出空间资产图（布局 / 材质 / 光源 / 机位占位，`asset-spatial-ledger.md` §三）；
- **第三批·道具**：关键道具出图（材质 / 反光 / 手持基准）；
- 每批产出后展示给用户确认，确认后才锁定进入下一批。

### 2d 交付《资产图册》（权威事实来源）
- 产出 `《[剧名]_资产图册.md`，每条 CHR / SCN / PRP 附：
  - 编码与短锚点（`@CHR-荆恪-正面` / `@SCN-山门` / `@PRP-打火机`）；
  - **资产参考图**（可直接投喂的分镜引用图）；
  - 索引标签（名字+装扮+16项+6项，仅作描述，不作交付物主体）；
- 该图册取代纯文字台账，成为 P3/P4 的唯一权威事实来源（Single Source of Truth）。

## 三、 门禁与确认点（违反即阻断）

| 门禁 | 位置 | 规则 |
|---|---|---|
| **门禁 1** | P2b → P2c | 资产清单未获用户确认 → 禁止出图 |
| **门禁 2** | P2c → P2d | 分批资产图未全部锁定 → 禁止进入分镜 |
| **门禁 3** | P3 | 分镜引用的 `@锚点` 无对应已锁定资产图 → 阻断并回补出图 |
| **门禁 4** | P4 | 投喂提示词引用未锁定资产 → 阻断 |
| **门禁 5** | P5 | 质检发现画幅/脸型/服装与资产图不一致 → P0 阻断 |
| **门禁 6** | P5（修改类交付） | 修改稿未跑「局部验证 → 联动冲突检查 → 全量审核」三步复验 / 未附《改动复验报告》 → 阻断交付（见 `quality-gate-review.md` §三） |
