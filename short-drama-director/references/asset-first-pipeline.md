# AI 短剧全流程 Asset-First 六阶段生产管线 (Asset-First Pipeline)

> ⭐ **全局总控流程（★权威）**：本文件定义本 skill 从立项到成片的**唯一生产顺序**。所有模块（剧本/资产/分镜/渲染/质检）都挂载在这六阶段上，禁止跳步。
>
> ⚠️ **两条正交轴，别混谈**：本文件管 **A 轴（任务复杂度 → 走不走资产链）**；**图在不在手里（M0/M1/M2 素材形态）** 由 `asset-delivery-modes.md`（★权威）管——**两者正交**，A 轴判不清按 A3 处理，**M 轴按用户实际条件处理，不取最高档**。
>
> 🔗 联动：**角色识别/归并/资产候选 → `character-extraction.md`（★角色提取权威）**；素材形态与门禁改判 → `asset-delivery-modes.md`（★权威，本文件所有门禁的判定细则以它为准）；画幅/风格/平台锁定 → `aspect-ratio-adaptation.md`；剧本门控 → `screenplay-gate-engine.md`；资产图执行 → `asset-spatial-ledger.md` / `production-ledger-handbook.md`；分镜 → `blocking-direction.md` / `spatial-topview-camera.md` / `sd-combat-engine`；渲染 → `seedance-render-engine.md` / `model-adapters.md`；质检 → `quality-gate-review.md`。

## 〇、 核心原则（铁律）

1. **生产顺序先于一切**：P0 立项锁定 → P1 剧本门控 → P2 数字资产包 → P3 空间调度+分镜 → P4 投喂生成 → P5 质检，**禁止跳步、禁止倒序**；
2. **默认只出提示词，不直接出图（2026-09-16 用户确认 · 最高优先级）**：本管线默认交付 = 出图提示词/文档，**不调用出图工具直接生成图片**（含角色基准图、场景母版、道具图、分镜关键帧/首帧图）。只有用户**明确逐次下发出图口令**（"出图/生成图片/跑图"）才执行；执行仍须先过下方门禁 1（资产清单确认）+ 门禁 2（分批逐批确认），禁止把"开始 P2 资产出图"当默认动作；
3. **图在哪儿，决定门禁怎么判（与第 2 条配对）**：本包**不持有图**——图由用户在外部平台自行生成并持有。因此「资产」的合格形态**分三级**：**M0 纯提示词**（不写图号）/ **M1 编号占位**（写 `图N` + 必附《素材接线单》，**默认**）/ **M2 已入库**（用户交回、登记图册）。**每次交付首行必须声明当前形态**。判定细则与门禁改判表见 `asset-delivery-modes.md`（★权威）；
4. **"名字+装扮"是否算资产，按形态定**：**M2** 下资产 = 可直接投喂的角色/场景/道具参考图，文字描述只是索引标签；角色图版式由四字段模板的「排版结构」确定；**M1** 下资产 = **编号 + 用途 + 外观要素档案 + 接线单一行**；**M0** 下资产 = **外观档案复述块本身**（文字即资产）。**三种形态都算"有资产"，不存在"M0 就等于没资产"**；
5. **无图不进分镜 → 改判为条件门**：分镜引用的锚点必须有**对应物**，但"对应物"按形态定义——M2 指向已锁定资产图；**M1 指向已登记的图号（在接线单/素材映射表内）**；**M0 指向已写出的文字档案**。**"没有图"本身永不构成阻断理由**（原"无图不进分镜"绝对门已废止）；
6. **不索要 · 不阻塞 · 不假装 · 要声明**：禁止索要图片作为继续流程的条件；禁止因缺图阻断任何阶段；**禁止写不存在的图号、禁止声称"与资产图册一致/已核验"而实际从未见过图**；每次交付首行声明形态。详见 `asset-delivery-modes.md` §五；
7. **画幅、风格、平台在 P0 一次锁定**，全流程沿用（见 `aspect-ratio-adaptation.md`）；
8. **分批出图 + 逐批确认**（**仅用户下发出图口令后适用**）：资产不一次性堆砌，按 角色→场景→道具 分批产出，每批锁定后才进下一批；
9. **资产依赖分级（A0~A3 · A 轴）**：Asset-First 能力全保留，但按任务复杂度触发——**A0** 纯文字/单镜/无角色一致性要求：不强制资产链，文字描述可直投（禁用图号即不受门禁 3/4 约束）；**A1** 单角色单镜：资产可选（有参考图更稳）；**A2** 跨镜角色/场景一致性：启用相关角色/场景资产；**A3** 多人/多场景/连续剧集/高一致性项目：完整执行六阶段（默认档）。**判定不清按 A3 处理（宁全勿缺）**。

## 一、 六阶段总览

```text
P0 立项锁定（画幅 / 风格 / 平台 / 时长）+ ★素材形态初判（M0/M1/M2，默认 M1）
  ↓
P1 剧本五阶门控（前提 → 结构 → 节拍 → 实体 → 专业剧本页）
  ↓
P2 【数字资产包】（本 skill 核心阶段 · 按 M 形态分流）
  ├─ 2a 实体提取：先建立角色全集并完成称谓归并，再筛视觉资产候选；另提取 SCN/PRP/AUD
  ├─ 2b 资产清单：角色全集 + 资产候选/处理理由 + 出场证据 + 外观事实/缺口；用户核对角色边界与遗漏
  ├─ 2c 出图/出词（★按形态分流；角色按确认后的资产候选逐批处理）
  │     M0 → 产出「外观档案复述块」供各段复用（不写图号）
  │     M1 → 产出「出图提示词（用户外部跑图）+ 图号编号 + 《素材接线单》」（默认）
  │     M2 → 分批出图：①已确认角色候选参考图（排版按四字段模板）②场景资产图 ③道具图，每批确认锁定
  └─ 2d 交付《资产图册》（★按形态降级）
        M0 → 《外观档案册》（无图，纯文字档案）
        M1 → 《资产编号册 + 素材接线单》（编号 + 用途 + 外观要素 + 该挂哪张）
        M2 → 《资产图册》（附资产参考图，单一事实源）
  ↓
P3 空间调度 + 分镜（锚点按形态指向：M0 文字档案 / M1 已登记图号 / M2 已锁定资产图；CAM1~4 / 180°轴线）
  ↓
P4 投喂生成（Seedance 2.5 / 2.0 强制二选一，每单元 ≤15s，三层解耦提示词）
  ↓
P5 质检（P0/P1/P2 + 一致性：M2 可比图像；**M0/M1 改判为"与文字档案一致"**；**修改稿另须跑改动后三步复验并附《改动复验报告》，见门禁 6**）
```

## 二、 P2 数字资产包执行细则

### 2a 实体提取（从剧本自动派生）
- **角色先全量登记，再筛资产**：必须读取 `character-extraction.md`，扫描指定范围内全部场次，建立「角色全集」；覆盖画内人物、画外发声者、仅被提及人物、群众组、回忆/想象人物及身份待核对象。每项至少有称谓映射、出现方式、可定位的出场依据和身份判断状态。
- **角色识别纪律**：有证据才合并姓名/别名/称谓；身份揭晓前保留待核，不强并；换装、受伤、年龄阶段通常记作同一人的状态变体；替身/双胞胎/复制体有剧情证据时单列；不具名群众按群体登记。亲属关系只记剧情事实，禁止据此推导外貌相似、骨相比例或家族色彩。
- **再筛视觉资产候选**：综合复用、剧情功能和视觉连续性判断，不用「至少两镜」作唯一门槛。一次性关键人物可以入选；反复出现的匿名群众不因此逐人建档。分别标出独立角色基准、群体描述、文字记录、非视觉人物及不入选的理由。
  - 角色 CHR：A（核心）/ B（常驻或关键功能角色）/ C（群众组或低视觉风险角色）；角色全集中的非视觉人物可保留索引，不自动分配视觉资产。
  - 场景 SCN：核心场景（多集出现 / 关键打斗 / 重场戏）必须建档；一次性过场场景可仅文字；
  - 道具 PRP：剧情关键物证 / 多镜出现 / 有防穿模风险的道具必须建档；
  - 声音 AUD：OS / 对白 / SFX / BGM 四类，进产出册声音资产表。
- **角色建档判定**：按 `character-extraction.md` 的复用/剧情功能/视觉必要性三项判断并写明理由。入选后按素材形态处理（**M0 建外观档案 / M1 建编号档 / M2 建图档**）；未入选但在范围内的人物仍保留在角色全集。
- **场景与道具判定**：场景、道具沿用各自的复用与剧情关键性标准，不把角色资产阈值机械套用于其他实体。

### 2b 建档清单（用户确认门禁 1）
- 输出《角色全集》和《视觉资产候选表》：临时ID、主名/别名映射、身份/关系事实、出现方式、出场位置与原文依据、资产处理理由、外观缺口、CHR 编码建议；并列 SCN/PRP/AUD 清单；
- **必须让用户确认角色边界、称谓归并和资产候选无关键遗漏/错位后才进入 2c**；只对会改变建档数量的身份歧义集中提问，未知外观标「未设定」而不阻断其余工作；
- 角色提示词阶段按 `asset-spatial-ledger.md` 四字段模板编排：画幅、排版结构、服装与身体材质、面部特写；五官 10 项与服装 6 项填入对应描述。提取阶段不虚构缺失五官，不额外要求亲缘推导、比例尺、HEX 色盘、材质小样、人物履历或图上五官拆解展示。
- ⚠️ **本步与出图无关**：清单是**文字/编号层**的确认，**不要求用户此时提供任何图片**（原"未确认禁出图"在 M0/M1 下改判为"未确认禁进入 2c 建档"）。

### 2c 出图 / 出词（按 M 形态分流 · 每批确认门禁 2）

| 形态 | 本步产出 | 门禁 2 判定 |
|---|---|---|
| **M0** | **外观档案复述块**（发/服装/体态/年龄感/标志物五要素，供各段直接复用）+ 场景坐标系与 `SET_STATE` 登记 | 复述块是否**五要素齐全**（缺项 → 回补） |
| **M1**（默认） | **出图提示词**（用户拿去外部平台跑图）+ **图号编号** + **《素材接线单》** | 每个图号是否有接线单行 + "只控制什么/不控制什么"是否写全 |
| **M2** | ①已确认角色候选的参考图（排版按四字段模板）②场景（核心场景资产图）③道具（关键道具图），每批确认锁定 | 分批资产图是否全部锁定 |

> ⚠️ **M0 / M1 下不存在"分批出图"**——本包不出图，用户也不把图交回，**禁止以"资产图未锁定"为由卡住 P3**。

### 2d 交付台账（★按形态降级命名，禁止混称）
- **M0** → 产 `《[剧名]_外观档案册.md`：每条 CHR / SCN / PRP 附**外观档案复述块 + 场景坐标系 + 状态变体**，**不含任何图号**；
- **M1**（默认）→ 产 `《[剧名]_资产编号册.md` + 《素材接线单`：每条附**编号 + 用途 + 外观要素 + 该挂哪张 + 只控制什么/不控制什么**；**接线单是交付必备件**；
- **M2** → 产 `《[剧名]_资产图册.md`：CHR / SCN / PRP 全部附**资产参考图** + 短锚点，成为 P3/P4 唯一权威事实来源（Single Source of Truth）；
- **三种交付物共同点**：都是 P3/P4 的权威依据——**"有依据"不等于"必须是有图的依据"**。命名**不得混称**（M0/M1 稿里写成《资产图册》即为形态违约）。

## 三、 门禁与确认点

> ⚠️ **门禁按素材形态改判**：下表是**速查版**；**逐形态的完整判定细则以 `asset-delivery-modes.md` §二 为准**（本表与它冲突时以它为准）。

| 门禁 | 位置 | 规则（速查） | 形态影响 |
|---|---|---|---|
| **门禁 1** | P2b → P2c | 建档清单未获用户确认 → 禁止进入 2c | M0/M1 下 = 文字/编号层确认，**不涉及图片** |
| **门禁 2** | P2c → P3 | 本批产出未确认 → 禁止进入分镜 | M0/M1 下改判为"复述块齐全 / 接线单齐全"；**不存在"资产图未锁定"阻断** |
| **门禁 3** | P3 | 分镜锚点无对应物 → 阻断并回补 | **对应物按形态定义**：M0 文字档案 / M1 已登记图号 / M2 已锁定资产图 |
| **门禁 4** | P4 | 投喂稿锚点与映射不一致 → 阻断 | M0 无图号；M1 图号槽位须与接线单**逐条对应**；M2 原样 |
| **门禁 5** | P5 | 一致性不符 → P0 阻断 | M0/M1 改判为**"与文字档案一致"**（发/服装/体态/年龄感/标志物逐项）；**M2 才做图像级核验** |
| **门禁 6** | P5（修改类交付） | 修改稿未跑「局部验证 → 联动冲突检查 → 全量审核」三步复验 / 未附《改动复验报告》 → 阻断交付（见 `quality-gate-review.md` §三） | **不受形态影响，始终全量适用** |

**形态声明为交付前置**：交付稿**首行未声明素材形态（M0/M1/M2）** → 视为形态未定，机检告警（`sd-feed-engine/scripts/gate_check.py` 闸门 6），**不得交付**。
