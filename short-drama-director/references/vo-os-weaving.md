# 旁白（VO）与内心独白（OS）视听编织规范 (Voice-Over & Off-Screen Weaving)

> 📌 **来源与定位（V6.9 并入正文）**：整合自 legacy V5.0.2《旁白与独白视听编织规范与剧本》（V6.x 重写时遗失，仅存 AUD 台账分类与混音电平痕迹）。V6.9 应实测反馈「独白/旁白无格式规程」正式并入。解决两大通病：**旁白泛滥变成广播剧**、**内心独白变成说教工具**。
>
> 核心主张：**声画分离、高反差对比、严格控制篇幅**。旁白与独白不是"台词的补充"，是引爆画面深度的**结构件**。
>
> 🔗 流程位置：P1 剧本（画外声台词入稿）→ P4 投喂（画外声镜行写法）→ P5 质检 → 机检 C14 兜底。

---

## 一、 三大编织纪律

### 纪律 1 · 篇幅钢性卡口（防"听书化"）

单集声音容量分配（以 90~120s 单集计）：

```
【单集总时长】
 ├─ 画面/动作留白        约 40%~50%
 └─ 声音容量            约 50%~60%
      ├─ 角色开口台词     ≥ 70%（占声音容量）
      └─ 旁白+独白 VO/OS ≤ 30%（占声音容量）
```

- **字数上限**：每分钟成片中，VO+OS 总字数 **60~80 字封顶**（折算 15s 段 ≤20 字；机检 C14 按 >20×段数告警，容差线 25 字/15s）；
- 给画面留出足够的动作反应时间——画外声一多，完播率死在"听书感"。

### 纪律 2 · OS 声画分离红线（防"对口型穿帮"）

> **铁律：内心独白（OS）发声时，画面中的角色绝对不许张嘴。**

- **画面承载标准**：闭口神态微特写承载声音张力——瞳孔收缩、紧捏的手指、雨水打在睫毛上、嘴角毫无波动；
- ❌ 错误：画面写"陆渊愤怒地瞪着对方" + 声音独白咆哮（角色嘴却在动/画面与声音打架）；
- ✅ 正确：`画面：陆渊低着头，雨水顺睫毛滑落，嘴唇紧闭，纯黑的眼睛死死盯着橱窗里的广告巨幕。` + `声音：画外·内心独白（OS）：这是顾家，偷走沈家的第三千天。`
- **为什么 OS 禁用官方 `{}` 台词字符**：`{}` 是锁口型对白通道——模型会给台词配张嘴动作，直接打穿声画分离红线。OS 一律走**声音段**（见 §二），画面写死"嘴唇紧闭/不张嘴"。**机检 C14 拦截**。

### 纪律 3 · VO 冷漠审视法则（防"旁白翻译画面"）

> **旁白（VO）不是用来翻译画面动作的，而是提供与画面高反差的信息差，或客观、冷静、近乎残酷的时空审视。**

- ❌ 错误：`画面：她无助地走在雨中。旁白：她感到极其绝望。`——复述画面 + 心理描写，双重违规；
- ✅ 正确：`画面：她穿着破烂麻衣，浑身湿透，走在霓虹闪烁的帝都街头。旁白（VO，冷漠）：帝都，每分钟有十个新公司注册，也有十个沈家这样的名门，无声蒸发。`
- 判据一句话：**把旁白删掉，画面信息量不得减少**——删掉后画面照旧讲得通的旁白，就是复述，删。

## 二、 七段式投喂写法（格式权威 · 对齐 model-adapters §5）

### 镜行归属规则（一句话）

> **"台词："字段只装画内开口对白（锁口型）；OS 与 VO 是画外声，一律写进"声音："段并标注画外身份，"台词：无。"**

### OS（内心独白）镜行模板

```text
00:04-00:08 [镜头2] 紧特写 · 侧角 · 固定。陆渊低着头，雨水顺着帽檐砸在手背，嘴唇紧闭，
嘴角毫无波动，眼神深处一丝光亮缓缓苏醒。声音：[SFX: 雨声] + 画外·内心独白（OS·声音暗哑极平静）：
"八年了。林姨，他们把你推下去的那个天台，就在我头顶。"。台词：无。
```

- 画面段**必须含闭口证据**（嘴唇紧闭/抿唇/嘴角无波动——FACS 画面语言，不写 AU 编号）；
- 声音段标注 `画外·内心独白（OS·音色描述）："台词文本"`；
- 台账登记：`AUD-[角色]-OS`（干燥近讲，相对电平 0 dB，对齐 production-ledger-handbook §声音表）。

### VO（旁白/画外音）镜行模板

```text
00:00-00:06 [镜头1] 大远景 · 俯瞰 · 缓降。深夜暴雨中的顾氏集团总部大楼，霓虹在雨水中折出血红。
声音：[SFX: 暴雨、远处警笛] + 画外·旁白（VO·冷漠机械低沉）："在帝都，每分钟有三万亿资金流转。
但黑石街，不属于阳光。"。台词：无。
```

- VO 通常挂在**无人物镜**或**人物闭口镜**上；台账登记 `AUD-VO-旁白`；
- VO 默认走后期贴声（成片内置人声的合成风险高、且 VO 本就不锁任何口型）；用户明确要求"VO/OS 成片内出声"才走生成通道，此时仍守纪律 2 闭口红线。

### 双路线选择（OS/VO 成片出声方式）

| 路线 | 写法 | 适用 |
|---|---|---|
| **后期贴声（默认推荐）** | 镜行画面照写（含闭口证据），OS/VO 台词文本进【音效】段末尾"画外声清单"或交付物附《画外音贴声单》（台词文本 + 入点秒 + 音色描述） | 一切 OS/VO；声画分离天然成立 |
| **生成内嵌（2.5 进阶 · 用户明确要求时）** | OS/VO 文本写入声音段并保留"画外"标注，2.5 不使用 `{}`；画面段写死闭口 | 用户点名要"视频里直接有人声" |

## 三、 使用时机与禁令

### 五类正当用途（在此之外不用）

1. **点题转折**：段落/全集收官处一句定调（"顾家的大楼……该塌了"）；
2. **立人设自述**：第一集人物登场，一句自述钉死身份与处境（"我辛苦劳累了一辈子"）；
3. **委屈账**：情绪顶点后把"具体的账"摊给观众（独白写事实清单，不写"我好委屈"）；
4. **时空审视/时间锚**："第三千天""深夜十一点"——冷静的时间刻度；
5. **信息差投放**：观众知道、画面角色不知道（悬念引擎）。

### 四条禁令（违者 P1 重构）

1. **禁交代设定/前情**：世界观、金手指、人物关系一律不走画外声（设定走画面物证与冲突自己长出来）；
2. **禁复述画面**：旁白说画面里正在发生的事（纪律 3 判据）；
3. **禁替代冲突**：用独白解释"她很生气"来省掉一场攻防戏；
4. **禁连排**：OS/VO 不与相邻镜的画外声连排、不紧贴断章收尾（画外声结束后至少一镜画面/对白缓冲）。

## 四、 机检对照（C14 · scripts/validate_prompt.py）

| 检查 | 级别 | 判定 |
|---|---|---|
| OS 镜行画面含开口词（张嘴/开口/说道/喊着等，在"声音："前的画面段内） | **FAIL** | 声画分离红线，改闭口神态微特写 |
| OS/VO 写进"台词："字段 | **FAIL** | 台词字段只装画内开口对白 |
| OS/VO 使用 `{}` 台词字符 | **FAIL** | `{}` 锁口型，必穿帮 |
| 段内 OS 镜数 >2 或 VO 镜数 >1 | WARN | 超配额，回检是否可删 |
| 段内 VO+OS 总字数 > 折算上限（≈20 字/15s 段） | WARN | 篇幅钢性卡口 |

> **统计口径（2026-09-19 校正）**：配额只统计**【时间轴分镜】的时间码镜行**——OS/VO 是"在某镜里发声"的行为。
> 写在【强制禁止项】/【音效】/【接续状态】里的"画外音/旁白"字样**不是使用**，不计镜数也不计字数
> （原实现按行扫字样，曾把"画外音期间不得张嘴"这条禁止项误算成一次 VO 使用并多计 40 字配额，见 CHANGELOG 2026-09-19）。

> 画外声台词本身**不计入** `dialogue-speed-check` 语速自检与镜行时长口型预算（无口型可锁），但**计入成片时长**——贴声段镜长照常按情绪节拍定（法则 17）。

## 六、 与既有规则的关系

- `model-adapters.md` §5.2（对白语气规范）：**画内对白的语气位与本文件的画外声音色位同构**——同为"紧贴角色名的全角括号"；`（语气）` 与 `（OS·音色）`/`（VO·音色）` 是同一形态在画内/画外两个分支上的落法。语气位 **2.0/2.5 同规格必写**；音色锁仅 2.5 且为可选增强（本例 §五 表中 `【陆渊（声如古潭）："顾城。在里面吗？"】` 即为本规范的标准形态）；
- `quality-gate-review.md`：OS 张嘴穿帮列 P1 结构缺陷（自动修复：改闭口神态）；无戏剧任务空镜 P2 维持；
- `★ facs-micro-expression.md`：闭口神态按画面语言写（唇/下颌区可见动作），AU 编号不进正文（分层铁律）；
- `production-ledger-handbook.md`：AUD 台账 OS 行口径对齐（干燥近讲 0 dB），新增 `AUD-VO-旁白` 行；
- `validate_prompt.py`：C14 机检兜底；`segment-splicing.md`：OS/VO 不紧贴段缝断章（连排禁令与空镜任务分工）。

- [ ] 每分钟 VO+OS 总字数 ≤60~80 字（15s 段 ≤20 字）；
- [ ] 每个_OS_镜画面段含闭口证据，无开口词；OS/VO 全部在"声音："段，"台词：无。"；
- [ ] 未使用 `{}` 承载 OS/VO；
- [ ] VO 删掉后画面信息量不减（不复述）；
- [ ] 五类正当用途之外无画外声；无连排、不贴断章；
- [ ] AUD 台账已登记 OS/VO 行；
