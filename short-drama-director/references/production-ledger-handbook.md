# 《剧组资产图册》与工业化台账总控规范 (Production Ledger Handbook)

> 🔗 **流程位置：P2 数字资产包（见 `asset-first-pipeline.md` ★权威）**。本规范定义台账**结构**。
>
> ⚠️ **台账按素材形态分三种（权威 = `asset-delivery-modes.md`）**：**本包不持有图**——图由用户在外部平台生成并持有。因此：
> - **M0 纯提示词** → 产出 **《外观档案册》**：CHR/SCN/PRP 每条附**外观档案复述块**（发/服装/体态/年龄感/标志物）+ 场景坐标系与 `SET_STATE`；**无"资产参考图"字段**；
> - **M1 编号占位（默认）** → 产出 **《资产编号册 + 素材接线单》**：每条附**编号 + 用途 + 外观要素**，并逐号给出"你该挂哪张 / 只控制什么 / 不控制什么"；**"资产参考图"字段保留但留空**（用户侧持有）；
> - **M2 已入库** → 产出 **《资产图册》**：**此时"资产参考图"字段才必须填写**。
>
> **本节以下所有"资产参考图"必填字段，仅在 M2 下为硬约束；M0/M1 下留空不是缺陷**，不得因此索要图片或判定台账不完整。

---

## 一、 资产图册核心架构（Markdown 标准结构）

一份合格的《资产图册》（由原《剧组产出册》升级）必须包含以下六大核心板块：

```text
《[剧名]_资产图册.md》
├── 1. 风格与摄影基准（机型、镜头组、色温光系、参考电影、画幅锁定）
├── 2. 风险与合规监测（平台敏感词过滤、防封禁合规转译）
├── 3. 角色资产台账（CHR- 编码、层级、必定演员、运行范围、**资产参考图**）
├── 4. 声音与音效资产表（AUD- 编码、OS/对白/环境音、分层电平）
├── 5. 关键道具与资产表（PRP- 编码、关键特征、防穿模规范、**资产参考图**）
├── 6. 空间场景清单（SCN- 编码、空间类型、光线/时段、机位基准、**资产参考图**）
└── 7. 分集单元执行表（U01~Uxx、生成方式、渲染规格、状态）
```

> ⚠️ 相比旧版核心升级：CHR / SCN / PRP 三板块新增 **“资产参考图”** 字段（角色参考图按四字段模板的排版结构；场景/道具按各自模板）。**该字段的填写要求按素材形态分级——M0/M1 下留空，M2 下必填**；文字描述在 M2 下降级为索引标签，**在 M0/M1 下则是资产本体**。

## 二、 六大资产标准化编码规范

### 1. 角色资产编码（CHR-）
- **格式**：`CHR-[角色名]-[正面/侧面/状态/服装]`
- **必填字段**：
  | 字段 | 说明 | 示例 |
  |---|---|---|
  | **永久ID** | 角色全局唯一标识 | `CHR-荆恪-正面` |
  | **主名与称谓映射** | 主名、别名/称谓及归并依据；不确定时标待核 | `荆恪 ← 荆将军（第2集自称确认）` |
  | **身份/设定** | 年龄、职业、核心性格 | 30岁男主，外表冷静寡言，眼神冷峻 |
  | **梯队分级** | A（核心主角）/ B（常驻配角）/ C（群众） | `A - 核心主角` |
  | **出场依据** | 登场集/场与简短原文证据；全集人物均须可追溯 | `EP01-S03：「……」` |
  | **建档理由** | 复用、剧情功能、视觉连续性；未入选也记处理理由 | `跨集复用，需脸型连续` |
  | **必定演员** | 绑定脸模/LoRA ID 或指定生成模型 | `ImageGen: 1024x1536 high-cinematic` |
  | **运行范围** | 登场集数与场景覆盖 | `第 1~12 集，全剧核心` |
  | **外观事实/缺口** | 原文明确、可确认推断、未设定分开记录 | `原文：短发；年龄未设定` |
  | **状态变体** | 换装/年龄阶段/受伤/伪装状态关联同一角色 | `EP03正式服（同一CHR）` |
  | **资产参考图** | 按 `asset-spatial-ledger.md` 四字段模板制作，M2 下分镜/投喂直接引用 | `@CHR-荆恪-基准` → 资产图文件 |

### 2. 声音资产编码（AUD-）
- **格式**：`AUD-[角色名/音效]-[类型]`
- **类型定义**：
  - `AUD-[角色]-OS`：内心独白（干燥近讲，相对电平 0 dB）
  - `AUD-[角色]-对白`：现场台词（环境空间感微混响，相对电平 0 dB）
  - `AUD-[场景/动作]-SFX`：物理碰撞与招式音效（相对电平 -6 dB）
  - `AUD-[情感/氛围]-BGM`：背景配乐（相对电平 -14 ~ -18 dB）

### 3. 关键道具资产编码（PRP-）
- **格式**：`PRP-[道具名]`
- **必填字段**：
  - 道具名称与属性（如 `PRP-金属打火机`：复古磨砂黑银双拼，带刻痕）
  - 剧情关键作用（如“第四集揭露身份的关键物证”）
  - 防穿模/防变异描述（材质、反光度、手持抓握基准）
  - **资产参考图**：关键道具出图，分镜引用 `@PRP-打火机`（**投喂层落位＝【场景资产】栏，与 `@SCN-` 并列写**；判定与 M0/M1 写法见 `model-adapters.md` §5「道具锚定纪律」——2026-10-13 补，此前该写法仅存于本手册、投喂层无位可放）

### 4. 场景空间清单（SCN-）
- **格式**：`SCN-[场景名]`
- **空间属性**：室内/室外、日景/夜景、主色调（如暖橙晨光、冷蓝夜雨）
- **空间快照**：设定 3D 空间左右边界与 180° 轴线基准
- **资产参考图**：核心场景出空间资产图（布局/材质/光源/机位占位），分镜引用 `@SCN-山门`
- **出图标准**：跨 2 镜以上或关键打斗/重场戏的场景必须出图（见 `asset-spatial-ledger.md` §三）

### 5. 分集单元执行表（U01~Uxx）
- **格式**：`U01` ~ `Uxx`（按**模型契约表** `model-adapters.md` §5 的组数预算切分——2.5 默认 25~30s/组时 3 分钟约 6~8 组，2.0 ≤15s/组时约 12~15 组；本表**不写死组数与单组时长**，以编译时实际契约为准）
- **单元属性**：视觉生成方式（图生视频/文生视频）、美术设定、对白与语速自检状态、渲染规格（9:16 / 16:9 4K）、状态（待生成/已初审/已定剪）。

## 三、 指令交互与输出格式示例

当用户输入 `/剧组产出册`、`/生成台账`、`/数字资产包` 或 `/资产图册` 时，系统先按 `character-extraction.md` 核对角色全集和视觉资产候选，再按 `asset-first-pipeline.md` P2 流程执行：
1. 输出《角色全集》与《视觉资产候选表》（主名/称谓映射、出场证据、出现方式、处理理由、外观缺口）及 SCN/PRP/AUD 清单 → 用户确认；
2. 分批出图（角色 → 场景 → 道具），每批确认锁定；
3. 交付《资产图册》（CHR/SCN/PRP 全部附资产参考图 + 短锚点 @名）；
4. 文末提供分镜推进建议（P3）。
