# 台词语速自检引擎 (Dialogue Speed Check Engine)

> 🔎 导航（2026-08-28 自检新增）：本模块为**台词语速与对白时长的唯一自检流程**，与 `wenxi-micro-expression.md`（对白时间预算）`dialogue-doctor-7d.md`（七维第6维节奏）协同。**每条台词投喂前必须过本自检**，尤其是有对白的分镜/视频提示词。

---

## 一、 语速三档标准（核心基准）

| 档位 | 语速 | 适用场景 |
|---|---|---|
| **标准语速** | **3.5 ~ 5 字 / 秒** | 普通对白、文戏推进、信息交代 |
| **慢速重音** | < 3.5 字 / 秒 | 金句宣言、临终遗言、情绪顶点、威慑台词（一字一顿） |
| **快速爆发** | > 5 字 / 秒 | 情绪失控、争吵、紧张逼问、连珠炮（⚠️ 单段连续 >5字/s 不得超过 3 秒） |

**速算公式：**
$$\text{口播时长} = \frac{\text{可发音字符数}}{\text{语速（字/秒）}}$$
$$\text{对白总时长} = \text{口播时长} + \text{标点/句读停顿} + \text{情绪停顿} + \text{金句余韵}$$

* **最短时长（最快有效）**：`字数 ÷ 5`
* **最长时长（最慢有效）**：`字数 ÷ 3.5`
* 判定区间：口播部分应落在 `[字数/5, 字数/3.5]` 秒内；**总对白时长**须再叠加停顿与余韵，且整组 ≤ 单组上限（15s）。
* **字数口径**：只数可发音字符（汉字、数字、外文字母），标点符号不计入语速公式，另按独立停顿预算处理（顿号/逗号 ≈ 0.1~0.3s，句号/感叹/问号 ≈ 0.3~0.6s）。

## 一·补、 语气 → 语速档联动（2026-09-19 新增）

台词语气位（`台词：【角色（语气）："…"】`，规范见 `model-adapters.md` §5.2）里的**力度维与节奏维直接决定语速档**——语气不是纯音频描述，它会改动镜长预算：

| 语气词类型 | 语速档 | 对镜长的影响 |
|---|---|---|
| 气音 / 低语 / 断续 / 一字一顿 / 拖长音 | **慢速重音 < 3.5 字/s** | 按慢档下限算时长（`字数÷3.5` 起） |
| 急促 / 连珠 / 拔高 / 抢话 | **快速爆发 > 5 字/s** | 按快档上限算（`字数÷5`），但连续 >5 字/s 不得超 3 秒 |
| 冷笑 / 嗤笑 / 讥诮 / 平直 | 标准 3.5~5 字/s | 冷嘲类"说半句停半句"，句内停顿时长按 ×1.5 估 |

- **必做**：语气位里出现慢档词（气音/低语/一字一顿）时，**不得再按标准档 4 字/s 倒推镜长**——这是"台词塞不进镜、被迫拉伸凑时"的常见根因（与法则 17 时长守恒联动）；
- **反过来说**：镜长按法则 17 由剧情倒推时，语气档是"剧情"的一部分，必须参与计算。

## 二、 三档自检判定（P0~P2 级）

| 判定 | 条件 | 处置 |
|---|---|---|
| ✅ **合规** | 语速在 3.5~5 字/s，且单句 ≤24 字 | 通过，按预算时长投喂 |
| ⚠️ **超长句（P1）** | 单句 > 24 字 | **强制拆镜**：通过正反打/过肩/切入反应镜头拆 2~3 镜，每镜 ≤18 字 |
| ⚠️ **金句缺发酵（P2）** | 关键台词/高潮金句后无 0.3~0.8s 无对白反应镜头 | 补 0.3~0.8s 微表情/旁观者反应镜头（瞳孔骤缩/倒吸凉气/静场） |
| 🔴 **超时/压缩（P0）** | 台词所需时长超出该镜预算，或为塞时长强行放慢/加速 | 重构台词或调整镜次分配，严禁超镜时长 |

---

## 三、 五步自检流程

1. **拆句**：把台词按逗号/句号/感叹/问号拆成独立小句；
2. **计数**：每句只数**可发音字符**（汉字/数字/字母），标点不计入字数；
3. **停顿预算**：按句内逗号（≈0.1~0.3s）与句末符号（≈0.3~0.6s）估算标点停顿；
4. **套档**：按场景情绪选定语速档（标准/慢速/快速）；
5. **速算**：`口播时长 = 字数 ÷ 语速`，再加停顿与金句余韵得**对白总时长**，对照该镜时间轴预算；
6. **判定**：套用二、三档判定 → 输出结论 + 建议。

## 四、 输出契约（每条台词自检卡）

```markdown
* **台词**：“[台词文本]”
* **字数**：N 字
* **语速档**：标准 3.5~5 字/s / 慢速重音 / 快速爆发
* **语气档来源**：语气位（如 `气音·发颤`）→ 判慢速重音（无语气位或标准档语气词则写"标准档"）
* **所需时长**：约 X ~ Y 秒（N÷5 ~ N÷3.5）
* **判定**：✅ 合规 / ⚠️ 超长句需拆镜 / ⚠️ 缺金句发酵 / 🔴 超时
* **建议**：[拆镜方案 / 补反应镜头 / 重构]
```

## 五、 常见字数速查表（标准语速 3.5~5 字/s）

| 字数 | 所需时长 | 判定 |
|---|---|---|
| ≤8 字 | 1.6~2.3 s | ✅ 短句，适合金句/威慑 |
| 10 字 | 2.0~2.9 s | ✅ 标准句 |

## 六、 拆镜示范（超长句处理）

**原台词**（33 字）："三年前你杀我师父灭我师门占我武馆今日我陈烬归来倒要看看谁该灭门偿命"

**拆镜方案**（每句只数汉字，标点另计停顿）：
```
镜1（近景·正面）："三年前，你杀我师父，灭我师门，占我武馆。"（16字 ≈ 3.2~4.6s + 4处停顿≈0.6s，总≈3.8~5.2s ✅）
镜2（特写·眼神）："今日我陈烬归来。"（7字 ≈ 1.4~2.0s + 句末停顿，金句前预留0.3s ✅）
镜3（近景·步步逼近）："我倒要看看——谁，该灭门偿命！"（11字 ≈ 2.2~3.1s + 破折号与感叹停顿，结尾预留0.5s发酵 ✅）
```

## 七、 与质检门禁联动

* 在 `quality-gate-review.md` 的 P0/P1 检查项中**并入语速维度**：
  * 有对白的提示词组，在交付前须先过本自检（拆句→计数→停顿→套档→速算→判定）；
  * 单组对白总时长 + 镜头动作时长 ≤ 单组上限（15s）；
  * **语速自检卡作为内部 QC 附件**，默认不写入最终视频生成提示词正文（避免污染投喂文本，也避免增加模型负担）。
* 声音三层架构中，对白（0dB 相对优先）按自检时长落在时间轴上，不得与 SFX/BGM 抢时段。
