# 多分支互动短剧写作格式与示范标准（山音2.0版）

本标准旨在向创作者展示**多分支剧情（Interactive Drama / 互动短剧）的标准工业化排版格式。**
**在互动短剧中，剧情通过一个“公共节点（Intersection）”引出多个“选择肢卡片（Choice Cards）”**，再分流至不同的**“独立分支结尾剧本（Branch endings）”**。

---

## 🧭 一、 互动短剧大纲架构图

```
                ┌─── [公共节点：寒刀临颈] ───┐
                │                           │
         [玩家选择肢 A]               [玩家选择肢 B]               [玩家选择肢 C]
                │                           │                           │
      [分支结尾一：深渊行者]       [分支结尾二：微光救赎]       [分支结尾三：无限悬置]
     （封闭式·血仇吞噬）         （治愈式·大义救赎）         （开放式·余味无穷）
```

## 🎬 二、 互动短剧双轨剧本示范：《暗影抉择》

- **同一故事主线**：陆渊在暴雨中的废墟平台，终于将大仇人顾城逼入死角。顾城手里捏着沈家昭雪的唯一账本，另一只手用枪顶着沈惊歌的额头。平台下方是滚烫的熔岩。
- **字数与排版规范**：严格执行“子弹台词律（≤15字）”与“声音事件（SFX）”。

---

### 🎴 阶段 2：玩家交互选择肢卡片（Interactive Choice Card）

此时，屏幕中央弹出三个金色边框的选择肢，并伴随 10 秒倒计时：

- **【选择 A】── 射击顾城。**（放弃账本，直接肉体消灭，进入《深渊行者》结局）
- **【选择 B】── 交换黑卡。**（放弃复仇，用帝王黑卡交换沈惊歌，进入《微光救赎》结局）
- **【选择 C】── 针分双向。**（极限操作，同时射击账本与手枪，进入《无限悬置》结局）

### 💻 阶段 3：三大分支结局独立剧本

#### 【分支结尾一：深渊行者】（选择 A 触发 ── 封闭式·血仇结局）
- **戏剧内核**：肉体消灭，大仇得报，但公义物证（账本）随之坠入深渊。

| 镜号 | 景别 | 时长 | 画面描述（AI/画师指令） | 听觉音效/BGM | CV台词（严格保真） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **#04-A** | 特写 | **4s** | 陆渊眼神一厉，指尖黑光大盛。冰针如闪电般暴射而出。 | 【音效】尖锐刺耳的“咻”金属破空尖啸声（SFX）。 | **无台词** |
| **#05-A** | 中景 | **7s** | 冰针瞬间穿透顾城握枪的手腕。顾城惨叫，手枪脱手飞出。但在同一秒，他狰狞冷笑，用另一只手死死把沈家账本扔进了平台下方的熊熊大火中。 | 【音效】骨肉碎裂声，纸张入火的“呼”爆燃声（SFX）。 | **顾城**（惨叫，疯狂大笑）：哈哈！沈家，永远翻不了案！ |
| **#06-A** | 全景/卡点 | **15s** | 陆渊飞身救下沈惊歌。顾城在黑雾锁链的缠绕下坠入深渊。沈惊歌看着大火里的账本，脱力瘫软在陆渊怀里，放声痛哭。陆渊的双眼，彻底化为没有眼白的纯黑色（被暗影彻底吞噬）。 | 【BGM】悲壮、宏大的交响乐响起，在沈惊歌哭声和雨声中渐隐（Dissolve）切黑。 | **陆渊**（抱紧她，声如死水）：账本没了。但顾家，死光了。 |
