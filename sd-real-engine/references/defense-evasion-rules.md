# 防守三态与闪避大幅化 (Defense 3-States & Evasion) · ★权威总控

> 打斗的"好看"一半在挨打方。防守方被破防后必须经历真实的失衡过渡过程，**严禁被重击后下一帧立刻原地满血架防**。闪避必须大幅化——小幅微移在画面上等于没动。

---

## 一、 防守三态溃败链条

```text
┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐
│  1. 完整态 (Full) │ ───>  │ 2. 崩防线 (Break) │ ───>  │ 3. 过渡态 (Mess)  │
│ 桩步稳固,架桥封门 │       │ 招式被破,双臂弹开 │       │ 狼狈侧闪,零碎抵抗 │
└──────────────────┘       └──────────────────┘       └──────────────────┘
```

### 1. 完整态 (Full Defense)
桩步稳固，双臂架桥护头护胸，姿态从容。**此态最长 1.5~2s**，随即必须进入变化（模型无法长时间保持姿态）。

### 2. 崩防线 (Break Line) · 0.3~0.5s
被重拳/扫腿直接震散格挡：双臂向两侧弹开，中线与要害彻底大开。
- 写法：`重拳砸在格挡双臂上，双臂被震得向两侧弹开，中路门户大开`。

### 3. 过渡态 (Messy Transition) · 0.5~1s
来不及重新架防，只能靠狼狈本能零碎抗争：
- 狼狈极低下潜 / 铁板桥大后仰弯腰 / 单臂仓促向外乱拍 / 碎步踉跄后撤。

> ⚠️ 写防守溃败时，**三态必须连续发生**，禁"破防后立刻复原"。

## 二、 闪避大幅化法则

**严禁小幅平移**：禁止写"微微侧身一让""轻轻偏头""稍稍后退"。

必须是大幅度肉体运动：

| 闪避方式 | 写法要点 | 视觉特征 |
|---|---|---|
| **极低位下潜** | 身形骤降贴地 | 重拳擦着头皮削过，削断发丝/帽檐 |
| **铁板桥大后仰** | 腰身向后折叠 ≥45° | 腿风自面门上方两指处呼啸而过 |
| **侧空翻/360°旋转跳开** | 闪避即位移 | 闪避+换位一步完成，落地即蓄力 |
| **大步滑移/滑步** | 大幅横向/斜向位移 | 重心低、幅度大，瞬间拉开距离 |
| **贴地滑铲** | 下盘突破/避险 | 从腿间滑过或滑至侧后 |

**闪避即位移、位移即蓄力**：闪避落地的瞬间身体已进入下一招的起手（借势反击/拉开距离），禁止"闪开→站定→再出手"。

## 三、 防守方零碎抵抗写法（过渡态弹药库）

- 单臂仓促拍开：`守方单臂斜拍，勉强改变拳路方向，拳锋擦耳而过`；
- 缩身下潜：`守方缩身下潜，攻方重拳自头顶呼啸而过`；
- 碎步后撤：`守方碎步连连后撤，脚下踉跄，险些绊倒`；
- 本能格挡：`守方双臂胡乱格挡，每挡一下都被震退半步`。
