## 一、 时长预算协议

1. **单组时长**：**按总控模型契约表执行**（`model-adapters.md` §5：2.5 默认 25~30s / 2.0 上限 15s；下限 12s、禁 16~24s 碎段区）——⚠️ **本节不再写「推荐每组 ≤15s」**，该值仅适用 2.0；单镜 3~5 秒、一组 3~4 镜为节奏参考。**打戏例外条款**：快节奏打斗/单段信息量小时允许下探至下限 12s（见 `model-adapters.md` §5 铁律）；
2. **2.0 时长铁律**：2.0 单段上限 15s，**不是 10s 也不是固定值**——按剧情内容量倒推（台词 3.5~5 字/s + 动作节拍），禁卡 10s、禁全片统一段长、禁"段长÷镜数"机械等分；
3. **时长前置预算**：`目标组数 = 预估成片总时长 ÷ 模型契约表对应单组时长`（2.5 按 25~30s/组 → 180s 约 6~8 组；2.0 按 ≤15s/组 → 180s 约 12~15 组）；
4. **单组即成品**：每组自带时间轴（00:00 起）、画幅风格、资产短锚点、分镜详情与负面词，整组复制即投喂；
5. **长段**：15s 以上必须用官方 `[起-止秒]` 时间戳分段且一镜连贯运镜过渡（模型不支持组内硬切）。

## 二、 版本语法对照（投喂前核对）

| 语法项 | Seedance 2.5 | Seedance 2.0 |
|---|---|---|
| 音效标记 | 官方字符：音效 `<>`、台词 `{}`、音乐 `()`、字幕 `【】`；社区 `[SFX: ...]` 亦可 | 无官方字符，音效写入镜行 `声音：` 文字描述，**默认由模型生成** |
| Hit-Stop | 允许三件套（1~2 帧微停顿+接触点火花+双刃咬死震颤声） | **禁顿挫词**（顿挫/阻尼/弹开），打击感靠接触瞬间画面本身 |
| 运镜 | 单段可写复杂连续运镜与转场 | 每镜一条简单运镜，禁一镜多转折 |
| 蓄力 | 可写压缩收束蓄力 | 必须边打边蓄，禁静止蓄力段 |
| 参考图 | ① 全能参考模式（参考图组锁形象，默认）② 首尾帧模式（first_frame+last_frame，与参考图互斥） | 单参考图锁形象（**图 ≤9** · 2026-10-17 修订），**无首尾帧** |
| 参数行 | 不使用——model 写进【画幅风格】句尾 `model=` | 同左 |
| 台词 | 走声音层 `{}`，不写进口型 | 写入台词栏锁口型节奏，模型生成对白（默认视频内出） |

> ★ **段7 极简口径（2026-10-13）**：默认只写上面四项。旧长清单（角色变形 / 手部异常 / 慢动作升格 / 分身…）已废——按 §5.0.4「禁令失效三改法」，被禁词根本身就是画面词，长清单等于给模型递画面词表。打戏段若确有某类穿帮史（如多人场面分身高发），最多**按需追加 1~2 条**并在交付说明写理由（权威见 `short-drama-director/references/model-adapters.md` §5）。

### 镜行书写规则（硬约束）
- 镜行格式：`00:00-00:05 [镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`；
- **每镜行尾必带行内 `声音：` 与 `台词：`**（无台词写"台词：无。"）；
- 镜行**不写"跟随@谁"**（跟随目标融进动作描述，如"镜头随其位移横移"）；
- 动画中带神态：`他甩棍转身的瞬间冷笑，棍梢带出一道风声`（神态挂动作上，禁独立静止特写）；
- **段末定格（取代原接续状态尾行，2026-10-09 · 时长 2026-10-12 用户裁定为「末 1 秒整秒硬定格」）**：每段末镜行内写 `第 13.5 秒起运动收束、末 1 秒全体人物保持姿态与站位、动作完全静止、画面定格`（**人物全部在场、无遮挡、无字幕压屏**，确保末帧可截；末镜景别禁大远景）；**末 1 秒在剪辑时整秒剪除**（余下末帧即定格帧）；终段按 R1 写 `胜负收势/悬念收尾（定镜收束）`。
  > ⚠️ **本条仅 D锁①末帧定格承接适用（2026-10-18 补 · 粉丝实测踩坑）**：本段若选 **D锁②换机位硬切**，**本条整条不写**——②法定不写末 1 秒定格，末镜改写 `接口余量 0.5 秒：保留未收死的运动，供剪辑吃转场`。机检 `C11b` 已按②豁免（末镜含「接口余量 / 硬切」即不报），**不会因为没写定格而报警**。①/② 选哪条见总控 `short-drama-director/references/segment-splicing.md` §四·乙 分流表。

### 站位声明（一行式 · 每段必写）
- 四要素（每人一段括号）：位置（画面左/右/中）+ 依托物（空间锚点）+ 朝向 + 姿态；
- 轴线行：多镜同场景必写 `左A右B`（或对调后全段保持），声明后全段禁越轴；
- 位移行：逐人写 `起点→终点`，每步有动作原因（攻击/闪避/击退），**禁瞬移**；
- 静态段写 `全员原位，无位移`；
- **禁画图**：禁 V3 俯视 ASCII 空间图/坐标表/初始图+位移因果链（太复杂模型理解不了）。
- **多人同场（2~4 人）升级为三行制**（主轴行 + 从轴行 + 全员动态行），格式与范例见 `multi-opponent-rules.md` §八；1v1 场景仍用本节一行式。

## 四、 音效与声音排布（2.5 / 2.0 分版）

### Seedance 2.5（官方字符）
- 音效 `<>` 叠在时间轴对应秒段，必须具体，禁"震撼音效"；
- R1 可用音效词库（写实向）：

| 场景 | 可投喂音效 |
|---|---|
| 破空拳/扫腿 | `<Air-cut Whoosh 重型破空呼啸>` |
| 拳脚命中 | `<Impact Thud 沉重受击闷响>` / `<Bone Snap 骨骼受力脆响>` |
| 格挡/架招 | `<Block Clash 格挡碰撞闷响>` |
| 近身缠斗 | `<Scuffle Grunt 缠斗喘息闷哼>` |
| 环境破坏 | `<Shatter 玻璃碎裂>` / `<Crack 地面龟裂>` / `<Rubble 碎石滚落>` |
| 摔投 | `<Body Slam 重物砸地闷响>` |
| 追逐脚步 | `<Running Footsteps 急促脚步>` |

- **声音事件时间线**：音效按事件排时间线序列，每个动作事件对应一个音效事件：`拔刀鸣（0.5s）→ 破空呼啸（1.2s）→ 交击爆鸣（2.0s）→ 冲击爆破（2.5s）`；
- **空间纵深音**：远层事件用低频闷响+混响，近层用高频脆响+干声；
- **死寂转余响**：绝杀命中后先留 0.3~0.5s 死寂，再放环境余响（碎石滚落/风声/耳鸣），比全程轰鸣更有打击重量。

### Seedance 2.0（文字描述 · 默认视频内出）
- 音效/台词以文字描述写入镜行 `声音：`/`台词：`，**默认由模型生成**；
- 禁 `[SFX:]` 标记、禁顿挫词；
- 台词文本写入台词栏锁口型节奏；仅用户明确指定"不出台词"才写后期配音说明。

## 五、 资产锚点规则（@CHR/@SCN）

- 使用 `@CHR_name` / `@SCN_name` 明确对应资产图，**严禁无主代词**（"他/她/神秘人"）；
- 多参考图（角色+服装+场景混投）必须**逐实体**写绑定：`严格保持 @CHR-A 的脸型与发型（参考图1），只改变服装为……（参考图2）`；
- **真人脸红线（官方硬约束）**：参考图严禁含真人人脸，一律动漫/CG/绘画风格；
- **素材标注用途**：每份参考素材标注（锁定外貌/动作/音色/运镜），禁只丢图不说明；
- **2.0 参考图仅锁定形象**：禁投 `first_frame`/`last_frame`，禁写首尾帧相关。

## 六、 负面词与自检（S5 机检）

### 负面词三区（★ 2026-10-13 极简口径：默认只写基线四项）
```text
【默认基线（极简 · 段7 只写这个）】
画面：禁字幕、禁水印（含 Logo）；
音频：禁背景音乐、禁旁白。

【按需追加（确有该类穿帮史才挑 1~2 条，交付说明写理由）】
画面：角色变形 / 手部异常 / 服装变化 / 分身 / 复制人 / 慢动作升格 …
文字：文字 / UI / Logo / 角标 / 可读文字 / 真实 UI
```
> ⚠️ 长清单**默认禁加**——按「禁令失效三改法」，被禁词根（多指/变形/分身）挂着「禁」字照样被当画面词读，长清单 = 亲手给模型递画面词表。权威见 `short-drama-director/references/model-adapters.md` §5。

### S5 机检清单（出稿前逐项过）
1. **字数门禁（分镜段粒度 · R1 档内）**：**只计【时间轴分镜】段正文**的中文 ≤500 字/组，不含另六个模板段——**本条是「分镜段正文」这一粒度的唯一真源**。⚠️ 它与总控闸门3 的**整单元**口径并存、不冲突：闸门3 计七段合计（2.0 ≤2900 / 3000 硬上限；2.5 ≤3600 / 4000 硬上限），本条只管镜行本身的信息密度；两者都超时，先按本条压镜行描述，再按闸门3 压管理话术。来源：Seedance 官方指南建议提示词 ≤500 中文字 / 1000 英文词（**官方建议值，非平台硬字段上限**，各入口字段上限实测在 800~2500 字符量级），动机是文本过长会分散模型注意力致元素丢失。参考区间（贴门禁线）：4 镜稿 320~480 字、5 镜稿 400~500 字；超限时**压缩描述而非删镜**，因果链不断；
2. **时长**：**按总控模型契约表**（`model-adapters.md` §5）——2.5 默认 25~30s、2.0 ≤15s；本行不再另写死值；
3. **版本语法**：2.0 无 `[SFX:]`/顿挫词/首尾帧；2.5 用官方字符；
4. **画幅一致性**：所有镜行/构图词与锁定画幅一致（16:9 禁"垂直安全区/上下叠压"竖屏词，9:16 禁横屏构图词）；
5. **七段式完整**：七段齐 + 每镜行尾带声音/台词（**段末无接续尾行**，2026-10-09 废止；末帧定格写在末镜行内）；
6. **站位声明**：四要素+轴线+位移行齐全，禁 ASCII 图；
7. **镜长节奏（C13）**：同段 ≥4 镜且同值镜长占比 ≥70% → 重排镜长（快慢呼吸交替，覆盖 ≥3 个取值）；
8. **高压词扫描**：无"对峙/蓄势/悬停/站立静止"类静止段、无抽象打斗词、无特效词（光波/冲击波/法阵）、无直白血腥词（对照 impact-physics.md §五 词典）。
9. **多人增项**（同场 ≥2 人时叠加）：同镜交手 ≤3 人、特写 <3 人、无「站等」角色、主角每镜在场、主轴唯一、每人 ≥2 项外形差异、分身负面词已写入 —— 细则见 `multi-opponent-rules.md` §十。
