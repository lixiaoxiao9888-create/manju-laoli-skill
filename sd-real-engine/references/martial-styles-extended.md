## 〇、 取用原则（★只取神，不取形 —— 先读）

> **唯一真源**：节奏、衔接、站桩禁令、升格禁令、腾空上限，一律见 `r1-combat-core.md` §八（★取神不取形 · 节奏硬口径）。本节只讲**本文件特有的读法**。

**只取三样（神）**

1. **招式名与外形特征** —— 模型需要知道「日字冲拳 / 铁山靠」长什么样（形态、轨迹、接触点）；
2. **劲力原理与发力方向** —— 力从哪来、怎么走、作用于何处（腰马传递 / 螺旋上钻 / 离心横扫）；
3. **打击部位与受力反馈** —— 打哪儿、打中后身体怎么反应（肌肉凹陷 / 骨骼脆响 / 重心失衡）。

**不取四样（形）**

| 不取 | 为什么 | 替代真源 |
|---|---|---|
| **12 式表的排列顺序** | 那是该门派**拳套的固有顺序**，不是战斗顺序；顺次执行 = 站着打套路 | `r1-combat-core.md` §三 单场战斗节拍弧 |
| **「典型连招 A→B→C」箭头链** | 只表示招式之间的**劲力流向与因果关系**，不是衔接脚本 | `kinetic-chain-11.md` 11 环动力链 |
| **「节奏特征」行的节奏** | 那是该门派的**演练节奏**，不是本包成片节奏 | `r1-combat-core.md` §八 三条节奏硬口径 |
| **「起手X / 起势」「收势X」** | 套路的首尾动作，单独成镜必出静态呆立 | `r1-combat-core.md` §七 R1 克制收尾写法 |

**三条红线（细则见 §八，违者 P0）**：机关枪式近景对招（零间隔消打一体）｜升格慢镜默认 0 处｜**严禁站桩式对打**。

> 另注：本文件镜头列里的「缓慢拉远 / 慢速推近」**只指运镜速度，不等于时间升格**；成片运镜一律按 `camera-action-specs.md` 重写。

**反例（禁写）**：❌ 两人站定轮流出招；❌ 把 12 式表拍成 12 个镜头、以「收势X」收尾；❌ 照箭头链逐镜拍 A→B→C。
**正例（本包口径）**：✅ 抢步切偏门，日字冲拳连射三击（**击与击之间零间隔**），对手边退边拍手化解、第三击下潜避开并顺势扫腿。

## 一、 武学核心技法详解

> ⚠️ **详解表读法**：以下各表为**招式名录**（门派拳套的固有排列），**不是战斗顺序**；表内「收势X」行为套路收尾动作，**不单独成镜**。取用边界见 〇。

## 九·⅛·½、蔡拳核心技法详解

> 蔡拳的灵魂是“偏门快打”——不是正面硬拼，也不是粘桥缠住不放，而是三角低马立身，消身避正面，离桥抢攻，从侧翼、身后、肋下、桥手缝隙里突然打进去。核心口诀：快速灵巧，消身借力，主攻偏门，离桥抢攻。

### 蔡拳禁忌

1. 禁止把蔡拳写成普通连掌或蔡李佛大开大合；蔡拳必须有三角低马、消身、偏门、离桥抢攻。
2. 禁止纯正面平视拍摄三角滑步；会丢失偏门绕袭横向空间感，必须用30-45°斜侧/侧俯。
3. 指尖戳击、肘尖撞击命中瞬间必须用微距特写抓住（可配 1~2 帧微顿，仅 2.5），但长连招必须用中景/全景交代侧身滑步逻辑。
4. 腿法必须藏在桥手下方，三角钉腿/低步勾弹不能写成普通正面高踢。

## 九·⅛·¾、少林旋风地堂腿（地趟低腿核心12式）核心技法详解

> **腾空技法取用**（口径见 `r1-combat-core.md` §八 ★唯一真源）：本门「腾空层」技法（按地腾空旋风脚 / 鲤鱼打挺撞腿 / 低空扫堂旋风）一律按该口径取用——只取「贴地滚 → 低空扫」两层，**不写腾空旋**；「腾空水平旋转」转译为「撑地起身瞬间的水平扫腿」（撑地为支点、腿走低弧、落地即卸力续接下一动）。

> 少林旋风地堂腿的灵魂是“贴地滚、低空扫、腾空旋”——以滚、伏、仆、卧四类低身法为根基，全程贴近地面游走，专攻脚踝、小腿、膝盖和下盘根基；通过滚身闪避、撑地旋扫、翻身弹踢和腾空旋风脚完成高低切换。它不是普通低扫腿，也不是单纯旋风踢，而是从地面死角打起，把对手站立根基先拆掉，再用低空旋转与腾空旋风收束。

### 少林旋风地堂腿禁忌

1. 禁止写成普通低扫腿；必须有滚、伏、仆、卧等低身法和手掌撑地借力。
2. 禁止把按地腾空旋风脚写成普通站立旋风踢；起点必须来自贴地或伏地按地，靠双掌反作用力弹起。
3. 禁止纯正面平视拍贴地旋转扫腿；低位旋转必须用垂直俯拍、60°斜俯或30-45°斜侧环绕交代地面轨迹。
4. 长连招必须展示“贴地滚→低空扫→腾空旋”至少两层空间变化，否则就失去地堂腿特色。
5. 滚身锁膝、伏地后绊不能写成静态抱腿；必须写清滚身惯性、腿部夹缠、膝线/脚踝受力方向。

## 九·¼、巴西战舞（Capoeira）核心技法详解

> 巴西战舞的灵魂是“弹跳空翻游走”——全程保持弹性起伏，以罗达环形周旋为基础，高空空翻、中位回旋、低位贴地三层切换。不硬扛正面攻势，靠旋转、空翻、后撤迂回拉扯距离，攻防连贯如舞步。

|奇达戈俯冲劈掌|全景·30°低仰·俯冲跟随→急速推镜·跟随双掌俯冲下劈轨迹|突出重力加持、俯冲压迫和落地滑步|

### 巴西战舞禁忌

1. 禁止把巴西战舞写成普通旋踢；必须有弹跳、空翻、贴地、环形周旋至少两种空间层级。
2. 转圈弹跳步法禁止纯正面平视拍摄，必须斜侧/斜俯或环绕展示罗达空间感。
3. 阿乌空翻、阿乌梅利亚空中连踢必须使用中景/全景交代完整身体，不可单用特写。
4. 库拉多低位扫踢必须贴地、撑地、扫脚踝/小腿，不能写成普通低扫。
5. **禁写特效**："沿翻转/回旋路径流动的特效"一律删除，只写身体轨迹本身（翻转弧线、衣摆随动、撑地支点）——R1 下巴西战舞的观赏性来自动作连贯与空间层级，不来自任何光效（见 SKILL.md §一 铁律 6）。

## 九·⅕、谭腿（十二路谭腿）核心技法详解

> 谭腿是"南拳北腿"之北腿代表，拳三腿七，12种腿法全覆盖（弹/踩/截/蹬/劈/挂/撩/扫/鞭/踹/膝/摆），相当于腿法百科全书。拳谚："练拳不练腿，如同冒失鬼" / "手是两扇门，全凭腿打人，谭腿四只手，人鬼见了都发愁"。

### 谭腿起源

|维度|内容|
|-|-|
|**起源**|山东临清龙潭寺，昆仑大师（后周李崇进）所创，原名"潭腿"|
|**少林增补**|明正德年间少林相济禅师与龙潭寺互换所学，少林后人增添第十一、十二路|
|**命名三系**|潭腿（寺名）= 谭腿（河南谭姓传说）= 弹腿（技法命名），三者同源|
|**腿法法则**|"腿不过膝"（临清本源）→ 少林版扩展至中高位，但低盘弹踢始终为根基|

|**攻防关系**|上下盘同步——手防上腿攻下|腿为主手为辅|八臂均等|闪避即攻击|

## 九·⅕·½、洪拳核心技法详解

> 洪拳的灵魂是“硬桥硬马”——不是轻飘连掌，也不是纯拳击，而是以四平大马扎根，桥手攻防一体。长桥大开大合负责阵地压制，短桥贴身寸劲负责近身爆发；口诀是“有桥寻桥，无桥造桥”。

1. 禁止把洪拳写成轻飘掌法或普通连拳；必须有四平大马、沉腰坐胯、硬桥硬马。

3. 磨桥、留桥、分桥不能只用特写；必须用中近景/中景交代双方桥手位置和缠绕关系。
4. 订桥、穿桥、撞桥命中瞬间必须切特写/微距特写，表现拳尖/指尖/肘尖爆点。
5. （R1 转译）"气"一律写成沿桥手、马步与中线运动的尘土、衣摆动态，禁装饰性光效（见 SKILL.md §一 铁律 6）。

## 九·⅓·½、柔道（Judo）核心技法详解

> 柔道的灵魂是"柔"——不是硬打硬扛，而是利用对方的力和自己的杠杆原理把对方摔倒。和擒拿手的区别：擒拿手是"抓住关节让你动不了再打"，柔道是"借你的力把你整个摔出去"。

## 九·⅓·⅓、三十六路腿法（武当北派）核心技法详解

> 36路腿法是武当北派高道匡常修所传的腿法百科全书——不是单一拳种，而是腿法本身的完整进阶体系。从直摆性到屈伸性到腾空性到组合到巅峰，7级36种腿法全覆盖。与12路谭腿互补：谭腿=12路拳腿组合套路，36路腿法=纯腿法36种技法。

### 36路腿法 vs 12路谭腿对比

|维度|12路谭腿|36路腿法|
|-|-|-|
|**性质**|12路拳腿组合套路|纯腿法36种技法|
|**每路内容**|每路含手法+腿法组合|每路只有腿法本身|
|**覆盖面**|12种核心腿法|36种完整腿法+8种组合腿法|
|**独有价值**|拳三腿七的实战套路|腿法取名+分类+进阶的完整系统|

### A组：直摆性腿法（1-5路）——腿法地基

### 擒拿手8大核心手法

所有36式都由这8种手法组合而来，出提示词时可以从这8种手法自由搭配：

### 擒拿/摔技后续行为链体系（必须连贯，禁止断档）

> **核心原则**：擒拿/锁技/摔技不是终招，而是"中间态"——拿住/摔倒之后必须紧接后续行为。如果只写"抓住对方手腕"或"将对方摔倒"就结束，画面=两个人贴在一起不动=节奏停滞。后续行为分三类：**追击**（我方继续打）、**反制**（对方脱身反击）、**地面战**（摔倒后转入地面缠斗）。

#### 一、擒拿后的追击链（拿住再打）

> **逻辑**：关节被锁=对方身体被控制=要害暴露=必须追击打进去。没有"拿住不动"的选项。

|擒拿动作|控制结果（对方状态）|可追击的后续行为|视觉效果|

|抓腕反扭|对方手腕被反扭，身体被迫侧转跪地|膝顶面部/胸口 / 手刀砍颈 / 标指刺咽喉 / 肘砸后脑|对方跪地侧身→膝盖从正面撞入面部，身体弓成虾形|

#### 四、擒拿摔投完整连招模板（可直接套用）

> 这些模板是"擒拿→追击"或"摔投→追击"的完整动作链，出提示词时可整段使用。

**模板1：抓腕反扭→膝顶面部→推倒→跪压锁颈**
节奏：慢(控)→快(打)→爆(摔)→控(锁)

1. 抓住对方来拳手腕向外反扭，对方被迫侧身跪地
2. 膝盖从正面直撞对方面部/胸口，对方身体弓成虾形
3. 抓住对方肩膀猛力前推，对方被推倒面朝下趴地
4. 单膝跪压对方后背，双手扣住对方颈部锁死

**模板2：过肩摔→下劈腿→对方翻滚脱身→谭腿截**

1. 抓住对方衣领/手臂，转身背对弯腰将对方翻过肩膀摔出
2. 对方仰面倒地瞬间，高举腿下劈腿/下劈掌砸向对方胸口
3. 对方翻滚避开劈砸起身反击
4. 顺势谭腿截击对方起身冲来的路径

**模板3：绊腿旋臂→跪膝砸肋→对方撑地半月踢反制→截拳道截断**

1. 一手抓住对方手腕向外拧旋同时一脚插入对方腿后绊住，上拧下绊摔翻
2. 对方侧身倒地，跪膝重重砸入对方肋部

## 九·⅔、虚构身法 → 写实位移转译通则

> 身法≠攻击技法，是移动闪避的空间策略。用户点名**虚构身法**（小说/影视/动漫/游戏里的轻身功夫）时，一律按本通则转译为写实位移，**不得照抄原著效果**；「禁写」列是原著超自然表现，**照抄会被平台判为玄幻或直接生成失败**。

| 类别 | R1 写实转译（可写） | 禁写（原著超自然表现） |
|---|---|---|
| 轻身 / 瞬移 / 踏水类身法 | 借力折向（写明起跳点→蹬踏支点→落点，落地屈膝卸力）、蹬墙**一次**换向、快速小碎步变向、蛇形绕行、贴地滑铲、翻滚侧闪、浅水踏步涉行 | 无支点凭空换位、空中二次变向、滞空停留、身形一晃已在数丈外、点水不沉 |
| 缠绕 / 滑脱类贴身身法 | 上肢缠封 + 脚下小步绕转的近身连续攻防；被控时下沉重心 + 旋腰转胯抽手脱出（写「抽手转体脱出」与脱出后的失衡半步） | 无受力脱离物理接触、身体如游鱼般滑脱 |
| 「越走越强」类内息设定 | 疲劳与呼吸写进动作（越到后期呼吸越重、动作幅度收紧、步法变沉） | 力量随步数推进递增、隔空致伤、无接触受力 |

### 八卦掌禁忌

1. 禁止把八卦掌写成原地站桩连拍掌；必须有走圈、换身、绕侧、绕背。
2. 禁止90°纯正面平视拍摄转圈游走；会丢失环形步法空间感。
3. 多层抖掌、绕身穿掌不能只用特写；必须用中近景/中景交代身体与对手的相对位置。
4. 掌根撞击、指尖穿刺、托掌命中瞬间必须切特写/微距特写。
5. 长连招必须至少出现一次全景或斜俯，展示完整八卦圆轨迹。

## 九·⅐、太极拳核心技法详解

> 太极拳的灵魂是"化"——不是硬打硬扛，而是以柔克刚、借力打力。掤捋挤按采挒肘靠八法对应八方力，缠丝劲贯穿一切动作。化劲不是退让，是引开对方来力后顺势反击——化即打。

### 太极八式招式详解

|招式|动作描述（执行级）|攻击部位|视觉特征|实战定位|
|-|-|-|-|-|
|**掤**|前臂向前上方撑出，如气球膨胀向外弹开对方来力，掤手接触对方拳面/前臂|前臂|前臂撑出如球膨胀，来力被弹开|接劲——所有化劲的起点|
|**捋**|双手沿对方来臂方向顺势向后拉引，将对方来力引向身侧空处|双掌/前臂|双手如抽丝般顺力引走，对方因惯性前扑|引化——来力最顺的化解|
|**挤**|前臂贴身向前挤出，后手按在前臂内侧助力，整体如楔子挤入|前臂+掌|前后手合力挤出，力从脚到腰到臂整条链|挤入——化劲后最直接的反击|
|**按**|双掌从胸前向前下方推出，力从脚底贯穿到掌根|掌根|双掌推出，推力贯穿，衣摆被推得向后掀起|推击——最直接的攻击|
|**采**|手掌抓住对方手腕/前臂向外下方猛拉拽|掌/指|抓住向下拽，对方重心被破坏|采引——破坏重心最有效|
|**挒**|前臂横向外翻转拧开对方来臂|前臂|前臂横拧，对方来臂被拧开侧翻|挒开——横向破开来臂|
|**肘**|曲肘以肘尖向前/横向击出|肘尖|肘尖短促爆发，力从腰传到肘|肘击——近身重击|
|**靠**|肩/背向对方身体挤靠撞击|肩/背|全身重量靠入，挤撞一体|靠打——贴身最重|

|维度|内容|

|**核心灵魂**|化——以柔克刚，借力打力，化即打|
|**发力机制**|缠丝劲——一切动作都走螺旋，力从脚底沿腿→腰→脊→臂螺旋传导到指尖|

## 九·⅑、咏春拳（小念头正统核心套路）核心技法详解

> 截拳道的灵魂是"截"——不是等对方打完再反击，是对方攻击启动瞬间就截断其攻势。三截（截击标指/前手寸拳/阻截踢）+时空拦截+黏手封控=以更快的速度打断对方的节奏。

> 散打的灵魂是"踢打摔一体"——远踢近打贴身摔，三种距离三种武器无缝切换。接腿快摔是独门绝技，身法过载是节奏杀手——转体鞭拳/转身后蹬等大幅招式是完播率保障。

## 二、 兵器写实移植（镜头法则与转写公式）

> **R1 写实适用**：本节 9 套正统剑法与长柄镰刀一律按**真实兵器长度与重量**写——**兵器重量三件（出手迟滞·轨迹·碰撞反馈）必须写**。剑光/剑芒类特效**一律禁**。

### 兵器技法总原则

|原则|要求|错误写法|正确写法|
|-|-|-|-|
|**兵器不是徒手换皮**|必须写清兵器关键部位参与动作；剑法写剑尖/剑刃/剑脊/剑格/剑身/握柄，长柄镰刀写镰尖/镰刃/镰柄/镰钩/刃背|“角色用兵器攻击”|“镰尖直线平刺咽喉，镰钩外侧勾住对方枪杆向外拉扯卸械”|

### 兵器镜头禁忌

1. **中景/全景兵器攻防禁止90°侧面正拍**：会像横版格斗游戏，兵器厚度和空间纵深消失；必须改30-60°斜角。
2. **高速兵器招式不能全程特写**：特写只用于破绽/命中/格挡/勾卸瞬间，持续0.2-0.5秒后必须切走。
3. **大圆弧剑花/满月镰斩不能用近景**：近景只会看到一团光，必须中景/全景展示完整轨迹。
4. **太极剑禁用剧烈抖动**：杨式太极剑要稳定、柔和、低对比度，不能写成独孤九剑式高速乱刺。
5. **独孤九剑禁用厚重拖尾**：它是“细、准、快、破绽单点”，不是大刀式宽轨迹。
6. **长柄镰刀禁用锁链、分身、结界、大范围黑雾**：写实死神镰只允许单柄长金属镰刀、冷银浅灰金属刃光、短距飞镰和镰钩卸械。
7. **兵器碰撞不能只写爆炸**：必须写剑身/剑格/剑脊、镰刃/镰钩/镰柄或太刀刀尖/刀刃/刀格/刀背的物理接触，爆炸只是反馈不是动作本体。
