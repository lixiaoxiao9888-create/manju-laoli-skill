# R1 打斗核心法则 (R1 Combat Core) · ★权威总控

> 本文件是真人写实打斗的**定档与节奏总纲**。任何任务先读本文件确认 R1 口径，再进目录树其他文件。与 short-drama-director 的 R2/R3 规则冲突时，以本文件为准。

---

## 一、 R1 写实克制档定位

| 项 | R1 写实克制（唯一档位） |
|---|---|
| 适用题材 | 写实格斗、警匪追逐、悬疑暗杀、喜剧打斗、儿童向打斗 |
| 动作美学 | 「轻≠弱，轻=快而重」；以真实受力反馈为先，特效让位于物理 |
| 开局硬撞 | **不强制**，1.5s 内发生攻防接触即可（第一帧建议双人同框中近景，禁远景慢热铺垫） |
| 近景机枪对招 | 可选（有则走序列化招式链，见 `real-fight-techniques.md`） |
| 气爆/特效 | **不强制**，以真实受力反馈为主（肌肉凹陷/骨骼脆响/脚步犁地/环境破坏） |
| 终结收尾 | **允许克制收势或悬念收尾**（反派踉跄后退、主角收拳喘气、胜负留白） |
| 升格/慢镜 | **默认禁用**（实测破坏节奏）；仅用户明确要求且 ≤1s 可用 |
| 站桩式对打 | **严禁**（所有招式必须挂在步法位移/重心转换上；禁"两人站定轮流出招"） |
| 打斗最低线 | 快慢呼吸交替，同节奏连续 ≤5 秒 |
| **多人同场（2~4 人）** | 走 `multi-opponent-rules.md`（★多人唯一真源）：主角唯一锚点 · 同镜交手 ≤3 人 · 三拍轮转禁站等 · 1v2 用 4~5 镜 / 1v3 用 5~6 镜 |

## 二、 R1 完播潜力评分（启发式自检）

$$\text{评分} = 0.20 \times \text{开局吸引力} + 0.30 \times \text{节奏呼吸} + 0.25 \times \text{运镜丰富度} + 0.25 \times \text{情绪拐点}$$

| 维度 | 权重 | R1 执行指标 |
|---|---|---|
| 开局吸引力 | 20% | 1.5 秒内发生攻防接触；第一帧双人同框中近景 |
| 节奏呼吸 | 30% | 快慢交替，同节奏连续 ≤5 秒；禁全程同一强度平推 |
| 运镜丰富度 | 25% | 同运镜 ≤2 秒，同景别 ≤3 秒（近景/特写除外）；15 秒 5~8 次精准切换 |
| 情绪拐点 | 25% | 8~12 秒区间出现一次局势逆转/破防爆发/破绽抓取 |
| 收尾 | 核心 | 克制收势（踉跄/喘气/收拳）或悬念收尾（胜负留白/威胁未除） |

## 三、 单场战斗节拍弧（防平推）

禁止从头到尾同一强度平推。按节拍弧推进，强度有起落：

```text
接敌（试探接触）→ 试探（互探虚实）→ 施压（一方占优）→ 破防（防线崩溃）→ 逆转/收势
```

- 每一节拍 2~4s，节拍之间必须换节奏（快→慢→快）或换机位（见 `camera-action-specs.md`）；
- 喜剧打斗可把"逆转"换成"巧合翻盘"（如误伤自己/道具背叛），但同样要节拍弧。

---

## 四、 情绪拐点写法（8~12s 区间必有一处）

- **破防爆发**：守方防线被硬生生震开 → 攻方趁势连击；
- **破绽抓取**：攻方招式用老收不回 → 守方抓住空档反打（局势逆转）；
- **威胁升级**：对手亮出第二形态/援手入场/新武器（体现为画面内可见新元素，禁旁白解释）。


---

## 五、 中段留白与神态记忆点（R1 适用版）

> ⚠️ 实测铁律：**"留白/对峙/静止/悬停"字眼 = 模型渲染成呆立**。留白必须靠运动或环境动态实现。

1. **运动中换档替代静止留白**：两波高潮之间的缓冲段，角色保持位移（滑步调整距离/环绕换位），节奏由密集对招降到试探性步法，但**动作不中断**；
2. **神态挂载在动作上**：禁止独立静止特写（"她冷笑（静止）"）。必须写成"她侧身让过拳锋的瞬间冷笑/甩棍转身时啐了一口"——神态是动作的附属属性，不单独成段；
3. **唯一可用的短停**：命中瞬间 1~2 帧微停顿（Hit-Stop，仅 2.5）；或用户明确要求的 ≤1s 慢镜（必须配环境动态：汗水飞溅/衣摆甩动/灰尘扬落），禁止人物静止全身。

## 六、 开局写法（R1 无硬撞版）

- 第一帧 = 双人同框中近景（人物占画面 ≥1/3），禁大远景风景慢热；
- 1.5s 内发生**接触**即可，不必硬撞：探步抢中线、刺拳试探、侧闪下一步逼进都算有效接触；
- 例：`00:00-00:01.5 [镜头1] …两人几乎同时向前抢步，右手刺拳虚晃，随即各自侧闪错身，距离重新拉开。`
- **多人场景例外**：第一帧改为「主角 + 至少一名对手」同框中近景（人物合计占画面 ≥1/3），其余人以动态从画面边缘进入；轴线与景别按 `multi-opponent-rules.md` §六。

---

## 七、 收尾写法（R1 克制版）

- **允许**：收势收镜（收拳喘气、甩手中淤血）、悬念收镜（胜者转身、败者扶墙站起）、局面留白（交战被第三方打断）；
- 决胜一击仍然需要把"命中受力"写完（见 `impact-physics.md`），只是不强制冲击波/嵌墙等夸张余震；
- 例：`00:13-00:15 [镜头4] …一记低位扫踢命中对方膝弯，对方单膝砸地；胜者后退半步收拳，呼吸急促，镜头缓慢拉远收镜。`

## 八、 外部招式库的从属地位（★取神不取形 · 节奏硬口径）

> `martial-styles-extended.md`（武学详解扩展库）与 `technique-combo-library.md`（技法合规库）是从外部源包移植的**招式素材库**，不是动作剧本。二者与本文件冲突时，**一律以本文件为准**。

**招式库只提供三样（神）**：① 招式名与外形特征；② 劲力原理与发力方向；③ 打击部位与受力反馈。

**招式库不提供四样（形）**：

| 不取 | 本包替代真源 |
|---|---|
| 套路顺序（12 式表排列 = 门派拳套固有顺序，非战斗顺序） | 本文件 §三 单场战斗节拍弧 |
| 衔接方式（库内「A→B→C」箭头链只表劲力流向，非拍摄顺序） | `kinetic-chain-11.md` 11 环动力链 |
| 节奏与时值（库内「节奏特征」行属门派演练节奏） | 本文件 §二 节奏呼吸 + 本节三条硬口径 |
| 起势 / 收势（套路首尾动作，不得单独成镜） | 本文件 §七 R1 克制收尾写法 |

### 三条节奏硬口径（违者 P0 阻断）

| # | 口径 | 执行标准 |
|---|---|---|
| ① | **机关枪式近景对招** | 近景对招段一律用**序列化招式链**（`real-fight-techniques.md` §五）：全链 **2~3 秒内 6~10 击**、**击与击之间零间隔**（打出即收、收即出）、守方逐击反应不同并带步法位移。禁「两人快速对打」这类模糊写法。 |
| ② | **禁多余升格 / 慢动作** | 升格慢镜**默认 0 处**；仅用户明确要求且全片 ≤1s 可用。命中瞬间 1~2 帧微顿（Hit-Stop）**仅 2.5 可用**、不计入升格。库内镜头列的「缓慢拉远 / 慢速推近」**只指运镜速度、不等于时间升格**；成片运镜一律按 `camera-action-specs.md` 重写。 |
| ③ | **严禁站桩式对打** | 两人站定轮流出招、或原地打完整套 = **P0 阻断**。所有招式必须**挂在步法位移或重心转换上**（抢步 / 绕侧 / 撤步 / 换位 / 低伏）。库内「稳扎不动 / 定马 / 原地」类字样说的是**下盘结构**、不是「人不动」——成稿一律写成「下盘扎稳的同时步法仍在切进 / 换位」。 |

### 附 · 腾空口径（★唯一真源）

- **跳踢 / 腾空**：离地 ≤1.2m、单次 ≤0.6s、**落地即卸力并续接下一动**；禁「空中不落地」「悬停帧」；库内「凌空 / 空中不落地」字样**禁止照抄进成品稿**；
- **被动离地**（被击飞 / 被摔倒）不受上述时长限，但落地须写清受力与惯性延续；
- **旋身角度**：单次旋身 ≤360°（禁多周旋转）；各招式表内的 `(≤360°)` 标注为本口径的**回声**，真源在本节。

### 附 · 「定格」与「定镜收束」分工铁律（与总控 D锁①及 C11b 互锁 · 2026-10-14 消除左右互搏）

- **打斗过程镜（第 1 镜 ~ 倒数第 2 镜）**：**严禁写「定格 / 静止 / 对峙不动」**（过程镜写定格 = 人物打到一半卡死呆立 = P0 阻断）；唯一允许的短停是命中瞬间 1~2 帧物理阻尼微顿（Hit-Stop，仅 2.5）；
- **段末最后 1 镜的结尾 1 秒（D 锁①末帧定格承接）**：为供下一段截取清晰尾帧，段末最后 1 秒**法定写** `第 X 秒起运动收束，末 1 秒两人保持姿态与站位、动作完全静止、画面定格`（或写 `定镜收束`，机检 `C11b` 均予放行；该末 1 秒在剪辑拼接时整秒裁除，不进成片）。
  > ⚠️ **仅 D锁①适用（2026-10-18 补）**：本段若选 **D锁②换机位硬切**，**本句整条不写**——②法定不写末 1 秒定格，末镜改写 `接口余量 0.5 秒：保留未收死的运动`；机检 `C11b` 已按②豁免（末镜含「接口余量 / 硬切」即不报），**不写定格不会报警**。①/② 分流见总控 `segment-splicing.md` §四·乙。

### 负例与正例（P0 判据）

- ❌ 两人站定，甲出拳 → 乙格挡 → 甲再出拳（**站桩式对打**）；
- ❌ 把某门武学的 12 式表按顺序拍成 12 个镜头、以「收势X」收尾（**照搬套路**）；
- ❌ 照箭头链逐镜拍 A→B→C→D（**照搬套路顺序**）；
- ❌ 全片出现多处长升格 / 慢动作（**破坏节奏**）；
- ✅ 甲抢步切入偏门，日字冲拳连射三击（**击间零间隔**），乙边退边拍手化解、第三击下潜避开并顺势扫腿（本包口径）。
