# 真实格斗招式库 (Real Fight Techniques) · ★权威总控

> R1 写实打斗的招式来源。所有招式取自真实搏击/传统国术/冷兵器实战体系，**禁虚构招式名**（"灭世拳/天罡腿"等一律不出现）。按人物风格选招——一个角色锁定 1~2 个体系（如"半步崩拳+泰式扫踢"），招式库只是弹药，**风格归属写进角色卡，防止模型招式乱炖**。

---

## 一、 现代搏击体系（都市/警匪/写实格斗首选）

### 1. 泰拳（Muay Thai · 八肢武艺）
- **刺拳/直重拳/横勾拳**：高护架控距，后拳中线贯穿，横勾拳砸下颌；
- **中段扫踢/低位扫腿/蹬推踢**：支撑脚拧胯，胫骨如斧横砍肋部肝区，脚掌直线顶推阻断突进；
- **横斩肘/上挑肘**：近身缠抱，大臂水平横摆切割眉骨鼻梁，斜向上挑击下颌；
- **正顶膝/斜切膝/飞冲膝**：双手扣颈泰式颈夹，膝盖垂直顶撞胸腹或斜切浮肋，腾空飞膝俯冲爆头。

### 2. 散打（综合搏击 · 远踢近打贴身摔）
- **转体鞭拳/转身后蹬**：转体 180° 鞭拳横扫，转身脚跟向后直线蹬出；
- **接腿推摔/挟颈过胯摔**：接住对方踢击小腿向前推摔，挟住颈部转身过胯翻摔；
- **截线侧踢/快线鞭腿**：以腿截腿阻断攻势，快出快收连续轰击。

### 3. 空手道（刚劲直突 · 一击必杀 · 寸止顿劲）
- **正拳突**：拳从腰间冲出，拧腰转胯整劲直轰；
- **手刀劈**：掌缘如刀自上而下劈砍颈肩；
- **寸止顿劲**：全力出击 → 命中瞬间 1~2 帧微顿（Hit-Stop，仅 2.5） → 力量全部释放收招。

### 4. 拳击（Boxing）
- **刺拳试探/后手直拳/上勾拳/摆拳**：重心在双脚间转移，出拳后立即回防；
- **摇闪/侧闪/后仰闪**：摇闪躲直拳、侧闪让摆拳、小幅后仰闪刺拳。

### 5. 巴西柔术/综合格斗（MMA 地面系）
- **下潜抱腿摔/单腿抱摔**：低身下潜抱腿，肩顶髋部翻摔；
- **十字固（反关节拉直肘部）/裸绞（背后绞杀颈动脉）**：倒地缠斗终结技。

## 二、 传统国术体系（民国武行/动作片首选）

### 1. 形意拳（五行十二形 · 直线整劲穿透）
- **劈拳**：三体式立身，长线斜向下劈砸肩胸，前脚踩进半步，沉劲开路；
- **钻拳**：后拳沿胸腹中线向上螺旋钻顶，拳尖直刺咽喉下颌；
- **崩拳**：前后拳交替直线短促前崩，寸劲直击心口，双脚箭步连续跟进（半步崩拳）；
- **炮拳**：一手上架开劈打，另一拳横向平直猛炮砸击侧肋腰腹；
- **十二形**：虎形双扑、马形冲撞、鹞形绕身、燕形贴地钻击、猴形闪展。

### 2. 八极拳（刚猛短促 · 寸劲硬炸 · 贴身短打）
- **铁山靠**：全身重量与前冲力聚于肩背，如铁壁正面撞入，踩碎地面；
- **顶肘/盘肘/反背肘**：肘尖短促爆发前撞，破防重创；
- **阎王三点手**：左冲、右崩、左直连珠快拳打乱防线，紧接一记跺地顶心肘贯穿心口；
- **撑锤·十字整劲**：前拳轰出同时后手猛拉对拉，整劲前后贯穿爆发；
- **六大开（顶/抱/单/提/胯/缠）**：全面破开一切格挡架势。

### 3. 咏春拳（守中用中 · 短桥寸劲）
- **二字钳羊马/摊手**：二字马稳扎，前臂沿中线上扬外摊化开直拳；
- **伏手/膀手/窒手**：掌心向下压桥、肘部外拱弧形顶开摆拳、前下方短促压截对方发力点；
- **日字冲拳**：拳眼朝上立拳归中，双拳左右交替沿中线机括连射；
- **标指**：双指并拢沿中线平直穿刺咽喉心口，指尖先到；
- **捆手/拍手/低踢**：双臂螺旋缠臂封控，拍开防线零间隔打入，下盘隐蔽低踢脚踝胫骨。

### 4. 八卦掌（游身连环掌 · 趟泥走圈 · 避正打斜）
- **白蛇吐信**：沿圆步侧身滑走，单掌贴腰平直穿刺心口咽喉；
- **鹞子穿林**：趟泥步穿插绕至敌后，单掌自腋下、肋下钻出穿打；
- **乌龙摆尾/回身劈掌**：180° 大转身借离心力，掌根横扫侧肋或垂直劈砸脊柱中线；
- **狮子抱球/穿身绕掌**：双掌环抱撑架格挡，贴身螺旋环绕穿插点打胸腹空档。

### 5. 太极拳（以柔克刚 · 借力打力）
- **掤捋挤按**：前臂撑出如球弹开来力 → 双手顺力后拉引化 → 合力向前挤入 → 双掌推出贯穿；
- **采手引偏/挒开**：抓住手腕向下拽偏重心，横向翻转拧开来臂；
- **搬拦捶**：卸力后反手重拳轰击太阳穴。

### 6. 少林/地趟（贴地滚 · 低空扫 · 腾空旋）
- **贴地平扫腿/仆步勾撩**：身体侧伏贴地，单腿贴地横扫脚踝小腿；仆步极低挑勾脚踝；
- **侧滚截蹬/伏地后绊**：侧滚避上盘攻击，滚身脚掌截蹬膝弯；
- **滚身锁膝**：贴地滚至腿侧，双腿如夹钳缠住膝关节旋身带倒；
- **按地腾空旋风脚**：双掌猛按地面借力，身体自贴地瞬间腾空水平旋转，双腿如旋风刀轮横扫。

### 7. 巴西战舞（Capoeira · 弹跳空翻 · 倒置出腿）
- **基达达后撤/罗达转圈**：双脚弹性滑步回旋，以自身为圆心环形周旋；
- **安哥拉侧旋踢/马尔特洛翻转踢**：单脚支撑旋转 360° 水平扫腰；单手触地侧身半翻转斜挑下颌；
- **阿乌空翻**：双手撑地完整侧空翻；
- **库拉多低位扫踢**：极低位贴地横扫脚踝。

### 8. 柔道/摔跤（投技 · 重心破坏）
- **背负投**：经典过肩摔；**内股**（内侧挑摔）；**大外刈**（大弧线外侧扫腿）；**出足扫**（脚踝横扫）；
- **巴投**（仰身倒地脚蹬腹部翻摔过头顶）；**扫腰**；**体落**。

### 9. 擒拿/锁技（写实制伏 · 儿童向安全首选）
- **抓腕反扭/别臂扒肩/折肘卸肩/压掌卷腕/剪臂挫肘**；
- **反关节别臂制伏**：执法/暗杀场景制伏首选，写"双手反向扣颈翻摔/反关节别臂制伏"（合规转译，见 `impact-physics.md` §五）。

## 三、 兵器体系（犯罪片武器戏）

### 1. 九套正统剑法（写实用：武当太乙玄门剑 / 华山基础剑法 / 杨式太极剑）
- **武当太乙玄门剑**：道家圆转、步踏九宫、慢蓄快发（青龙出海、云卷长空、回锋点星）；
- **华山基础剑法**：干净锐利、长线直刺（白虹贯日、直刺咽喉）；
- **杨式太极剑**：以柔化刚、剑尖连续划圆走小弧（三环套月、退步穿林）；
- **剑法写作要点**：写清剑身几何轨迹（直线刺/弧线削/下劈），接触点（剑尖/剑刃），受力反馈（剑身震颤、双剑咬合火星）。

### 2. 冷兵器犯罪/暗杀向
- **匕首**：正握捅刺（弧线上撩）、反握划割（贴身挥切）、格挡卸刃；
- **短棍/甩棍**：高位劈打、横扫胫骨、格挡锁棍；
- **刀具写作要点**：R1 口径下**禁直接血腥描写**，写"利刃破空贴面划过/刀刃格挡溅出星火/刀身被架住震颤"，杀伤后果用受力与环境反馈暗示（见合规转译）。

### 3. 长柄/居合（默认非本包主推）
- **太刀居合**：胸口拔刀、居合快斩、回身横斩（写实版禁雷光/撕裂空间特效）；
- **长柄镰刀**：低身平镰扫胫、横月平斩、升镰挑割（写实版禁锁链/能量）。

## 四、 高级身法（写实位移，禁瞬移/悬浮）

- **借力折向**：蹬墙/踩栏杆/踩桌沿借力换向（写"蹬踏借力 + 明确支点"）；
- **贴地滑铲/滑步**：紧急避险/破下盘（写清滑行起点与终点）；
- **翻滚/侧空翻**：闪避即位移（配合 `defense-evasion-rules.md` 大幅闪避）。

## 五、 招式链写法（近景机枪对招 · 可选）

15 秒打戏如需近景对招段（2~3 秒），必须用**序列化招式链**，禁止"快速对打"：

```
攻击部位 -> 招式名 -> 防守方具体反应（逐击写清）
```


- 必须包含多种手部变化（拳/掌/肘/指），建议含肘击；
- 每击至少写清攻方部位+招式+守方反应，三要素缺一不可；
- 喜剧打斗：招式链可混入"道具打断"（拳到中途被伞柄/包/卷闸门打断），保持节拍。

### 节奏硬口径（★与招式链配套，细则见 `r1-combat-core.md` §八）

- **链内零间隔**：打出即收、收即出，全链 **2~3 秒内 6~10 击**；禁在链中插入停顿/对峙/对视；
- **守方必须动**：守方每击反应不同且带步法位移（退步/侧闪/下潜/绕侧），禁「站在原地逐招格挡」；
- **禁站桩式对打**：两人站定轮流出招 = P0 阻断，所有招式挂在步法位移或重心转换上；
- **禁升格慢镜**：默认 0 处，仅用户明确要求且全片 ≤1s；命中瞬间 Hit-Stop 1~2 帧（仅 2.5）不计入；
- 本链所取招式来自 `martial-styles-extended.md` / `technique-combo-library.md` 时，**只取招式名与发力原理**，衔接顺序一律本节口径。
