# 特效手绘化铁律与三层分层写法（拉片实证层）

> **定位**：本库治的是**"特效不像自己的画风"**——出片后特效全是**标准 3D 粒子**
> （烟雾就是烟、光柱就是光、星点就是星点），模型默认调用它训练集里的**通用粒子特效库**。
>
> **与既有规则的分工**：`sd-xuanhuan-engine/references/xuanhuan-elements-vfx.md` 管的是
> **"特效分几层、各层什么材质、占比多少"**（13 种三层复合元素 + 三混合配比）；
> 本库管的是**"这些层用什么表现手法画出来"**——**前者定成分，后者定笔法**，两层叠加使用。
>
> **来源**：吸收自外部包 `huhe-combat-director V2.1` 拉片实证层。适合**水墨、国漫、二次元**风格档；
> 3D 写实档（`sd-real-engine`）默认不套用，除非用户明确要求手绘化质感。

## 一、★ 特效手绘化铁律【实测校正 · 治"特效不像自己的画风"】

> **实测病征**：提示词只说了"紫粉妖雾""赤红枪芒"这类**概念词**，没规定**表现手法**。
> 模型于是套最省事的**通用粒子**——永远出不了"画出来的"质感。
>
> **根因**：**概念词 ≠ 表现手法**。不给笔法，就等于把控制权交给了模型的默认粒子库。

### 1.1 五手法表（写每一处特效时，五选一或叠加）

| # | 手法 | 写法（照抄可用） | 用在什么特效上 |
|---|---|---|---|
| ① | **泼墨 / 飞白笔触** | `以泼墨飞白笔触呈现，边缘毛糙有断笔与飞溅墨点，笔锋拖出干枯飞白` | 意境型法术、水墨系、能量起势 |
| ② | **漫画色块叠加** | `以漫画式平涂色块层层叠加呈现，色块边缘锐利有手绘感，非平滑渐变` | 爆发、能量填充、大招本体 |
| ③ | **手绘速度线 / 冲击线** | `手绘漫画式速度线自接触点向四周炸开，线条粗细不均、走势歪扭带攻击性` | 高速位移、命中瞬间 |
| ④ | **墨线勾勒** | `如同墨线勾勒，线条有轻重顿挫，非等比均匀描边` | 黑白闪、轮廓提示、力量纹路 |
| ⑤ | **笔触拖尾 / 残影** | `拖出笔触状拖尾，拖尾随时间变淡并崩解为手绘碎点，非平滑粒子消散` | 兵器轨迹、身法残影、能量尾迹 |

> ⚠️ **按画质档分适用（2026-10-12 用户裁定 · 让行条款）**：本轮三条与 §一 五手法是**泼墨仙侠 / 二次元 / 手绘国漫档**的硬约束；**3D 国漫（次世代写实渲染）/ 写实仙侠档**按 `sd-xuanhuan-engine/references/xuanhuan-elements-vfx.md` 的 **13 种三层复合元素 + 三混合配比**执行，**不强制叠加手绘笔法**——把写实档硬拉成水墨同样是"规则层产毒"。是否套用本条，以 `sd-xuanhuan-engine/SKILL.md` §六 与 `sd-combat-engine/SKILL.md` §六 的画质档判据 + `combat-rhythm-and-load-guardrails.md` §七 豁免表为准。

### 1.2 三条硬约束（一票否决）

1. **⛔ 禁用孤立概念词**：严禁**只写**「粒子」「光效」「能量波」「光芒」「烟雾」这类通用粒子概念词
   ——写了就等于**交出控制权**给模型的默认粒子库。
2. **✅ 强制搭配**：每个特效概念词后面**必须跟一个手绘化手法**：
   - ❌ `紫粉妖雾缠绕周身` → ✅ `紫粉妖雾缠绕周身，以飞白墨雾笔触呈现，边缘毛糙带干枯飞白`
   - ❌ `赤红枪芒破空而出` → ✅ `赤红枪芒以漫画式平涂色块叠加呈现，色块边缘锐利，沿枪尖拖出手绘笔触状拖尾`
3. **★ 黑白闪的真相**：黑白闪**不是"黑白滤镜"，是"手绘墨线图层"**——纯黑底上那些白色纹路
   **粗细不均、有断笔、边缘毛糙、走势歪扭**，是**手绘笔触**而非 3D 射线。详见 §五。

### 1.3 自检判据（一条速判）

> **把画面缩到很小看**：特效边缘**干净平滑** = 标准粒子（跑偏）；
> 边缘**毛糙、有笔触感、有粗细变化** = 手绘化（对）。
>
> **看边缘，不看中心**——这是本库唯一需要的检查动作。

## 三、★ 三层分层写法（照抄骨架 · 实测效果最好的特效句式）

> **与"三混合配比"的关系**：三混合配比讲**"每层占比多少"**（如 30/50/20）；
> 本写法讲**"每层是什么、按外中内怎么排"**。
> **先用本写法定结构，再用配比调权重**——两者是互补而非重复。

### 3.1 结构公式

```text
【特效名】——外层[水墨晕染飞白] + 中层[青蓝水浪翻涌] + 内层[白炽冰晶核心]，边缘附着[金色细碎流光符文]。
```

```
外层(笔触/飞白)  +  中层(主体材质/动量)  +  内层(核心发光体)  +  边缘附着(细节/符文)
```

| 层 | 承载什么 | 注意 |
|---|---|---|
| **外层** | 手绘感来源（飞白、晕染、毛糙边缘） | **最容易被模型省略，必须显式写** |
| **中层** | 主体形态与动量（流体、色块、能量体） | 与三混合配比的主体层对齐 |
| **内层** | 核心亮度与颜色（白炽、冰晶、熔岩核） | 定光源与冷暖 |
| **边缘附着** | 加分细节（流光、符文、碎点） | 可选，但性价比高 |

## 四、原型色彩绑定与本包既有规则的接口

> 外部包的"原型色彩绑定"（执笔者紫+墨 / 燃命者红+金 / 妖物紫粉等）**与本包已有能力重叠**，
> 不整库收录。真正需要对齐的只有两条**色彩纪律**，它们与本包 `sd-xuanhuan-engine/references/xuanhuan-elements-vfx.md`
> 的"冷暖对抗"、`sd-xuanhuan-engine/references/epic-battlefield-protocols.md` 的"阵营色彩锁"是同一件事，此处只作交叉提醒：

- **同色相撞大忌**：严禁"紫电打紫雾"——同色系对轰时，必须用**墨黑 / 白炽**做主角侧分离色；
- **三方强分离**：`主冲击色 vs 敌人主体色 vs 场景基底色` **两两可辨**；
- **色彩明暗纪律**：大面积低饱和环境色 + **仅一处高饱和法术色**；严禁整画面糊成鲜艳游戏 CG。

> 阵营色彩锁的**硬条与机检口径**仍以 `sd-xuanhuan-engine/references/epic-battlefield-protocols.md` 为准

## 五、黑白闪手绘化（★三个必须写进去的词）

> 黑白闪属**减速器**（配额见 `combat-intensity-guardrails.md` §三），且**必须手绘化**。

**三个必须词**：**手绘 / 墨线（或笔触）/ 粗细不均（或毛糙）**。
缺任何一个，模型都可能退化成**"去色的 3D 画面"**（干净、均匀、毫无笔触）。

**与包内既有规则的接口**：黑白闪的**分级与配额**
（一级/二级/三级冲击帧 + 3 帧白闪 + 同场只 1 次）以
`sd-combat-engine/references/impact-frame-and-banlist.md` 为准；本处只管**写法必须是墨线笔触**。


- **爆气顶点型**：`能量攀升到极限的瞬间，画面骤然切换成手绘黑白画稿：纯黑的背景上，白色闪电纹路向四周炸裂——线条是手绘墨线，粗细不均、有断笔飞白、边缘毛糙，中心一团强光——仅一帧，随即彩色画面回归。`
- **拳头型**：`拳头攥紧的刹那画面转为黑白两色，拳面上白色真气纹路如同墨线勾勒，线条有轻重顿挫、非等比均匀，黑色背景中炸出放射状手绘白线，边缘带飞溅的干墨点。`
- **命中型**：`重击命中的瞬间全画面褪成手绘黑白稿，只有接触点的白光刺目，放射线为手绘笔触所绘、歪扭而尖锐，随后色彩伴随火花一同炸回。`

- ⛔ 严禁：`★插入黑白闪 #1`、`<黑白闪 2帧>` —— 术语标签属工程标记，投喂稿零标记是硬底线。
- **标准三连**：纯黑背景极简构图（蓄力）→ 黑白闪（顶点）→ 彩色爆发（释放）。
