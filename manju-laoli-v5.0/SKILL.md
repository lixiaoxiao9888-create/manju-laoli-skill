### 0.2 三大考核标准（V2.1 新增·所有步骤产出必须自检）

> 用户考核标准，每一步产出前逐条自检，不达标先修改再输出：

1. **分镜衔接流畅、时长合理**
   - 时间轴连续：前一镜结束=后一镜开始，无跳秒/重叠/留白
   - 时长由**内容量决定**（信息量时长估算：读取一层≈2-3s，每多一层+2-3s），禁止硬凑
   - 相邻镜头不机械重复景别/机位/构图
   - 段间四重衔接（资产/动作/情绪/声音）+ 六重一致性锁

2. **剧情符合逻辑**
   - 因果链完整：每个动作有反应、每个信息有前置、每个反转不凭空
   - 每场有目标→阻碍→行动→变化→离场钩子
   - 不擅自新增角色/关系/道具能力，不改变剧情因果
   - 台词符合人物身份与当下目的，不重复观众已见信息

3. **宏大场景注意景别与焦段焦距提示词**
   - 宏大场景必须显式写景别 + 焦段（毫米数）+ 运镜（见 §4.5 宏大场景专项）
   - 大远景/航拍 → 广角（16-35mm）；中景叙事 → 35-50mm；特写 → 85mm+；人物与环境比例 → 明确标注
   - 人物与巨大环境的比例差必须写进画面描述（"人物仅占画面十分之一"）

### 0.3 写作红线

**绝对不要：**
- 写心理描写（"他意识到"、"她领会到"、"内心涌起"）
- 写括号暗示（"（其实是在掩饰紧张）"）
- 角色用台词解释设定或主题
- 说教片段、强行催泪、煽情独白
- 过度比喻句、书面化AI腔台词
- 在剧本/画面内容中写任何摄影机拍不到的内容
- 用抽象情绪词替代表演（难过/愤怒/委屈/绝望/崩溃/麻木/紧张/害怕）
- 在画面描述中使用"他/她/它/他们/她们/它们"指代角色（必须用姓名/图N/资产标签；原始对白内部可保留必要代词）
- 输出"短剧节奏""电影级""大片感""9:16画幅""生成模型"等Meta指令
- 输出精确身高数值（身高可以写范围/相对值）
- **写导演/明星/工作室姓名进最终提示词**（如"Wes Anderson风格""宫崎骏风格"）——**Seedance 等视频工具检测到导演/人名会违规拒绝生成**（用户实测确认）；大师风格只能用色系/构图/质感等描述性写法转述（见 §4.2.2 大师调色库用法）

**必须做到：**
- 台词口语化，像真人说话，≤40字/句（按角色性格、年龄、情绪控制语速，不机械；静态漫剧双轨剧本用更严的≤15字/句，见§2.1B）
- 用动作代替解释（动作即潜台词）
- 对话像冰山，只露一角
- 所有内容从视听角度出发
- 画面内容只写可见的动作和物体
- 声音列只写可听的声音，关键物理声音用 `[SFX: 音效内容]`

### 0.4 输出语言

- **默认纯中文输出**，包括提示词本身（资产级/剧情级/镜头级）

## 一、提示词工程（核心方法论·参考模块）

> 来源：AI影视工具箱（何止维+李一帆+森海）。**辅助层**，帮助写清镜头描述；不作为主输出结构。

### 1.1 显性动作 vs 隐性逻辑（何止维）

AI优先实现**最明确、最易视觉化、最强动作化**的内容。

- **显性动作**：画面能直接看到的明确动作（握刀、转头、水花溅起）→ AI容易实现
- **隐性逻辑**：空间关系、意图逻辑、身体朝向 → AI理解不了，容易翻车

实操三步：①找出核心动作 ②删掉高干扰动作 ③牺牲隐性逻辑，优先保证核心动作精准。

### 1.2 四大核心原则（李一帆）

精准>堆砌 | 具象>抽象 | 专业>通俗 | 结构>随机

### 1.3 具象化三层结构

物体层（场景/人物/道具）→ 细节层（色彩/材质/外形）→ 氛围层（光线/情绪/风格）

### 1.4 关键词权重规则

靠前关键词权重更高。核心主体放最前，修饰细节后置。有效长度核心：每个词有画面作用，无冗余。

### 1.5 提示词结构模板

`主体描述 → 构图/景别 → 运镜方式 → 光影方案 → 材质细节 → 美术风格 → VISUAL DNA`

### 1.6 长短提示词选择策略（补充·费曼学习法）

- **长提示词**：控制精细但易互相干扰 → 复杂场景、需精准控制的商业项目
- **短提示词**：AI 发挥空间大、易出惊喜 → 创意探索、风格测试、找灵感
- **有效长度原则**：不是越长越好，越精准越好；每个词都要为画面做贡献，没用的直接删
- **参考图用法**：不「抄」而是「解」——拆解参考图的构图/光线/色彩/材质/氛围五要素，用提示词重现；参考图+提示词=精准控制

### 1.7 标准化提示词三步走：基-氛-画（补充·打斗教程·填空式快速参考）

> 来源：AI漫剧打斗提示词标准化教程。用于快速搭建高质量提示词框架，与 §1.5 结构模板兼容、互补。

**记忆口诀：基-氛-画，三步走**

**模块A【基础设定】· 打地基**
- 画面风格和类型（美术风格+视觉维度+质感；例："国漫仙侠写实风格3D"）
- 场景环境（环境+空间+道具+氛围；例："万米高空云海翻腾，血色满月"）
- 核心角色（形象+服装+性格+能力状态；例："李天均黑发如瀑，青色仙袍"）
- 沉浸音效（环境音+动作音，弱化配乐）
- ⚠️ "两个人打架"→模糊→命中率极低

**模块B【氛围与画质】· 注灵魂**
- 风格核心：打斗气质与情感基调（凌厉爆发 vs 沉稳克制）
- 视觉基调：主色调+情绪变化曲线（例：金青黑，冷调压抑→金色高光炸裂）
- 画面质感：动画细节+特效层次（粒子流体、慢动作碎片飞溅）

**模块C【画面内容】· 填血肉（分镜式）**
- 时间轴：精确到秒，10秒视频拆2-3个核心分镜
- 景别层级 + 构图（对称/中心/动态/放射/压迫感）
- 运镜（固定/推拉/跟拍/环绕/手持/子弹时间，每段只做一种运动）
- 逐帧细节：动作越具体，AI 越精准
- 声画同步：每个分镜匹配专属音效

> 小白进阶路线：填表→加情绪曲线→设计镜头语言→声画精准配合。每周3个提示词，2周初步掌握。

### 1.8 负面排除提示词五类（V2.2 新增·复刻内容-03实战）

> 来源：《奇门镇煞人》分镜实战。生成段式投喂时附上，按五类组织，直接可用。

- **人物类**：五官变形、面部崩坏、表情僵硬、眼神空洞、手指畸形、服饰穿模、人物换脸、核心特征丢失
- **画面类**：画面跳帧、镜头乱晃、画面割裂、头部裁切、运镜卡顿
- **画质类**：过曝、欠曝、模糊、噪点、水印、字幕、logo、色彩溢出
- **场景类**：纯色背景、简陋背景、静态画面、无动态、无关场景乱入
- **内容类**：光影断层、口型错位、音效不同步、背景音乐、BGM、配乐、时长超标、无关角色乱入

> 与正文"无字幕，无背景音乐"配合：五类负向词是完整版，单段生成可用精简版。

### 1.9 镜头描述信息顺序（小逻主核·镜头脚本写作顺序）

按以下顺序组织镜头描述：**画面主体与构图 → 进行中的动作 → 重力及碰撞反馈 → 微表情与生理应激 → 光影变化 → 台词 → SFX → 英文标签**

### 1.10 分层生成逻辑（V2.2 新增·复刻内容-03实战验证）

> 来源：《奇门镇煞人》分镜实战（复刻内容-03）。AI 出图/出视频成功率的核心铁律：**不要试图让 AI 一张图/一段视频画完所有元素**。

**核心原则：一张画面只聚焦一个叙事焦点，其余元素由参考图/分层承担。**

错误示例（元素过载）："松田雄+手里拿铜镜+前面有气浪盾+外面有火墙+背后有石头" → AI 必定逻辑混乱。

正确拆层：
- **层1 特效特写**：聚焦单一特效（能量护盾/火墙/粒子），提示词只写该特效 + 环境氛围
- **层2 面部表演**：聚焦人物表情（愤怒/惊恐/决绝），提示词写面部+受光方向+皮肤细节
- **层3 物理撞击**：聚焦动作与破坏（被击飞撞石），提示词写动态姿势+环境破坏+粒子残留

**分层落点规则：**
- 每个分镜的提示词只承担 1 个主要叙事焦点
- 角色一致性由参考图保证（@角色图），提示词不重复描述已由参考图锁定的外形
- 特效叠加时逐层生成再合成，不写进同一段提示词

> 与 §4.6.2 变身模板配套：变身戏的"崩解→重组→爆发"本身就是天然分层（每阶段一个焦点）。

### 2.1 第一步：详细剧本创作

**输入**：剧本大纲（用户提供）
**输出**：分集详细剧本

**核心逻辑（小逻编剧创作）**：
- 先判断用户处于创意/结构/人物/正文哪个阶段，自动路由对应模式（创意开发→大纲→人物小传→剧本正文→制作交接）
- 每场必须回答：谁想要什么？谁/什么阻止？角色采取什么行动？释放什么新信息？关系或局势如何变化？为什么必须进入下一场？
- 场景结尾优先使用：未完成动作/新证据/身份暴露/关系逆转/代价出现/目标改变
- 冲突升级必须改变至少一项：阻力更强/时间更少/代价更高/盟友改立场/目标冲突/新信息推翻旧判断/错误方法反噬
- 连续场次不得重复同一种争吵或误会
- 角色名称硬性规则：动作和镜头描述必须用角色正式姓名，禁止代词

**分集规划：**
- 每集时长按剧情定（默认参考 90s，可弹性；内容不足90s用环境调度/动作中间态/人物反应扩展，不虚构剧情事实；内容超载在完整剧情节拍处断集）
- 每集内部弹性分段：**段长按剧情/场次自然切，3s~15s 不等，15s 是单段上限（不能超过）而非固定值**——一段戏讲完就收，有的段 7s 就收尾结束，不必硬凑 15s；每段承担 1 个叙事功能
- 叙事功能区参考（90s 集）：
  - 0-10s：视觉钩子/破题（异常画面、未完成动作、身份暴露、结果倒置）
  - 10-30s：人物目标与关系建立
  - 30-55s：冲突递进（动作-反应-信息释放逐层推进）
  - 55-75s：关系逆转（权力关系可见转移）
  - 75-86s：本集高潮（动作/决定/发现抵达顶点）
  - 86-90s：悬念骤停（未完成动作/突然重聚焦的视线/未知声源）
  - 以上区间是叙事功能区，不强制在固定秒数切换；每集回答一个小问题，同时提出一个更大的问题

**人物设计（Want/Need/Arc）：**
- Want（角色想要什么）→ 驱动外部行动
- Need（角色真正需要什么）→ 驱动内部成长
- Arc（弧光变化）→ Want与Need的冲突解决
- 长片/剧集附加：Ghost（创伤前史）+ Lie（错误信念）+ Flaw（性格缺陷）
- 小逻人物小传补充：欲望/需求/恐惧/秘密/缺陷/底线/能力/代价/弧光 + 戏剧功能 + 人物关系（表面关系/实际需求/隐藏矛盾/权力变化/关系终点）

**爆款开头四公式：**
1. 误会型：误会建立→悬念→反转真相
2. 身份反差型：你以为X→实际是Y
3. 时间压力型：在X时间前必须完成Y
4. 情绪积蓄型：日常→积累细节→爆发

**黄金3秒钩子设计（追加·爆款AIGC短剧规律）：**
> 来源：抖音&红果10大爆款AIGC内容分析。开篇3秒决定观众是否划走。
- 视觉冲击型：高能名场面直接开幕（天兵列阵/炸裂行刑/坠崖瞬间）
- 悬疑反差型：不合理的画面+疑问（众神跪拜一个慌张的假龙王）
- 情绪冲突型：极致对比开场（前世惨死切重生眼神，生死反差一秒入局）
- 场景惊奇型：未见过的视觉奇观（暗黑古风街巷+妖兽嘶吼+持剑出战）
- 60字钩子写作法：一句话说清"主角是谁→面临什么困境→为什么非看不可"

**场景情绪选择（追加·剧本拆解课）：**
> 同样情节在不同场合感受完全不同。场景本身在参与叙事、塑造情绪。
- 告白：西餐厅=郑重 / 菜市场=荒诞喜剧 / 大雨街头=戏剧激烈
- 诀别：火车站=未知远行 / 病房=接受死亡 / 战争废墟=愤怒复仇
- 对峙：豪华办公室=权力压迫 / 厨房=亲密关系撕裂 / 雨夜小巷=绝境对决
- 选择场景前先问：这个场合给情节加了什么情绪？它本身在说什么？

**五维微表演（剧本正文即用，不用抽象情绪词）：**
维度1 微表情与视线（瞳孔收缩/视线躲闪/睫毛颤动/眼睑收紧/咬肌嘴角变化）

维度3 动作中间态（手停在半空/转身停顿/半步收回/想触碰停在物体前/开口无声）

维度5 光影动态（转身使窗光从面部移到耳后/胸腔起伏带动衣领阴影位移/门缝扩大光线切入地面）

### 2.1A AI 剧本批量创作增强包（V3.2 新增·来源 AI通用提示词.docx）

#### a. 小说转漫剧剧本指令（三步法）

**第一步 拆解爆款逻辑**：让 AI 梳理小说前十章爆款结构（剧情设定/人物设定/钩子反转设定），梳理适合漫剧结构的主要故事线
**第二步 改编要求**：主题意思不变；开头反转霸气（反常识反逻辑，用对比反差猎奇拉踩排比）；故事跌宕起伏；结尾悬念；润色后画面感极强适配分镜；保留关键对话/情绪爆发点/剧情转折点；适配竖屏短视频节奏；严格遵守平台内容规范
**第三步 小说转漫剧指令（核心规则）**：
- 角色：资深漫剧编剧兼导演，竖屏短视频视听语言
- 核心原则：**绝对忠于原文**（不增删改，人物对话原文保留）；**纯动作与对话**（禁旁白/字幕/画外音）；可视化优先（背景/心理/世界观→可拍动作）；镜头标注；动作对话交替（不连续 5s 无动作、10s 无对话）；时长标注
- 动作判断：肢体动作/神态表情/环境变化/道具使用/镜头可捕捉细节/群演反应；心理描写必须转表情动作（"他心里很愤怒"→"苏墨攥紧拳头，指节发白 1s"）
- 对话判断：直接引语/明确说话动词/对话性拟声词；保留情绪动作指示：`角色名：（情绪）"对话原文"`
- 叙述性背景交代：世界观/人物背景必须通过对话或视觉转化（如命灯颜色变化+众人反应），实在无法转化才可补一句台词并标"*基于原文背景合理补充*"
- 竖屏镜头规则：远景 LS / 中景 MS / 近景 CU / 特写 ECU / 俯拍 HA / 仰拍 LA / 过肩 OTS / 跟拍 FT / 摇镜 Pan / 推镜 Push
- 时长规则：动作 0.5-1s（极简）/ 1-2s（简单）/ 2-3s（中等）/ 3-4s（复杂）/ 3-5s（环境）；对话约 3 字/秒，单句 ≤5s 超则拆分
- 输出格式：`场景：序号 内/外景 地点—时间` + `【镜头：类型】动作/对话` 块

**强制交互流程**：①输出当下全赛道爆款题材清单（标流量层级/核心设定/漫剧适配/受众）→ ②题材定制化配置（7 维度选配：进入方式/金手指/爽点方向/基调/性别情感线/篇幅/自由补充）→ ③输出全案框架 → ④确认与创作

**全案框架 7 大模块**：

2. 核心主角人设（固定姓名/开局极致惨境锚点/可视化金手指/强棱角性格/**暗面人设锚点**：表面 X 暗面 Y，标注首次暗示/半揭露/终极引爆节点）

**开场铁则**：黄金 3 秒留客；五感暴击（开篇 200 字内 ≥3 种感官体验，用"像是被……"通感隐喻）；粗粝生猛对白（允许脏口/嘶吼/诅咒，严禁书面腔）；心理操控型剧情推进

#### c. 剧本爆点公式（5 种，填空即用）
1. **身份反差**：隐藏的低贱身份 + 突然的高光时刻 + 无人相信的震惊
2. **绝境翻盘**：无法挽回的绝境 + 不可能的倒计时 + 一个被隐藏的王牌
3. **虐恋错过**：深爱 + 被冤枉 + 断崖式离别 + 一个迟来一步的证据
4. **逆转收尾**：已知结局 + 最后一秒逆转 + 金手指启动
5. **禁忌触发**：平静日常 + 突然闯入的外敌 + 一个不可触碰的禁忌被触发

#### 2.1B 剧本二次编写能力（短剧工业化参考·2026-08-15 吸收）

> 来源：短剧工业化参考（完整版见 references/短剧工业化参考/）。核心：**把大纲/素材二次编写成「双轨成片剧本」**——视觉资产与声音资产在剧本阶段彻底物理拆分，可直接对接 AI 生图师 + CV + 后期。与 §2.1 从零创作、§2.1A 小说转漫剧互补（2.1A 管「忠于原文转动作对话」，本节管「成片剧本的工业化排版与硬指标」）。

**① 体量规划与集数矩阵（动笔前先定轨）：**
- **轨A 季播精品**：12/24集，悬疑罪案/高概念/都市大女主/荒诞喜剧；底线=首集3秒完播>70%、整季完播>45%
- **轨B 重度长漫剧**：60-100集，系统开挂/重生逆袭/战神神豪/隐藏豪门；底线=付费卡点(10-15集)转化>8%

**② 单集秒级结构（120s 示例，可等比缩放）：**
```
[0-5s]   3秒强钩 Cold Open（直切高潮/反常动作，禁黑屏渐显）
[5-15s]  集头承接 Reaction（回应悬念，建立当场危机）
[15-50s] 冲突一阶 The First Beat（事件展开，主配角交锋）
[50-60s] 30秒微钩 Micro-Hook（新信息/细节翻转，对抗疲劳）
[60-105s]冲突二阶 Climax Peak（矛盾顶点，底牌揭开）
[105-120s]集末钩子 Cliffhanger（切在「最难受的临界点」）
```

**③ 五阶段创意工作流（自由的头，扎紧的尾）：**
1. **选题反庸俗自审**：列出本题材公共池套路≥3个划为禁区；自问「观众看完能带走什么独特体验（爽/虐之外的余味）？」
2. **视觉/听觉人设**：角色 Key Pose（「极怒时左眼瞳孔骤缩+嘴角冷笑」）+ 声线锚点（「烟熏嗓，每字在喉咙撕扯」）
3. **分集大纲结构整形（硬闸门）**：每集一句话弧光检查——「这一集主角被拿走了什么/换来了什么」，写不出的集数砍掉或合并；伏笔登记限时回收
4. **剧本写作**：先单轨，再询问是否要双轨（见④）
5. **剧本医生自检**：视听自检（有无画不出/说不出的心理？）+ 废话自检（删 AI 腔水词）

**④ 剧本格式（先单轨，再询问是否要双轨）：**
- **单轨 = 音画同步出**：画面（动作）和声音（音效/台词）写在同一段里，同步输出，不分列
- **双轨 = 音画分开**：视觉轨道（画面描述/景别/转场）与听觉轨道（音效BGM/台词）物理拆分成两列，分开写
- **默认先输出单轨剧本**：动作 + 音效 + 台词混写在同一段里（音画同步），一句话一个动作，只写可拍可听的内容，先让用户确认剧情对不对
- **输出单轨后必须询问**：「需要升级成双轨（分镜式成片剧本，音画分开）吗？」——用户确认要，再升级；不要则停在单轨
- 用户确认要双轨后，按下面格式把视觉/听觉物理拆分：

【双轨格式（按需升级）】
```
镜号：#01
【景别】特写/中景/全景/主观/过肩（只写三种景别，漫画师可执行）
【转场】切/冷开场/闪白/动态速度线拉近
【场景】[物理空间]·[日/夜]
【画面描述】[极简可画指令，含 Key Pose，禁心理描写]
【音效/BGM】[SFX环境音/爆破声/BGM节奏]
【台词】[角色名]（[语气/情绪]）：[子弹台词≤15字]
```
- **子弹台词律**：静态漫剧双轨剧本单句台词**≤15字**（半静态画面下台词是破局子弹，不是散文）；AI视频动态生成段式沿用**≤40字/句 + 时长拆句**（单镜 8-12字最自然，超过 15字拆成多个连续时间点，见 §2.4）
- **字数硬指标**：60s=总字数250-300/纯台词120-150/分镜8-12格；120s=总字数500-600/纯台词240-300/分镜16-22格
- **格 vs 镜（防混淆）**：「格」= 静态漫剧双轨剧本的分镜格（半静态，每格约5-7s）；「镜」= AI视频动态生成段的镜头（§2.2 的 18-26镜/90s，每镜约3-5s）。漫剧静态用「格」，AI视频动态用「镜」，两者密度不同属正常
- **特写率≥40%**：眼神/局部/关键道具特写是漫剧生命线
- **ASR 极限**：纯配音台词远低于 ASR 极限（60s 约210字 / 90s 约315字），为音效与画面留足动作时间

**⑤ 剧本二次编写（诊断 → 重写 → 探索）：**
- **诊断四维度**：节奏（情节松中紧 + 情感轻中重双轨错位）/ 时长（场景过长过短）/ 逻辑漏洞 / 对话问题（直白/书面腔/说教）
- **针对性重写**：潜台词重写（把说穿的真意压回冰山）/ 视觉改写（心理→动作生理）/ 反套路构思 / 台词口语化，只改问题段落保留已通过部分
- **What-if 多版本探索**：问题场景给 2-3 个改写方向，一句话说清「改了什么+为何更有效」，不做重写全文
- **伏笔审计**（悬疑/反转必做）：短程/中程/终极翻转分层登记（例：伏笔A #01左手端杯→#04左撇子笔痕；伏笔B #03停摆手表→#10死亡时间；终极翻转=审讯是对台词）

**红线（同 §0.3 + 蒸馏版）：** 零心理描写 / 零括号暗示 / 零死空间（每个字必须能画出或配出声音）/ 动作代替解释 / 对话只露冰山一角

### 2.2 第二步：分集分镜剧本

**输入**：分集详细剧本
**输出**：分集分镜脚本（镜头级，可直接转为生成段式）

**核心逻辑（小逻为主）**：

#### 时间轴（硬规则）

1. 将每集固定为 90s（或用户指定的目标集长），第一镜从0s开始，最后一镜精确结束于总时长
2. 单集内部只使用一条连续时间轴；不得拆段重置时间轴
3. 前一镜结束时间 = 后一镜开始时间；不得重叠、跳秒、留白
4. 场景切换不重置时间轴；场景标记不占用时长
5. 优先整数秒；确需小数时统一保留一位小数并精确闭合
6. 默认一次输出一集；长篇可连续多集，每集独立时间轴
7. 18-26 个镜头作为软性参考，根据剧情密度、台词长度、动作完整性调整（老李补充：信息量估算——读取一层≈2-3s，每多一层+2-3s；台词时长按角色性格语速脑内"演"一遍估算，再加反应时间）

#### 镜头语法（小逻为主）

- **动作-反应切镜**：关键施压动作/信息揭示/道具触发/突然进入/重要台词/关系逆转 → `动作镜头 → hard cut → 反应镜头`
- 动作镜头呈现**正在发生的物理行为**，不用已完成的静态结果替代过程
- 反应镜头呈现**可见生理应激**（瞳孔变化、睫毛颤动、喉结滚动、鼻翼微翕、呼吸停顿、指节收紧、重心后撤、视线失焦后重聚）
- 反应镜头不递归触发下一组反应镜头；连续两个反应镜头不得机械复用相同瞳孔/抿唇/握拳/后退动作
- 普通走路、自然呼吸、无叙事作用的转头不强制配置独立反应镜头
- 长镜头可通过横移、焦点转移、前后景调度在同一镜头内先后呈现动作与反应；受动者反应不得被遮挡/失焦/快速运镜吞没
- 剪辑衔接只按需使用：开场直入、hard cut、match cut、sound bridge cut；不使用叠化/淡入/淡出
- **宏观视觉换挡**：每 15-30s 一次明显换挡，任意两次间隔不超过30s。换挡方式：切场景/空间区域；全景与特写大跨度；固定转跟拍/轨道/手持；明显改变机位高度方位；逆转前后景位置/构图中心/空间权力；叙事焦点从面部转至道具/未知空间/新角色；真实光源明显改变明暗或色温。相近景别正反打、普通hard cut、轻微构图调整不算换挡

#### 景别、构图（小逻为主 + 老李/山音补充）

- 交替使用大远景/全景/中远景/中景/中近景/近景/特写/大特写/极端特写/环境空镜
- 不连续使用相同景别、相同机位、相同角度、相同构图
- 正反打可用相近景别，但改变方位、角度、前景遮挡、权力高度或焦距感
- 中景/全景/环境镜头优先前景遮挡+中景表演+远景环境三层纵深；特写/大特写不强制三层，保证瞳孔睫毛咬肌嘴角手指清晰
- 每镜只承载一个主要叙事动作或一个主要人物反应
- **叙事目的七分类（山音补充·每镜至少承担一个，保证镜头有功能）**：建立(Establish)/推进(Advance)/揭示(Reveal)/强调(Emphasis)/过渡(Transition)/共情(Emotion)/反思(Reflect)。写法：用一句话同时覆盖"做什么"和"为什么这么做"（"用背对背构图展现疏离"而非"展现关系变化"）
- 老李补充（切镜连接逻辑）：推近（全→中→特，逐渐深入内心；约54%常态路径）/ 拉远（特→全，抽离揭示，场景收尾）/ 弹跳（中→特→中）跨级跳切（全→特）用在惊讶/翻转/情绪断裂时刻
- 山音补充（镜头组：**每段=1个镜头组**，镜头组是节奏规划与分镜拆解之间的桥梁）：蒙太奇组（并列快切，每镜1-3s硬切）/ 递进组（景别逐步推近全→中→特）/ 因果组（动作-反应交替，景别随升温推近）/ 对比组（两画面对比，硬切冲击）
- 山音补充（动作-反应10变体）：标准型/反应前置/动作并置/反应省略/动作隐藏/反应延迟/同步型/反应链/重复渐变/链式衔接；70/30法则（70%常规模式撑骨架，30%出彩模式造记忆点）

**剧本→分镜翻译规则（山音补充·防丢内容）：**
- 每个 Beat → 至少1个镜头；情绪/动作变化 → 新镜头
- 台词 → 视觉化（动作即潜台词，不靠台词解释）
- 场景变化 → 新场次 + 空间锚点记录（方向/门窗/固定陈设）

**零损耗切割原则（山音补充·防AI脑补改剧情）：**
1. 切割后镜头须还原原始文本，严禁遗漏
2. 单镜头台词≤40字
3. 短句相加≤40字且动作连贯→合并
4. 100%复制原文，禁止脑补提炼
5. 开场首镜交代人物如何到达场景

#### 分级运镜（每镜只选一个主要运镜等级，不混用冲突标签）

- **特写/大特写/极端特写**：`locked-off tripod shot` 或 `ultra-stable micro-jitter`；按需加 `high facial detail focus`、`precise eye focus`、`controlled depth of field`、`micro expressions`、`subtle performance`；禁止剧烈晃动/快速漂移/大幅度手持呼吸
- **中近景/双人对峙/台词镜头**：`subtle cinematic handheld` + `realistic camera inertia`；随角色体态轻微低频滞后，保持面部稳定可辨
- **中景/中远景/全景/环境空镜**：`documentary-style cinematic handheld`、`natural breathing`、`controlled camera drift`；允许慢速漂移自然呼吸，主体轮廓不得模糊
- **斯坦尼康长镜头**：用于狭窄空间移动/多人调度/追随式叙事；保留真实相机惯性、步伐节奏、空间障碍反馈；不得穿越墙体家具人物
- 老李补充（运镜情绪词典）：推进=逼近审视专注 / 拉远=疏离揭示抽离 / 横移=漫游观察跟随 / 升降=上帝视角揭示规模 / 环绕=对峙张力卷入 / 甩镜=混乱能量速度感 / 手持=临场感不安 / 固定=稳定仪式感凝视

#### 机位权力与光影（小逻为主）

- 支配/施压方：微仰拍、前景压迫、较少头顶空间、暖色轮廓光
- 被压制/迟疑方：轻微俯拍、增加负空间、冷色顶光、眼窝阴影
- 势均力敌：平视、对称构图、相同高度机位
- 权力逆转：通过机位高度、前景遮挡、人物站位、焦点归属、构图中心转移表现
- "光随权移"建立在真实光源基础上：人物进入/离开既有光区、身体遮挡、门窗光、灯具方向改变面部明暗；不得无来源变光
- 环境光随呼吸体态在面部轮廓产生细微位移 → `ambient light drift`

#### 空间参考系统（空间导演转换器V3·2026-08-15 吸收）

> 来源：空间导演转换器-空间参考系统 V3（完整版见 references/空间导演转换器-空间参考系统-V3.md）。核心：**先空间，后镜头**——把分镜先转成「连续空间状态」，再写镜头/提示词，防 AI 生成时人物乱飘、瞬移、切镜重置。
> 与 §2.4 站位锚定铁律、§3.4 银幕轴线规则互补：站位锚定管「单镜内人物在哪」，本节管「跨镜空间如何连续变化」。

**两种空间模式（先判型再处理，勿用同一种方式处理所有场景）：**

| 模式 | 适用 | 核心 |
|------|------|------|
| **A 静态/对话型** | 对话、审讯、会议、站立/坐姿交流 | 锁一个空间状态 + 人物锚点 + 视线关系 |
| **B 动态/运动战斗型** | 战斗、追逐、群戏、走位变化 | 锁空间变化——多个连续空间关键帧 |

**A 静态型规则：** 锁定人物位置/左右关系/前后关系/朝向/视线关系/180°轴线/摄影机区域。人物可说话/眨眼/呼吸/点头/转头/微手势/微移重心，**不可换位/跨区/瞬移/因切镜重排**。

**B 动态型·空间关键帧（核心新概念）：**
> 动态场景不是「固定站位 + 人物做动作」，而是「空间状态随运动持续变化」。
- 用**一组按时间排列的空间关键帧**表达空间变化（如 0s初始→3s交战→6s被击退→10s重定位），每帧标人物相对位置
- 每帧必须同时表达五要素：**空间状态 + 运动方向 + 运动路径 + 动作因果 + 运动后的新空间状态**
- **运动因果铁律**：任何明显位置变化必须有动作原因——攻击→受力→沿击退方向移动→落到新位置。禁止「切镜后主角突然出现在右边」（除非分镜明确表现了移动回去）
- **关系 > 绝对坐标**：动态中不写死「主角=左」，记录「谁在谁哪侧 / 谁在谁前方 / 谁接近谁 / 谁远离谁 / 谁攻击谁 / 谁被击退 / 谁追谁」
- **动态空间锚点**：不是「人物永不动」，而是锁定「初始区域 + 运动范围 + 运动规则」（如「主角初始左后区，向中央前进，禁止无理由穿越女配」）
- **多人（5-8人）**：用区域（左前/右前/中央战斗区/高台）+ 阵营（主角组/敌人组）+ 目标关系（A1→C1）+ 运动关系（A1→中央），不逐个写坐标

**人物位置 ≠ 画面位置（必记）：** 真实场景位置 ≠ 画面左右位置。摄影机移动后，场景右侧的人可出现在画面左边/中央/前景/半身——只要真实三维关系没被破坏即可。

**摄影机规则：** 摄影机管景别/构图/角度/焦距/推拉/横移/过肩/反打，**不能无理由改变人物空间、为正脸重排人物、无理由越轴、镜像真实空间、把切镜变成场景重置**。

**镜头连续性（每切镜必查）：** 继承上一镜结束时的空间状态 → 人物位置 → 人物关系 → 运动结果 → 再选摄影机 → 执行当前镜。**上一镜被击退到哪，下一镜必须从哪继续**，除非分镜明确表现移动回去。

**过肩与反打：** 人物在场景右侧看向前方人物时，优先「右后侧过肩」，不为拍正脸把摄影机放到轴线另一侧。反打=改观察角度，≠左右交换/人物重排/空间重置。

**校验（并入门禁B）：** 空间连续（门窗家具不漂移）/ 动作连续（移动距离符合时间间隔）/ 视线连续（正反打方向匹配）/ 轴线连续（越轴需中性镜头）/ 资产统一。

#### 六维物理表演（小逻主核·画面描述强制）

- 画面描述严禁抽象情绪词替代表演
- 普通人物镜头至少覆盖**三维**；关键近景/特写/反应镜头至少覆盖**五维**
- 1 微表情与视线：瞳孔骤缩/慢扩、睫毛高频颤动、视线失焦/重聚、咬肌收紧、唇角肌理位移、眼睑不自主抖动
- 2 肢体与体态：重心前压/后移、双肩随呼吸起伏、指尖拧抓衣角、指节泛白、手腕紧绷、背部肌肉收缩、脚步半停
- 3 动作中间态：欲言又止、抬手悬空、转身一滞、半步悬停、触碰前微顿、物件即将落下、门即将开启
- 4 生理应激：喉结滚动、鼻翼微翕、额角筋络微凸、胸腔节律改变、吞咽停顿、呼吸短促、掌心收紧、肌肉细颤
- 5 光影呼吸：呼吸体态带动皮肤/衣领/面部轮廓/眼窝阴影细微位移 → `ambient light drift`
- 6 物理交互与重力反馈：肢体与道具/服装/地面/墙体/家具遵守现实碰撞体积；禁止肢体穿透、物件悬浮、手掌未接触却抓道具、脚底滑动、穿越场景结构；急停时头发衣摆随身物件保留向前惯性；搬重物通过手臂肌肉收紧/重心下压/膝部弯曲/脚掌支撑/躯干微晃呈现重量
- 优先使用动作中间态，不直接呈现已完成的静态结果

#### 文戏微表情四技巧（2026-08-10 吸收·消除AI面具感）

> 六维表演给「写什么」，本技巧给「怎么写」。根因：AI 感 = 模板化情绪词 + 过于工整对称 + 起承转合太流畅。

1. **情绪肌肉链（拒绝静态形容词，用动作替代情绪状态）**
   - 禁止直接写"伤心/难过/微笑"等模板词，只写面部肌肉即时运动，按肌肉先后顺序给 AI 逐帧执行指令
   - 示例（情绪熄灭版）：①眉心聚拢，挤出两道浅浅竖纹 ②下唇出现振幅不足 1 毫米的极细微颤抖 ③眉心缓缓舒展，情绪熄灭后面部平坦无波澜（皱眉肌→口轮匝肌→额肌的顺序）
2. **不对称与矛盾共存（打破 AI 完美对称）**
   - 不对称：单侧情绪，禁止全脸联动——"嘴角向左侧微扯，扯出半弧不完整苦笑，仅单侧面部发力，不扩散至眼底，右眼全程无任何情绪变化"
   - 矛盾共存：两种对冲情绪同时/短时间切换——"下眼睑泛红湿润，眼底藏破碎沉静悲伤；同时瞳孔剧烈收缩，眼神锐利决绝"（标注：0.5 秒内两种情绪转换、同步发生）
3. **量化生理指标（用数字消除模糊）**
   - 避免"微微/轻轻/些许"等 AI 会弱化的虚词，标注精准幅度/时长/距离
   - 基础量化词：振幅不足 1 毫米、动作幅度不超过 15°、唇角下沉半度、双肩向内收拢 2-3 厘米、整套动作耗时 1.5 秒、眼睑完全睁开前存在 0.2 秒卡顿
4. **克制与动作中断（制造真实失序感）**
   - AI 情绪起承转合完整流畅，真人会压抑、中途中断；写"启动→骤停"而非完整动作
   - 克制句式：话涌到嘴边强行吞咽收回；拼命压抑情绪，眼睑肌肉紧绷锁住眼眶泪水；拥抱动作启动后在最后一刻骤然克制停下
   - 细化替代：不写"流泪"→"眼眶泛红，泪水被眼睑肌肉锁在边缘，下眼睑持续细微颤动"；不写"摇头否认"→"摇头启动后摆动至 10 度突然减速停滞，思绪中断"

#### a0. 人物资产提取 JSON（V3.2 新增·来源 10 作业点评）

> 短剧人物一致性的根：**组别**（同一个人）+ **主从**（主=基准定妆照 / 从=各具体造型）。输入全本剧本 → 输出标准化人物视觉资产 JSON。

**工作流**：
1. 找出所有"需要在画面里实际出现"的人物（含回忆/照片/视频/梦境可视化出现的；无台词但构成画面主体的也提）
2. 把同一个人的所有称呼（正式名/昵称/小名/旧称/误认/职业/亲属称呼）合并成一个 `组别`
3. 每个组别先建 1 个 `主` 资产 = 基准形象（定妆照锚点）
4. 同一人有可视差异（服装/妆造/发型/年龄/伤血污破）拆成多个 `从` 资产，共享同组别
5. 统计每个 `从` 资产的出现次数 + 出现场次；6. 补全字段，输出 JSON

**硬规则**：
- 谁提取：实际出镜的人；不提：纯被提及、纯背景介绍、不实际出镜的
- 复合称呼拆："爸妈/父母/兄妹二人"必须拆成单人；"亲戚们/路人们"留泛称；禁止把"爸爸/妈妈"泛称直接当组别
- **主从拆分**：`主` = 基准形象锚；`从` = 在主的**脸、身形不变**前提下只换服装/妆造/状态
  - **脸会变的差异 → 另起"主"**（重大年龄阶段/转生/附身/毁容前后），同一组别可有多个主
  - **脸不变的差异 → 才是"从"**（服装/妆造/发型/状态：伤痕/血迹/脏污/破损/湿透/身份伪装）
  - 造型全程一致就只 1 个从；拿不准不拆
- 命名：`组别(阶段/服装/状态)`，如 `林晚(校服)`、`金妮妈妈(年迈)`、`陈庆圆(染血衬衫)`
- 场次绑定：连续场次没说造型变化 = 延续上一个已确认资产外观；原文明确换装/受伤 = 从该场次起新建"从"
- 字段取值：性别 男/女/未知；年龄 幼童/少年/青年/壮年/中年/老年/未知；对话 有/无；出现次数（"主"填 0）；人物简介 <100 字；服饰约 20 字；外形特征 ≤50 字（只写客观外貌，不写情绪/气质/心理）；**禁止编造原文没有依据的经历/职业/关系/设定**

**输出字段（固定）**：`姓名` / `组别` / `从属状态` / `性别` / `年龄` / `人物简介` / `对话` / `职业` / `服饰` / `外形特征` / `人设` / `出现次数` / `出现场次`

**出图提示词生成规则**（配套）：
- `主` → **文生图**：纯白背景、正面/侧面/背面全身三视图 + 一张大脸特写、素衣（基础中性服装不带剧情造型）、严格按外形特征
- `从` → **图片编辑**：以同组别"主"图为基底，锁定面部/五官/身形/肤色/发型基底，只改服装/妆造/发型/状态（伤痕/血迹/脏污/破损/湿透）
- 白底资产图不加负向约束（不会出字幕/水印/BGM）；缺陷/疤痕如实表现并露出（保一致性），但守审核边界（不裸露敏感部位、不血腥刺激）
- 不写情绪、气质、心理状态（这些不是外貌）
- 适用模型：中文生图模型（香蕉/Nano Banana、GPT），支持主图作参考图直接输入

#### b. 角色表情设定提示词（V2.1 新增·补齐小逻缺失的细微刻画）

> 小逻已有的表情设定是**图像生成指令**（十二宫格表情板），老李把它并入衔接层作为标准资产步骤；**镜头级表演的细微刻画**另由 §5 老李微表情库 + 小逻六维物理表演补齐。

**十二表情库（顺序固定）：** 平静 / 微笑 / 开心 / 悲伤 / 愤怒 / 害怕 / 惊讶 / 疑惑 / 羞涩 / 冷漠 / 哭泣 / 大笑

**表情强度与差异锁定：**
- 微笑 ＜ 开心 ＜ 大笑（眼睑收窄、面颊抬升、张口幅度、眼轮匝肌参与递增）
- 平静 vs 冷漠：眼睑更低、视线更疏离、口周肌肉更克制
- 悲伤 vs 哭泣：泪水出现 + 眼睑/鼻翼/口周应激强度
- 惊讶 vs 害怕：眉心聚拢/下眼睑紧绷/嘴角横向拉伸（害怕）vs 张力开放/下眼睑不紧绷/嘴型圆或椭圆（惊讶）
- 十二格不得重复、近似复制、镜像复制或只改嘴型忽略眉眼肌肉

**身份一致性锁定：** 每格同一人物（头骨/颧骨/下颌/双眼间距/眉峰/鼻梁/唇形/肤色/痣斑疤痕/发际线发型/服装配饰），表情只能改变面部表演及必要轻微头部动态，不得重新设计人物。严禁换脸、五官重塑、年龄漂移、光照漂移、画风漂移

**输出格式（表情设定提示词）：**
```

**运镜内嵌写法（V4.0.6 新增·AI电影级运镜，用户示例验证）：**

每个时间点可内嵌独立运镜，格式：`[时间码] 运镜：... 画面：...`。运镜跟随时间轴进化，串成一条情绪弧线（建立→引入→聚焦→爆发→收束），不再全局一个运镜。写法要点：

- 运镜写完整轨迹+景别变化+机位切换："AI电影级航拍俯冲推镜，大景深大全景缓慢下沉，镜头从穹顶高度穿过层层云雾垂直降落，至中景时切低角度仰拍"，不写"推镜"两个字
- 每个运镜有叙事功能：降落=建立环境 / 环绕=引入人物 / 推近=聚焦细节 / 后拉升格=爆发释放 / 静态凝视=收束
- 运动质感词可带："运镜丝滑无抖动""动态张力运镜""升格慢镜头"
- 视觉调度大-中-小-大层级：环境全貌→人物全身→面部特写→爆发全景，形成尺度对比收尾（"她很小，巨门很大"）
- 信息埋点：客观视觉承载叙事钩子（"脚底踩碎的是干涸的黑色血迹（不是她的）""她没有看镜头——她看的是镜头后上方"）
- 可整体参数前置：`【整体参数】时长，画幅，风格，负向提示词` 一个块开头（供单段直投），此时五段式其余模块仍按序保留

**六段式（仅>60s 长内容）**：在五段式【风格】之后、【色卡参考】之前插入 `【出场人物与场景】本段出场人物 + 场景位置（生成时在此处 @ 人物/场景资产图，是固定的资产引用位，每段必写）`，其余五段不变。

**色卡参考写法规则（2026-08-06 用户确认·每段必写）：**
- 位于【风格】之后、【镜头】之前，是独立固定模块，不可省略
- 写本段主色相 + 辅助色 + 高亮色 + 暗部色，每个颜色附 **HEX + RGB 参考值**（如 `千禧粉 #F1BB7B 241,187,123`，跨段共享同一色卡防漂移；§4.2.1 色卡垫首帧时提示词只写动作不写光影，画面自动咬住色卡色彩）
- 跨段共享同一色卡：相邻段主色相不变，只允许按情绪曲线微调高亮/暗部
- 使用方式：色卡参考图垫首帧（§4.2.1 三步）→ 提示词只写主体动作不写光影 → 画面自动复用色卡色彩，得到统一调色

**建议时间轴写法规则（2026-08-04 确认 + 08-05 强化 + 08-12 运镜内嵌 + 08-15 建议化）：**
- **定位：时间轴是「建议节奏」，不是硬命令**。秒数是给 AI 的节奏参考——AI 生成时可根据画面表现、动作完整性、台词语速自然微调，前后偏移 1-3s 属正常，不必逐秒精确。我们预估的秒数偶尔不准，**给 AI 留发挥空间，别卡死**。唯一不能妥协的两条硬底线：①**台词必须完整说完**（不许切半句/口型错位）；②**动作因果链连续**（不许人物瞬移/跳变/无因果换位）
- 每个时间点一段连续叙述，时长约 1.5-3s（老李参考：1-1.5s闪切冲击 / 1.5-2s钩子高潮快切 / 2-2.5s常规动作对白 / 2.5-3s叙事建立 / 3-4s情绪沉淀反应 / 4-6s慢镜定格收尾），段与段无缝衔接（前段末=后段首）；**每时间点可内嵌独立运镜 `[时间码] 运镜：... 画面：...`（V4.0.6），运镜跟随情绪弧线进化，见五段式结构下方专项**
- **开场直接炸开**：不解释来历，从冲突中间开始（"画面直接炸开——已经在打"）
- **动作 + 物理反馈 + 括号音效**嵌在描述里（"削断三根竹子，竹干从中断裂的声音"）
- **零心理描写**：只写眼睛能看到、耳朵能听到的东西
- 一句话一个动作，主谓宾主动句式，具体到物理细节（火光/水花/火星/断裂）
- 时间点分段：钩子/高潮用 1.5-2s 快切，情绪沉淀用 2.5-3s
- **台词**写为 `角色名："台词"`，台词时间按自然语速"演"一遍估算 + 反应时间
- **对白戏时长硬规则（2026-08-10 用户反馈）**：**台词没说完不许切镜**。时间点内台词必须按自然语速（≈4字/s，急躁5-6字/s，沉稳/醉酒/回忆≈3字/s）能说完；单镜台词 8-12字 → 该时间点拉长到 2.5-4s；15字以上 → 拆成 2-3 个连续时间点（说着→停顿/听者反应/道具特写→继续说），台词跨时间点必须连续，禁止为保 2s 快切节奏而断句/口型错位。对话段整体节奏由台词量决定，不是由 2s 切镜决定
- **宏大场景**时间点内必须写清：景别+焦段+人物与环境的比例差+运镜（§4.5）
- **站位锚定铁律（2026-08-11 用户反馈：AI生视频站位乱）**：每个时间点**第一句**必须写死人物空间关系——`[角色A]在画面[左/右/中/前景/后景]，[距谁多远/面向哪]，[角色B]在[相对位置]`；多人镜头补前后景或九宫格坐标；关键道具也锁位置（剑/钟/门/桌）。距离用具体数（两步/两米/三步），方位用左/右/中/前景/后景。**不写清站位 = 生成时人物乱飘**。跨时间点人物位置变化必须写明移动轨迹（"走向画面左侧崖边，经过师尊身侧"），不能只写动作
- **视线锚定铁律（2026-08-11 用户反馈：对话戏无视线约束）**：对话/对手戏每镜必须写明**谁看谁、看哪里、何时移开**——`[角色A]视线[低垂/直视/追随/望向X]`；听者与说话者都要写（"林澈始终垂着眼没抬头""视线第一次与师尊对上"）。听训/臣服/心虚用垂眼回避（averted gaze），表态/对峙/醒悟用直视（direct eye contact），离别/念旧用追随背影。**无视线指令 = AI 眼神乱瞟、对话无张力**。与站位锚定同列门禁必查。**扩充规则（2026-08-11 吸收小逻九宫格）**：①人物看向画外目标时，后续镜头展示的目标必须位于合理反向位置；②正反打镜头保持视线高度和方向匹配（说话者视线高度=听者视线高度）；③眼神特写必须与上下镜的观察对象一致；④表情强度随剧情逐格发展，相邻镜头不无故跳变（通过眼神/眉眼/嘴角/呼吸/手指/肩颈/身体重心表现变化）
- 关键物理声音在描述内括号标注，并在【声音】段汇总

```

【色卡参考】主色冷墨绿（竹林深处 #2F4F4F 47,79,79），辅助色湿竹叶青（雨湿竹叶 #2C9678 44,150,120），高亮色雨珠白（雨珠反光 #F3F9F1 243,249,241），暗部色竹影深青（竹丛阴影 #1C2C5B 28,44,91）

**组合一致性（每段必查）：**

- 结尾回到空间尺度对比形成视觉闭环（如开场爆炸火光 → 结尾窗外天光）

- 每段时长由剧情内容量决定（对话段按台词量自然语速≈4字/s估算，动作段按动作密度；读取一层信息≈2-3s，每多一层+2-3s）

- 一段只做一个镜头运动，不复合
- 画面内容与运镜绑定但不互抢

## 三、分镜组合一致性（V2核心升级·保留）

**目标：多段视频拼接成一集，段间无缝衔接，整体分镜要求高。**

### 3.1 双轨时间轴模型

- **段级时间轴**：每段独立镜头组，**段长按剧情/场次自然切，3s~15s 不等，15s 是上限不是固定值**（一段戏讲完就收，可 7s/10s/12s 收尾，不硬凑 15s）
- **集级时间轴**：多段首尾相接 = 连续总时长（前一镜结束=后一镜开始，无跳秒/重叠/留白）
- 两轨并存：分段生成时用段级，成片拼接时用集级

### 3.2 六重一致性锁

| 锁 | 内容 | 检查项 |
|----|------|--------|
| 资产锁 | 角色/场景/道具编号跨段不得重置 | 服装/骨相/道具状态连续 |
| 时间轴锁 | 段间时间连续 | 前段末=后段首，无跳秒 |
| 空间锁 | 空间方向/位置连续 | 视线轴/走位方向/门窗位置不漂移 |
| 光影锁 | 光源方向/色温/时间一致 | 同一场景光影不突变 |
| 风格锁 | 渲染/色彩/质感一致 | VISUAL DNA 每段声明 |
| **末态继承锁**（V4.0.2 新增） | **可变数据每段同步更新** | 后段继承前段结尾的人物站位/姿态/互动/构图，用分镜参考图锁死 |

**末态继承锁详解（AI 视频多段拼接核心）**：AI 视频 2.0 单段上限 15s，每段生成时无前段记忆（人物站位/姿态/互动每 15s 归零）。**禁止用上段尾帧当下段首帧直接拼接**（无动态继承，跳切最重）。正确做法：每段生成前，按上段结尾人物状态绘制分镜参考图，固定姿态/位置/互动关系，同步更新提示词中的变动数据。

### 3.3 段间衔接四重规则

1. **资产衔接**：相邻段共用同一关键帧/资产编号，道具与粒子连续
2. **动作衔接**：段尾动作与段首动作连贯（动作匹配转场优先）
3. **情绪衔接**：段尾情绪 → 段首情绪递进或反转（有逻辑）
4. **声音衔接**：SFX 跨段连续（环境音不中断）

### 3.4 银幕轴线规则（2026-08-11 吸收小逻九宫格）

- **主轴建立**：人物与人物、人物与道具、或人物运动方向形成主轴；默认将摄影机保持在轴线同一侧（一百八十度空间关系）
- **正反打**：保持视线高度和方向匹配；不得因反打镜像人物服装、场景结构或左右配饰
- **越轴处理**：必须越轴时，先加入中性正面、轴线上镜头或清晰运动过渡；不得直接硬越
- **反向位**：人物看向画外目标时，后续镜头展示的目标必须位于合理反向位置
- **空间稳定**：越轴反打时保持空间左右关系稳定，不得镜像房间
- **人物移动**：人物从画面一侧移动时，后续镜头保持一致银幕方向；不得无过渡镜头瞬移到房间另一侧；门窗、家具、灯具和关键道具不得因换机位而漂移
- 完整分镜九宫格规范见 references/小逻-视觉分镜九宫格生成.md

### 3.5 四大无痕转场

1. **遮挡转场**：前景全屏遮挡→切换。遮挡物：树木/墙体/路人
2. **甩镜转场**：高速甩镜头运动模糊切点
3. **动作匹配转场**：前后相同动作顶点切换
4. **相似构图转场**：前后构图/形状高度匹配

### 3.6 组合验证

- 多段拼合后总时长 = 目标集长 ± 0.5s
- 段间无黑屏/无转场断裂
- 每集检查：钩子是否在开头、悬念是否在结尾
- 考核标准①复核：衔接流畅（四重衔接+六重锁）+ 时长合理（内容量决定）

### 3.7 AI视频多段拼接方法论（V4.0.2 新增·实操验证）

> AI 视频 2.0 单段上限 15s，多段拼接成整集时最容易出现：画面跳切、人物动作断层、对白无气口。
> **根源**：每一段生成无前段记忆，新片段不会继承上一段的人物站位、姿态、互动等动态信息，每 15s 数据归零。
> **错误做法**：用上一段尾帧当下一段首帧拼接——完全没有动态继承，拼接痕迹最重。

**数据两类划分（核心认知）：**

| 类别 | 内容 | 处理方式 |
| :--- | :--- | :--- |
| **不变技术数据** | 人物资产图、场景图 | 全程固定导入，不变量 |
| **可变变动数据** | 人物站位、姿态、人物间空间互动、画面构图 | **每段都要同步更新**——拼接流畅的关键 |

**双方案搭配使用，缺一不可：**

**方案A·技术手段（适配 AI 生成特性）：**
1. **完善变动数据（重中之重）**：变动数据 = 提示词 + 参考图/分镜图 + 音视频素材，文字+参考图搭配使用（只靠提示词易反复抽卡）。每段生成前根据上一段结尾人物状态绘制分镜参考图，给 AI 明确人物姿态、位置、互动关系，同步更新提示词。
2. **拼接处用"切近（换机位）"**：不强行做同一个连贯长镜头，拼接节点更换机位、拆成两个不同镜头，规避同机位直接衔接的跳切卡顿。

**方案B·导演思维（观众视角优化观感）：** 从观感层面规避生硬拼接，与技术手段配合才能彻底解决——只靠单一方法无法应对所有剧情场景。

**实操流程：**
```
找拼接问题 → 分析根源（AI 无长时序记忆 + 可变数据未同步）
→ 双方案处理 → 核心操作：① 绘制分镜参考图  ② 拼接节点换机位
```

**与现有规则的衔接：**
- 跨段生成时：先定上段尾帧人物状态 → 绘制分镜参考图（固定姿态/位置/互动）→ 提示词同步更新变动数据 → 拼接节点换机位
- 硬切镜头建议单独生成后剪辑拼接
- **段间衔接三手法六式（V5.0.1 强化·每段拼接节点必用，禁止首尾帧拼接）**：

> 核心：**拼接节点=换机位节点**。每段尾和段首都预留衔接节点——段尾末镜不做完整收束（留动作中间态），段首首镜从动作承接点开始，且拼接节点必须满足三选一。

**三手法（至少选一，换机位是基础必选）：**
1. **换机位**：同一动作/状态换角度、换机位高度、换轴线方位（正→侧 / 平视→俯仰 / 远→近）——规避同机位直接衔接的跳切卡顿，最优先
2. **切景别**：跨级跳切（全景↔特写 / 中景↔大特写），景别跨度越大拼接痕迹越弱
3. **跨段反应**：段尾 A 的动作 → 段首 B 的反应镜头（动作-反应跨段成对）

**六式（具体衔接手法）：**
| 式 | 手法 | 用法 | 适用 |
|---|------|------|------|
| ① | 动作连续+换机位 | 段尾动作起始，段首同动作不同机位完成（match on action 跨机位） | 战斗/动作段之间·最佳 |
| ② | 反应镜头衔接 | 段尾 A 动作 → 段首 B 可见生理应激反应 | 施压/信息揭示后 |
| ③ | 景别跳切 | 段尾全景 → 段首特写（或反之），情绪断裂/强调时刻 | 情绪拐点/转场 |
| ④ | 声音先入 | 段尾声音延续到段首画面（雨声/剑鸣/台词气音跨段） | 氛围连续段 |
| ⑤ | 道具/细节衔接 | 段尾落点道具特写，段首同道具新角度 | 关键道具贯穿 |
| ⑥ | 空镜过渡 | 段尾动作收，段首环境空镜（雨幕/烛火/尘土）再接新段 | 节奏喘息点 |

**拼接节点设计规则：**
- 段尾末镜：留动作中间态/未完成收束（挥剑到一半/转身到一半/台词没说完），不落到静止pose
- 段首首镜：从动作承接点切入 + 换机位（必选）+ 按需叠加景别跳切/跨段反应/声音先入
- 禁止：同机位直接接续 / 尾帧当首帧 / 静止画面衔接静止画面 / 段尾收束完整再切
- 每个拼接节点在分镜剧本阶段就要标好（见 §2.2 分镜表"段间衔接"列）

完整方法论见 references/AI视频拼接问题总结-多段拼接方法论.md

## 四、导演视听控制

### 4.1 镜头运动词典（老李补充·运镜情绪）

| 运镜 | 关键词 | 情绪 |
|------|--------|------|
| 推进 Dolly In | slow dolly in | 逼近审视、专注 |
| 拉远 Dolly Out | slow dolly out | 疏离揭示、抽离 |
| 横移 Tracking | side tracking | 漫游观察、跟随 |
| 升降 Crane | crane up/down | 上帝视角、揭示规模 |
| 环绕 Orbit | counter-clockwise orbit | 对峙张力、卷入 |
| 甩镜 Whip Pan | fast whip pan | 混乱能量、速度感 |
| 手持 Handheld | subtle handheld | 临场感、不安 |
| 固定 Locked-off | tripod shot, locked-off | 稳定、仪式感、凝视 |

> 小逻分级运镜为本（特写稳定/中近景轻微手持/全景呼吸感/斯坦尼康长镜），上表补充情绪语义。

**真实手持三招（V2.2 新增·刺猬星球·消除摆拍感）：**
1. 运动轨迹不过度平滑：推进时短暂减速、接近主体前轻微停顿（人为操作痕迹）
2. 主体与镜头不同步：给运镜加微小滞后，模拟实拍反应延迟
3. 低机位大透视：压低机位仰拍，放大前景尺度对比，广角透视畸变让线条向消失点汇聚（史诗感/压迫感/电商张力）

#### 4.1.2 一镜到底长镜头六维控制（2026-08-10 吸收·奔跑/追逐/跟随叙事）

> 用于奔跑追逐、跟随式一镜到底。核心：把抽象氛围词全换成可执行的物理流程。

1. **镜头叙事目标**：动笔前定义运镜目的（示例：15s 一镜到底横向跟拍奔跑女主，营造紧张追逐压迫感；镜头短暂失焦偏移到追赶者，再快速抓回女主，构建空间层次）
2. **空间三层分层（强制）**：前景层 / 主体层（奔跑主角）/ 中景层（街道桌椅、路人、追赶者，承载冲突）/ 远景层（街道消失点、尽头出口）。分层防 AI 空间混乱
3. **物理惯性+不完美手持**：真实感来自镜头不完美抖动与惯性滞后——手持镜头自带呼吸微颤，撞击后镜头沉降
4. **焦点叙事设计（模拟摄影师临场失误）**：短暂失焦增强纪实感——"焦点短暂偏移至追赶者面部，越过人群漂移到远处女主，0.3 秒后迅速对焦拉回主体"，复刻真人拍摄重新锁定目标的临场操作
5. **分层声音空间**：声音随镜头景别同步变化构建立体声场——镜头转向追赶者时，女主喘息声退至声场远端，追赶者脚步声/粗重呼吸占据声场中心；镜头切回女主，她的喘息重新成为音频主体
6. **负面约束必加**：禁止中途切镜、禁止镜头瞬移变焦、禁止人物肢体滑行/身体融合、禁止物体丢失重量感

#### 4.2.1 色彩体系控制（V2.2 新增·刺猬星球 HEX 调色法）

> 来源：刺猬星球 super-i。解决 AI 生成画面色彩随机、跨镜头色彩漂移（小逻时间轴一致性的色彩层补充）。

**底层逻辑：把颜色控制提前到生成之前**，用色值代替模糊文字（"我要蓝色"→锁死 HEX 色域）。

**三步工作流：**
1. **获取专属色卡**：上传 10 张同风格参考图 → 扫描提取核心 HEX 色值 → 生成专属色卡图
2. **生图锁定色彩**：色卡作为参考图喂给生图工具，提示词只写主体 → 画面自动复用色彩体系
3. **视频色彩延续**：用色卡生成的高质量静态图作为**首帧参考图**垫入视频工具 → 提示词只写动作不写光影 → 视频咬住首帧色彩，得到院线级统一调色

**用法建议：**
- 漫剧立项时先做专属色卡（10张同风格参考 → 色卡），全剧色彩体系统一
- 每个场景变体（日/夜/战斗）可派生子色卡，但主色相不变
- 跨集色彩一致性：同一角色/场景沿用同一色卡

- 泥污 mud / 皮肤纹理 skin texture / 动物呼吸（冬日白气）
- 实用光 practical light（火把、油灯、烛光而非棚拍光）
- 环境损耗：旧工具、脚印、门框磨痕、炊烟

> 用法：写完华丽材质描述后，加 1-2 个磨损元素打破"全新感"。史诗感≠干净，真实感=使用痕迹。

#### 4.3.2 前景遮挡两神技（V2.2 新增·刺猬星球）

> 来源：刺猬星球 super-i。AI 默认生成无遮挡"全知视角"画面，前景遮挡告诉 AI "摄影机藏在哪"，用透视关系构建三维空间。

**① 物理遮挡前景（建立机位感与空间层次）**
- 原理：真实拍摄中摄影机有物理位置，前景遮挡=告诉 AI 镜头躲在哪（柱后/门外/窗前）
- 万能公式：`[工业级摄影参数] + [极度前景虚化（叙事介质）] + [中景主体与动作] + [背景环境] + [胶片与色彩质感]`
- 示例：大理石柱虚化前景框架左缘 + 中景女主打电话 + 酒店大堂 + teal & orange 调色 = "躲在柱后偷听"的叙事感
- 避坑：①不写"拍证件照"式流水账（无故事感）；②不加强行与环境不符的遮挡物（地下车库加樱花→破坏逻辑）

**② 氛围遮挡前景（打破真空感，让空气被感知）**
- 原理：用空气透视让光线传播有介质（新海诚=漂浮微尘/雨丝/薄雾让光有路径）
- 介质词直接进提示词：`atmospheric haze`（薄雾）`dust motes`（微尘）`particles`（颗粒）
- 避坑：①不滥用"极致细节、8k、锐利对焦"把空气杂质抹除（加重塑料感）；②只写"丁达尔光"不写介质→光柱像硬涂的
- 示例：金日光从窗涌进 + 薄雾充满房间 + 丁达尔效应 + 微尘在光束中发光 = 时间流逝的情绪感

> 与 §4.3.1 不完美现实主义互补：磨损感处理材质，遮挡处理空间与空气。

**宏大场景提示词必含四要素：**
1. **景别**：大远景/大全景/中全景等（见上表）
2. **焦段**：显式毫米数（16-24mm超广角 / 24-35mm广角 / 35-50mm标准 / 85mm+长焦）
3. **运镜**：航拍/升降揭示规模（crane up 从人物特写拉升到城市全貌）；大远景缓慢横移（建立空间广度）；推近（从全景逼近关键人物）；史诗场面可用"上帝视角垂直俯瞰 + 缓慢推进"
4. **人物与环境的比例差**：必须写清（"人物仅占画面十分之一""城门高度约为人物八倍""阵列如蚁群铺满原野"）

**宏大场景构图规则（山音/小逻综合）：**
- **三层纵深**：前景（人物/遮挡物）+ 中景（主体动作/人群）+ 远景（巨大环境/天空/地平线）必须同时存在
- **权力构图**：人物在巨大环境中的渺小 = 压迫感（微缩化）；人物居中+环境对称 = 仪式感；巨物从画面上方压入 = 威胁感
- **比例锚点**：先用有明确尺寸感的参照物建立比例（城门/树/旗/台阶），再放人物，AI 才不把巨物画小
- **航拍/高空机位**：垂直俯瞰或高位俯拍，用于军队阵列、城市、地貌；结合缓慢推进或横移
- **粒子与空气透视**：远景加空气透视（雾/尘/光线衰减），近实远虚强化纵深；风沙/旗帜/烟尘密度提示词要写
- **光影**：宏大场景光随规模走——破晓/黄昏金色侧逆光强调体积；乌云顶光强调压迫；光源方向与时间在场景资产中已锁定，镜头内不突变
- **VFX 提示词规范**：千军万马/巨物/灾难场面写"人群密度、阵列秩序、巨物与建筑比例"而非"很多人"；不写无法渲染的数量词（"数万"→"阵列延伸至地平线"）
- **宏观视觉换挡**：宏大场景天然是换挡点——进入宏大场景的第一镜用大远景，出宏大场景用特写收束，形成"宏观→微观"的视觉闭环

**宏大场景镜头描述示例（可直接进生成段）：**

#### 4.5.1 巨物美学专项模板（V3.2 增补·2026-08-09 用户实测确认）

> 来源：用户提供的 4 条实测可用巨物提示词（神话天龙/远古神像/天空巨鲸/极地巨冰兽）+ 当日连续测试验证。用于巨物/神兽/巨型遗迹等「巨物美学验证」镜头。

**两种写法（用户实测确认）：**

**写法A·单段直给（巨物提示词本身，适合静态/单图）：**
```
【神话XXX】巨物美学，【远古传说中的XXX，体貌描述——身躯/头部/材质/部分隐没（"仿佛无尽延伸"）】XXX巨大到超出人类理解并遮蔽天空，主体占据画面绝大部分空间，压迫感极强。画面前景或角落出现一个极其渺小的【人类】，如米粒般微小，用于形成强烈尺度对比。低角度仰拍，史诗级纵深构图，电影级光影，真实自然环境，超现实照片级真实，空气透视，翻涌云海，逆光，体积光与漂浮颗粒，低饱和高级色彩，窄画幅，极致细节，营造神圣、恐惧、孤独与敬畏感。【XXX】以具有压迫感的姿态凝视【镜头方向】
```

**写法B·六段式（用户确认"这才是我们的视频提示词格式"·仅>60s长视频生成段用这个）：**
巨物美学段若>60s 才走六段式（【风格】→【出场人物与场景】→【色卡参考】→【镜头】→【时间轴】→【声音】），把写法A的巨物结构拆进【时间轴】各时间点，镜头段写低角度仰拍+缓慢推近，时间轴内保持主体占满画面+米粒人类尺度锚+凝视镜头方向。**不要混用**：≤60s 的生成段一律用五段式（无【出场人物与场景】），仅>60s 用六段式。

**核心铁律（用户实测）：**
1. **主体占据画面绝大部分空间**——压迫感来自填满画面，不是远处展示
2. **渺小人类做尺度锚**——画面前景/角落放一个米粒般的人类，形成强烈尺度对比（比例差写"如米粒""微如尘埃"）
3. **低角度仰拍**——史诗纵深构图，巨物从画面压向观众
4. **体积光/空气透视/漂浮颗粒**——神圣感三件套，逆光 + 低饱和高级色彩
5. **情绪词收尾**——神圣、恐惧、孤独、敬畏感（按题材选）
6. **巨物凝视镜头方向**——低垂/俯视/凝视【镜头方向】，压迫感闭环
7. **❌ 禁用上帝视角俯瞰**——俯瞰会把巨物拍小、稀释压迫感（用户实测："上帝视角跟奇怪，反而让巨物变小了"）
8. **主体部分隐没**——"部分身体隐没在云层/浓雾/冰川"，暗示无尽延伸，比全貌更有压迫感
9. **❌ 巨物段人类禁说话**（2026-08-09 用户实测）——巨物段里人类一开口模型容易乱配台词，一律不写台词，人声只保留喘息/呼吸，纯视觉+环境音效

**巨物感强化八技法（2026-08-09 用户探讨确认·可叠加）：**
1. **局部特写对比（最强）**——不拍全身，拍巨物一个局部与人类同框（"巨物的一片鳞甲矗立在地面，人类站在鳞甲根部，身高只到鳞甲边缘的十分之一"），大脑自动脑补全身，脑补的永远比画出来的大
2. **出画构图**——巨物顶出画面边界（"巨物身躯向画面上方无限延伸，顶部超出画面边界——看不到头"），画面装不下它
3. **人类视角限制**——从人类仰视视角写，仰到极限看不到全貌（"人类仰头仰到脖子极限，只能看到巨物下巴的下缘，再往上全被遮蔽"）
4. **多层尺度锚（两级台阶）**——人类→参照物→巨物三级对比（"人类站在断裂的石柱旁，石柱高约人类五倍；巨物的一片鳞片，比整根石柱还高"）
5. **速度反差**——巨物极慢人类极快（"巨物每眨一次眼耗时三秒；人类在它脚下拼命奔跑，跑出几十步，巨物才微微侧头"），越大越慢，速度差即尺度暗示
6. **物理反馈**——巨物一动环境给反馈（"巨物迈步，地面裂纹如蛛网向地平线蔓延，碎石在人类脚边跳动，远处石柱成排倾倒"）
7. **声音先行+低频**——声音比画面先到，低频吞掉人声（"巨物心跳如闷雷，从大地深处传来，人类脚下的碎石随心跳节奏跳动"）
8. **剪影+隐没**——巨物大半隐入雾/云/黑暗只露轮廓（"巨物大半身躯没入暮色浓雾，仅剩山脊般的轮廓在雾中起伏，仿佛仍在生长"）

**组合建议**：最狠组合 = ①局部特写 + ③视角限制 + ⑧隐没（人类只看到局部、仰头看不到全貌、大半还在雾里）。

### 4.6 动作戏专项（V2.2 新增·参考 3D 动作戏视频生成笔记 + 用户验证）

> 来源：桌面《[1.24]--3D动作戏视频生成 笔记》（即梦 Seedance 实战课）+ 用户验证的变身戏模板。动作戏/变身戏/高速打斗场景直接套用本节框架。

#### 4.6.1 破坏效果三级层级（升级/破坏场面必用）

从轻微到彻底，按破坏程度递进描写，AI 才能呈现可感知的破坏过程：
- **初级**：表面出现裂痕（水晶高台深度裂痕、墙面裂纹蔓延）
- **中级**：结构解体（廊柱沙化、墙体剥落、梁柱断裂）
- **终极**：整体湮灭（建筑化为粉尘、物体消失殆尽）

> 写法：先写破坏起点（裂痕），再写结构解体（沙化/剥落），最后写整体湮灭（粉尘），逐级升级，不跳级。

#### 4.6.2 变身戏模板（用户验证可用·7阶段）

变身/觉醒/进化类场景的标准化时间轴结构：

| 阶段 | 时间占比 | 内容 |
|------|---------|------|
| 1 蓄势 | 0-15% | 原形态静止特写，材质细节清晰（粗糙布料/旧铠甲纹理），周围环境微动 |
| 2 崩解 | 15-30% | 原服装/装甲从肩部/胸口开始崩解，撕裂成发光碎片，碎片悬空 |
| 3 能量聚集 | 30-45% | 碎片与流光沿身体环绕升腾，空气扭曲，发丝无风自扬 |
| 4 瞳孔异变 | 40-55% | 特写瞳孔：异象虚影与神光浮现，标志变身启动 |
| 5 重组 | 50-70% | 花瓣/鳞甲/光翼等新形态元素从四周汇聚，沿身体曲线嵌合成形，咔嗒声密集 |
| 6 爆发 | 65-85% | 新形态成形瞬间能量炸开（花海龙卷/冲击波/光爆），环境受破坏（见4.6.1） |
| 7 收势 | 85-100% | 主角立于废墟/光芒中，余波微震，粉尘沉降，慢推特写眼神收尾 |

**变身戏五条硬规则：**
1. 觉醒前后形态必须分两张设定图上传（工具层：即梦等需 @各自形态图）
2. 崩解→重组必须写清「旧材质→碎片→新材质」的转化过程，不直接跳变
3. 爆发段的破坏效果按三级递进（4.6.1），与变身强度匹配
4. 收势用慢推+眼神特写定格，完成情绪闭环
5. 材质对比较量：旧形态粗糙质感 vs 新形态锋利半透明（花瓣/鳞甲/水晶）

#### 4.6.3 动作戏节奏组合

**慢-快-静节奏（变身/觉醒戏）：** 起始中景环绕升格慢镜 → 高速推进爆发 → 收尾环境静默
**快-定-震-随-收节奏（多人打戏）：** 快速横向跟拍（疾速视界）→ 定住关键帧 → 撞击/爆发震动 → 跟随动作/飞射物 → 收尾定格

**速度表现三件套（高速运动必写）：**
1. 残影轨迹（高速移动留残影）
2. 空气扭曲（突破音障/高速物周围空气变形）
3. 动态模糊（运动物体边缘模糊）

#### 4.6.4 动作戏材质精度对照（写进画面描述）

| 对象 | 精度描述 |
|------|---------|
| 服饰布料 | 质感 + 运动褶皱（衣袂翻飞时的褶皱变化） |
| 植物/藤蔓 | 表皮粗糙纹理 + 新芽鲜嫩感对比 |
| 铠甲/金属 | 反光 + 锁链金属冷感 |
| 能量体 | 透光特性 + 边缘发光 |

#### 4.6.6 多人打戏约束（防比例失调）

- 群众/士兵数量写明确数字或范围（"几十名无脸银甲净尘使"），不写"很多人"
- 战斗比例平衡：我方/敌方数量与战力匹配，用文字约束防止一边倒失调
- 新角色加入用 @角色名 标记并上传设定图；未出场角色从提示词删除
- 多角色协调：每个角色的动作方向/节奏对齐，避免各自为战

#### 4.6.7 多角色动作拆分（V2.2 新增·刺猬星球）

> 来源：刺猬星球 super-i。解决多角色画面"动作混乱、改A毁B"——AI 注意力算力偏移：多个动作塞进同一句，AI 只保一个角色，其他变背景板，且不懂"同时/接着"的时序。

**① 时间分段拆分（视频）**：不要流水账（"左边男人喝咖啡，右边女人跳舞，接着男人鼓掌"→AI混淆时序）。改成：
- 分时间段明确算力重心：`0-3s 焦点：左男喝咖啡；4-8s 焦点：右女跳舞；8-10s 左男鼓掌`
- 每段时间只保一个主角色动作

**② 空间占位（画面构图）**：明确标注角色位置：
- `画面左侧：男人；画面右侧：女人` → 避免 AI 抓错主体

**③ 语义编辑锁定修改**：不用蒙版重绘（边缘闪烁+刷掉满意角色），用工具的视频编辑功能：
- `保留右侧的女人，把左侧男人的动作改成抬手打招呼` → AI 精准识别角色只改目标部分

**④ 分镜拆分破摆拍**：不要把所有动作塞进一个长镜头，拆三段（以"车站告别"为例）：
- 阶段1 特写-情绪铺垫：女主微红眼眶、攥着车票的手
- 阶段2 中景-动作爆发：松手、转身奔跑
- 阶段3 全景-高潮定格：升格慢动作相拥、火车呼啸
- 避坑：不必强求背景完全一致，观众注意力在人物动作，细微背景差异自动忽略

> 工具适配（即梦 Seedance）：上传场景参考图+角色设定图（全身/三视图）→ 提示词用 @角色名 关联 → 选模型（2.0/2.0fast）→ 全能参考类型 → 16:9 或 9:16 → 默认 15s 一段（可拆 7 组镜头）。批量生成同风格镜头只需改变化部分。

#### 4.6.8 武打动作体系（V4.1 新增·融合工业级15格PREVIS系统）

> 来源：桌面《职业学校推荐skill/6.txt》工业级 15 格武打 PREVIS 系统（2026-08-16 入库）。补 4.6.1—4.6.7 缺的「动作本身」：动力链 / 攻防博弈 / 连续性 / 轴线 / QA。**打斗戏分镜与提示词直接套本节**。完整版（20 章，含 15 格 PREVIS 故事板生成与转提示词全规则）见 `references/武打PREVIS-15格动作预演系统.md`。

**① 动作动力链（每招必写 11 环）**：意图 → 起手准备 → 重心变化 → 脚步位移 → 核心发力 → 肢体传导 → 攻击轨迹 → 接触点 → 命中/格挡反馈 → 收招惯性 → 下一格继承。禁止只画结果（挥拳/踢腿/爆炸/对波/静态摆姿势）——必须让观众看懂动作怎么发生。

**② 15 格节奏结构（默认骨架，服从剧情）**：P01 建立空间与距离 → P02 起手试探 → P03 脚步启动重心前移 → P04 首次攻击进入 → P05 闪避格挡 → P06 首次碰撞 → P07 受力失衡 → P08 反击夺权 → P09 位移贴身 → P10 连招/兵器博弈 → P11 关键命中/缴械破防 → P12 身体反馈惯性 → P13 空间重建 → P14 稳住重心 → P15 反扑起手。**P15 不结束战斗**（除非剧情明确要求）——打斗是过程的高能截面，不是结局。

**③ 攻防博弈**：节奏 `快→快→停→爆→反馈→反制→续`；每 3-5 格一次节奏变化，每 6-8 格一次主导权变化；禁止全程单方连击、禁止全程同一动作。

**④ 拳脚与武器**：拳必写哪只手/蹬地/重心/腰胯/肩送/拳峰落点/对方先反馈哪；腿必写支撑腿/抬膝/髋转/轨迹/脚背掌跟落点/命中后重心；摔投拆六步（进入→控制→卡重心→发力→离地失衡→落地反馈），复杂地面技不单格完成。兵器必写谁持/哪手/长度/刃向/轨迹/接触点/滑动/压刃/震手；**刀剑碰撞不悬空**，至少一种：压刃/滑刃/挑刃/偏转/震手/卡位/缴械/余震；禁止武器穿模/换手/消失/长度漂移/无接触点。

**⑤ 连续性五锁（每格继承上一格）**：状态继承（站位/朝向/重心/脚位/手部/伤势/体力）· 180°轴线（A左B右，跳轴只能经环绕/顶视/正面/摇镜重建，跳后保持新关系）· 惯性（前冲发衣后甩、急停衣发前甩、旋转同向，禁止互相冲突）· 伤势破损持续不自动恢复 · 特效不替代身体接触。禁止：瞬移/无理由换边/空间重置/多手多脚/肢体穿模/身体融合。

**⑥ 动作 QA 速查（写前自检）**：15格齐？攻防成对？动力链在？接触点明确？命中后身体反馈？武器不穿模？左右站位连续？轴线成立？惯性方向对？伤势连续？无真实肤色/彩色材质？

**⑦ 故事板转 Seedance 提示词（用户要求逐格输出时）**：故事板锁顺序/景别机位/站位/动作方向/武器位置/接触点/衔接；人物图锁脸型服装、场景图锁环境灯光天气、武器图锁外形握持。提示词必须忽略白模材质/编号/箭头/标注。每条 14 要素：镜头编号/建议时长/对应宫格/景别机位/运镜/动作起点/脚步重心/发力链/武器动作/接触反馈/收招惯性/下镜衔接/环境声音/禁止项。声音默认无 BGM，只留环境+呼吸+脚步+衣料+破风+碰撞+落地；写实打斗禁彩色能量特效；上镜结尾自然接下镜开头，禁止每镜从静止重新开始。

#### 4.6.9 二次元打戏提示词体系（V4.1 新增·二次元打戏方法论提炼）

> 来源：桌面《职业学校推荐skill/武打skill.md》（353KB 原文，2026-08-16 提炼入库）。与 §4.6.8 分工：**PREVIS 管"动作对不对"，本节管"打戏燃不燃"**。完整版（含 32 条铁律全表、15 种运镜+组合公式、9 角色劲气速查、技法总览、近景三模板）见 `references/二次元打戏提示词体系.md`。打斗段写完必过：§4.6.8 动作 QA + 本节燃向铁律 + 门禁D。

**① 完播率公式**：开局冲击 20% × 节奏呼吸 30% × 运镜丰富度 25% × 情绪拐点 25%。开局 1.5s 内必须攻防接触（禁全景铺垫）；升级版：0.5s 内两种极端招式正面硬撞+微慢镜定格（2 秒跳出率降 38.98%）。

**② 15 秒骨架**：0-1.5s 开局硬撞 → 1.5-5s 近景对招 → 5-8s 空间变化（维度≥2次）→ 8-9s 快攻升级 → 9-12s 情绪拐点 → 12-14.5s 终结技（呼吸帧→破局→绽放→余震）→ 以高潮收尾**不设收尾帧**（冲击波/碎石灰尘就是最终帧）。

**③ 双观赏性**：远景看大动作（奇观型），近景看杀意（密度型）。**15s 内至少 1 段 2-3s 上半身近景对招**，纯远景大动作≠完整打戏。近景节奏=机枪节奏：3轻1重 / 左右交替加速 / 封破杀。

**④ 招式序列化（铁律25）**：AI 对"机枪节奏/快速"等定性词执行偏差 30-40%——**必须写招式序列+落点+防守反馈**：`右摆拳打脸→左勾拳打下巴→右直拳打鼻梁→左横肘切眉骨→右标指刺咽喉，防守方依次侧偏、下潜、拍开、架桥、后撤`。禁止写"每秒攻击≥多少次"。近景手部观赏性排序：砸肘>横肘>寸拳>上勾拳>标指>推掌>冲拳>拍掌。

**⑤ 镜头规格五要素（每次镜头必写）**：`[景别]·[拍摄视角+角度]·[运镜方式]·[跟随目标]`——景别四选一（全/中/近/特）、视角五选一（正/侧/斜/俯/仰）、角度具体值（30°仰/90°侧/45°斜俯）、跟随目标必写。禁"镜头拉远/靠近/跟随拍摄"。⚠️**空间感铁律：中景及以上禁 90° 侧面正拍，必须 30-60° 斜角制造纵深**。

**⑥ 燃向铁律十诫（精选）**：视觉巅峰五要素同窗触发（大幅动作+快节奏+全景+特效+运镜缺一打折）· 呼吸帧需≥1.5s 高速铺垫（无铺垫定格=无聊）· 每击必有空气反馈（拳风+命中气爆，形态随攻击变）· 被击反应差异化（面部→后仰/腹部→弓虾/下盘→跪地）· 闪避大幅化（禁"侧身一让"，下潜贴地/后仰≥45°/后空翻）· 防守三态（被破防后 0.3-1s 不能恢复完整防守）· 特效服从角色主色（找不到归属的颜色删掉）· 禁 360°环绕/螺旋上升运镜 · 同对战招式零重复 · 全文≤2000字（超字数先删负面提示词）。

**⑦ 劲气速查**：太极=黑白、白鸽=紫黑、红茶=橙红、凛羽=冰蓝银白、雷电=纯紫银紫、芭乐=粉渐变、冰女=蓝白硬冰、剑神=红紫瞬闪、绯雪=火红烈焰刀弧。写法：`右腿如钢鞭甩出，紫黑气焰沿小腿弧线炸裂成新月弧刃`（禁"角色释放紫色特效"）。

**⑧ 角色战斗结构（创建打斗角色必用）**：主战技法 1-2 个占 70% + 破招技法 1-2 个占 20-30%（破防/摔投/锁控）+ 终结技法 1 个（视觉爆点）；距离覆盖 ≥2 类（近身/中距/空间变化）；动作维度 2-3 类（站立/腾空翻转/地面控制）。禁止平均使用技法；同类技法禁止全堆叠；必须有角色动作签名（一句话说清跟别人不一样在哪）和特效性格（灼烧/冻结/绽放/电弧，颜色只是基础）。创建流程：展示技法总览（推荐 4-5 个）→ 分配结构 → 输出角色卡 → 确认。

**⑨ 兵器规则（持械打斗必用）**：中景/全景兵器攻防禁 90° 侧面正拍（像横版格斗游戏）；高速兵器招式不能全程特写（只用于破绽/命中/格挡瞬间 0.2-0.5s）；大圆弧剑花/满月斩禁近景（必须中景/全景看完整轨迹）；**兵器碰撞不能只写爆炸——必须写剑身/剑格/刃口物理接触**。转提示词公式：`[角色]+[步法/重心]+[身体发力]+[兵器部位]+[攻击轨迹]+[命中/格挡目标]+[兵器反馈]+[镜头目的]`。用户指定具体兵器体系时先读对应专项库（剑法/镰刀/太刀/轻功/修仙剑招），禁止只凭招式名生成；徒手对战不调用兵器库。

**⑩ 终结技素材速查**：呼吸帧 8 种选 1（极慢定格/汗珠飘落/发丝静止/对视定格/风停/气焰收敛）；空间变化最低要求 15s 内 ≥2 种类型（腾空+贴地/倒置+侧翻，禁全程站桩）；情绪拐点两型——压制型（暴怒觉醒/连击加速/绝招释放/全力碾压）或逆转型（化劲反击/破绽捕捉/身法逆转/以退为进/绝境爆发/入身逆转）；终结技三幕=破局（打破攻防平衡）→绽放（全力输出）→余震（冲击波/粉尘收尾）。详细素材库（20+ 空间变化类型、14 种逆转技法、8 种呼吸帧全表）见 references。

**⑪ 武学招式库（写打斗取招式）**：拳法系（咏春日字冲拳/标指、八极铁山靠/顶肘、太极云手/揽雀尾、八卦走圈/鹞子穿林、形意崩拳）、腿法系（谭腿十二路弹踩截蹬劈挂撩扫鞭踹膝摆、蔡拳偏门快打、巴西战舞倒置贴地、跆拳道540°旋风踢）、摔投系（柔道背负投/大外刈/内股、柔术十字固/三角绞、擒拿反关节）、身法系（凌波微步/缩地成寸/燕子三抄水）、兵器系（华山/独孤九剑/玉女剑/子午剑、长柄镰刀）。**取用规则**：招式名直接写入提示词（"凤眼插指直刺咽喉"），配招用各武学典型连招，招式必须过动力链（§4.6.8）+序列化（§4.6.9），同对战零重复，特效服从角色主色。完整表见 `references/武学招式库-经典招式速查.md`。

### 4.7 世界观构建九面法（V2.2 新增·可选参考）

> 来源：Cinematic World Generator（OAK）。用于**新场景/新世界观设计前**的世界速查，或宏大场景前的文化设定。核心思想：**把设定变成"画面里正在发生的事"，每个方面都是一张电影剧照，不是设定集**。已定剧本的常规分镜可跳过本节。

#### 4.7.1 九面清单（每个方面=一个具体场景，不重复场景类型）

#### 4.7.2 世界连续性要素清单（同一部电影感）

所有场景共享：气候 / 材料 / 服饰 / 建筑 / 工具 / 符号 / 动物 / 行为 / 地形 / 光线逻辑 / 色彩逻辑 / 质感。

> 与 §3.2 六重一致性锁（同一集内）互补：本节是**世界观层面**的连续性（跨集跨场景），设定一个世界后所有场景自动继承。

#### 4.7.3 使用中空间原则（建筑/场景不展示）

- 建筑：冒烟的屋顶 > 空楼；进城门的人 > 城门全景；守卫下的石雕 > 石雕特写
- 场景：正在被使用的空间才有生命；写"功能"不写"外观"
- 判断标准：这一镜去掉人后还有故事吗？没有→合格；有→改成使用中

> 与现有"禁止展示式构图"一致，本节给出正面写法。

#### 4.7.4 场景/镜头必备五问（写每镜前自问）

1. 这一帧里正在发生什么？
2. 前景/中景/背景分别是什么？
3. 镜头为什么选这个机位（查 §4.1.1 决策表）？
4. 场景里哪个元素在"被使用"？
5. 这个画面有没有"被发现"的现场感（非摆拍）？

### 4.8 导演风格参考库（类型路由·老李补充）

**情绪基调(A)：** 日常写实/情绪美学/诗意冥想/荒诞主义/悲剧/喜剧/黑色幽默/浪漫
**类型片(B)：** 惊悚/心理惊悚/恐怖/犯罪/黑色电影/悬疑推理/科幻/奇幻魔幻
**动作与对抗(C)：** 现代动作/武侠/战争/灾难
**题材与关系(D)：** 爱情/家庭亲情/青春成长/传记/体育竞技
**形式与叙事(E)：** 伪纪录片/公路片/歌舞片/动画/实验先锋
**社会视角(F)：** 社会现实主义/历史古装/政治讽刺/主旋律

**武侠动作重点参考：**
- 胡金铨：定机位+精确走位，静→静→爆节奏，一招定胜负，留白
- 徐克：创意运镜不受物理限制，甩镜+快切制造混乱能量，粒子密度极高，关键决杀慢放
- 李安：动作舞蹈化，长镜头展示连续动作序列，山水画式构图，动作即内心

**现代动作重点参考：**
- 查德·斯塔赫斯基：宽镜头展示全身动作，长镜头中多人打斗，霓虹色系，动作清晰性优先
- 吴宇森：慢动作核心，多角度覆盖同动作，双枪对称构图，暴力即美学
- 乔治·米勒：画面中心法则（关键信息始终在画面正中心），双色高反差，极快但可读

**史诗/宏大场面重点参考（V2.1 新增）：**
- 彼得·杰克逊：史诗级远景+亲密的角色特写交替；大场面调度（数千角色战线）；航拍壮阔景观
- 宫崎骏：云风水的动态构图；前景草花/中景角色/背景云山三层独立运动；飞行失重感
- 库布里克：对称构图+单向透视（宏大的对称压迫感）；上帝视角俯瞰；广角+长焦并置

> 参考风格只用于镜头与提示词创作，**不把导演/明星姓名写进最终提示词**（内容安全红线）。

## 五、表演控制（老李微表情库·补充层）

> 主核为小逻六维物理表演（§2.2）；本模块在小逻未覆盖的**细微表情刻画**上补齐，二者叠加使用：
> 关键近景/特写镜头 = 小逻六维（≥5维）+ 老李微表情库（克制即张力）。

### 5.1 三维情绪描述法

| 维度 | 错误 | 正确 |
|------|------|------|
| 表情 | 开心 | 嘴角上扬，眼尾弯起，眼角自然笑纹 |
| 动作 | 无 | 双手微抬，身体轻轻小幅晃动 |
| 语气 | 无 | 语调轻快，带着惊喜轻微颤音 |

情绪必须搭配触发场景：有前因后果才自然。

### 5.2 微表情时间轴切片法

核心法则：**克制即张力**。情绪收缩在眼神、面部肌肉微动、呼吸中。

情绪拆解公式：`动机 + 眼神 + 呼吸 + 脸部 + 身体 + 声音 + 收尾`

时间轴格式（2-3秒/片）：
```
0-2s: [角色外貌前缀]，[初始状态]，[微表情细节]
2-4s: [第一个变化]，[动作幅度]，[情绪过渡]
6-9s: [情绪深化]，[面部变化]
12-15s: [最终状态]，定格收尾，无黑屏无转场
```

### 5.3 矛盾肢体语言（高级技巧）

描述矛盾的生理信号而非直说情绪。
- "嘴角还在笑，眼睛里的光却慢慢弱下来"
- "鼻翼轻动，咽喉吞咽，眼眶微湿但不落泪"
- 嘴在笑眼在累 > 单纯哭泣

### 5.4 情绪基底库

| 情绪 | 微表情配方 |
|------|-----------|
| 失望/心碎 | 眼神光亮减弱、眼眶微红不落泪、视线下移、极轻微叹息 |
| 心虚/撒谎 | 视线极小范围游移、眨眼频率微增、咽喉微动、呼吸变浅 |
| 释怀/笑对 | 眼神由紧绷转柔、轻微长呼气、肩膀线条松弛、嘴角极淡微笑 |
| 愤怒/压抑 | 眼神定死、呼吸变慢且沉、下颌线极微小紧绷、肩膀完全静止 |

### 5.4.1 视线-情绪对照速查（2026-08-11 吸收 AI影视工具箱 + 小逻表情设定）

| 视线状态 | 对应情绪/意图 | 英文标签 |
|----------|--------------|----------|
| 视线低垂落于地面/桌面 | 听训、臣服、隐忍、回避冲突 | averted gaze |
| 视线直视对方瞳孔 | 表态、对峙、质问、醒悟、威胁 | direct eye contact |
| 视线追随背影/移动目标 | 离别、念旧、不舍、暗中关注 | tracking gaze |
| 视线极小范围游移 | 心虚、撒谎、盘算 | shifty eyes |
| 视线定死不眨 | 愤怒压抑、杀意、审讯压迫 | dead stare |
| 视线下移 + 眼眶微红 | 失望、心碎、委屈（不落泪） | downcast eyes |
| 视线望向画外某方向 | 悬念、回忆、目标锁定（下镜给反向位目标） | off-screen gaze |
| 眼神由紧绷转柔 | 释怀、原谅、温暖 | softening gaze |
| 一侧眼睑微眯 + 视线重新判断 | 怀疑、重新评估、设防 | appraising gaze |
| 视线疏离平直（眼睑更沉） | 冷漠、无视（与"平静"区分靠活动量） | detached gaze |

**用法**：写对手戏时从表中直接选视线状态（含英文标签），配合 §2.4 视线锚定铁律使用；表情强度随剧情逐格发展，相邻镜头不无故跳变。

> ⚠️ **标签职责分工（2026-08-11 用户实测：强行套表反致效果变差）**：英文标签每镜 2-4 个的配额，**优先给中文描述不出的镜头/表演质地**（cinematic handheld、depth of field、motion blur、precise eye focus）；视线关系用中文写明后，不重复占用英文标签位，仅关键表演节点（垂眼回避/直视表态）用 averted gaze / direct eye contact 强调。**已验证的标签组合优先，勿为套表而替换**——把镜头词换成视线词会损失画面质感（实测：subtle cinematic handheld→tracking gaze 后效果变差）。

### 5.5 四大红线（表演输出前自查）

1. **禁环境人物与空间位移**：交互对象替换为镜头/画面方向；打斗场景对手改为被动画面描述（"刀刃撞击护甲"不写"对手格挡"）
2. **禁抽象心理描写**：全部翻译为面部肌肉与呼吸动作
3. **禁动作超载**：2-3秒切片内最多1-2个微小动作，用"缓缓、极轻微、慢慢"；打斗场景适度放宽但每镜仍控制在2-3个核心动作
4. **强制自查**：有主角以外人称代词？→删。有心理活动？→翻译成肌肉动作。

### 5.6 好莱坞表演系统（ACTING SYSTEM 升级·V3.1）

> 来源：HELL GRIND 项目 ACTING SKILL（Seedance 2.0 角色表演系统），全文见 `references/ACTING-SKILL-角色表演系统.md`。
> **核心公理：表演是压力下的行为（BEHAVIOR under pressure），不是情感展示。** 角色想要什么、什么挡着、他怎么去拿——情感只是这场斗争的副产品，永远不直接写情感。

#### 5.6.1 场景五支柱（每个角色每场戏必拆）

| 支柱 | 内容 | 错误写法 | 正确写法 |
|------|------|---------|---------|
| 目标 | 此时此地想要什么，**动词指向对手** | 生气 | 让他还钱 |
| 障碍与赌注 | 什么挡着 + 失败代价 | 无 | 两小时期限/傲气不让求饶 |
| 战术 | 达成目标的具体方法（动词） | 全场一招 | 施压→诱惑→羞辱→讨价→威胁，失败就换 |
| 节拍 | 最小行动单位，2-4次变化 | 整场无变化 | 停顿/变姿势/变速/换视线，节拍变化必须可见 |
| 潜台词 | 真实想法 vs 嘴上说的 | 直接说 | 非问之问/重复问/突然换话题/不合时宜的玩笑/过短回答 |

#### 5.6.2 角色表演主档案模板（150-220词，一段式，每角色一份）

```
Character acting as [NAME]. [年龄/体型/体态——身体是履历书]. [心理引擎一句]。Vocal profile: [音色/口音/语速/情绪下如何破音]. Key physical habits and tics: [招牌小动作+触发器；压力小动作+触发器；隐藏行为；面具及其破裂条件]. Walking style: [命名步态+重量/节奏/落脚]. However, when [情绪触发器], [面具崩溃后的转变]. [可选: 软化对象——唯一让脸真软下来的人/物].
```

**规则：**
1. **只写可观察行为**：不写"他很紧张"，写"下唇颤抖、重吞口水、张嘴深吸气、抿唇急呼出"
2. **每个小动作都有触发器**：不是"他掰指节"，是"他在无聊对话中掰指节以假装自信"（格式：动作+何时/为何）
3. **命名步态**："power-walk""peacock strut""battering-ram stride"，再拆重量/步幅/躯干/头
4. **面具+裂缝**：至少一个"However, when X——"条款（主导步态在拒绝后碎成孩子气的塌肩）——一人同时演两种真相才是人不是木偶
5. **软化对象只给一个**：一个人/动物/物，不稀释
6. **无服装**：服装在场景/外观块，表演档案必须跨服装存活
7. **无摄影机无色彩**：表演只管表演
8. **身体承载传记**："被过往斗争磨损的体格""永远紧张的肩"——职业/旧伤/自我认知写在身体里

#### 5.6.3 眼睛生命（每条档案每场戏必写）

死眼睛是 AI 表演的头号破绽。必写：
- **微扫视+视线目标**：视线持续移动（漂移/闪开思考/扫向细节/落回），永不冻结锁定一点
- **真实眨眼率**：压力下快速连眨；控制中缓慢平静；走神时"眨-失焦"
- **活体眼神光**：眼睛必须湿润、有光、活着
- **控制的静止是选择不是死亡**：掠食者式少眨眼要慢而刻意，视线仍缓慢移动
- **眼神先于思考/头部**：眼睛先到目标，再转头；话语出口前思想已可读

#### 5.6.4 声音永久锁定（不随场景改编）

- 每角色一个 Voice prompt 永久声纹：`"A [age]-year-old [origin/accent]. [音色]; [语速]; [情绪特征——压力下如何变]."`
- 角色说话时**逐字粘贴**到音频字段，永不修改；出现但不说话则省略
- 表演段落里的声部描述（节拍变速/破音/低语）与 Voice prompt 必须一致

#### 5.6.5 状态而非过渡（视频生成铁律）

模型擅长状态、搞砸过渡。写**已经在动作中**："投掷中、挥拳中、踱步中"，不写"伸手进包、掏出、蓄力"的过程。逐拍链状态，不叙述连续过程。

#### 5.6.6 群像与空间

- **群体反应是波浪不是同步**：一个人先笑，第二个慢半拍，第三个不笑；同时同步=假
- **反应比动作值钱**：事件后最珍贵的画面是目击者的脸
- **威胁前冻结**：群像持续微动→关键威胁时一切静止（动→静的对比就是标点）
- **移动=动机**：没人无缘无故穿场（逼近=升级/转身=驱逐/站起=夺权/冲突中坐下=悖论权力/停在门口=决策点/开始收拾=身体最后通牒）
- **强者静而弱者躁**：危险不来自危险者本人，来自周围人的张力；威胁无预告（无蓄意停顿无慢速转身）
- **消耗累积**：被磨垮的角色，身体累积变灰/变重/反应变慢，场景间永不重置

#### 5.6.7 0-5 表演等级量表（自查）

| 等级 | 名称 | 特征 |
|------|------|------|
| 0 | 人偶 | 念台词，无行为 |
| 1 | 朗诵者 | "表情化"文本+指示情感+图解式身体 |
| 2 | 勤勉 | 能猜出目标，但单战术/反应慢/空停顿 |
| 3 | 工匠 | 有目标有节拍，会听对手，身体合理。缺：潜台词/意外战术/状态惯性 |
| 4 | 活着 | 连续行为+对比战术+潜台词与文本分叉+身体里的地位+反应先于台词+至少一个意外但真实的抉择 |
| 5 | 磁铁 | 4全有+悖论：同时好笑又可怕/残忍又迷人/撒谎又动人——**双重真相**，单一干净情绪在特写里是合成感 |

主角镜头瞄准 4+；自查 2 以下先改再交。

## 六、影视美学与画面（老李补充层）

### 6.1 影视美学核心价值观（补充·审美鉴赏 + 导演课）

**形式与内容的统一（文质彬彬）**
> 质胜文则野，文胜质则史。文质彬彬，然后君子。——《论语·雍也》
- 质（内容）= 故事情节、人物、主题
- 文（形式）= 画面风格、音乐风格、剪辑风格、表演风格
- 伪精致陷阱：视觉越华丽、故事越空洞，形式失效；形式必须为内容提供支点
- **AI创作最易犯错误**：把特效堆满但无扎实故事线、合理画面衔接、匹配的音配乐节奏

**创作者的三个认知层级**
1. 眼低手低：看不出好坏，也做不出（初学者，只能做初级执行）
2. 眼高手低：能看出好坏，还做不出（进步关键阶段——**先洗眼睛再练手**）
3. 眼高手高：审美判断力+创作执行力兼备（终极目标）
> 核心结论：想做出好作品，先看过好作品。AI创作=把真人/动漫作品的审美积累用AI工具再做一遍。

### 6.2 影视美学七大传统

现实主义 / 形式主义 / 古典主义 / 表现主义 / 超现实主义 / 诗意美学 / 史诗美学

### 6.3 意象体系设计

- **视觉母题**：贯穿全片反复出现的视觉元素
- **唯一高亮区**：全片中让观众视线追着走的核心视觉锚点
- **意象闭环**：开场与结尾用同一意象的不同尺度/状态形成回收（宏大场景尤适用：开场大远景的巨物 → 结尾特写里的同一巨物残片）

### 6.4 双轨节奏系统

**外部情节节奏**（松/中/紧）+ **内在情感节奏**（轻/中/重）

两条轨道错位是高级叙事手法——情节松+情感重的错位（画面越平静，情感越沉）。

### 6.5 导演三道问

1. 观众知道什么，角色不知道什么？→ 悬念/信息不对称 → 决定镜头视角
2. 想让观众感受到什么情绪？→ 情绪目标→视觉手段 → 决定节奏光影
3. 电影感来自什么？→ 区别于小说的纯电影表达 → 决定镜头运动/构图/声音

## 七、工业化流程

### 7.1 三段式

前期30%：创意→分镜→素材准备（角色设定图/场景图/关键帧/风格参考）
中期40%：AI生成画面→人工迭代
后期30%：剪辑合成→配乐音效→成片

### 7.2 三轮迭代

第1轮定风格 → 第2轮调构图 → 第3轮细化材质光影。禁止一开始抠细节。

### 7.3 避坑清单

- **分辨率陷阱**：画质由提示词决定，分辨率只改画布尺寸
- **先宏观后微观**：极简提示词定方向→逐步细化
- **单变量调试**：一次只改一个变量，可追溯效果来源
- **参考图策略**：拆解要素（构图/光线/色彩/材质/氛围），非直接复制
- **时长硬凑**：不为了凑90s把爆炸写成12s，内容量决定时长（用户纠错记录）
- **段数硬凑**：不每集硬凑6段，剧情驱动（用户纠错记录）
- **表格分镜投喂**：用户要的是生成段式叙述，不是表格（用户纠错记录）
- **表演缺失**：不写"开心/难过"，用微表情+生理应激（小逻六维+老李微表情库）
- **宏大场景画小**：不写"很多人/大场面"空词，用比例锚点+焦段+分层纵深（§4.5）

## 九、开源电影级提示词方法论（HELL GRIND · V3.1 新增）

> 来源：Higgsfield 开源 AI 电影《HELL GRIND》（95分钟，全提示词/资产开源，2026-08-07 入库）。用户验证过的专业提示词——按可复用方法论分类提炼入库。
> 分类方法论全文：`references/HELL-GRIND-提示词分类方法论.md`（V4.1.3 起为唯一保留件，原文全集 252KB 已应要求移除）。
> 用法：**长段/多镜头段提示词直接套本章骨架**；短段仍用 §2.4 五段式（≤60s）；>60s 长内容才升级六段式。

### 9.1 提示词骨架（PROMPT FRAMEWORK）——长内容顶层结构

长提示词按此顺序组织，缺一不可（详细说明见方法论文件 §一）：

```
SCENE CONTEXT        场景上下文（承接上一镜，1-2句）
STRICT / WORLD LOCK  铁律区（本段所有硬约束集中声明）
ACTIVE REFERENCES    本段激活的资产引用清单（角色/场景/道具 @引用）
LOCATION MAP         空间布局锚点（方位/距离/几何关系）
FIRST FRAME          第0帧画面状态（开局即定）
FORMAT MODE          格式（时长/画幅/帧率/慢动作策略）
OPTICS               光学（胶片/镜头/颗粒/快门）
CAMERA               摄影机（运镜/机位/性格）
ACTION TIMING        动作时间轴（逐beat秒级编排）
PHYSICS              物理（重量/惯性/接触阴影）
LIGHTING             光线（光源/色温/方向）
AUDIO                声音（环境SFX/台词/音乐规则）
CHARACTER ACTING     表演（微表情/反应节奏）
STYLE                风格（导演风格转述/质感）
QUALITY              质量（8K/毛孔级皮肤/实拍感）
POSITIVE CONSTRAINTS 正约束（明确"画面里必须有"什么）
```

**关键设计：** 骨架按"AI消费优先级"排序（铁律/空间在前，动作居中，风格质量收尾）；每字段只写一次，动作段引用前面锁定内容（"Camera rules continue"）；结尾固定写 `References = visual identity / costume / environment matching only. Generate 100% original continuous live-action cinematography from scratch.`（参考图只做身份匹配，动态画面100%原创）。

### 9.2 资产引用体系（长片一致性根基）

- **资产编号**：`<<<uuid>>>` + `[imageN]` 双标识，文字描述兜底
- **分状态建资产**：同一角色按状态拆（常态/湿身/带伤），同段只激活需要的状态
- **身份切换（IDENTITY SWITCH）**：变身/受伤时显式声明 `<<<A>>> → <<<B>>>`，从某帧起只用B——杜绝中途漂移
- **参考图标注用途**：`CHARACTER REF — appearance only` / `SCENE REF — space only` / `ELEMENT REF — do not copy framing`；场景分正面/背面（FRONT SIDE / BACK SIDE）两张
- 环境参考图只继承风格/色调/氛围，禁止复制构图和机位

### 9.3 统一大气指令（跨镜头一致性杀手锏）

把贯穿所有镜头的大气参数**单独成块，要求每段原样粘贴**——这是长片不漂移的核心秘密。锁定参数：色温（如4500K冷阴天）/ 雪暴等级（每帧100-200片雪花）/ 能见度（30-50米）/ 调色板（60:30:10）/ 光线（overcast冷漫射光）/ 地平线（无可见地平线）/ 风向。

**无限军团模式**（战场类）：每2-3秒从雾里冲出3-5个新敌；地下再生每镜5-8次；第0帧已在战场中心（无开始过渡）；后景敌人运动矢量永远指向主角；史诗规模写"单帧500-1000人暗示10000+"不写"数万"；人群写"3种样式混合"不写克隆。

### 9.4 铁律区写法（STRICT / HARD LOCK）

- **正约束**：写"画面里必须有"——`EXACT 3 CHARACTERS` / `No duplicates` / `第0帧长矛必须在骑兵手中` / `盾牌开拍前已长好`
- **硬锁清单**：慢动作/位置锚点/角色解剖/动作编排/硬切转场/光线，每个单独一条 `⚠️ XXX (HARD LOCK)`
- **几何锁定**：罗盘定向（NORTH=天窗墙...）+ 锁定距离（两人EXACTLY 2.5米）+ 锚点不动（柱子固定不跟随）+ 比例锚点（怪物360cm，头是人的两倍高）

### 9.5 动作编排（秒级beat写作）

- **单镜头beat**：`动作(0-2秒): [核心动作] + [SLOW-MOTION段落,放慢4-6倍] + 慢动作细节 + [回到正常速度]`
- **帧率渐变**（一镜内）：`60fps → 240fps（重慢动作）→ ⚡10000fps（子弹时间，只给3个峰值瞬间）`——ramp都在机内完成，绝不是剪辑切
- **多镜头段**：`multishot sequence — 15 SECONDS · 21:9 · 8K · 60fps · hard cuts only · exactly 6 numbered shots`；每镜之间 `HARD CUT — [大气参数锁定摘要]`（把须延续的参数浓缩一行，防漂移）
- **多角色时序**：每beat只保一个主角色动作，其他角色只写在场状态

### 9.6 战斗戏专项

- **死亡规则统一**：不死系死亡=黑色尘雾/黑沙；`切开即崩解，两半分离后变黑色尘雾爆发`
- **有机武器 vs 持械**：`整条手臂变成水晶武器——不是握在手中的武器` / `骨刃是身体的一部分，没有手没有握柄`（写进AVOID：不要画手）
- **战斗摄影机性格**：`非常活跃手持剧烈摇晃反应性相机，像战地摄影师冲入战场`；反应性jolt；每0.5-1秒插入动态CU（0.2-0.5秒），whip pan连接
- **一镜到底（ONER）**：`SINGLE CONTINUOUS HANDHELD ONER, NO editorial cuts`；whip-pan是机内运动不是剪辑；PHASE A中段开场→B格挡反击→C连杀狂潮→D持续战斗无结局；马匹规则写死（`马永不停留/永不撞盾/从旁全速掠过`）；结尾不解决（`take ends mid-action`）
- **体力疲劳递进**：长战斗写主角疲劳（白气呼吸/转身变慢/有一刀擦过肩甲）——真实消耗感

### 9.7 表演与情绪（SOLO PORTRAIT 范本）

- **情绪弧线时间轴**（10秒单人特写）：0-3s持续醒悟（眼神下移/瞳孔放大/浅震惊呼吸）→ 3-6s醒悟加深为悲伤（眉心上挑/嘴唇抿紧/一滴泪滑过血迹）→ 6-10s悲伤转暴怒（眼神抬起/眉毛下压/下颌紧咬/面部微颤/太阳穴血管鼓起）
- **表演硬规则**：台词前后各留1秒静默（先拍脸再开口，说完继续hold）；台词内容绝不视觉化（无闪回无幻影）；声音优先混音（说话时环境声duck到低音量）；只演剧本台词（无即兴无嘟囔无画外音，没台词就是沉默）
- **毛孔级皮肤**：`pore-level realism — vellus hair（毳毛）, asymmetric moles（不对称痣）, capillary flush（毛细血管泛红）, pore-shadow matching on-set light`

### 9.8 环境镜头范本

- **城市航拍空镜**（8秒）：完整参数锁（600米高度+15度前倾+地平线y=35%+2.39:1+整段匀速右移）；运动层级（摄影机匀速横移/环境斜雨/主体两辆车/内部云层闪电）；闪电时刻表（0.8s+3.2s+6.1s，每次配数秒后闷雷）；调色板60:30:10；连续性锁（始终只有两辆车/地铁高架空载/云层永不散）
- **自然亲密空镜**（5秒）：手持中景开始→缓慢匀速后拉→两人变小融入广阔自然；负向清单极详细（无音乐无接吻无慢动作无他人无胡须无对白无文字）

### 9.9 图像编辑提示词（损伤修正范本）

- **结构**：`Edit this image. [总目标] Apply these corrections consistently across all views.` → CHANGE 1删除类 / CHANGE 2削减类 / PRESERVE保留类 / CHANGE 3比例类 / CHANGE 4可读性 → `Final goal: [最终画面一句话]`
- **原则**：删除/削减/保留三类分开写；削减给"完整清单"（`这就是面部损伤的完整清单`）防止AI加戏；负向清单给具体参照物（`NOT horror movie victim`）；保留项写死（身份/结构/体型/发型/服装/姿势/布局/背景）

### 9.10 统一风格前缀 + 导演风格转述表

每段可复用基础前缀（与§1.7基-氛-画同构）：`Style: 8K IMAX. Photorealistic — no 3D render, no game engine` → `Lighting: Natural light only — contre-jour backlight, camera on shadow side, atmospheric haze` → `Color: 60:30:10` → `Camera: Physical cine lens. 180° shutter motion blur` → `Skin: Pore-level realism` → `Acting: Hollywood — micro-pauses` → `Physics: Gravity and inertia respected` → `Composition: Rule of thirds + golden ratio` → `Continuity: No identity drift` → `Technical: 24fps, 8K` → `Audio: Environmental SFX only. No music. No subtitles.`

### 9.11 项目级工程秘密（总结）

1. 一致性不是靠"记得"，是靠"复制"——统一大气指令/无限军团指令/第0帧指令要求每段原样粘贴
2. 资产是长片的命——每角色每状态独立资产，变身用 IDENTITY SWITCH
3. 正约束优于负约束——"EXACT 3 CHARACTERS"比"不要第4个人"有效
4. 几何锁死——罗盘+距离+锚点，空间不漂移
5. 硬切=状态摘要——HARD CUT 后跟一行大气参数摘要
6. 长片=多段骨架——每段独立完整骨架，段间靠"Scene context: 承接上一镜"衔接
7. 负向清单收尾——每段结尾列 AVOID/NEGATIVES，把最易翻车点列全

### 9.12 CINEDANCE 导演系统（V3.1 升级·详细版见 references）

> 📄 完整版：`references/CINEDANCE-HIGGSFIELD-提示词导演系统.md`。定位：§9.1 骨架的"母版"（4-D 方法论 + 输出前静默 QA，适合"首生成即可用"的高要求场景）。以下为速查要点：

**4-D 内部方法论**：D1 Deconstruct（只保留本镜可见可闻内容，删陈旧@标签/前场措辞）→ D2 Diagnose（预诊首帧空/角色迟到/视线反转/道具拿错手等失败风险，逐项加短锁）→ D3 Develop（顺序：场景上下文→输出设置→激活引用→地点地图→首帧占位→空间调度→角色锚点→格式→光学镜头→摄影机→动作时间→物理材质→光曝光→音频→正锁→局部失败锁；**空间规则先于镜头风格，光是优先锁不是装饰**）→ D4 Deliver（只输出最终提示词，不带QA/推理/笔记）。

**镜头控制：视场角代替毫米数**（Seedance 对可观察镜头结果响应更好）：107°广角贴脸/84°经典广角/47°标准人眼/29°短长焦中景/18°经典长焦紧特写/8°超长焦监视（必加前景遮挡30-45%）。脸部肖像84→29→18；环境动作47→84→107；远距观察8°。**同节拍内混内容类=镜头漂移**。

**长焦/广角可观察结果堆栈**（每镜≥4/3条）：长焦=背景完全柔化/主体锐利/奶油散景/背景压扁/雾悬浮；广角=前景身体存在感/环境环绕可见/边到边合焦/直线保持直线/相机物理贴近。反漂移锁：`本镜任何部分不得变成[广角/长焦]`。

**摄影机写为物理操作员行为**：`camera fixed at X`/`lens at hip height`/`subject occupies screen-left third`/`profile preferred`；手持写物理描述（操作员呼吸/重心转移/有机不完美校正），禁 digital jitter/random shake/gimbal smoothness。

**首帧占位锁**：`The first visible frame already contains all required characters in their correct positions. No empty establishing frame. No delayed character reveal.`（仅用户明确要求才允许空开场）。

**空间调度锁**：每主体写屏幕位置+世界位置+距地标距离+身体朝向+视线方向+运动方向+前中背景；**视线与身体朝向分离写**（`torso faces X`/`eyes stay locked on X`）；**地标近距锁禁弱词**（禁用 near/around/beside，替换 `within 1 meter`/`back against the wall`/`hand on the handle`）。

**多镜连续性锁**：默认单镜连续；多镜必须显式定义每剪（Shot A 时长/相机/首帧/调度/动作 + 切型 + Shot B 全套），绝不让模型发明剪；剪后不重置动作不传送角色；允许 HARD/SMASH/MATCH/INSERT/REVERSE/WHIP CUT，禁 fade/crossfade/dissolve。

**灯光优先锁**：逆光锁 `Subject stays between camera and the brighter background. Camera stays on the shadow side. Faces remain in deep shadow unless explicitly lit. Only rim light, edge light, wet speculars, eye glints, and environmental bounce reveal detail.`；光向必写（主光源/光向/相机与光相对侧/阴影轮廓侧/背景亮度/曝光优先/允许高光/禁止光失败）。

**上下文隔离**：最终提示词是密封的当前镜头文档，禁场景号/集标签/脚本头/前场摘要/未用角色地点标签/previously/again/same as before/continues。

**参考控制层级**：身份参考管脸/身体/比例/服装；地点参考管建筑/材质/地理/光向（不得覆盖所需机位）；道具参考管形状/尺度/状态；风格参考不得覆盖身份/调度/动作/光学/灯光。**高细节只给需要控制处，低细节给泛美描述——改进来自更强信号，不是更多赘肉**。

**输出前静默 QA（20项）**：所有@标签实际用到？删了陈旧@标签？首帧正确？每角色位置/视线/身体朝向清楚？地标近距物理锚定？机位侧清楚？镜头性格按内容类型？镜头防漂移？灯光防平？道具在正确的手？动作物理可行？时间块一致？对白干净仅台词？避免场景号和上下文泄漏？QA隐藏不外露？

### 9.14 情绪驱动电影感提示词（V3.2 新增·来源 Quill 免费版）

> 📄 完整版见 Obsidian `07-课件内容/AI导演思维10天课程/提炼内容/`。通过情绪/叙事意图/观众心理反推镜头角度/焦距/构图/景深/光线/色彩/材质/氛围/胶片质感。**绝不把术语当通用提质词堆砌**。

**先想六问**：观众位置（受害者/目击者/追逐者/上帝视角/亲密参与者）→ 权力关系（谁支配谁）→ 空间心理（开放/封闭/压缩/空旷/迷宫/垂直/坍塌）→ 叙事焦点（人/威胁/物/环境/光/缺席）→ 视觉温度（有生命/温暖/无菌/死亡/神圣/被污染）→ 真实程度（纪录片/神话现实/灾难现实/梦境逻辑）。

**情绪→视觉决策表速查**：恐惧/压迫=低机位仰拍+长焦压缩+侧逆光穿尘+低饱和冷调；巨物渺小=人眼高度+人压底部边缘+巨物比人清楚；敬畏=低机位正面对称+小人物+纪念碑主体+真实大气逆光；幽闭无路=长焦压平/紧广角畸变+删天空地平线+低亮度+出口方向无光；孤独遗弃=远距静态旁观+大量负空间+冷灰弱光；权力权威=仰拍或眼平对称+居中垂直轴+硬侧光受控阴影；追逐恐慌=手持肩高跟拍+倾斜线/局部遮挡/前景虚化+实用光强对比；亲密脆弱=近距眼平/过肩+标准到短长焦+浅焦锁眼/手+暖肤柔对比。

**镜头速记**：低机位=权力上移(弱势/压迫)；高机位=脆弱/被监视；眼平=纪实在场；广角=逼近/畸变/恐慌；长焦=压缩纵深/不可逃避；浅景深=锁叙事焦点；深焦=关系全可读。

**硬规则**：①确定性——不写 or/或/斜杠选项，每个变量只选一个；②默认电影机质感——写真实电影机+胶片（`电影机拍摄`/`35mm 胶片扫描质感`/细腻颗粒/柔和动态范围/轻微 halation），绝不只写"电影感"；③每个选择都有情绪功能——把效果拆成镜头/曝光/颗粒/高光/色彩行为，不写抽象赞美。用户给了字段模板时严格保留标题/标点/顺序。

## 十、使用建议

### 完整工作流

```
剧本大纲 → ①详细剧本 → ②分集分镜脚本 → 衔接层(三视图/表情/场景/剧情分镜格) → ③每集分镜提示词 → 生成验证
```

**①详细剧本：** 小逻编剧创作逻辑（阶段路由/场次戏剧单元/冲突升级/五维微表演/角色名称硬规则）→ 分集规划 → 分段结构 → 资产登记
**②分集分镜脚本：** 小逻时间轴（0-90s连续/18-26镜/动作-反应hard cut/宏观视觉换挡/六维表演/资产统一/硬校验）+ 山音补充（镜头组/动作反应变体/信息量时长）
**衔接层：** 角色三视图提示词（小逻正交标准）→ 角色表情设定提示词（十二宫格）→ 场景提示词（焦段体系）→ 剧情分镜格提示词（每场一个）
**③每集分镜提示词：** 按生成段式输出纯中文提示词（≤60s 五段式 / >60s 六段式）→ 自检门禁D+E
**生成验证：** AI视频生成 → 角色骨相一致检查 → 道具连续检查 → 光影来源检查 → 段间衔接检查（考核标准①）

### 模型选择

- 极端特写/微距镜头 → Kling 1.6 或 Runway Gen-4
- 人物微妙表演（微表情/生理应激）→ Pika 2.0 或 Kling 高细节模式
- 粒子特效密集场景 → Kling 1.6（粒子物理一致性）
- 环绕运镜+物理交互 → Kling 关键帧首尾帧功能
- 宏大场景/大远景/航拍 → 可先出静止关键帧验证比例再生成动态（防巨物画小）

### 跨段生成衔接

- **首尾帧方案已废弃（V4.0.2）**：不再用上一段尾帧当下一段首帧直接拼接——AI 无长时序记忆，动态信息每 15s 归零，直接拼必跳切。
- 正确做法：每段生成前**绘制分镜参考图**（固定上段结尾的人物姿态/站位/互动）→ 提示词同步更新变动数据（站位/姿态/构图）→ 拼接节点**更换机位**（切近/反打/换景别）
- 不变数据（人物资产图/场景图）全程固定导入；可变数据（站位/姿态/互动/构图）每段同步更新
- 硬切镜头建议单独生成后剪辑拼接
- 光影不变则生成时锁定光源方向描述
- 段间衔接四重规则（资产/动作/情绪/声音）逐段核对 + 末态继承锁检查（详见 §3.7）
