# 武打PREVIS：15格动作预演系统（工业级）

> **来源**：桌面《职业学校推荐skill/6.txt》工业级 15 格武打 PREVIS 系统，2026-08-16 融合入库。
> **用途**：①武打戏分镜拆解的动作体系（动力链/攻防博弈/连续性/轴线/QA）；②生成 15 格白色 3D 武打 PREVIS 故事板图（可选）；③故事板逐格转 Seedance 2.0 提示词。
> **与主体关系**：§4.6.8 为压缩速查，本文件为完整版。打斗戏编写/检查以本文件为准。
> **注意**：本系统定位是"动作预演/动作体系"，PREVIS 故事板图生成非漫剧主流程必需；漫剧生产直接套用其中动作拆解规则 + 转提示词模式。

---

## 一、核心任务

根据人物、服装、场景、道具、武器、生物和视觉参考图 + 武打剧情，自动设计并直接生成一张 15 格白色 3D 武打 PREVIS 故事板（或按用户要求输出逐格 Seedance 提示词）。

默认只生成 15 格：5 列 × 3 行、16:9 横版、P01—P15、从左至右从上至下。

- 第一排：P01、P02、P03、P04、P05
- 第二排：P06、P07、P08、P09、P10
- 第三排：P11、P12、P13、P14、P15

所有分镜格：尺寸统一、边框统一、留白统一、标题位置统一、阅读顺序明确；不得漏格、重复格、错序、生成第 16 格。每格只表现一个清晰、独立、可动画化的静态动作节点。

## 二、参考图使用规则

用户上传的图按用途自动归类：

- 人物定妆图/三视图/特写 → 人物参考
- 无人物环境图 → 场景参考
- 单独服饰图 → 服装参考
- 刀剑棍枪匕首 → 武器参考
- 单独物品图 → 道具参考
- 动物/怪物/灵兽 → 生物参考
- 镜头/光影/构图示例 → 视觉参考

**人物参考图锁定**：身份、年龄感、身高、体型、头部/脸型/发型轮廓、服装剪裁轮廓、鞋子/配饰轮廓、战斗风格、武器归属。

**场景参考图锁定**：战斗空间结构、地面结构、门窗楼梯位置、障碍物位置、高低差、可移动路线、前景/中景/背景、战斗边界。

**武器参考图锁定**：武器类型、长度、外轮廓、握持位置、刃口方向、使用手、武器状态。

参考图只用于提取轮廓、比例、身份、造型、动作和空间关系。最终必须转换成白色 3D 预演模型，**不得继承参考图的真实颜色和复杂材质**。

## 三、白色 3D 武打 PREVIS 风格

WHITE CLAY ACTION PREVIS / 3D WHITE MODEL COMBAT STORYBOARD / GREYBOX MARTIAL ARTS PREVIS

人物、服装、头发、鞋子、配饰、武器、道具、车辆、生物、建筑和场景，全部转换为：哑光白 / 象牙白 / 浅暖灰 / 柔和浅灰，无纹理 3D 模型。

**人物保持辨识度，但只能通过以下特征区分**：身高、体型、脸型轮廓、发型轮廓、服装剪裁、配饰轮廓、武器、战斗姿态、站位。面部只保留简化体块（额头/眼窝/鼻梁/嘴部/下颌）。

**禁止**：真实肤色、真实发色、彩色眼睛、皮肤毛孔、真实布料颜色、真实金属颜色、电影成片调色、照片级真人面孔。

**必须保留**：人体体块、肌肉受力关系、武器接触点、地面接触点、接触阴影、地面投影、前后景层次、战斗空间纵深。禁止全部白成一片——通过浅灰明暗和环境遮蔽表现结构。使用明亮、柔和、中性的摄影棚顶光与环境光。

## 四、自动动作拆解（核心方法论）

收到武打剧情后，内部将故事拆成 15 个连续动作节点（不向用户展示拆解过程）。

**每个动作必须具备完整动作动力链（11 环）**：

1. 动作意图
2. 起手准备
3. 重心变化
4. 脚步位移
5. 腰胯或核心发力
6. 肩肘腕或髋膝踝传导
7. 攻击轨迹
8. 接触点
9. 命中或格挡反馈
10. 收招惯性
11. 下一格继承状态

**禁止只表现动作结果**。禁止只画：挥拳、踢腿、劈砍、爆炸、摔倒、人物飞出、双方对波、静态摆姿势。必须让观众看懂动作是怎么发生的。

## 五、15 格动作节奏结构（默认，服从用户剧情）

| 格 | 内容 |
|---|---|
| P01 | 建立战斗空间、双方初始位置和距离 |
| P02 | 主攻方起手或试探 |
| P03 | 脚步启动与重心前移 |
| P04 | 第一次攻击进入 |
| P05 | 防守、闪避或格挡 |
| P06 | 第一次接触与力量碰撞 |
| P07 | 受力反馈与重心失衡 |
| P08 | 反击方夺回主动权 |
| P09 | 第二轮位移或贴身 |
| P10 | 核心连招或武器博弈 |
| P11 | 关键命中、摔投、缴械或破防 |
| P12 | 命中后的身体反馈和惯性 |
| P13 | 双方空间重新建立 |
| P14 | 被压制方重新稳住重心 |
| P15 | 下一轮反扑、追击或反制起手 |

**P15 不得表现完整战斗结束**。短时武打故事板是战斗过程的高能截面，不是完整结局。除非用户剧情明确要求结束，否则禁止：一方彻底获胜、双方同时收招、战斗结束式对视、爆炸后定格、胜利姿势、完整终结式收尾。

## 六、攻防博弈规则

15 格中不能全部由一方连续攻击。必须体现：攻击、防守、闪避、格挡、反制、主导权变化、重心变化、距离变化、节奏停顿、再次爆发。

**默认节奏：快 → 快 → 停 → 爆 → 反馈 → 反制 → 续**

- 每 3 至 5 格至少出现一次节奏变化
- 每 6 至 8 格至少出现一次主导权变化
- 禁止 15 格全部使用同一种动作；禁止全程只有挥拳；禁止全程只有对砍；禁止全程只有能量碰撞

## 七、拳脚动作规则

**拳法必须明确**：哪只手出拳、后脚如何蹬地、重心向哪里移动、腰胯如何转动、肩膀如何前送、拳峰接触位置、对方身体哪一部分先反馈。

**腿法必须明确**：支撑腿、抬膝方向、髋部转动、踢击轨迹、脚背/脚掌/脚跟接触点、命中后对方重心变化。

- 肘击和膝撞必须发生在合理近身距离
- 摔投必须拆成：进入 → 控制 → 卡住重心 → 发力 → 离地或失衡 → 落地反馈
- 复杂摔技、锁技和地面技不能在单格内完成

## 八、武器格斗规则

所有武器镜头必须明确：谁持有武器、哪只手握持、武器长度、刃口方向、攻击轨迹、接触点、滑动方向、压刃关系、杠杆关系、武器受力后的震动或偏转。

**刀剑碰撞不能悬空**，必须表现以下至少一种：压刃、滑刃、挑刃、偏转、震手、卡位、缴械进入、武器余震。

**禁止**：武器穿过身体、武器长度漂移、武器突然换手、武器突然消失、刀剑没有接触点、刃口方向错误、武器悬浮碰撞。

## 九、动作状态连续性

每格必须继承上一格的角色状态。内部持续记录每个角色的：当前位置、朝向、左右站位、重心、脚位、手部状态、武器位置、武器持有手、呼吸状态、体力状态、受伤状态、当前主导权、当前惯性方向。

**禁止**：瞬间换边、无原因换位、突然改变脚位、突然换手、忽略上一格动作惯性、忽略上一格伤势、忽略上一格武器位置、人物距离突然改变、场景空间重置。

## 十、摄影机轴线

战斗开始后建立明确的 180° 轴线。默认：角色 A 位于画面左侧，角色 B 位于画面右侧。不得无理由换边。

**必须跳轴时，只能通过以下方式重新建立空间**：环绕镜头、顶视镜头、中立正面镜头、快速摇镜、摄影机绕过双方。跳轴后必须在后续镜头中保持新的左右关系。

## 十一、人体解剖和接触规则

所有分镜必须保证：四肢数量正确、左右手/左右脚归属明确、肩肘腕/髋膝踝连接正确、骨盆方向正确、头颈肩关系正确、双腿支撑逻辑成立、重心落点合理、手掌握持正确、武器归属正确、接触点明确、双人身体不能融合。

**禁止**：多手多脚、关节反向、肢体穿模、人体断裂、手脚归属混乱、漂浮受力、武器穿模、身体融合、复杂缠斗无法辨认、锁技方向错误。

**遇到地面技、摔投、贴身缠斗、多人混战或双武器时**：降低单格复杂度、使用中景或俯视镜头、减少极端透视、减少身体遮挡、明确谁在上位谁在下位、明确左右手和腿部归属、将复杂动作拆成多格。

## 十二、惯性规则

所有大动作后必须保留惯性：肩膀延迟回正、腰胯回收、脚步重新找平衡、武器余震、袖口延迟摆动、衣摆延迟甩动、长发二次摆动、呼吸短暂停顿、受击后的重心延迟。

- 角色前冲：头发/衣摆/配饰向后
- 角色急停：身体先停，头发和衣摆继续向前甩动
- 角色旋转：袖口形成弧线、头发形成旋转惯性、武器轨迹保持同方向

**禁止**头发、衣摆和武器惯性方向互相冲突。

## 十三、伤势与状态持续

剧情出现以下状态时必须保持连续：衣服破损、武器损伤、污渍、泥点、灼痕、伤痕、发饰松动、跛行、呼吸急促、体力下降。

白模系统中伤势和污渍使用：浅灰色标记、表面缺口、模型凹陷、衣物破损轮廓、姿态变化表达。**禁止镜头之间自动恢复。**

## 十四、特效规则

特效只能用于加强动作，不能替代身体接触。拳脚、武器和身体动作必须先成立，才能增加特效。

白模 PREVIS 中的特效只能用：白色、浅灰色、半透明灰色。可表现：气劲、刃光、冲击波、烟尘、火焰体积、魔法范围、运动残影、碎片、飞尘。

**禁止**：彩色能量、大面积光污染、特效遮住人物、用光柱碰撞代替动作、用爆炸代替具体命中、漂浮施法代替脚步位移、全身被光效包裹。

## 十五、彩色导演标注线

白色 3D 分镜画面中允许加入少量、清晰、半透明的彩色动作箭头和轨迹线：

- **红色箭头**：人物身体移动方向
- **蓝色箭头**：摄影机运动方向
- **绿色圆圈/短线/焦点框**：构图视觉焦点
- **橙色箭头**：力量传导、冲击和受力方向
- **紫色半透明区域**：烟雾/爆炸/魔法/特效影响范围
- **黄色弧线**：刀剑棍枪匕首等武器运动轨迹
- **白色虚线**：人物视线方向

所有标注：直接画在对应分镜画面中、起点终点明确、与实际动作一致、细线、半透明、不遮挡面部/手脚/武器接触点/核心动作、不与动作方向冲突。**每格最多 3 类标注**。没有人物移动不强行加红线；固定镜头不强行加蓝线；没有武器不加黄色武器轨迹。箭头必须是技术标注，不得变成装饰性速度线。

## 十六、镜头语言

15 格不能全部使用相同景别、焦段和机位。根据动作功能选择：

| 动作功能 | 景别 | 焦段 |
|---|---|---|
| 建立空间 | 大全景/全景 | 35mm |
| 起手与观察 | 中景 | 35mm 或 50mm |
| 脚步与重心 | 低机位近景 | 35mm 或 50mm |
| 高速突进 | 广角跟拍 | 24mm |
| 近身碰撞 | 中近景 | 24mm 或 35mm |
| 拳脚命中 | 近景/极近景 | 50mm 或 85mm |
| 摔投和缠斗 | 中景或俯视 | 减少透视错误 |
| 武器压刃 | 手部/接触点近景 | — |
| 重新建立空间 | 全景/环绕/顶视 | — |
| 反扑起手 | 脚步/手指/眼神/武器卡位特写 | — |

运镜必须服务动作，不得为了炫技破坏动作可读性。

## 十七、分镜文字规则

页面只允许出现：主标题、副标题、P01—P15 编号、简短镜头标签、简短动作节点名。

每格下方深灰信息栏：第一行 `P## / 景别`；第二行不超过 6 个中文字符的动作节点名。

**禁止**：大段对白、长段说明、动作分析文字、时间码、英文参数表、QA 报告、水印、无关文字。如果中文文字无法稳定生成，优先保证 P01—P15 编号、顺序和画面动作正确，动作标题可以省略。

## 十八、内部 Action QA（25 项）

生成前内部检查，不展示给用户；发现问题在生成前自行修正：

1. 是否正好 15 格
2. 是否为 5×3 布局
3. P01—P15 是否顺序正确
4. 人物身份是否一致
5. 发型和服装轮廓是否漂移
6. 人物比例是否变化
7. 左右站位是否连续
8. 180° 轴线是否成立
9. 脚步和重心是否合理
10. 动作是否具有动力链
11. 攻防是否存在博弈
12. 接触点是否明确
13. 命中后是否有身体反馈
14. 武器握持和刃口方向是否正确
15. 武器是否穿模
16. 是否出现多手多脚
17. 是否出现肢体穿模
18. 复杂动作是否拆格
19. 衣摆/头发/武器惯性是否正确
20. 伤势和破损是否连续
21. 彩色箭头方向是否正确
22. 箭头是否遮挡核心动作
23. 是否全部为白色 3D 白模
24. 是否残留真实肤色和彩色材质
25. P15 是否保持战斗继续

## 十九、武打故事板转 Seedance 2.0 提示词模式

默认工作是生成 15 格 PREVIS 故事板。只有用户明确要求"按故事板生成 Seedance 2.0 提示词 / 输出 P01—P15 视频提示词 / 按每个宫格写视频提示词"时，才进入视频提示词模式，不再重新生成故事板图片。

**故事板负责锁定**：P01—P15 镜头顺序、景别和机位、构图、人物站位、动作方向、武器位置、接触点、空间关系、前后镜头衔接。

**人物参考图负责**：最终视频中的脸、年龄、发型、肤色、体型、服装、鞋子和配饰。

**场景参考图负责**：建筑、地面、灯光、时间、天气和环境材质。

**武器参考图负责**：武器外形、长度、颜色、材质、握持方式和所在手部。

**生成提示词时忽略故事板里的**：白色 3D 白模材质、空白面部、分镜边框、页眉、P 编号、标题文字、箭头、动作线、运镜线、技术标注、页面留白。

**每条提示词必须包含 14 要素**：

1. 镜头编号
2. 建议时长
3. 对应宫格
4. 景别和机位
5. 运镜方式
6. 动作起点
7. 脚步和重心
8. 身体发力链
9. 武器动作
10. 接触反馈
11. 收招惯性
12. 下一镜衔接
13. 环境声音
14. 禁止项

**声音**：默认无背景音乐，只保留环境声、呼吸声、脚步声、衣料声、武器破风声、碰撞声和落地声。普通写实武打禁止彩色能量特效；只有用户明确要求仙侠/魔法/超能力/能量效果时，才允许加入附着在动作和接触点上的克制特效。不得用特效代替身体动作。不得让每个镜头从完全静止重新开始——上一镜结尾必须自然连接下一镜开头。

## 二十、最终绝对禁止（红线汇总）

禁止输出不足 15 格 / 超过 15 格 / 漏格 / 重复格 / 错序；禁止人物换脸、体型漂移、服装轮廓漂移；禁止武器突然换手、长度漂移、消失；禁止多手多脚、肢体穿模、武器穿模；禁止复杂动作单格完成；禁止无接触命中、无受力反馈；禁止人物瞬移、无理由换边、空间重置；禁止用特效代替身体动作；禁止全程同一动作、同一景别；禁止纯静态摆姿势、海报式构图；禁止照片级真人风格、真实肤色、真实发色、彩色服装、电影成片调色；禁止二维漫画、Q 版、玩具黏土风；禁止 P15 表现完整战斗结束。
