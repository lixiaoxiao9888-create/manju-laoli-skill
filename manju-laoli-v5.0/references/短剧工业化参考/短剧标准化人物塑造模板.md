# 短剧标准化人物塑造完整模板（极精细版）

本模板专为**每秒都在与“划走”做斗争**的短剧/漫剧设计。短剧角色的人设不是文学写意，而是**高强度的戏剧发动机**。
本模板废除一切无意义的心理描写与冗长家世，所有维度全部指向**“可拍、可听、可情绪投流”**。

---

## 💻 模块一：人物全维设定矩阵（视听资产清单）

每一项设定都必须是漫画师/AI生图师、CV（配音演员）和剪辑师能直接转译成素材的具体指令。

| 维度分类 | 核心设定项 | 设定标准与工业化规范 |
| :--- | :--- | :--- |
| **1. 基础社会属性** | **姓名 / 年龄 / 阶级** | 必须有明确的社会阶级标签（如：破产千金、赘婿、豪门私生子、打工人）。 |
|  | **对外显身份 (表)** | 别人眼里的他。越卑微、越寻常、越窝囊越好（如：聋哑送外卖的、前台实习生、林家废物赘婿）。 |
|  | **对内真身份 (里)** | 真实的他。必须是该世界规则里的绝对顶点或强力威胁（如：神医圣手、黑客大佬、帝国第一财阀、重生全知者）。 |
| **2. 视听资产锚点**<br>*(严禁虚无描述，必须落到3个具体细节)* | **① 职业习惯动作（视觉）** | 角色不说话时，能证明其身份的无意识动作。（例：女主极度紧张时会单手做“外科医生无菌戴手套”的拉扯动作）。 |
|  | **② 招牌物件/配饰（视觉）** | 镜头会反复特写的关键道具，也是身份反转的伏笔。（例：男主脖子上挂着的生锈铜钱，特写其实刻着“隐世龙王”私印）。 |
|  | **③ 动作/语言微习惯（视听）** | 角色特有的微动作或口头禅。（例：每次被挑衅，先慢条斯理地摘下眼镜擦拭，擦完戴上的那一帧就是“反击信号”）。 |
| **3. 声音资产锚点** | **声线/语气规范（听觉）** | 给CV的明确声标。（例：男频隐藏大佬声线必须极低沉，带微弱的磨砂感，被嘲讽时一律用“气声冷笑”而非“哈哈大笑”）。 |
|  | **专属声音事件（听觉）** | 主角出场或反击时，后期必须配的标志性环境音。（例：疯批总裁出场前，必然有手杖敲击地面的“笃、笃”声）。 |
| **4. 关系力场配置** | **共情锚点（情感保护伞）** | 主角唯一在乎、早早善待主角的人，主角出手护人的终极理由。（例：病床上的妹妹、唯一尊重他的聋哑岳父）。 |
|  | **压力源（极致反派）** | 站在主角对立面，用最具体、最公开的方式羞辱主角的靶子。（例：嫌贫爱富的继母、狂妄的未婚夫）。 |
|  | **见证链（吃瓜群众）** | 充当主角打脸/掉马甲时的“放大器”。（例：董事会全员、同学会同学、宗门大比的师兄弟）。没有见证者的打脸等于没打！ |

## ⚙️ 模块二：性格写法与人设极简化规则（10秒立人设）

短剧观众耐心极低，绝对不要写“复杂的多重人格”。我们采用**“反差设定 × 情绪杠杆”**公式。

### 1. 人设公式
$$ 记忆点 = 极度卑微/老实（表） \times 极致强大/疯批（里） $$
- **写法铁律**：表身份有多低，里身份就得有多高，中间的落差就是**“情绪张力”**。
- **性格标签极简化**：只写1个**主性格标签**（对外展示，如：顺从、温和）+ 1个**核心隐藏原力**（对内，如：极度护短、绝对掌控）。

### 2. 台词与潜台词双轨制
- **子弹台词律**：任何角色的单句台词**禁止超过15个字**。短剧里的台词是武器，不是散文。
- **不解释律**：绝对不许用台词跟反派解释自己的设定。
- ❌ 错：`“你别看我只是个前台，其实我早就拿到了哈佛双学位，还黑了你们的财务系统！”`
- ✅ 对：`“合同第三页，第七行。财务章用错墨了。”`
- **冰山对话**：嘴上说一分，画面做九分。眼神死盯、手里捏碎杯子，嘴里却在温顺地道歉。

## 🚫 模块三：短剧人设禁忌与排毒层（严禁触碰的毒点）

### ❌ 禁忌 1：无脑降智隐忍（软弱无骨）
- **毒点表现**：主角为了水集数、拖剧情，在没有理由的情况下疯狂被反派踩。
- **排毒方案**：主角必须**有具体且可拍的“隐忍理由”**（如：在等一个倒计时、在等最关键的证据成熟、或者共情锚点被反派捏在手里）。观众容忍隐忍，是因为知道主角在“暗中落子”。

### ❌ 禁忌 2：全程被动等救场（工具人主角）
- **毒点表现**：主角自己什么都没做，每次危机都靠男主/大人物出面空降捞走。
- **排毒方案**：主角必须是**危机的主要解题人**。哪怕别人帮忙，也是因为主角提前布了局，或者主角付出了对等的代价。

### ❌ 禁忌 3：口号式独立（伪大女主）
- **毒点表现**：台词里疯狂喊着“我要靠自己、男女平等”，实际行动一遇到困难就靠霸总送钱送权。
- **排毒方案**：女主必须有可见的专业布局、真实的战术代价。当众撕下伪善反派的面具，不靠霸总撑腰，靠自己手里的铁证和智商。

### ❌ 禁忌 4：降智反派与纸片草包
- **毒点表现**：反派毫无逻辑，坏得像个纯粹的精神病，为了作恶而作恶。
- **排毒方案**：反派必须有具体的资本、真正的社会威胁（真有点本事，主角打赢了才有快感）。反派的势利要有市井生活质感，而不是悬空的大吼大叫。

## 📈 模块四：人物成长线与情绪波谱格式（集集记账）

短剧没有时间写“三十集慢悠悠的心理转变”。我们采用**“情绪换轨”**与**“资产记账”**。

### 1. 季度“集集弧光记账表”格式
分集大纲中，每一集写完，必须在主角的成长账本上记一笔。写不出这一句的集数，就是注水集，直接砍掉。

- **记账格式**：
$$\text{这一集：}[主角] \text{ 被拿走了 } [具体资产/情感] \implies \text{ 换来了 } [具体成长/反击筹码] $$
- *例（第12集）*：林默被剥夺了在顾氏的实习生资格（被拿走），换来了顾氏核心财务系统的底库访问权限（换来筹码）。

### 2. 四阶段情绪阶梯（以80集短剧为例）

```
【第一阶段：1-3集】── 共情起手（惨到极致）
                       主角在公开场合被用最具体、最戳生活痛感的方式羞辱，
                       瞬间建立观众的“同情与渴望复仇”代入感。
【第二阶段：4-12集】── 蓄压冲刺（筹码暗落）
                       主角不断收集反击子弹（观众知道，反派不知道），
                       在一卡付费卡点（10-12集）前蓄积到极限。
【第三阶段：13-55集】─ 循环递进（反派分期付款地死）
                       主角不能一次性把大BOSS拍死。必须小反派（女配/狗腿子）每5集倒一个，
                       大反派不断加压，每次打脸释放必须成倍对齐蓄压。
【第四阶段：55-65集】─ 塌腰预警（降维打击与真失去）
                       主角突遇质变级打击（如马甲暴露、共情锚点受重创）。
                       主角必须“真失去”一样东西，进入最低谷，逼迫其舍弃外挂，用肉身和纯智商决战。
【第五阶段：66-80集】─ 总引爆与新常态
                       全剧底牌全开。马甲彻底炸碎，给观众带来全剧最大、最奢侈的见证链爽感。
                       结局重归高段位的新常态。
```

## 🎬 模块五：完整案例示范（外科缝合圣手 → 豪门复仇嫡女）

以下以古装/AI短剧大女主《寒刀缝春骨》女主为例，完整展示模板填充质感。

### 1. 基础属性
- **姓名**：沈惊秋
- **对外身份 (表)**：顾府那个唯唯诺诺、天生不能说话的“哑巴冲喜新娘”。
- **对内身份 (里)**：天下第一刺客盟、金牌“缝合医圣”。她那一双能握剑缝尸的玉手，捏死或医活一个人都在瞬息之间。

### 2. 视听资产（画师/AI生图与后期重点特写）
- **① 职业习惯动作（视觉特写）**：她日常总是把双手藏在宽大的水袖里。每当杀机起时，镜头必须特写她白皙的手指在袖中作“拈针引线、凌空缝合”的动作，指尖有极细的银丝反光。
- **② 招牌物件（视觉特写）**：她发髻上别着一根极钝的木簪，外人以为穷酸。在第15集反击时，她当众拔下木簪，里面竟是十六节如鱼骨般咬合的“听雪寒针”。
- **③ 语言微习惯**：由于装哑，她日常只用点头和低眉顺眼表示顺从。但在第3集，她首次在暗室开口，声音极冷，没有任何语调起伏，像冰块在银盘里摩擦。

### 3. 声音资产
- **声线/语气**：装哑时无声；开口时是标准的“冷玉声”，毫无人类情感，多用肯定句，从不说废话。
- **专属声音事件**：只要她准备动手，后期必然会响起极细微、高频的“银针破空、丝线拉紧”的蜂鸣音（SFX），背景BGM瞬间死寂。

### 4. 关系力场
- **共情锚点**：前夫家唯一没有嘲笑她、还给她分过半块冷馒头的憨厚小书童（阿福）。
- **压力源**：心狠手辣、纵容儿子打死丫鬟，且一直对她冷嘲热讽的顾家主母（大反派）。
- **见证链**：顾家一年一度的“春日家宴”，在场有各路高官、名门家主。

### 5. 季度弧光记账示范
- **第3集记账**：沈惊秋被主母当众罚跪在雪地中（被拿走尊严），换来了她暗中用银针挑断了主母身边大管家的关键筋脉（换来主母断一臂的战略筹码）。
- **第55集（塌腰位）记账**：阿福被主母设计乱棍打死，沈惊秋的第一层金指针包丢失（真失去），沈惊秋彻底放弃装哑，血染主母院落，决定打破刺客盟“不杀凡人”的契约，进入终极血仇复仇状态。
