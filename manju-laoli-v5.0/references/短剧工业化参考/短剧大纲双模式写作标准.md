# 短剧大纲双模式标准写作规范（精修版）

本标准面向短剧与中视频内容，分为**“单集独立短剧”**与**“多集连续短剧”**两套大纲写作标准。**
**我们坚持：**“大纲是地基和体检表，不是散文。”** 拒绝空泛的情节描述，每一段、每一集的任务必须数字化、视听化。

---

## 💻 模式一：单集独立短剧大纲标准格式（5-10分钟独立故事）

- **适用场景**：中视频独立漫剧、B站精品叙事短片、电影节投递短片。
- **核心纪律**：**“一个人、一件事、一个不可逆的变化。”** 严禁塞入第二主题或多余支线。

### 1. 固定五段式结构规范（短A：铺陈-断裂型）
单集独立短片的核心逻辑是**“规则的甜头变成绞索”**。

| 结构断点 | 时长比例 | 核心叙事任务（大纲写作必须包含的动作） |
| :--- | :--- | :--- |
| **第一段：前置钩（Teaser）** | **5%** | **【僵局先行】**：直接抛出危机最激烈的瞬间片段，或者一个“极不正常”的日常特写，引发“他怎么会沦落到这一步”的悬念。 |
| **第二段：建置与甜头（Setup）** | **35%** | **【建立常态规则】**：展现主角的伪装、秘密或某种赖以生存的手段，并让他尝到甜头。**【双义细节】**：此处建立的规则细节，必须在后面变成绞索（例：盲人按摩师因为装盲获得顾客信任，并借此偷听商业机密）。 |
| **第三段：常态断裂（Inversion）** | **15%** | **【一脚踩进雷区】**：一个外来变量侵入，原本保护主角的伪装/规则瞬间翻转为危机。主角不能退缩，必须硬着头皮维持规则（例：杀人犯进入按摩店，盲人按摩师不能露馅）。 |
| **第四段：僵局拉锯（Struggle）** | **35%** | **【单向升压】**：在极小空间/短时间内，每个细微动作都在“露馅/不露馅”的刀刃上。危机不断逼近，压迫感呈螺旋上升，逼迫主角做出**打破内在矛盾的终极选择**。 |
| **第五段：高潮切黑/新常态（Climax）** | **10%** | **【无声的重锤】**：高潮必须在动作或情感的最高点戛然而止。**【悬置切黑】**：不给标准答案，而是留给观众一个精确设计的两难结局（A结局与B结局各意味着什么），余味无穷。 |

### 2. 剧情排布逻辑与写作要求
- **倒着长出来的结尾**：写大纲前，必须先确定最后一镜的画面。短片是结尾的艺术，所有前面的铺垫都是为了最后那一锤。
- **单一变量极致推演**：只引入一个不属于现实的脑动偏移（如：一个能看见别人死亡倒计时的眼镜），其余所有社会规则、物理逻辑必须 100% 遵守现实。
- **三次递升律**：主角试探或反抗必须是三次，每次代价和赌注翻倍。两次不够形成节奏，四次显得疲劳。

## 💻 模式二：多集连续短剧大纲标准格式（60-100集长剧 / 12-24集季播剧）

- **适用场景**：竖屏付费短剧、横屏多集爆款短剧、长篇漫剧。
- **核心纪律**：**“观众的耐心以秒计价，每一集的终点必须是下一次付费的卡点。”**

### 1. 宏观全剧五段大骨架（以80集短剧为例）

大纲整体规划必须符合以下波浪形曲线：

- **第1段：开局段（第1-3集）——【锚定与承诺】**
- *任务*：第1集3秒内给主角一个极度具体、当众、戳生活痛感（如彩礼、背叛、顶罪）的被虐现场。第3集内亮出主角金手指/里身份/前世记忆。向观众承诺“这个人必翻身”。
- **第2段：上头段（第4-12集）——【蓄压与冲刺】**
- *任务*：第一卡付费点（通常在第10-12集）之前，大反派挑衅不断升级，主角不降智隐忍，而是暗中收集子弹，卡点前一集停在**“大招抬到半空中”**的瞬间。
- **第3段：付费初段（第13-30集）——【兑付与扩局】**
- *任务*：第13集足额兑付打脸，第二卡付费点（第26-30集）前，安排身份揭穿级（掉大马甲）的大反转，将格局从“个人恩怨”扩为“家族/行业大战”。
- **第4段：中段循环段（第31-60集）——【梯队消耗与防塌腰】**
- *任务*：小反派每5-8集倒下一个，倒下方式绝不重复。在全剧 55%-65% 位置（第45-52集），必须爆发**质变级塌方事件**（如共情锚点被打碎，主角陷入真失去的谷底），防止中段塌腰。
- **第5段：终局段（最后10-15集）——【总引爆与重归常态】**
- *任务*：大反派底牌全开，主角置之死地而后生。全剧最大的马甲在万人见证链前彻底炸碎。收尾重归高阶新常态。

## 📝 模式二的单集大纲标准写作模板（工业化落位规范）

大纲动笔前，每一集必须按照以下标准格式填充。**拒绝写“林默和顾城发生冲突，林默解决了他”这种废话，必须写出物理动作和信息变化。**

### 单集大纲标准卡片模板：

```markdown
第X集：《单集名》
【基本定位】
  - 单集模板选择：[ E1打脸 / E2憋屈 / E3卡点 / E4掉马甲 / E5情感 / E6反扑 ]
  - 时长预算：[ XX秒 ] / 预计分镜数：[ XX格 ]
【剧情排布三步法】
  - 1. 承接（5-10秒）：[ 迅速交代/解决上集末留下的悬念或危机 ]
  - 2. 推进（10-80秒）：[ 本集的核心物理冲突或信息交锋，产生具体的强情绪 ]
  - 3. 集末钩（最后10秒）：[ 切断动作在正中间。谁进来了？什么碎了？底牌翻到一半？ ]
【季度连接与审计】
  - 一句话弧光记账：这一集，[角色] 被拿走了 [X] ── 换来了 [Y]
  - 牵引力源检查：[ 属于四大引力哪一种？未解危险 / 未兑付对峙 / 未解谜题 / 人物下落 ]
  - 伏笔登记：[ 本集埋下的种子 Z，预计在第 XX 集回收 ] / [ 本集回收的第 XX 集种子 ]
```

## 🔍 两套大纲写作的核心避坑指南（剧本医生终审对照）

### ❌ 单集独立短剧最易犯的错：
1. **高潮被建置挤压**：前面解释世界观或人物身世花了 70% 篇幅，导致后面冲突解决得莫名其妙。**【纠偏】**：前史不单独成戏，全部融在动作里。
2. **解释人物学到了什么道理**：结尾大说大笑，或者安排角色念台词说教。**【纠偏】**：结尾只留最后一个无声画面（如《邻居的窗》最后在雪地里久久驻足），让观众自己体会。

### ❌ 多集连续短剧最易犯的错：
1. **卡点停在“事件交代完”**：例如写到主角跟反派说：“明天我让你破产”，全集完。观众没有付费冲动。**【纠偏】**：卡点必须是**“动作进行到一半”**（例：主角把巴掌扇到距离反派脸侧 3 厘米处，或者鉴定报告刚撕开一半露出名字的首字母）。
2. **憋屈集无节制连续**：连续 3 集以上让主角挨打不还手，且主角毫无后手。**【纠偏】**：严守**“憋屈不过2集律”**。第2集憋屈结束前，必须让观众看到主角暗中下子，给观众释放的安全感。
