# 短剧60秒与90秒成片剧本排版与篇幅控制对比（工业化标准工业化标准）

本指南旨在向创作者展示**60秒（极速爆发型）**与**90秒（悬疑拉锯型）**短剧/漫剧在景别切分、镜头密度、声音字数硬卡口以及戏剧张力排布上的物理差异。

- **60秒的核心**：**“无台词动作与特写对切的闪击战”**。绝无多余废话，用视觉冲击直接抓人。
- **90秒的核心**：**“情绪蓄压与正反打拉锯战”**。有空间展示听者的反应、道具的质感、以及台词在冰山之下的博弈。

## 💻 剧本二：90秒情绪拉锯型独立剧本《名门退婚录》

- **成片时长要求**：严格控制在 90s。
- **镜头密度规划**：12 个镜头（平均 6s / 镜，包含了正反打与反应镜头的博弈空间）。
- **字数算力控制**：总字数 420 字。纯配音台词 175 字（ASR 极限为 315 字，为情绪停顿、见证链反应、道具特写留出了 45秒 的“张力时间”）。
