## 一、拳法系

### 咏春（守中用中·贴桥快打）
定位：近身贴桥，中线最短距离爆发，黐手听劲。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 日字冲拳 | 肘贴中线直线冲出，拳面短距爆发，连珠炮式 | 主战·近身连击 |
| 标指 | 四指并拢直线插击，指尖如锥，取咽喉/眼/肋 | 破招·致命点穴 |
| 摊手 | 前臂内旋摊开化力，引开对方来拳 | 防守·化劲起手 |
| 伏手 | 前臂下压伏按，压制对方桥手 | 防守·控桥 |
| 膀手 | 上臂外旋架起，以骨格挡重击 | 防守·卸力 |
| 寸拳 | 贴身极短距离发力，拳面贴肉骤爆 | 终结·近身暴击 |

典型连招：摊手化劲→日字冲拳连击→标指刺喉（破绽收尾）。

### 八极（刚猛贴靠·硬开硬打）
定位：贴身短打，寸截寸拿，一靠定乾坤。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 崩拳 | 拳沿直线崩出，腰胯整劲透体 | 主战·正面突破 |
| 顶肘 | 肘尖横向/向前顶撞，近身最短距离最暴力 | 主战·贴身破防 |
| 铁山靠 | 整身侧靠，肩胯一体撞飞对手 | 终结·一靠定局 |
| 六大开 | 顶、抱、单、提、胯、缠连环发劲 | 主战·连续压制 |
| 撑锤 | 沉马撑拳，十字整劲砸下 | 主战·重击 |

典型连招：崩拳破门→顶肘开防→铁山靠收尾（力量碾压型角色标配）。

### 太极拳（以柔克刚·化劲借力）
定位：听劲化劲，引开来力顺势反击，禁止硬碰。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 云手 | 双臂交替画圆，缠绕化开连续攻击 | 防守·连续卸力 |
| 揽雀尾 | 掤捋挤按四劲连贯，引进落空 | 破招·借力摔 |
| 搬拦捶 | 搬开+拦挡+捶击三步连发 | 主战·反击组合 |
| 如封似闭 | 双臂封挡后前推，封闭对方攻势 | 防守·封门 |
| 海底针 | 俯身下插掌，破下盘 | 破招·低位突袭 |
| 闪通背 | 侧闪同时穿掌击出 | 破招·闪反击 |

典型连招：云手化劲→揽雀尾引进落空→闪通背反击（化劲型角色模板）。

### 八卦掌（游身走圈·绕侧击背）
定位：不走直线不走腾空，弧线绕圈永远在侧后方打。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 白蛇吐信 | 穿掌直插，掌如蛇信快收快发 | 主战·快攻 |
| 鹞子穿林 | 绕侧穿身，从对方侧后空隙穿过 | 破招·绕背 |
| 乌龙摆尾 | 以一脚为轴水平旋转出掌，掌风沿圆弧展开 | 主战·旋转压制 |
| 回身劈掌 | 走圈中突然回身劈砸 | 终结·走圈逆转 |
| 狮子抱球 | 双掌抱圆合击 | 主战·合击 |

典型连招：走圈游走→鹞子穿林绕背→回身劈掌砸背（永远在对方侧后）。

### 形意拳（五行直进·硬打硬进）
定位：直进直取，半步崩拳打天下。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 崩拳 | 半步直进+拳沿中线崩出，整劲透体 | 主战·核心招式 |
| 劈拳 | 拳臂如斧劈落，劈砸对方中线 | 主战·重击 |
| 钻拳 | 拳沿螺旋钻出，穿破防线 | 破招·突破 |
| 炮拳 | 沉身发力如炮弹出膛 | 终结·爆发 |
| 虎形 | 扑身双爪，气势压人 | 终结·猛扑 |

典型连招：半步崩拳连打→钻拳破防→炮拳收尾。

## 二、腿法系

### 谭腿（十二路·招小速快）
定位：弹踩截蹬劈挂撩扫鞭踹膝摆十二路，低位快、高位狠。
| 路 | 招式 | 动作要点 | 使用场景 |
|----|------|---------|---------|
| 1 | 弹 | 小腿屈伸弹出如弹弓，快弹快收 | 试探+连弹 |
| 2 | 踩 | 脚掌千斤坠踩踏，踩住即控 | 破势+压制 |
| 3 | 截 | 以腿截腿，截在半途 | 防守反击核心 |
| 4 | 蹬 | 脚跟直线蹬出如攻城锤 | 拉距+重击 |
| 5 | 劈 | 腿高举过顶劈落如斧 | 大幅博眼·终结 |
| 7 | 撩 | 腿由下向上撩起挑击 | 低位偷袭要害 |
| 8 | 扫 | 贴地横扫下盘如秋风扫叶 | 破下盘+扫倒 |
| 9 | 鞭 | 转腰带腿横扫如鞭抽 | 中段杀伤最大 |
| 10 | 踹 | 侧身侧踹如侧炮封门 | 横向推开+重击 |
| 11 | 膝 | 提膝贴身撞击 | 贴身终结·暴击 |
| 12 | 摆 | 髋为轴画弧摆击如钟摆 | 连击收尾 |

节奏三段：前段弹踩截蹬（轻→重）→ 中段劈挂撩扫（变化最大）→ 后段鞭踹膝摆（重→暴击→收）。
高度三级：低位（弹踩截扫·不过膝）/ 中位（挂撩鞭踹·齐腰）/ 高位（劈蹬膝摆·过肩·博眼）。

### 蔡拳（偏门快打·三角低马）
定位：三角低马消身借力，主攻偏门，离桥抢攻，不粘桥久耗。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 凤眼插指 | 凤眼指直线刺咽喉/心口，后手护面 | 过渡牵制 |
| 侧身挂捶 | 侧滑消身，拳背大圆弧下挂劈 | 破招过渡 |
| 横哨扫掌 | 转腰长桥横向平扫肋腰 | 主战压制 |
| 三角钉腿 | 低位直线钉踏大腿/膝盖，藏于桥下 | 破招牵制 |
| 消身顶肘 | 滑至偏门扣臂顶肘撞肋 | 主战/破招 |
| 离桥分桥 | 双掌分拨不粘桥，抢步切偏门 | 破招过渡 |
| 偷步标拳 | 偷步贴近后手直线贯穿重拳 | 主战 |
| 借力旋撞 | 绕后借回身惯性旋身撞背 | 情绪拐点/终结 |
| 跃步穿打 | 腾空跃步指尖穿插腋下肋下 | 终结 |

典型连招：凤眼插指→侧身挂捶→横哨扫掌 / 离桥分桥→偷步标拳→消身顶肘 / 三角钉腿→低步勾弹→跃步穿打。

### 巴西战舞（低姿翻转·反常识出腿）
定位：身体倒置/贴地/旋转，攻击角度反常识，翻滚=闪避+位移+蓄力+出腿。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 库拉多低位扫踢 | 单手撑地极低位贴地横扫脚踝 | 破招·死角反击 |
| 阿乌空翻 | 双手撑地完整侧空翻脱离攻击线 | 闪避+逆转 |
| 马尔特洛翻转踢 | 身体翻转腿从侧上/空中斜线扫出 | 主战·倒置攻击 |
| 安哥拉侧旋踢 | 撑地旋转如陀螺出腿 | 主战·旋转压制 |
| 奇达戈俯冲劈掌 | 腾空俯冲劈掌 | 终结·高位打击 |
| 本吉跳跃顶击 | 跳跃腾空顶击 | 终结 |

### 跆拳道（腾空炫技·博眼担当）
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 540°旋风踢 | 腾空水平旋身 540° 踢出（水平旋身非竖向翻腾） | 终结·视觉巅峰 |
| 下劈 | 腿高举过顶垂直劈落 | 终结·重击 |
| 后旋踢 | 转身后旋扫击 | 破招·逆转 |

## 三、摔投锁控系

### 柔道（投摔·借力翻摔）
定位：以摔为主，借对方冲力/重心翻转，站立→地面一气呵成。
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 背负投 | 抓臂转身将对方从肩上翻摔身前 | 终结·过肩翻摔 |
| 大外刈 | 扫断支撑腿+身后推压，对方直接摔倒 | 主战·腿扫翻摔 |
| 内股 | 腿从内侧挑起对方大腿借冲力翻转 | 破招·逆转 |
| 巴投 | 自身先倒地用脚蹬腹将对方翻过头顶 | 逆转·捨身技 |
| 出足扫 | 扫对方支撑脚踝 | 破招·快速摔倒 |
| 扫腰 | 转腰扫腿带摔 | 主战 |

### 柔术（地面锁控·终结绞杀）
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 十字固 | 控臂反向压肘，关节反锁 | 终结·地面降服 |
| 三角绞 | 双腿锁颈绞杀 | 终结·锁控 |
| 裸绞 | 背后双臂锁喉 | 终结·暗杀 |
| 下潜抱摔 | 下潜抱腿摔倒 | 破招·切入地面 |

### 擒拿（反关节·控械夺刃）
| 招式 | 动作要点 | 使用场景 |
|------|---------|---------|
| 抓腕反扭 | 抓腕反向扭转迫使松手/转身 | 破招·卸械 |
| 锁肘 | 反关节锁死肘部 | 控制 |
| 别臂按压 | 别臂压肩压制 | 控制 |

## 四、身法系（玄幻位移）

| 身法 | 动作要点 | 使用场景 |
|------|---------|---------|
| 凌波微步 | 踏六十四卦方位行进，身体方向与脚步方向不一致，每一步都在意外位置 | 玄幻·不可预测走位 |
| 踏雪无痕 | 高速移动不留痕，残影连连 | 高速突进 |
| 缩地成寸 | 一步跨出瞬移数丈 | 拉距/切入 |
| 燕子三抄水 | 连续三次借力腾跃，空中换向 | 腾空连变 |
| 八步赶蝉 | 八步之内追至身后 | 追击 |
| 幻影换位 | 残影迷惑+真身换位 | 逆转·迷惑 |

## 五、兵器系精选

### 剑法（快剑/破招/博眼三型）
| 体系 | 定位 | 代表招式 |
|------|------|---------|
| 华山基础剑法 | 正统快剑·主战 | 白虹贯日（直刺）、金雁横空（横斩）、苍松迎客（防守起手）、天马行空（腾空刺） |
| 独孤九剑 | 破招专精·后发先至 | 破刀式、破剑式、寻瑕刺隙、虚引实击、回身断势（先读专项库） |
| 玉女十九剑 | 缠斗锁械·以柔制刚 | 流云叠影（连刺）、缠剑锁械、回身绕刺、碎星点刺 |
| 峨眉子午剑 | 脆劲快刺·点穴专精 | 子午穿心、闪步突刺、旋腕点目、低扫绊足 |

**剑招写法公式**（兵器转提示词）：`[角色]+[步法/重心]+[身体发力]+[剑身部位]+[攻击轨迹]+[命中/格挡目标]+[剑身反馈]+[镜头目的]`
示例：`青岚碎步贴近，腰胯小幅拧转，剑尖走极小侧弧绕开对手剑锋中线，直线点刺持械手腕，剑尖命中瞬间爆出冷白星芒；特写·45°斜侧平视·急速推镜·推进至剑尖刺入手腕破绽处定格0.2秒。`
