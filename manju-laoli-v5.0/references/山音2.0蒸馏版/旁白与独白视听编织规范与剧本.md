# 旁白（VO）与内心独白（OS）视听编织规范与剧本（山音2.0版）

本标准旨在解决短剧/漫剧创作中**“旁白泛滥导致变成广播剧”**或**“内心独白变成说教工具”**的通病。**
**我们坚持：**“声画分离、高反差对比、严格控制篇幅。”** 旁白与独白不仅是听觉线索，更是引爆视觉画面深度的“结构件”。

---

## 📐 一、 旁白与内心独白三大编织纪律

### 1. 篇幅比例钢性卡口（防止“听书化”）
- 在 90-120 秒的单集中，声音容量分配必须严格遵守以下黄金比例：

```
                    ┌─── [单集总时长 100%] ───┐
                    │                         │
            【动作/画面留白】             【声音/台词容量】
               (约 40%-50%)                 (约 50%-60%)
                    │                         │
                    │         ┌───────────────┴───────────────┐
                    │         │                               │
                    │     【旁白/独白 (VO/OS)】           【角色开口台词】
                    │       (占声音容量 ≤ 30%)             (占声音容量 ≥ 70%)
```

- **字数上限**：1分钟成片中，旁白+独白总字数**严格控制在 60-80 字以内**，给画面留出足够的动作反应时间。

### 2. 内心独白（OS - Off Screen）的“声画分离红线”
- **铁律**：当配音台词为“内心独白”时，**画面中的角色绝对不许张嘴**。
- **画面承载标准**：必须用闭口神态、瞳孔收缩、紧捏的手指、或者环境（如：雨水打在睫毛上）等极其精细的微特写，来承载内心独白的声音张力。
- ❌ *错误描述*：`陆渊（内心想）：顾家，我一定要让你们付出代价！`（画面写“陆渊愤怒地看着镜头” ── 扁平，无张力）。
- ✅ *正确描述*：`【画面】陆渊低着头，任由冰冷的雨水顺着睫毛滑落。他那双纯黑的眼睛死死盯着橱窗里顾城的广告巨幕，一动不动。` + `【音效】高频的耳鸣蜂鸣音（SFX）。` + `陆渊（内心独白，OS）：这是顾家，偷走沈家的第三千天。`

### 3. 画外旁白（VO - Voice Over）的“冷漠审视法则”
- *功能定位*：旁白（VO）不是用来翻译画面动作的，而是用来**提供与画面高反差的信息差**，或者提供客观、冷静、近乎残酷的时空审视。
- ❌ *错误旁白*：`旁白：“沈惊秋无助地走在雨中，她感到极其绝望。”`（直接违反“去心理描写”红线，且复述了画面）。
- ✅ *正确旁白*：`【画面】沈惊秋穿着破烂麻衣，浑身湿透，一步步走在繁华、霓虹闪烁的帝都街头。` + `旁白（VO，冷漠，机械）：帝都，每分钟有十个新公司注册，也有十个沈家这样的名门，无声蒸发。`

## 🎬 二、 旁白与独白交织实战剧本：《黑石深处》

- **时长规划**：90秒。
- **题材风格**：都市悬疑、复仇、黑色电影质感。
- **声画结构**：旁白（VO，时代审视） + 内心独白（OS，男主面具之下的真实力量） + 极简台词（5句以内，子弹律）。
