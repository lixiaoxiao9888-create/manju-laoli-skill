# 变身戏 10s 提示词（用户验证示例）

> 由漫剧老李 V2.2 §4.6 动作戏专项生成，用户确认「这个变身不错」。作为变身戏模板的实战参考。

**【风格】** 3D国漫唯美风格融合破坏美学，超写实3D渲染，虚幻引擎5极致画质，电影级暗光质感，高对比度光影，主色调从觉醒的粉金白过渡到狂暴粉紫，情绪从内敛觉醒到炸裂释放

**【镜头】** 24mm广角建立空间，中景环绕升格慢镜起手，随后推近至面部特写，爆发段急速拉出转为全景跟随毁灭洪流，镜头轻微呼吸感，跟随能量流动方向

**【时间轴】**

0-1.5s：花汐跪在水晶高台中央，粗糙麻布祭袍垂落，双手交叠在膝前。高台四周云海翻涌，几十名华服群众如玩偶般静立。镜头环绕慢移，麻布表面粗粝纹理清晰可见。（低沉能量嗡鸣声）

1.5-3s：麻布祭袍从肩部开始崩解——布料撕裂成无数发光碎片，碎片脱离身体后悬停在空中，边缘泛着金色微光。花汐指尖轻颤，瞳孔缓慢放大，睫毛颤动。（布料撕裂声、玻璃碎裂声）

3-4.5s：发光碎片与金色流光沿身体环绕升腾，发丝无风自扬。空气在碎片周围轻微扭曲。特写瞳孔——花影虚像与神光在虹膜中浮现，泪珠悬在眼角未落。（能量嗡鸣渐强，碎片碰撞的细碎声响）

4.5-6s：四周花瓣与光粒从云海汇聚，沿身体曲线高速重组——锋利半透明的花瓣层层嵌合，咔嗒声响成一片，战裙从腰部向上蔓延成形，裙摆边缘花瓣如刃。（花瓣嵌合的密集咔嗒声）

6-7.5s：战裙成形瞬间，粉色花海龙卷以花汐为中心炸开——亿万花刃旋转扩散，水晶高台被犁出数米深裂痕，宫殿廊柱表面沙化剥落。花汐单手向下压出裁决姿态，衣袂与裙摆在冲击波中狂舞。（风暴呼啸声、能量爆炸声）

7.5-9s：花汐立于高台中央，神光瞳孔直视前方，战裙花瓣在余波中微微震颤。四周粉尘缓缓沉降，围观群众衣袍被气浪掀动后静止。（能量余韵的低鸣）

9-10s：慢推镜头逼近花汐面部——瞳孔中神光收敛，嘴角极轻微上扬。背后建筑在灰白粉尘中坍缩湮灭，环境归于静默。（湮灭声、环境静默）

**【声音】** 低沉能量嗡鸣、布料撕裂崩解声、玻璃碎裂声、碎片碰撞细响、花瓣嵌合咔嗒声、风暴呼啸、能量爆炸、湮灭闷响、环境静默收尾

**无字幕，无背景音乐**
