> **本文档是交付层核心规则库 · 权威文件**

## 〇、核心原则：先素材，后画面

写提示词时**先说明素材是谁**，再写画面动作。多主体或需跨镜头复用时，人物锚定固定写：

```
将 图1 中的[身份/外观/服装]定义为 <角色名>
```

锚定后，后续镜头只用 `<角色名>` 指代。锚定句**只写定义，不追加说明**。

**关键道具锚定（2026-10-13 新补 · 治「道具在投喂层无 @ 位」）**：道具与人物同理，**先锚定再引用**，但**不新增栏位**——写在【场景资产】栏、与 `@SCN-` 并列：

```
【场景资产】@SCN-xxx（参考图N）；@PRP-xxx（参考图M）  ← M1/M2全能参考极简写法：只@资产与参考图号，严禁二次介绍场景陈设、人物外貌衣着或道具材质（防止文字覆盖/干扰参考图）；随身核心道具（如主角佩剑/法宝/信物）须在持有角色出场的所有段落全程 @ 跟随！（兼容旧式「外观以场景/道具参考图锁定；状态…」）
```

- **只锚关键道具**（承担叙事功能 / 跨镜一致 / 有状态变化）；场景固定陈设随场景母版出图，**不写 `@PRP-`**；
- **M0 无图时**改「道具外观复述」（材质·造型·尺寸基准·色彩/纹样 + 状态轨迹），逐段复述、禁"同上"；
- 判定与完整纪律见总控 `model-adapters.md` §5「道具锚定纪律」；道具出图归 `sd-asset-engine/references/prop-template.md`。

> ⚠️ **M0 替代写法（无图时）**：`<角色名>` 的指代照用，但**不写"将 图N 中的…"**，改为**外观档案复述块**——即每次（每段）首次提及时完整复述该角色的外观五要素（发/服装/体态/年龄感/标志物），**禁止写"同上 / 同前 / 照旧"**。理由：模型每段零记忆，"同上"等于没写（权威与理由见总控 `short-drama-director/references/asset-delivery-modes.md` §三 文字锁）。

## 一、素材编号体系

| 写法 | 对应角色 | 说明 |
|---|---|---|
| **图1 / 图2 / 图3 …** | 总控「图N」体系 | **唯一写法** |
| 视频N | 视频参考 | 动作/运镜参考或被延长视频 |
| 音频N | 音频参考 | 环境声/语气/同步音效 |

⚠️ **禁用写法**：`@图片N` / `@ImageN` / `@Video N` / `asset-xxx` / `CH001` / `SC001` / `ST001` —— 这些是外部包或内部管理编号，**不得出现在最终可投喂提示词里**。

**人物锚定示例**：
```
将 图2 中的青年男性、黑金纹饰旧袍定义为 <玄衡>，将 图3 中的女性、暗青色战衣定义为 <青鸢>
```

## 二·五、参考图投喂顺序约定（战斗/特效重场首选）

> **来源**：吸收自用户玄幻一镜到底参考稿的"参考图顺序"写法。**顺序本身就是优先级声明**——把最需要"锁死"的素材排在前面。

**推荐顺序（场景优先 · 敌人可省）**：

| 序 | 素材 | 为什么排这里 |
|---|---|---|
| ① | **场景** | 空间与光是**刚性锚点**——模型会重绘人物，但不会重绘空间结构；先定空间，后续镜头才有立足点 |
| ② | **主角/核心角色** | 全片出镜最多、最不能漂的资产 |
| ③ | **初始武器 / 关键道具** | 与主角同框的稳定物；有形态变化时用初始形态 |
| ④ | **进阶形态**（武器第二形态 / 变身后形象） | 与③**相邻编号**，帮模型建立"同一角色/同一件器物的两个形态"关联 |
| ⑤ | **敌人 / 群演 / 龙套** | **可无参考图，纯文字描述**——把有限的图位留给更需一致的资产 |

**四条铁律**：

1. **场景永远排第一**——顺序不是"想到哪张写哪张"，场景优先是硬序；
2. **顺序写进《素材接线单》的排列**——用户在平台素材区按单子顺序挂图，顺序 = 接线单行序；
3. **群像/敌人可省图**——省下的图位（按该模型上限：H3 ≤9 / 2.5 ≤30，红线 2）留给更需要一致性的资产；
4. **同角色多形态相邻编号**——避免模型把两个形态当成两个无关主体。

**示例**（对齐接线单行序）：
```
图1 场景母版（浮空仙阙云海）
图2 主角（女剑仙）
图3 初始武器（单剑）
图4 进阶武器（成对双刀）
（敌人/兽潮：无图，纯文字描述）
```

## 三、素材引用红线（11 条）

| # | 红线 |
|---|---|
| 1 | **图号只能有两个来源**：① **用户提供**；② **本次交付的《素材接线单》显式定义**。**除此之外禁止凭空写图号**——尤其禁止"为了提示词看起来完整"补一个编号进去。图号是**给用户的接线说明书**，凭空写＝让用户去挂一张不存在的图 |
| 2 | 每组/每单元实际使用的**图片参考总数**按 A 锁模型取上限：**H3 ≤9 张**（总素材 ≤12）/ **Seedance 2.5 ≤30 张**（总数 ≤50）/ **Seedance 2.0 单图 1 张**。⚠️ **9 张是 H3 的上限，不得套到 Seedance 2.5**（原写死 9 张会人为压制 2.5 的多图一致性能力，2026-10-12 修订） |
| 3 | 参考图状态不是"定稿"时，**必须标注风险** |
| 4 | 同一角色多段尽量用同一图号；锚定后优先用稳定 `<角色名>` |
| 5 | `视频N` **不得同时承担角色/动作/风格/构图四种任务**，必须说明只参考哪一项；延长任务直接写"向后延长 视频1" |
| 6 | 音频参考**必须提醒版权/可商用性** |
| 7 | 启用首帧图时，写清**只控制第 0 秒**，不控制整段动作和结尾状态 |
| 8 | 启用场景角度图时，写清**只控制当前镜头空间方向和透视** |
| 9 | 场景母版/角度图/角色图/道具图/首帧图/调度图**不能互相替代**；每张图都说明"只参考什么/不参考什么" |
| 10 | 首帧图与场景角度/调度图冲突时，**不要输出最终提示词**，先提示重做 |
| 11 | 不把 `asset-xxx`、`CH001`、`ST001` 等内部 ID 直接写进可投喂描述；必须通过图号、`<角色名>` 或自然语言桥接 |

## 四、首帧 / 调度 / 参考图优先级

> ⚠️ **M0 不适用**：本节整体以"图确实存在"为前提。**M0（纯提示词）下不启用任何一条**——本包看不到图，无法核对优先级与冲突，硬写只会产生虚假断言。

同时存在多种素材时，按以下优先级理解：

| 优先级 | 素材 | 锁定内容 | 不继承 |
|---|---|---|---|
| 1 | **首帧图** | 第 0 秒构图、人物初始位置、道具位置、空间侧别、摄影机侧、光影方向 | 整段动作、结尾状态 |
| 2 | **调度图 / 侧别锁定卡** | 空间逻辑、点位、移动路线、摄影机安全区、轴线、内外侧、禁止区 | 画风、人物外观 |
| 3 | **场景角度图** | 当前镜头从哪个方向看同一空间、空间透视、门窗家具相对位置、固定光源方向 | 人物、人群、剧情动作、第 0 秒构图 |
| 4 | **场景母版** | 空间结构、固定家具、门窗、光源、透视、环境风格 | 人物、人群、剧情动作 |
| 5 | **角色图** | 脸型、发型、服装、体态、年龄感 | 场景、临时表情、姿态 |
| 6 | **道具图** | 外观、材质、颜色、状态；文字内容须在提示词另写 | — |

### 冲突处理规则

> ⚠️ **M1 下的根本限制**：本包**看不到图**——因此本节所有"冲突判定"在 M1 下**只能基于文字信息推导**，**不得声称"已比对确认冲突"**。正确动作是**向用户提出需要核对的点**（附"怎么核对"），而不是给出一个基于想象的结论。**M2（图已入库）才可做图像级判定。**

| 冲突 | 处理 |
|---|---|
| 首帧图 ↔ 调度图 | **停止输出**，要求先重做首帧或修正调度图 |
| 首帧图 ↔ 场景角度图 | 先确认角度图是否与场景母版一致；角度图正确 → 重做首帧；角度图与母版冲突 → 重做角度图 |
| 首帧图 ↔ 场景母版 | 优先保留场景母版的空间结构，重做首帧 |
| 场景角度图 ↔ 场景母版 | 优先保留用户确认的场景母版，重做冲突角度图 |
| 首帧图 ↔ 角色/道具外观 | 优先保留角色/道具图，重做首帧或在限制中明确修正 |
| 道具已在场景/角度/首帧可见 + 又引用道具图 | **不视为冲突**，但必须启用**道具单实例锁**；无法判断是否同一件 → 要求用户确认或标注高风险 |

## 五、人物 / 道具锚定细则

**标准句式**：
```
将 图N 中的[身份/外观/服装]定义为 <角色名>
```
**道具写法（不新增栏，并入【场景资产】栏）**：
```
@PRP-道具名（外观以道具参考图锁定；状态：〔初始〕→〔终态〕）
```

**规则**：
1. 锚定句**只写定义，不追加说明**。
2. 没有正式角色名时，临时命名 `<角色A>` / `<角色B>`，仍按同一句式锚定。
3. **不使用编号主体标签**做人物锚定。
4. 如果图号后紧接动词或方位词，必须改成 `<角色名>` 或补名词隔断，**避免数字粘连歧义**。
5. 一致性细节放进素材锚定、镜头限制或段末状态。
6. **道具锚点族 = `@PRP-`**：与 `@CHR-`（人物）、`@SCN-`（场景）并列；**仅关键道具登记**，同一道具跨段/跨集**沿用同一 `@PRP-` 名**（对齐 `prop-template.md` §四 三处同名）；道具的**持握/位移/状态变化**写镜行，锚定行**只锁外观与状态**。

## 六、与总控体系衔接

| **素材形态 M0/M1/M2** | **本文件的前置条件**——权威 = 总控 `short-drama-director/references/asset-delivery-modes.md`。**M0 下本文件的编号/优先级/冲突三节整体不适用** |
