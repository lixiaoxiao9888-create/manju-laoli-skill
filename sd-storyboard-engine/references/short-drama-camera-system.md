# 短剧视感机位体系（景别 · 焦段 · 机位 · 运镜 · 景深 · 群像 · **四轴联动矩阵**）

本文件是分镜引擎的镜头系统规则库。所有机位/运镜设计必须先通过物理可行性检查，再按情绪匹配与频率名额执行；口径按总控锁系统执行（Seedance 2.5 与 2.0 语法分开禁混写）。

## 一、景别约束

- 每个镜头必须标注景别，整组分镜中景别必须有变化，不能连着三个近景。
- 可用景别：大远景 → 远景 → 全景 → 中全景 → 中景 → 中近景 → 近景 → 特写 → 大特写。（**跨段承接口径**：段缝两侧**必须同档（0 级）**——尾帧截图即下段首帧参考、画面须逐档咬合；末镜做了收束动作的禁反向收紧 ≥1 级，未做收束的最多容忍 1 级——见 `short-drama-director/references/segment-splicing.md` §四·补）
- 基础规则：情绪越强，景别越紧。动作越大，景别越松。
- 每组镜头至少包含：1个大景别（定场/环境）、1个特写（情绪锚点）、1个中景（信息交代）。
- 景别必须匹配场景物理空间（见 `scene-space-adaptation.md`）：室内封闭小空间最大景别上限是全景，禁止大远景、远景、鸟瞰。

### 景别与情绪反规则

重锤情绪反着用更有力，每场戏至少识别1个反规则机会点：

- 悲伤/绝望爆发 → 反而拉远（拉镜或切大景别），让人物在环境中渺小。
- 震撼/认知崩塌 → 反而固定大特写，让观众无处可逃。
- 暴力/冲击瞬间 → 反而切空镜或拉远，留白让观众脑补。
- 孤独/被遗弃 → 反而用大景别人物居中构图。
- 判断标准：常规情绪用基础规则（越强越紧）；重锤情绪（生死、离别、真相、崩溃）反着用。

### 对话场景景别递进

1. 开场定场：第一个镜头必须是中景或全景，交代谁在场、站位、空间关系。禁止对话开场直接给特写或近景。
2. 对话推进：侧45度过肩中景/中近景正反打为主，保持空间连贯。
3. 情绪爆点：才推到特写/大特写。
4. **特写比例区间 25%~40%**（仅限人物特写，物件特写不计入）。**机检 C18n 兜底**（`short-drama-director/scripts/validate_prompt.py`，越区间报 WARN）。
   - **「人物特写」定义（2026-10-13 补齐 · 治口径歧义）**：画面主体为**人物的面部 / 眼睛 / 或人的身体局部（手、拳、肩背等肢体）**，且承担表演或情绪功能 → **计入**。
   - **「物件特写」定义**：画面主体为**非人的物**（道具、器物、环境物件：榜文 / 旗面 / 街灯 / 马具 / 信件 / 玉佩等）→ **不计入配额**。
   - **⚑ 判定基准（机检同此口径）**：镜行内**有人物锚点（`@人名` / `@CHR-`）或人体部位词** → 判人物特写；**两者皆无** → 判物件特写，剔除。
   - ⚠️ **历史教训（2026-10-13）**：本区间此前**只有规则、没有断言** —— 某项目 72 镜人物特写仅 **19.4%**（低于下限）而机检零告警。「只写不检」＝不生效。
5. 每段对话至少1个双人同框关系镜头。

6. **长对白段必有关系镜**：段内含台词镜 ≥6 时，段内至少安排 1 个**过肩双人反打**镜；双侧摆位 ≥2 人时，至少 1 个镜头**两人同框**。二者**满足其一即可**。缺则全程单人正拍轮切，观众读不出「在对谁说话」，关系戏塌成两段独白。机检 **C17b** 兜底（WARN 级，不阻断）；**豁免三类**：单人对镜独白、电话/远程对话、一方已离场。

（注：特写 **25%~40%** 是**景别维度**的区间，非"不超过 40% 即可"——低于 25% 说明该给的特写没给（详见下节场景清单）；常规镜头 ≤30% 是**机位维度**，两者独立达标、互不抵扣。**机检 C18n 按镜行口径统计：含人体局部肢体、剔除纯物件特写；镜数 <6 不判。**）

#### 特写使用铁律与场景清单（粉丝实测反馈并入）

> 📌 **来源**：粉丝「森林」实测反馈（2026-09-29）——「可以在 skill 里面提示词多加入一点特写镜头，少一点空镜头吗」。核实发现：特写原来**只有 40% 上限、没有下限、也没有场景指引**——规则只说"不许太多"，从没说"什么时候必须用"，导致实操中特写被压到偏低。本节把"上限"补成"**区间 + 必须给特写的场景清单**"。

**特写不是"可选项"而是"情绪工具"**——它把观众的注意力强行锁在一点上，是短剧最省成本的强调手段。区间 **25%~40%**：低于 25% 说明该给的特写没给（情绪落不了地）；高于 40% 说明滥用（人脸廉价化、节奏碎）。

**以下 5 类场景，必须给特写（不允许只用中景带过）**：

| 场景 | 为何必须特写 | 写法要点 |
|---|---|---|
| **情绪拐点** | 人物态度/心境转变的瞬间，只有特写能承载 | 转变**发生的那一帧**给特写，非转变全程；配微表情（见 `shot-economy-and-acting.md` §五·五） |
| **关键道具** | 道具是剧情钥匙（信件/玉佩/证据/伤口），特写起"指认"作用 | 用物件特写（不计入人物特写配额）；画面要"进行中"（正在被拿起/被看到），非静态陈列 |
| **眼神记忆点** | 短剧靠"一个眼神"立人设/留钩子 | 给大特写（眼+眉），眼神要有明确对象与情绪，忌空洞平视 |
| **台词重音** | 关键台词的重音字/句尾，特写放大器 | 特写挂在这一句上；忌每句都特写（只给重音句） |
| **反应镜头** | 听者对关键信息的反应比说话更有戏 | 听者反应特写，与说话镜构成正反打；反应要有具体变化（非重复前一镜） |

**以下场景，禁止给特写**：

- 开场定场镜（必须先给中景/全景交代空间，见上文第 1 条）；
- 需要同时交代空间关系的镜头（特写承载不了空间级事件，与总控 C18d 一致）；
- 同一情绪连续第 3 个特写（情绪重复＝废镜，见镜头经济性）；
- 无明确情绪/信息任务的特写（凑数镜）。

**自检（不输出）**：全段通读——(1) 特写占比是否落在 25%~40%？(2) 五类必给场景是否都给了特写？(3) 是否有"禁止场景"误给了特写？

### 景别与表演幅度绑定（2026-10-10 并入）

景别决定表演幅度——**每个景别只能写它装得下的东西**。写入超出景别容纳范围的身体或人物，模型会直接生成错误画面。这是"画面内容"字段的硬边界，与 §六 群像 A/B 档互补。

| 景别 | 只能写 | 禁止写 |
|------|--------|--------|
| **特写 / 大特写** | 眼皮、眨眼、眼神焦点、唇线、喉咙、下颌、鼻息、尾音、气断、沉默余味 | 大幅肢体动作；胸部以下、完整腿脚、远处人物、复杂空间关系（局部手部或局部道具**仅在确实入画时**写） |
| **近景 / 中近景** | 眉心、眼神路径、嘴角、呼吸、肩颈、手指小动作、轻微重心变化；与对方的距离、前景遮挡、视线关系 | 多人完整站位、完整道具传递路径、需展示手脚的动作（此类改中景/全景或拆镜） |
| **中景 / 半身** | 手部、肩线、重心、身体前压/后撤、与桌/门框/床沿/墙角等锚点的关系；面部反应清晰但不堆细节 | 堆满五官细节 |
| **全景 / 远景** | 身体线条、站位、步伐、距离变化、关系压迫、空间隔离、人物被环境吞没或推到边缘 | 复杂微表情 |

**密度互斥（信息量守恒）**：运动镜头复杂时，演员动作减半；演员动作复杂时，镜头运动简化；台词复杂时，画面动作简化；情绪复杂时，空间动作简化。静态近景表演细节可以更密，但仍不得过载。

### 景别占比预算表（★ 2026-10-16 新增 · 补「景别维度只有特写一个区间」的缺口）

> **缺口由来（粉丝「森林」2026-10-16 反馈 · 核验属实）**：景别维度此前**只有「特写 25%~40%」一个区间**，大远景/远景/全景/中全景/中景/中近景/近景**全无占比预算**——执行者只能靠「阶梯跃迁」+「别连着三个近景」这类软约束兜，整段景别分布全凭手感。本节把景别维度补成**一张表**。
>
> ⚠️ **与机位维度分开读**：本节是**景别维度**预算；「常规镜头 ≤30% / 侧45度 30%~40% / 侧面（90°）≤15%」是**机位维度**（§三 机位配比铁律），两者**独立达标、互不抵扣**（同本节上方「特写区间」注）。
>
> ⚠️ **基准性质（★ 必读）**：下表区间是**起步基准（推演值）**——由本包既有软约束量化收敛而来，**不是平台实测数据**。项目首次使用应按成片实拍反馈校准，校准结果写进项目台账；**窄幅变体（如全程紧景别的心理惊悚向）须显式声明理由**，不得静默越界。

| 景别（§一 九档归并） | 文戏 / 对话段 | 打戏 / 动作段 | 说明 |
|---|---|---|---|
| 大远景 / 远景 | 0%~10% | 5%~15% | 定场 / 环境交代；室内封闭空间按 `scene-space-adaptation.md` 禁大远景 |
| 全景 / 中全景 | 10%~20% | 20%~35% | 空间关系 / 群像 / 位移展示 |
| 中景 | 15%~25% | 15%~30% | 信息交代主力档 |
| 中近景 | 15%~25% | 10%~20% | 对话主力档 |
| 近景 | 5%~15% | 5%~15% | 情绪逼近；**禁连续 ≥3 镜**（§一） |
| 特写 / 大特写 | **25%~40%** | 10%~25% | 文戏沿用既有区间（机检 **C18n**）；打戏特写是情绪锚点，**不设 25% 下限** |

**三条读表纪律**：

1. **是体检表，不是配额表**——区间用于**事后核对分布**，不是"必须凑够"；某档落在区间内**不等于**合格（每镜仍须有对应情绪/信息任务，见 §九 画面内容约束）。
2. **下限同样有效**——低于下限＝该给的镜头没给（与特写区间的逻辑同源）；高于上限＝该档滥用（如近景堆满＝情绪钝化）。
3. **小样本不判**——段内镜数 <6 时只看 §一 的最低结构要求（≥1 大景别 + 1 特写 + 1 中景），**不套占比区间**（与 C18n「镜数 <6 不判」同口径）。六档**中位值之和 ≈100%**，允许按题材 ±10% 整体漂移。

## 二、焦段约束

每个镜头必须标注焦段。焦段是叙事工具——决定空间感、透视关系和情绪张力。

> ⚠️ **与 C20m 的分工（2026-10-24 P9 补）**：焦段写在**镜行头**（`景别 · 焦段 · 角度 · 运镜`），这是元数据槽，**C33 要求必填**；
> `C20m` 禁的是把同一套相机术语写进**镜行正文的动作描写**（`焦平面全程死锁面部无漂移`）。
> 一句话：**头上写焦段 = 必须；正文写相机参数 = 禁止。** 详见 `short-drama-director/references/model-adapters.md` §光影片段·边界②。

| 焦段 | 等效焦距 | 叙事用途 |
|------|----------|----------|
| 鱼眼 | 8-16mm | 癫狂/迷幻/主观失衡，慎用 |
| 超广角 | 14-24mm | 史诗场景/建立镜头/英雄登场 |
| 广角 | 24-35mm | 环境交代/室内全景/群体场面 |
| 标准 | 35-50mm | 日常叙事/中景对话/客观记录 |
| 中长焦 | 85-100mm | 人物特写/肖像/情绪逼近 |
| 长焦 | 135-200mm+ | 远距离观察/偷窥/孤立感 |
| 微距 | 1:1放大 | 极致细节/泪滴/纹理/关键道具 |

选择规则：

- 大景别 → 超广角或广角。禁止用标准焦段拍大远景。
- 人物特写/肖像 → 中长焦85mm。禁止用广角拍人物近景（除非刻意扭曲——如广角+大仰角制造威压畸变，须为情绪服务）。
- 远距离观察/偷窥 → 长焦。极致细节 → 微距。混乱/精神崩溃 → 鱼眼（一部片最多1-2次）。
- 焦段必须匹配场景物理空间（见 `scene-space-adaptation.md`）。
- 全片至少使用4种不同焦段（在场景物理允许范围内）。

### 景别 → 焦段 逐级对照表（★ 2026-10-16 新增 · 补齐「中近景 / 近景」空档）

> **缺口由来（粉丝「森林」2026-10-16 反馈 · 核验部分属实）**：此前**硬绑定/硬禁令只有两条**——① 大景别 → 超广角/广角·禁标准；② 特写/肖像 → 85mm·禁广角。全景/中景只能从上方焦段表的「叙事用途」列**推导**（广角=室内全景/群体场面、标准=中景对话），而**中近景 / 近景两档完全没有落点**。本节把逐级对照补齐——**不是新增禁令，是把既有口径摊平成一张正列表**。

| 景别 | 首选焦段 | 允许区间 | 禁用 / 越界条件 | 依据 |
|---|---|---|---|---|
| 大远景 / 远景 | 超广角 14-24mm | 14-28mm | 标准 35-50mm 拍大远景 | 既有硬绑定① |
| 全景 / 中全景 | 广角 24-35mm | 24-50mm | 室内长焦 >135mm（S1 层高不足） | 焦段表「室内全景/群体场面」+ `scene-space-adaptation.md` §S1 |
| 中景 | 标准 35-50mm | 28-85mm | — | 焦段表「中景对话」 |
| **中近景** | **中长焦 85mm** | **50-100mm** | 广角 <24mm | ★本次补齐：卡在「标准 ↔ 中长焦」之间，对话半身镜 |
| **近景** | **中长焦 85-100mm** | **85-135mm** | 广角 <35mm（既有「禁广角拍人物近景」的正面落点） | ★本次补齐 |
| 特写 / 大特写 | 中长焦 85mm | 85-200mm | 广角（除刻意畸变，须为情绪服务） | 既有硬绑定② |
| 极致细节（泪滴/纹理/关键道具） | 微距 1:1 | — | — | 焦段表 |

**两条读表纪律**：

1. **超出「允许区间」＝须在镜行写明理由**（如「广角 + 大仰角制造威压畸变」）——既有口径照旧，本节只是把它从"两条"扩到"逐级"；
2. **与 §五 景深联动**：中近景/近景/特写 → 浅景深；中景以下 → 可按 §五 变化；强浅景深时降低物理雾或 diffusion（§五）。

## 三、短剧视感机位体系

每个镜头必须标注机位角度。不允许全程平视。

机位由**方向轴 × 高度轴**共同定位，两轴可自由组合（如"侧45度+大仰角"），组合让单一镜头同时携带方向与高度的双重情绪。

### 方向轴

| 角度 | 情绪表达 | 适用 |
|------|----------|------|
| 正面 | 直接、坦荡、对抗 | 面对面对峙/坦白/摊牌 |
| 侧45度 | 张力与交流并存、立体、有层次 | 对话与叙事的默认机位——对峙/试探/暗涌/权谋 |
| 侧面（90°） | 隔绝、疏离、心门关闭、美学构图 | 回避/诀别/内心封闭/独白式疏离 |
| 过肩 | 对话经典，建立空间关系 | 双人对话/对峙 |
| 主观视角POV | 沉浸代入 | 角色视角/恐惧/发现 |

### 高度轴

| 角度 | 情绪表达 | 适用 |
|------|----------|------|
| 平视 | 中性、平等、客观 | 日常叙事、中性对话 |
| 微仰/微俯（≤15°） | 隐性的强弱暗示 | 常规叙事的隐形调味 |
| 仰拍（15°-45°） | 力量、威严、压迫、英雄感 | 英雄登场/强者/施压 |
| 俯拍（15°-45°） | 弱小、孤独、无助 | 弱者/受害者/失败者 |
| 大仰角（45°以上） | 压倒性力量、神圣或恐怖、巨物感 | 权力碾压/威慑时刻/恐惧源头/不可抗力 |
| 大俯角（45°以上） | 被世界碾过、彻底的绝望、宿命 | 惨败/被遗弃/极致孤独/宿命时刻 |
| 鸟瞰/上帝视角 | 全知、宿命、渺小感 | 地理交代/战场全景/宿命 |
| 荷兰角 | 世界失衡、认知崩塌、心理异变 | 真相揭露/精神防线击穿（每集≤1镜或不用，见下） |

### 机位配比铁律（短剧视感核心）

口径：一次输入的全部原文视作一集；多场景分文档输出时，名额在全集内统筹分配。

- **常规镜头占比≤30%（区间25%-35%）**。常规镜头=平视（含≤15°微仰微俯）+正面或纯过肩+平稳运镜（固定/缓慢推拉横移），无手持晃动、无荷兰角。常规镜头是呼吸与基准线——定场、过渡、留白、平静对话用它，让激进机位有对比、有落差、有重锤感。压到三成不是消灭常规，而是让每一个常规镜头都有存在的理由。
- **侧45度是对话与叙事的默认机位**，建议占全片30%-40%——比正面立体、比侧面保留交流感，是短剧视感的主力。
- **侧面（90°）≤15%**，只给心门关闭级时刻：回避、诀别、内心封闭、独白式疏离。侧脸必须配轮廓光（有源——窗/灯/火/霓虹），无轮廓光的糊黑侧脸不合格；人物侧面贴墙时改用侧45度。
- **大仰角与大俯角各≤3次/集**，只给权力与命运的顶点时刻。二者对切（大仰角拍强者→大俯角拍弱者）是权力碾压的经典组合，各算各的名额；单一大仰角或大俯角连用不超过2镜。
- **荷兰角每集≤1镜，或选择不用**。必须落在全集心理最失衡的一瞬——真相击穿、精神崩塌、世界观倾覆；倾斜幅度10°-20°，轻微到看不出来=没用，夸张到滑稽=失控。全集没有够格的失衡时刻就不用，绝不硬凑。
- 激进机位必须由画面情绪买单：有对应情绪节点却仍全程平视=浪费机会；无对应情绪节点硬上倾斜俯仰=炫技废镜。两种都禁止。
- 全片至少6种不同机位角度（方向×高度组合计为不同角度），连续3个镜头不得全部平视正面。口径说明：单场景输出时物理与情绪机会不足6种不硬凑——单场至少覆盖4种，侧45度优先；多场景累计达到6种。

### 物理可行性检查

- 大仰角机位贴近地面或腰部以下向上拍，室内外均可；广角+大仰角的透视畸变可用于威压扭曲（刻意为之则放行）。
- 大俯角必须找到真实高点（楼梯口/二层回廊/高柜顶部/门框上沿/山坡/天桥），室内普通层高（S1/S2）无高点可用时降级为30°-45°俯拍，禁止凭空悬空机位。
- 侧面机位需要人物侧向有放置空间——侧面贴墙会拍到一面墙皮，改用侧45度。
- 鸟瞰要求镜头能放到场景正上方3米以上，室内普通房间层高不足禁止使用。
- 过肩需要机位能退到人物背后至少1.5-2米。

### 机位角度反规则

- 阴险反派 → 平视或微仰（近在咫尺的威胁比崇高更阴险）。
- 受害者的恐惧 → 大仰角拍施暴者（代入受害者视角，压迫感最大化）。
- 失败者的尊严 → 平视（保留人格）——绝境中反而平视，是他最后的体面。
- 英雄的脆弱瞬间 → 俯拍（立体化）。
- 强者从神坛跌落 → 大俯角（从云端跌进尘埃）。
- 每场戏可识别1-2个反规则机会点。

（注：景别反规则每场**至少 1 个**，机位反规则每场 **1-2 个**，两者独立计数、不合并。）

### 过肩镜头几何 · 左右前景判定（2026-10-10 并入）

过肩是对话戏的主力机位，也是最容易写错的机位——**左右前景写反，模型会把肩膀挡在错的位置，甚至把前后景人物颠倒**。写"过肩"必须**同时写清摄影机在被越角色的背后还是前侧、越过哪一侧肩**，并按下表落到画面左右前景：

| 过肩类型 | 摄影机位置 | 画面**左**前景 | 画面**右**前景 |
|---|---|---|---|
| 后肩过右肩 | 角色**背后** | 该角色右肩 | — |
| 后肩过左肩 | 角色**背后** | — | 该角色左肩 |
| 前肩过右前肩 | 角色**前侧**、向其身后拍 | — | 该角色右前肩 |
| 前肩过左前肩 | 角色**前侧**、向其身后拍 | 该角色左前肩 | — |

- **前肩过肩只保留**前景角色的相应肩部、侧颈或少量侧脸边缘，**完整正脸与躯干不入画**；
- 后方主体必须与前景角色存在**足够横向错位、能从该机位真实露出**；若二人前后完全重合被前景挡住，**不得写"后方人物可见"**；
- 无法确定摄影机在背后还是前侧、或越过哪一侧肩时，**不得含混写"左/右前景"**——先明确人物朝向与摄影机位置再写；
- 需**区分三种左右**：物理空间左右、画面构图左右、人物自身左右；摄影机换位或反打可以改变**画面左右**，但**不得因此改写人物的物理位置或自身左右**。

### 摄影几何四步流程 · 每镜先定机位再定可见内容（2026-10-10 并入）

**禁止先写构图 / 画面内容、再倒推机位。** 写每一镜前，内部按固定顺序完成判定：

1. **读上一镜结束状态**——人物站位、朝向、视线、关键道具控制者；
2. **定位本镜摄影机**——位置与观察方向，确认是同侧、过肩还是反打；
3. **判定可见性**——从该机位实际可见的人物、身体范围、道具、前中后景与遮挡关系；
4. **只写第 3 步成立的内容**——需要展示完整位移、多人关系或完整道具路径时，改用足够宽的景别。

- 构图按 `摄影机位置 → 主体 → 实际可见前景 → 实际可见后景/遮挡 → 景别可见范围` 依次判断；
- **反打镜头由新机位独立重建**前后景——上一镜的后景角色**不会**因剪辑自动出现在反打里；只有沿新机位视线真实可见、且未被前景人物或道具遮挡的角色，才能写入该镜；
- 不可见角色写"**不入画**"，**不得为了说明其仍在场而虚构后景**；
- 构图、机位、画面内容若互相矛盾，**以实际摄影机位置与可见性为准**，并重写其余字段。

### 三·五 · 形态 → 机位适配（ESTHETIC-BASE-TO-CAMERA · ★ 2026-10-13 新增）

> **由来（粉丝系统性实测反馈）**：「**3d 的分镜因为是横屏，如非必要不要给平视的脸部特写（应该是带点角度的侧视）**」；「3d 和仿真人的微表情要做深入补充」。
> **病根**：本引擎此前**完全不感知影像基底**——I 画风锁（真人 / 2D / 3D / 水墨）对分镜**不可见**，同一套机位规则通吃；且**没有「特写 × 平视正面」的组合级禁令**——现有规则分别管**方向轴、高度轴、景别轴**，**没有一条管"组合"**，执行者写 `特写 | 正面 | 平视` 完全合规（方向=正面是"坦荡对抗"合法选择、高度=平视是"中性客观"合法选择）。

基底取值见总控 `short-drama-director/references/style-bible/style-lock-protocol.md` §三 与 `short-drama-director/scripts/style-lock-ladder.py`：`BASE_LIVE`（真人实拍）/ `BASE_ANIME`（3D CG · 半写实仿真人）/ `BASE_2D`（2D 手绘）/ `BASE_INK`（水墨二维）。

| 基底 | 人物脸部特写 · 角度策略 | 正面平视脸特写配额 | 备注 |
|---|---|---|---|
| **BASE_ANIME**（3D CG / 半写实仿真人） | **必须带角度**：侧 45 度 / 侧面 / 微俯 / 微仰 | ⛔ **0（默认禁用）** —— 除非「正面对峙 / 摊牌」有明确情绪理由且镜行写明 | 3D 模型正面平贴脸出片「无纵深、塑料感、易恐怖谷」——**粉丝主诉病灶** |
| **BASE_LIVE**（真人实拍） | 可正面平视，但**须守配额** | **≤ 人物特写总数的 1/3** | 真人无恐怖谷，仍受「常规镜头 ≤30%」总量约束 |
| **BASE_2D**（2D 手绘） | 以**风格化为准** | 可用，但**同场连用 ≤2 次** | 手绘不存在恐怖谷，正面平视脸是合法风格选择 |
| **BASE_INK**（水墨二维） | 同 2D 口径 | 可用，**同场连用 ≤2 次** | 留白与构图优先，脸部特写本就不是主力景别 |

**组合级禁令（★ 本节核心）**：**「人物脸部特写 × 平视正面」是一个"组合风险"——三个轴各自合规 ≠ 组合合规**：

- **3D / 仿真人（BASE_ANIME）**：该组合**默认禁用**，须改用**带角度的侧视**（侧 45 度 / 侧面 `+` 微俯微仰）。**唯一豁免**：正面对峙 / 摊牌 / 直视挑衅等**有明确情绪理由**的瞬间，且**镜行必须写明理由**（如「正面对视 · 摊牌」）。
- **真人（BASE_LIVE）**：该组合**受 1/3 配额约束**——超配额时把多余的脸部特写改为侧 45 度 / 过肩。
- **2D / 水墨（BASE_2D / BASE_INK）**：该组合可用，**同场连用 ≤2 次**。

**与既有规则的关系**：本节**不替代** §三 的方向轴 / 高度轴表，而是在其**上加"组合层"约束**——三轴各自合规（方向=正面合法、高度=平视合法、景别=特写合法）**不等于**组合合规。**未感知基底 = 违规**（基底未锁定 = 停下询问，⛔ 不得默认真人）。

**自检（不输出）**：逐条人物脸部特写镜行过一遍——(1) 当前基底是什么？(2) 该镜是否为「特写 × 平视正面」组合？(3) 若是，当前基底允许吗？配额超了吗？(4) 3D / 仿真人下是否已改带角度侧视、或已写明豁免理由？

### 变焦族四件套 · 区分口径（★ 2026-10-16 新增 · 治「光学变焦无独立条目 + 机检别名误判」）

> **缺口由来（粉丝「森林」2026-10-16 反馈 · 核验属实且比反馈更严重）**：运镜表此前**没有独立的「光学变焦」条目**——变焦只在 ① 上表「滑动变焦」② 单技法表 #5「Snap Zoom」（还与"直线推镜"混写在一句里）两处露面；**且机检把变焦做成了错误别名**（`short-drama-director/scripts/validate_prompt.py` 旧版把 `Zoom` 一律归为滑动变焦族，并把「变焦推进 / 急推变焦」计进滑动变焦的「全片 ≤1」名额）→ 写一个普通光学变焦推拉，换个写法就掉进两个坑之一：**要么被当成 Dolly Zoom 占掉全片唯一名额（误报超限），要么完全不受任何规则约束（无档可依）**。本节把四件套分开定义，并同步修机检别名。

| 名称 | 机位 | 焦段 | 画面特征 | 判据关键词 | 名额 |
|---|---|---|---|---|---|
| **推镜 / 拉镜**（dolly in/out） | **位移** | 不变 | 透视关系改变（近大远小加剧、有视差） | 推镜 / 推近 / 拉镜 / 拉远 / 直线推进 | 按 §四 重技法表 |
| **光学变焦**（Zoom In/Out） | **不动** | **变化** | 透视不变、画面**整体等比缩放**、无视差 | 光学变焦 / 变焦推拉 / Zoom In / Zoom Out | 非重技法；**不得与位移运镜叠加**（见 §七 禁令③） |
| **急速变焦**（Snap Zoom） | 不动 | 变化（高速） | 0.2~0.5 秒内冲到位 | 急速变焦 / 急推变焦 / Snap Zoom | 一镜只用一次，禁与升格同用 |
| **滑动变焦**（Dolly Zoom · 希区柯克变焦） | **位移** | **反向变化** | 主体尺度恒定、背景剧烈推拉塌陷 | 滑动变焦 / Dolly Zoom / 推进变焦反向拉移 | **全片 ≤1**（§四 重技法表） |

**三条判据纪律**：

1. **"位移 + 变焦"同时出现 = 滑动变焦**（无论是否写"Dolly"）——机检按此口径计数（C18l）；
2. **纯光学变焦不得写成"Dolly Zoom"**，也**不得省略为孤立"变焦"**——须写全「光学变焦推近 / 光学变焦拉远」，否则机检无法把它与滑动变焦区分开；
3. **光学变焦不是推镜的替代品**——机位能移动时优先用推镜/拉镜（位移才有空间纵深变化）；光学变焦只用于**机位确实无法移动**的场合（贴墙 / 狭窄 / 隐蔽观察 / 长焦偷窥）。

### 手持晃动三级烈度

烈度必须由情绪买单，禁止无理由晃动：

1. **手持微晃**——紧张上升段（情绪4-6分）的底色，替代稳定器的轻微呼吸感，让画面有毛边。
2. **手持晃动**——冲突与混乱段（情绪6-8分），跟拍/围拍中的自然颠簸。
3. **手持剧烈晃动**——爆发顶点专用（情绪≥8分）：剧烈甩动、地平线失稳、焦点呼吸，观众心跳跟着画面跑。仅限暴烈冲突、惊恐逃窜、精神失稳、灾难瞬间的最高点；每集≤3个镜头段落；允许连续2-3镜短链（追逐/暴乱段落，此为"禁止连续3镜同一运镜"的显式例外），链后必须接稳定运镜收束形成反差；禁止在平静/对话/抒情段落使用。剧烈晃动之前的镜头越稳，爆发时越炸。

### 运镜-情绪匹配

不是if-then机械配对，由情绪强度+类型+场景节奏共同决定：

- 情绪爆发点：基础用推镜，重锤情绪（绝望/崩溃）反用拉镜，震撼瞬间反用固定大特写。不要每个angry都推镜。
- 离别/结束/孤独：基础用拉镜，独白式孤独反用固定中景，群体遗弃反用升降拉远。
- 动作/行走：紧张追逐用手持（按三级烈度对号入座），庄严行进用轨道，漫步用稳定器跟拍。
- 顿悟/认知崩塌：滑动变焦（全片≤1次），其他顿悟用推镜+固定组合。
- 关系揭示/主体崇拜：环绕（每场戏≤1次）。关键沉浸段落：按叙事需要选择连续长镜或真实切镜，不为满足镜数强拆。连续运镜先写明起终机位、可通行路径、主体位移、遮挡与轴线变化；路径穿墙、层高不足或无法保持主体可见时，改走可行路径或回导演层决定切镜。此为制作策略，不是模型官方能力断言；不得发明“辅助运镜占比 1/3”等阈值。
- 紧张/混乱/纪实感：手持晃动按三级烈度对号入座，紧张度越高晃动越大。运镜速度=情绪强度。

**情绪节奏曲线（设计前内部识别，不输出）**：通读原文，标记每个情绪节点，标注三要素——**类型**（紧张上升／爆发／沉默留白／震撼凝固）、**强度 1-10 分**（此分值即下文三级手持烈度与运镜速度的分档依据）、**持续度**（持续若干镜／瞬间）。据此画出情绪曲线：上升段变紧变快、爆发点用重锤镜头、平复段变松变慢留白。镜头节奏跟随曲线，不全程匀速。

**运镜速度=情绪强度**：

| 情绪强度 | 运镜速度 | 运镜稳定性 | 典型运镜 |
|----------|----------|------------|----------|
| 平静/日常（1-3分） | 慢/极慢 | 稳定器般平稳 | 极缓慢推拉/极缓慢横移/微漂移 |
| 紧张上升（4-6分） | 中速 | 微晃 | 跟拍/中速推镜/手持微晃 |
| 爆发/混乱（7-9分） | 快/突变 | 手持晃动（8分以上升级为剧烈晃动） | 快速推镜/手持晃动/手持剧烈晃动/快速横移 |
| 沉默/留白 | 静止/极慢 | 极稳 | 极慢拉镜/极缓慢横移（固定仅限重锤后留白长镜） |
| 震撼/凝固（10分） | 静止或滑动变焦 | 极稳 | 固定大特写/滑动变焦/环绕 |

不允许"平静情绪用快速运镜"或"爆发情绪用缓慢固定"——除非刻意反规则。同一场戏内运镜速度应随情绪曲线变化，不要全程匀速。

**固定镜头是稀缺资源（★ 仅打戏 / 动作段适用）**：常态镜头一律以微运镜（极缓慢推/横移/漂移）替代绝对静止，让画面保持流动。固定只留给三类时刻——重锤瞬间的凝固、段落句号、情绪重锤后的留白长镜。10%上限即为此设。

> ⚠️ **文戏 / 对话段不适用本条（旧「对话段落不得全程固定」与「15s运镜≤2」已随本次修订废止）**：文戏与叙事段遵循**「动静随剧情自然发生」**（见 §四 运镜分档）——静态聊天/展示可自由用固定，情绪逼近/人物走位可自由用缓慢推拉与跟移（配 10~15cm 物理限位），既不强迫每镜都动，也不限制每段只能动 2 次。

**留白镜头**（情绪重锤后必加）：环境空镜/反应镜头（无台词）/动作细节空镜/长固定镜头。每个情绪重锤瞬间后必须至少1个留白镜头，景别通常比爆发镜头更松，不允许立即接下一个情绪重锤。

**镜头节奏=叙事节奏**：快节奏段落（追逐/打斗/争吵）镜头短促、景别跳跃、运镜快速；慢节奏段落（沉思/对话/独白）镜头长、运镜慢、固定多。节奏转换必须有过渡，不允许硬切。

### 重技法频率上限

用多了廉价化，只用于重锤瞬间。如果一场戏没有明显的重锤瞬间，就不要用任何重技法：

| 重技法 | 全片上限 | 单场上限 |
|--------|----------|----------|
| 滑动变焦 | ≤1次 | ≤1次 |
| 环绕/弧形 | ≤3次 | ≤1次 |
| Snorricam | ≤1次 | ≤1次 |
| 鱼眼 | ≤2次 | ≤1次 |
| 荷兰角 | ≤1次（或不用） | ≤1次（或不用） |
| 大仰角 | ≤3次 | ≤2次 |
| 大俯角 | ≤3次 | ≤2次 |
| 手持剧烈晃动 | ≤3个段落 | ≤2个段落 |
| 升降 | ≤2次 | ≤1次 |
| 摇臂 | ≤2次 | ≤1次 |
| POV主观视角 | ≤3次 | ≤1次 |

### 微运镜（画面持续流动）

即使是"平静"镜头，也优先用极缓慢的推镜、极缓慢的横移或呼吸感的轻微漂移让画面保持流动，避免绝对静止导致的呆板。平静≠冻结，极缓慢的推镜是"克制的情绪逼近"，比固定镜头更耐看。

### 四·二 · Lubezki × Deakins 物理运镜与光学锁焦规程（2026-10-14 粉丝 shotlist-builder 吸收）

> 📌 **病根与升级动机**：此前写「极缓慢推镜 / 手持微晃」属定性标签，模型不知道推进 10 厘米还是 2 米（推猛即人脸变形、站位漂移）；而为防漂移改成纯「固定」又会让画面退化为死板监控摄像头。本节引入 Lubezki × Deakins 电影摄影物理量化规程，**镜行头仍保 `[镜头N] 景别 · 角度 · 运镜。` 三要素不变（兼容全套机检），在镜行描述内植入以下四把物理与光学锁**：

1. **推拉运镜厘米级物理限位锁（10~15cm Physical Dolly Limit）**：
   - 凡使用缓慢推镜 / 拉镜（push-in / pull-out），必须在镜行描述中锁死**厘米级物理总位移与纯物理轨道属性**：`整段移动距离不超过 10~15 厘米，速度慢到几乎察觉不到，纯物理轨道微移无变焦拉伸`。
   - **震惊 / 顿悟反应标准式**：`镜头开始严格静止冻结 0.5 秒 → 随后极缓慢推进 10~15 厘米（纯物理位移无变焦）`。既产生前景与焦外背景的真实视差滑动（Parallax），又绝不会把人物站位推崩。
2. **文戏「固定」的呼吸感与摄影师贴身随动补偿（Breathing Lock & Active Reframing · 仅限P3分镜设计层，禁塞入P4镜行）**：
   - 在 P3 分镜导演构思层，理解「固定」并非死板监控，摄影机可主动跟随角色脸部运动微调；但**进入 P4 投喂提示词镜行时，严禁写入「焦平面全程死锁面部无漂移 / 毫米级构图补偿 / 呼吸式微动 / 画面线条笔直构图平整 / 柔和色块与微光」等摄影机理论术语（机检 C20m 红线拦截！）**——镜行头只标 `[镜头N] 特写 · 侧45度 · 固定。`，镜行正文 100% 写人物与道具的纯物理动作！
   - **愤怒 / 紧绷对峙手持**：镜行头直接标 `手持微晃` 或 `缓推`，不写冗长摄影机说明书。
3. **单镜内分阶段情绪运镜（Phased Camera Arc · 单镜随表演节拍 ①②③ 同步变运镜）**：
   - 当同一连续镜头内角色情绪发生转折（如暴怒 → 强行压抑克制），摄影机状态须在同一镜内分阶段同步演进，并与表演节拍序号 `①②③` 咬合：
     - `镜头起幅（节拍①②，角色怒气紧绷）：摄影机明显手持呼吸式漂移、上下微抖；`
     - `中段过渡（节拍③④，角色压制情绪）：摄影机不安晃动逐渐减弱，漂移幅度收小；`
     - `镜头收尾（节拍⑤⑥，角色恢复克制）：摄影机转为平稳、流畅、克制的极细微规律呼吸微动。`
4. **光学物理锁（毫米焦距 + F1.4 浅景深 · 统一归入【画幅风格】总栏，禁塞入P4镜行）与 0.3~0.5 秒闪切建立镜**：
   - **光学参数落点铁律（与 C20m 互锁）**：`85mm`、`50mm`、`35mm`、`F1.4 浅景深` 等光学参数统一写在段首 `【画幅风格】` 栏（如 `镜头35~85mm中浅景深`）或 P3 九字段分镜表的参数列；**P4 投喂镜行正文严禁塞入「85mm F1.4极浅景深 / 焦平面死锁 / 画面线条笔直」等说明书废话**，以免稀释短镜头人物动作权重！
   - **0.3~0.5 秒极短闪切定场（Split-Second Flash Establishing）与俯拍收尾（Top-Shot Freeze）**：支持在单镜长特写前用 `0.3~0.5 秒` 瞬间空间定位切入，或末拍用正上方俯拍时间静止定格。

### 运镜变化铁律

相邻镜头运镜方式应产生变化，禁止连续3镜使用同一种运镜（唯一显式例外：手持剧烈晃动的爆发顶点短链，见手持三级烈度）。同一场戏内运镜方式至少覆盖4种，避免单一手法贯穿全场。

全片至少使用8种不同运镜方式（在场景物理允许范围内）。口径说明：单场景输出时物理可用运镜不足8种不硬凑——单场至少覆盖4种，多场景累计达到8种；禁止为凑多样性使用无叙事理由的运镜。

复合运镜的完整论述见 `shot-economy-and-acting.md`。

### 高光时刻运镜专题（英雄登场 / 认知颠覆 / 制胜一击）

> 本专题是 §四 的**组合应用库**——**不新设任何名额**，所有上限仍按 §四「重技法频率上限」与 §三「机位配比铁律」执行；与本文件其余规则冲突时以后者为准。
>
> 三套组合只用在**对应情绪节点**。用错节点、或两套叠加使用必廉价——高光镜头一滥，全片高光尽失。

**① 英雄登场**（人物首次以强者/主角姿态进入，或回归救场）

| 环节 | 写法 | 作用 |
|---|---|---|
| 入画 | 低机位大仰角定场，超广角 14-24mm，人物自画幅下缘升入 | 先给「个头」，再给「身份」 |
| 展开 | 摇臂随身体升起（或环绕半圈） | 把威压从「角度」延续成「运动」 |
| 收束 | 缓推至面部中近景/近景 | 落到「人」，不落到「神」 |

- 名额：每场戏 ≤1 组；大仰角、摇臂、环绕各自照 §三/§四 名额计入，不额外开恩。
- 禁：全套连用超过 4 镜（一过 4 镜就变慢动作宣传片）；人物尚未站稳就切环绕（像在转圈，不像登场）。

**② 认知颠覆**（真相击穿、背叛、世界观倾覆）

- 组合：滑动变焦（Dolly Zoom · 主体不动、背景急推或急拉）→ 荷兰角定格 → 焦点转移（从人脸拉出到背景物证）。
- 名额：滑动变焦全片 ≤1、荷兰角每集 ≤1（见 §三/§四）；三者**不得叠加在同一镜**。
- 禁：与英雄登场的推镜/环绕混用——两套情绪方向相反，混用互相抵消。

**③ 制胜一击**（打戏终结帧、逆转的最后一击）

- 组合：升格（高帧率慢放）→ 螺旋环绕半圈 → **固定大特写凝固**（命中瞬间的「顿」拍）→ 缓拉收束。
- 名额：每场打戏 ≤1 组；打戏侧「起-爆-顿-收」四拍细则见 `sd-combat-engine/references/combat-rhythm-and-load-guardrails.md`。
- 禁：命中帧用晃动或甩镜——「顿」拍必须稳定凝固，观众判断「打到没打到」就看这一帧。

#### 单技法镜行参考写法（8 套 · 可直接取句式，参数按当次填）

> 上面三套是「**组合**」（一套走完一个情绪节点）；下表是「**单技法**」——任取一条写进**一个镜行**，用在三套组合的对应环节里，或单独用在某个需要强调的单镜。**两套叠加使用必廉价**（同一镜不许既是滑动变焦又是螺旋环绕）。

| # | 技法 | 用在哪 | 镜行参考写法（照句式换主体 / 场景） |
|---|---|---|---|
| 1 | 贴地低角度垂直仰冲升镜 | 英雄登场（起幅） | `极端低角度贴地起幅 → 垂直升降机极速抬升伴随仰角上倾 → 终幅定格于胸部以上微仰视中景。主体自地面稳步站立，镜头自脚底战靴连贯扫至冷峻下颌，逆光边缘光勾勒身形。` |
| 2 | 360° 动态螺旋环绕升降 | 拔刀 / 群敌环伺 | `以主体为圆心顺时针 360 度快速螺旋环绕 → 机位自腰部平视提升至 45 度斜俯视 → 正面特写处急停阻尼定格。主体拔刀出鞘，刃身寒芒随环绕掠过镜头反光。` |
| 3 | 滑动变焦视差冲击（Dolly Zoom） | 认知颠覆（核心镜） | `经典滑动变焦（推进变焦反向拉移 / Dolly Zoom）→ 景深剧烈拉伸变幻。主体面部在画面中心尺度恒定，背景长廊 / 群山以肉眼可见速度向后塌陷压缩，双眸锋芒毕露。` |
| 4 | 前景遮挡破框横移突现 | 刺客突袭 / 神秘救场 | `前景焦外断壁全遮挡起幅 → 摄影机向右横移飞掠过障碍物（Reveal Shot）→ 景深瞬间合焦至中景主体。主体自阴影中显露，眼神凌厉，周身气流排开飘尘。` |
| 5 | 极速推镜与微距打击急停（Snap Zoom + Hit-Stop） | 高燃打击 / 大招成型 | `全景急骤直线推镜（Snap Zoom）→ 0.2 秒画面物理阻尼停顿震颤（Hit-Stop）→ 极端微距特写锁定眼眸。主体瞳孔骤缩。` |
| 6 | 焦点纵深转移英雄步入（Rack Focus） | 绝境救场 / 强者漫步 | `深景深固定机位 → 焦点由前向后纵深拉移（Rack Focus）→ 前景败退者转虚、后景漫步者转实。主体自浓烟中穿行而出，步伐稳重，长兵器拖地带出火星。` |
| 7 | 变速掠影与砸地冲击（Speed Ramping） | 速度型位移 / 凌空落地 | `速度升降格切换（快起 → 慢速空中定格 → 原速砸地冲击）→ 广角贴地微仰震颤。主体单膝顿地降落，地面震碎冲击波环形扩散。` |
| 8 | 逆光剪影渐显与边缘光剥离 | 幕后大能现身 / 至尊登场 | `慢速推近正面机位 → 起幅强逆光纯黑剪影 → 迈步出光带出高反差轮廓光。主体自强逆光源中走出，面部冷酷阴影分明。` |

- **名额与冲突**：技法 3 / 5 / 7 属**重技法**，各自照 §四 名额计；技法 5 与 7 **不得与升格慢镜同时用**（同一镜只能有一个时间轴异常）。
- **打戏域边界**：技法 5 / 6 / 7 用在**打斗 / 武打**场合时，节奏与打击反馈细则**以 `sd-combat-engine` 为准**（本表只管运镜句怎么写，不管打戏节拍）。
- **技法 1 / 8 的逆光**必须有**光源动机**（见 `short-drama-director/references/lighting-and-antifake.md` §一），无源的「黑剪影」不合格。

**自检（不输出 · 四条）**：① 本场是否真有对应情绪节点（没有就别用）？② 三套组合里是否只用该用的那一套？③ 名额是否超（大仰角 / 环绕 / 摇臂 / 滑动变焦 / 荷兰角各自数）？④ 单技法是否**两套以上叠在同一镜**（是 → 删到一个）？

## 五、景深约束

每个镜头必须标注景深策略。

| 景深 | 特征 | 适用 |
|------|------|------|
| 浅景深 | 主体清晰，背景虚化 | 人物特写/肖像/情绪聚焦/孤立主体 |
| 深景深 | 全画面清晰 | 大景别/环境交代/多人物关系/全景清晰 |
| 焦点转换 | 焦点从A转到B | 视线引导/关系转换/揭示/反应 |

- 人物特写 → 浅景深（配合中长焦85mm）。大景别/环境交代 → 深景深（配合广角，小光圈）。
- 需要引导观众视线从A转到B时 → 焦点转换。
- 全片景深策略需有变化。浅景深时降低物理雾或diffusion，避免背景被抹糊。

### 关系戏浅景深的前提（2026-10-10 并入）

- 暧昧、亲密距离缩短或关系拉扯场景**可用**浅景深与明显背景虚化（可写"浅景深，背景明显虚化成柔和焦外"），加强人物隔离、视觉亲近感与注意力集中；
- **前提**：出口、人物站位、多人关系或关键道具连续性**必须清晰时，不得使用过强虚化**——双人镜头须保持**双方**必要面部反应、手部动作与听戏反应可读；
- 单人镜头保持主体面部与关键手部清晰；
- **浅景深不是所有场景的默认风格**——不得全片套用。

### 镜面 / 玻璃 / 反射 · 高风险构图（2026-10-10 并入）

- 镜面、玻璃、反射**只在剧情或视觉任务必要时使用**，优先**直接拍摄人物**；
- 使用时**只保留单一反射面与简单、静止、可判断的空间关系**；
- **关键身份、动作方向、人物交互与连续性结果，不得只依赖反射表达**；
- 除非用户指定，避免：多层倒影、镜内镜、反射中的复杂动作、依赖镜像方向的关键表演。

## 六、人物群像管理

按景别分两级管理：

| 档位 | 景别 | 多人管理要求 |
|------|------|--------------|
| **A档（严格）** | 大远景/远景/全景/中全景/中景 | 必须数人头、必须带齐在场角色、画面描述覆盖所有人 |
| **B档（宽松）** | 中近景/近景/特写/大特写 | 不强制多人、聚焦主体即可、背景人物可虚化或不在画面 |

- 每个场景必须列出完整人物清单（主要角色+次要角色+功能性角色）。次要角色是否出镜按叙事需求确定。
- A档景别镜头必须逐一写出每个在场角色的位置和动作，主要角色一个都不许漏。次要角色标注"出镜"的也必须出现。
- **★ 群像行为（2026-10-24 P7 新增）**：A 档镜头除"位置和动作"外，还必须给**每个无名可见人一件自己的事**（事务句三件套：手上事务 + 幅度 + 视线归属）。判"本段要不要群像"走 A/B/C 开关，判"写到哪一型"走 R/P/S 三型——**权威 = 总控 `short-drama-director/references/crowd-behavior-direction.md`**。禁「众人围观/大家在旁/周围人群」这类聚合词（= 模型自由发挥 → 全员同步站桩）。
  - 同镜 ≥3 人时，事务必须**每人各异**；景别越紧、人离主体越近，事务细节越要写到 R 型；远景一律 S 型一句封顶。
  - **打戏段、纯特写段、密闭双人戏不适用**（C 类）——这三类直接写「除 @XX 外无其他人物」，走 C20h 原句式。
- B档景别镜头只需写清主体，背景人物写"虚化"即可，不需要逐一罗列。
- 3人及以上场景，A档群像镜头（画面内≥2人）占比不得低于该场景镜头总数的40%。
- 角色中途离开必须交代离开动作，下一个A档镜头才允许消失。
- 从A档切到B档再切回A档：A档镜头必须恢复群像，B档期间次要角色"消失"是正常的。

### 7.2 三条组合级禁令（★ 本节核心 · "三轴各自合规 ≠ 组合合规"）

> **原理**：§一 / §二 / §三 / §四 **各管一个轴**，四条各自合规的组合**仍可能违规**——**"组合"本身要有一条规则**。以下三条是当前已识别的高频组合风险。

**禁令①：「紧景别（近景/特写）× 平视正面」组合** —— 受 §三·五「形态 → 机位适配」的基底配额约束（**配额权威见 §三·五，本节只给落地口径**）：

- **3D / 半写实仿真人（BASE_ANIME）**：**默认禁用**；唯一豁免＝正面对峙 / 摊牌有明确情绪理由且镜行写明理由；
- **真人（BASE_LIVE）**：受「≤ 人物特写总数的 1/3」配额约束；
- **2D / 水墨（BASE_2D / BASE_INK）**：可用，同场连用 ≤2 次；
- **落地口径**：矩阵 **第 4 / 第 5 行默认给「带角度」**——照矩阵取即可，不要临时改回平视正面。**基底未锁定 = 停下询问**，⛔ 不得默认真人。

**禁令②：「大景别（全景及以上）× 长焦（>135mm）」组合** —— 长焦压缩空间，与"交代空间 / 建立关系 / 展示站位"的任务直接相冲；室内层高不足时更直接穿帮（`scene-space-adaptation.md` §S1）。**要"宏大"用广角 + 低机位仰拍，不是用长焦。**

**禁令③：「位移运镜（推/拉/移/升降/跟拍）× 光学变焦」在同一镜内叠加** —— 二者同时作用 = **无声明滑动变焦**（Dolly Zoom，全片 ≤1）；**非刻意不得叠**。需要"主体不变、背景塌陷"就写滑动变焦并占名额；否则**二选一**（机位能移动 → 用位移运镜；不能移动 → 用光学变焦，见 §四 变焦族四件套）。
