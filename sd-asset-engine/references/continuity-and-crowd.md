# 资产连续性与群像体系（Continuity & Crowd · 场景 / 道具 / 群像资产 / 人群调度）

> **本文档是资产引擎规则库 · 权威文件**
> 融合来源：script-writing-studio 05 模块（场景连续性 + 道具单实例锁 + 人群调度）
> **换算**：外部包英文编号（SC/SCV/SB/CL/CR/PR/FF/ST/NP）→ 全部改为总控「图N」体系 + 中文功能名。

---

## 〇、为什么需要这份文件

**问题**：资产图做好之后，跨段使用时会出三类问题——① 场景空间方向前后不一致（穿帮）；② 同一道具在多张图里出现 → 模型生成两个实例；③ 人群在每段都不一样 → 无连续性。

**本文件提供四个连续性工具**：场景空间锁定、道具单实例锁、**群像资产卡**、人群调度卡。

---

## 一、场景空间连续性（防穿帮）

### 1.1 空间方向锁定（必写）

同一场景多次出现时，**空间方位必须一致**：

```
必写内容：
① 分界面定义：这个空间的"门/窗/主光源"在哪个方向
② 侧别命名：面向某个参照物时，左右各是什么
③ 人物允许区：人物可以站在哪些位置
④ 人物禁止区：不该出现的位置（如穿墙、悬空）
⑤ 硬约束句：交给分镜/投喂的固定句
```

### 1.2 场景多角度包（图N 口径）

需要多角度展示同一场景时，**每个角度单独一个图号**，并写清"只参考什么 / 不参考什么"：

```
图N（V01 正向）：只参考拍摄方向、空间透视、门窗家具相对位置、固定光源
图N+1（V02 反向）：同上，方向相反
图N+2（PLAN 俯视）：只参考平面布局与人物可站立区域
```

⚠️ **角度图不替代场景母版**——母版定结构，角度图定方向。

### 1.3 场景光影连续性

同一场景在不同场次若光线变化（白天→夜晚），**必须写清变化理由**（时间推移/剧情事件），且**光源结构保持一致**（窗在哪、主光从哪来不能变，只能变强度和色温）。

## 二、道具单实例锁（★ 高频出错点）

### 2.1 问题场景

**同一件道具已经在场景图、角度图或首帧图里可见，同时资产库又提供了这件道具的参考图** → 模型容易生成**两个实例**（桌上一个、手里一个）。

### 2.2 锁定写法（必写四要素）

```
① 对应关系：图N 对应的是画面里哪一件可见道具
② 数量限制：本段/全片只允许出现几个
③ 用途限定：图N 只用于外观/材质/颜色/屏幕状态，不新增第二件
④ 状态互斥：角色拿起后，原位置必须变为空
```


### 2.3 小道具朝向规则（手机/照片/证件）

**AI 模型经常把手机自动转成"正面朝镜头"**，甚至把背面也生成成屏幕。凡道具有正反面/信息面，**必须写清朝向**：

| 道具状态 | 写法 |
|---|---|
| 不需要看屏幕 | 优先让屏幕朝向手心/桌面/角色身体；"限制：手机背面朝镜头，屏幕朝手心不可见" |
| 需要看 UI | 必须明确"屏幕正面朝镜头"，并写清只允许出现哪些中文 UI/数字/图标 |
| 照片/证件 | 写清正面是否可见；"限制：照片正面贴在桌面上不可见，观众只看到照片背面" |

**必须禁止**：手机背面变屏幕、正反面同时是屏幕、随机 UI、随机文字。

## 三、群像资产卡 + 人群调度卡（两层 · ★ 2026-10-16 升格为两层）

> **缺口由来（粉丝「森林」2026-10-16 反馈 · 核验属实）**：本包资产体系**只有三族**——角色 `CHR` / 场景 `SCN` / 关键道具 `PRP`（见 `short-drama-director/references/asset-first-pipeline.md` §P2：分批出图「①角色 4 View 资产板 ②场景资产图 ③道具图」）。**"一群人"没有资产位**：`three-list-extraction.md` §七 的「群像/群体角色」只给一段**文字描述**（无图号、无出图规范），本节原有的「人群调度卡」又是**投喂层的密度句**（且明文"无路人需求时不新增字段"）——两者都**不是可跨段复用的资产**。结果：**家族 / 侍卫队 / 围观村民 / 朝堂百官**这类群体，每段长相都可能变，与"每段零记忆"的模型特性叠加 = 必然群像漂移。本节把群像补成**资产层 + 投喂层两层**。

### 3.0 两层分工（先判"要不要资产化"，再决定写法）

| 层 | 产物 | 阶段 | 编号 | 职责 | 何时用 |
|---|---|---|---|---|---|
| **① 群像资产卡**（★ 新增） | 《资产图册》第四族 **`GRP-N`** + 群像参考图 | P2 资产层（出图） | `GRP-N` | 锁**长相**：统一制式 / 体态 / 年龄构成 —— 跨段复用 | **有辨识度的固定群体**（家族、门派弟子、侍卫队、朝堂百官、固定班底） |
| **② 人群调度卡**（既有） | 投喂层**人群密度句** | P4 投喂层（写句） | 无编号 | 锁**分布**：前景/中景/远景几人、人流方向、遮挡 | **无辨识度的背景人群**（街头路人、顾客、乘客） |

> **一句话判据**：**这群人"要不要长得一样"？** 要 → 建 `GRP-N` 群像资产卡；不要 → 只写人群密度句，**不建资产**。

> **★ 第三维（2026-10-24 P7 新增）**：上述两层只覆盖「**长相**」与「**分布**」，**不覆盖「行为」**。
> 一群长相一致、分布合理的人，照样可以人人站桩不动（用户实测：教室后排「像僵尸一样在那儿看着」）。
> **行为是独立维度，权威在分镜引擎** `short-drama-director/references/crowd-behavior-direction.md`——
> 本文件 §3.2 的 ⑧ 行为字段只是它在**资产/调度侧的落点**，完整判据（A/B/C 开关 + R/P/S 三型 + 停顿恢复曲线）以该文件为准。

### 3.1 群像资产卡（★ 2026-10-16 新增 · 第四族资产）

**触发门（命中任一即建卡）**：① 同一群体**跨 ≥2 段**出现；② 群体承担**叙事功能**（侍卫护驾 / 家族列席 / 百官朝拜）；③ 群体在**特写或中近景**里入画（景别越紧，长相越要锁）。

**卡模板（7 字段 · 缺一即不合格）**：

```
【群像资产 GRP-〔编号〕】〔群体名，如：宋府家丁〕
① 统一制式：服装/甲胄/发式/配饰的统一规格（逐项写清，禁"统一着装"这类空话）
② 年龄与性别构成：如"25~40 岁男性为主，混 1~2 名中年女性"
③ 体态与身高带：如"170~180cm，体格偏壮；无过瘦/过高者"
④ 可辨识度分级：**A 级**（有个体脸，须逐个 4 View）/ **B 级**（统一制式无个体脸，一张群体参考图即可）
⑤ 数量与密度基准：默认同框人数带 + 允许的稀疏/密集档
⑥ 场景绑定：常出现于哪些场景（对应 `SCN-`）
⑦ 状态轨迹：有无换装/受伤/溃散等跨段状态变化（`→` 连写，无变化写"无状态变化"）
```

**出图规范（B 级主力 · 与角色 4 View 同源）**：

- **一张群像参考图 = 3 格横向并排**：① **制式细节格**（甲胄/服装正面特写）② **3~5 人合影格**（交代体态带与年龄构成）③ **远景群像格**（交代密度与遮挡关系）；
- **B 级群体**：②③ 格内**不刻画个体五官**（统一制式、脸部弱化），避免模型"发明"个体脸 → 下一段变脸；
- **A 级群体**：**必须先按 `character-lineage-and-sheets.md` 把其中出戏的个体升为 `CHR-` 角色**（逐个 4 View）——**禁用一张群像图硬扛有台词的个体**；
- 统一参数：〔画幅〕〔焦段 50mm〕等效无畸变；**禁**在群像图里出现主角（主角走自己的 `CHR-` 资产）。

**投喂层锚点**：`@群体名`（如 `@宋府家丁`）——**与 `@人名` 同栏同待遇**，写在【核心人物】栏末（七段式**不增段**，见 `model-adapters.md` §5）；**M0 形态**（无图）时按 §三 文字锁口径**逐段复述制式**，禁写"同上/同前"。

**与三族锚点的关系**：`GRP-N` 是**资产层编号**（进《资产图册》），**不新增行内锚点前缀族**——投喂层仍走 `@群体名`（与 `@周慕` 同形），故 `@CHR-` / `@SCN-` / `@PRP-` 三族口径**不变**。

### 3.2 人群调度卡（既有 · 仅用于无辨识度背景人群）

**何时启用**：公共空间、街道、商场、车站、学校、医院、营业餐厅等**需要路人真实感**的场景。

**调度卡必写内容**：

```
① 绑定信息：对应哪个场景（图N）
② 密度等级：稀疏/中等/密集
③ 景深层次分布：前景几人、中景几人、远景几人
④ 人群类型：路人/顾客/学生/乘客……（与场景匹配）
⑤ 移动与遮挡规则：人流方向、是否遮挡主体
⑥ 声音与氛围：环境人声层次
⑦ 禁止项：不允许出现的元素
⑧ 行为字段（★ P7 新增 · 治「背景人僵尸化」）：每人/每层正在做的事——
   前景写具体事务（动词+宾语），中景写事务+穿画方向，远景只写整体倾向；
   禁「站着/看着/在旁/围观」等状态词，必须落到手上动作
```

> **⑧ 是必填项，不是可选项**：①~⑦ 全是「**有多少人在哪**」，⑧ 是「**他们在干什么**」。
> 缺 ⑧ ＝ 模型自配行为，默认产物就是站桩僵尸（用户 2026-10-24 实测：教室后排「像僵尸一样在那儿看着」）。
> ⑧ 的完整写法、三型分级（R 反应人 / P 事务人 / S 密度人）、字数预算与正反示例，
> 权威 = `short-drama-director/references/crowd-behavior-direction.md` §三。

### 3.3 与投喂的衔接（★ 关键）

**人群卡必须被翻译成模型能直接理解的"人群密度"句子**：

❌ **不要只写**："人群卡001 / 同上一段人群 / 保持之前人流"
✅ **必须写**："本段可见：前景 2 名路人（模糊）、中景 5 名顾客走动、远景 10 余人，人流自画面左向右移动，不遮挡主角面部"

⚠️ 场景母版如果是**空场图**，只作为空间结构/灯光/透视/固定物参考；启用人群时**直接写本段可见人群**，不写"不继承空无一人状态"这类管理说明。

⚠️ **无路人需求时**，**不新增人群字段**，只在限制里写"不允许出现额外人物、路人、群演"。

## 四、视觉风格锁（简要 · 图N 口径）

> 已有 `short-drama-director/references/aspect-ratio-adaptation.md` 等风格规范，此处仅补充"风格锁"的写法。

需要固定项目视觉风格时，建立**风格锁**（可给图号），包含：

```
① 风格身份：媒介质感、整体调性
② 人物审美锁：脸型/体态/皮肤质感标准
③ 场景审美锁：空间质感/材质/年代感
④ 画面质感锁：颗粒/渲染方式/反差
⑤ 正向词：必须投喂的词
⑥ 负面词：防跑偏词包
⑦ 转译短句：交给分镜/投喂的短句
```

⚠️ **风格锁编号不进最终投喂提示词**——必须翻译成自然语言（详见 `sd-feed-engine/references/engineering-language-cleanup.md` §三）。

⚠️ **风格光影冲突时融合不覆盖**：风格锁的默认光影与当前分镜真实光源冲突时，**以当前镜头真实光源为准**，但保留风格的媒介质感、反差控制、颗粒方式。

## 五、资产红线

| # | 红线 |
|---|---|
| 1 | 场景空间方向前后段必须一致，不能"这一段门在左、下一段门在右" |
| 2 | 角度图不替代场景母版；每张图说明"只参考什么/不参考什么" |
| 3 | 道具已在其他图可见时，必须启用单实例锁，不得新增第二件 |
| 4 | 小道具朝向必须写清（手机/照片/证件类） |
| 5 | 人群卡必须翻译成"人群密度"句，不写内部编号 |
| 6 | 无路人需求时不新增人群字段，只写禁止项 |
| 7 | 风格锁编号不进最终投喂稿，必须翻译成自然语言 |
| 8 | **有辨识度的固定群体（跨 ≥2 段 / 承担叙事功能 / 入中近景以上）必须建 `GRP-N` 群像资产卡**——只写密度句＝群像每段变脸 |
| 9 | **群像资产卡不得替代角色资产**：有台词/有特写的个体必须先升为 `CHR-` 走 4 View，禁用一张群像图硬扛 |
| 10 | **人群调度卡必须填 ⑧ 行为字段**（每人/每层正在做的事）——只填①~⑦（密度/层次/方向）＝模型自配行为，默认产物是站桩僵尸；权威 `short-drama-director/references/crowd-behavior-direction.md` |
