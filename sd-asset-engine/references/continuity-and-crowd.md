## 〇、为什么需要这份文件

**问题**：资产图做好之后，跨段使用时会出三类问题——① 场景空间方向前后不一致（穿帮）；② 同一道具在多张图里出现 → 模型生成两个实例；③ 人群在每段都不一样 → 无连续性。

**本文件提供三个连续性工具**：场景空间锁定、道具单实例锁、人群调度卡。

---

## 一、场景空间连续性（防穿帮）

### 1.1 空间方向锁定（必写）

同一场景多次出现时，**空间方位必须一致**：

```
必写内容：
① 分界面定义：这个空间的"门/窗/主光源"在哪个方向
② 侧别命名：面向某个参照物时，左右各是什么
③ 人物允许区：人物可以站在哪些位置
④ 人物禁止区：不该出现的位置（如穿墙、悬空）
⑤ 硬约束句：交给分镜/投喂的固定句
```

### 1.2 场景多角度包（图N 口径）

需要多角度展示同一场景时，**每个角度单独一个图号**，并写清"只参考什么 / 不参考什么"：

```
图N（V01 正向）：只参考拍摄方向、空间透视、门窗家具相对位置、固定光源
图N+1（V02 反向）：同上，方向相反
图N+2（PLAN 俯视）：只参考平面布局与人物可站立区域
```

⚠️ **角度图不替代场景母版**——母版定结构，角度图定方向。

### 1.3 场景光影连续性

同一场景在不同场次若光线变化（白天→夜晚），**必须写清变化理由**（时间推移/剧情事件），且**光源结构保持一致**（窗在哪、主光从哪来不能变，只能变强度和色温）。

## 二、道具单实例锁（★ 高频出错点）

### 2.1 问题场景

**同一件道具已经在场景图、角度图或首帧图里可见，同时资产库又提供了这件道具的参考图** → 模型容易生成**两个实例**（桌上一个、手里一个）。

### 2.2 锁定写法（必写四要素）

```
① 对应关系：图N 对应的是画面里哪一件可见道具
② 数量限制：本段/全片只允许出现几个
③ 用途限定：图N 只用于外观/材质/颜色/屏幕状态，不新增第二件
④ 状态互斥：角色拿起后，原位置必须变为空
```

**示例**：
```
限制：图7 碎屏手机就是首帧中桌面右下角那一部手机，本段只允许出现这一部；
图7 只补裂纹和机身外观，不新增第二部手机。角色拿起手机后，桌面原位置必须变为空，
不得桌上和手里同时各有一部手机。
```

### 2.3 小道具朝向规则（手机/照片/证件）

**AI 模型经常把手机自动转成"正面朝镜头"**，甚至把背面也生成成屏幕。凡道具有正反面/信息面，**必须写清朝向**：

| 道具状态 | 写法 |
|---|---|
| 不需要看屏幕 | 优先让屏幕朝向手心/桌面/角色身体；"限制：手机背面朝镜头，屏幕朝手心不可见" |
| 需要看 UI | 必须明确"屏幕正面朝镜头"，并写清只允许出现哪些中文 UI/数字/图标 |
| 照片/证件 | 写清正面是否可见；"限制：照片正面贴在桌面上不可见，观众只看到照片背面" |

**必须禁止**：手机背面变屏幕、正反面同时是屏幕、随机 UI、随机文字。

## 三、人群 / 群演调度卡

### 3.1 何时启用

公共空间、街道、商场、车站、学校、医院、营业餐厅等**需要路人真实感**的场景。

### 3.2 调度卡必写内容

```
① 绑定信息：对应哪个场景（图N）
② 密度等级：稀疏/中等/密集
③ 景深层次分布：前景几人、中景几人、远景几人
④ 人群类型：路人/顾客/学生/乘客……（与场景匹配）
⑤ 移动与遮挡规则：人流方向、是否遮挡主体
⑥ 声音与氛围：环境人声层次
⑦ 禁止项：不允许出现的元素
```

### 3.3 与投喂的衔接（★ 关键）

**人群卡必须被翻译成模型能直接理解的"人群密度"句子**：

❌ **不要只写**："人群卡001 / 同上一段人群 / 保持之前人流"
✅ **必须写**："本段可见：前景 2 名路人（模糊）、中景 5 名顾客走动、远景 10 余人，人流自画面左向右移动，不遮挡主角面部"

⚠️ 场景母版如果是**空场图**，只作为空间结构/灯光/透视/固定物参考；启用人群时**直接写本段可见人群**，不写"不继承空无一人状态"这类管理说明。

⚠️ **无路人需求时**，**不新增人群字段**，只在限制里写"不允许出现额外人物、路人、群演"。

## 四、视觉风格锁（简要 · 图N 口径）

> 已有 `short-drama-director/references/aspect-ratio-adaptation.md` 等风格规范，此处仅补充"风格锁"的写法。

需要固定项目视觉风格时，建立**风格锁**（可给图号），包含：

```
① 风格身份：媒介质感、整体调性
② 人物审美锁：脸型/体态/皮肤质感标准
③ 场景审美锁：空间质感/材质/年代感
④ 画面质感锁：颗粒/渲染方式/反差
⑤ 正向词：必须投喂的词
⑥ 负面词：防跑偏词包
⑦ 转译短句：交给分镜/投喂的短句
```

⚠️ **风格锁编号不进最终投喂提示词**——必须翻译成自然语言（详见 `sd-feed-engine/references/engineering-language-cleanup.md` §三）。

⚠️ **风格光影冲突时融合不覆盖**：风格锁的默认光影与当前分镜真实光源冲突时，**以当前镜头真实光源为准**，但保留风格的媒介质感、反差控制、颗粒方式。

## 五、资产红线

| # | 红线 |
|---|---|
| 1 | 场景空间方向前后段必须一致，不能"这一段门在左、下一段门在右" |
| 2 | 角度图不替代场景母版；每张图说明"只参考什么/不参考什么" |
| 3 | 道具已在其他图可见时，必须启用单实例锁，不得新增第二件 |
| 4 | 小道具朝向必须写清（手机/照片/证件类） |
| 5 | 人群卡必须翻译成"人群密度"句，不写内部编号 |
| 6 | 无路人需求时不新增人群字段，只写禁止项 |
| 7 | 风格锁编号不进最终投喂稿，必须翻译成自然语言 |
