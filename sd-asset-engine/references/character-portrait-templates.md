# 人物立绘提示词模板（写实 / 3D / 2D 三风格）

> 精编自《场景·人物·道具 生图提示词生成器》
> 归属技能：sd-asset-engine（资产生图引擎）｜工作流 Step 4 人物模板
> **图底横向细节条（硬性 · 2026-10-12 用户裁定 · 第五轮修正）** = **【声纹锚】声纹波形 / 频谱可视化（非文字图形 · 视觉一致性锚）＋【音色速览标签】≤8 词英文（唯一入图文字）**；**完整 Voice Description（2–4 句）不进图**，以文本形式留在提示词文档与《素材接线单》。除此之外其余文字一律禁止；衔接总控角色资产规范（权威在总控 short-drama-director）；资产编号沿用总控「图N」体系。

## 一、使用说明（硬性规则）

- 先确认风格（3D / 2D / 写实），三套模板**分开使用**，不得混用。
- **角色整板固定 16:9 横版**（含四格与底部细节条），内部格子布局另定；成片画幅仍跟 B 锁，不将竖屏成片比例套到角色整板。M0/M1 验收提示词是否写明规格，不声称核验图片；M2 才核实实际图面与尺寸。
- 所有「〔…〕」为占位符，从剧本角色设定与用户资产清单（图N=角色名+造型要点）提取填充。
- 三套模板共用同一骨架：角色设定表 → 立绘提示词 → 人物音色描述（完整版纯文本 + 速览标签入图）→ **角色四格纯图板（面部特写 + 无脸正面/90°侧面/背面全身 + 图底声纹锚）**。
- **Voice Description 为必填项（两档 · 2026-10-12 第五轮修正）**：① **完整版**（英文 2–4 句）必须用英文撰写并原样保留在提示词文档与《素材接线单》中，**不进图**，禁止省略、禁止翻译成中文；② **速览标签**（≤8 词英文）必须撰写，**渲染于图底部（全图唯一入图文字）**，禁止省略。
- **图底横向细节条必须入图（硬性 · 2026-10-12 用户裁定 · 第五轮修正）**：图底部**必须**有一条**横向细节条**，只装两样东西——**①【声纹锚】声纹波形 / 频谱可视化（非文字图形）**；**②【音色速览标签】≤8 词英文，必须渲染于图底部，是全图唯一允许出现的文字**（文字清晰正确、无乱码缺字变形，禁止漏标）。⚠️ **术语正名**：图底那行英文 = **音色交接文本（Voice Description · timbre，指"听起来什么样"）**，**不等于声纹**（声纹 = "这个人是谁"的生物特征）；包内旧称「音色锁」一律更正为「**音色速览标签 / 音色交接文本**」。声纹锚**非文字**、**不占「唯一入图文字」名额**、**不宣称能锁声线**（声线锁定走音频侧 TTS 音色 ID / 参考音）。其余一切文字（角色名 / 编号 / 视角名 / 脸部处理 / 水印 / logo 等）仍**一律禁止**。
- **除音色外零文字（硬性 · 2026-10-10 粉丝反馈纳入 / 第四轮修订 · 2026-10-12 第五轮口径同步）**：角色资产图**除图底部的英文音色速览标签 + 声纹波形外不得出现任何其他文字**——不标角色名、不标编号、不标视角名（正面/侧面/背面/面部特写）、不标脸部处理、不加边框文字/水印/logo/角标。**图上文字只有一处：底部英文音色速览标签（≤8 词）；声纹波形属图案，不算文字。** 病灶：出图信息过多 + 中文字渲染成乱码；另：完整版长英文（100+ 字符）易崩字/被模糊/被杀成字幕水印残留，故缩为 ≤8 词速览标签。
- **立绘纯净规则（硬性）**：人物立绘只呈现**人物本体 + 身上穿戴配饰**；**禁止手持任何道具、禁止身前/身侧/地面放置任何独立道具**（酒葫芦、破碗、剑、手机、书本等一律不得入图）；手部保持自然姿态（垂放/搭膝/交叠/负手等）；道具统一由 `prop-template.md` 单独出设定图，不得混入人物立绘。
- **立绘无 Pose（硬性）**：所有人物立绘统一为**端正站立展示（no pose）**——身体直立、正面朝向镜头、头部端正、无任何动作姿态；**禁止坐姿、蹲姿、行走、战斗姿势、动态动作等一切 pose**；4 View（正面/90°侧面/背面全身）为同一站姿的不同观察视角，不是动作变化；膝盖以下特写为站立姿态下的下装+鞋袜细节。
- **同一人物多造型换装（硬性）**：当资产清单中同一人物出现多套服装/造型（如钱多多A乞丐造型=图1、钱多多B整洁造型=图2），每套造型必须**独立生成一张立绘提示词**。第一套造型使用完整「共用骨架」模板从零生成（含完整 Voice Description 文本 + 图底横向细节条：声纹锚 + 音色速览标签）；第二套及之后的造型使用「同一人物多造型换装生图提示词模板」（见第五部分），核心指令为：**保持人物脸型、人脸细节完全一致，人物音色一致，仅修改服装**，禁止改变脸型、五官、肤色、年龄感；**换装造型不重复写 Voice Description 音色提示词、图底部不重复渲染音色速览标签**（声纹波形沿用第一套造型的同一条波形），音色统一以第一套造型参考图为准。
- **单一面部锚点（硬性 · Face-Anchor Uniqueness · 2026-10-09/10-10 粉丝反馈纳入）**：**全图只允许一处渲染清晰可辨识的五官**——即「面部特写」格（头部近景，头部占该格高度 ≥70%，五官 10 项锁定 + 性别锚点收尾）。**除此之外的每一幅画面**（全身正面立绘、正面/侧面/背面全身）**脸部一律「无脸」——头部完整保留在画内（头型/发型/颈部/肩线齐全），只让面部区域不刻画五官**；禁止出现第二张可辨识的脸、禁止第二个清晰眼神光。⚠️ **禁止「砍头」（2026-10-10 修正）**：**不得把头部裁掉、抹去或推出画框**——模型靠画面里的头锚定**头身比例**，**头部不入画会导致头部比例失真（头忽大忽小、头身比走形）**；旧「无头」写法自本条起**废弃**。⚠️ **禁止字面马赛克**：提示词中不得出现 `mosaic / pixelated / censored / 马赛克 / 像素化 / 打码`——生图模型会把它们渲染成**真实像素块与审查条纹理**，污染画面并被判为异物/水印；「马赛克」在本包只作**口语别名**使用，落到提示词必须转译成「无脸（无面部细节）」。完整规则见 **§七 角色资产板图面规则**。
- **全身完整性（硬性 · Full-Body Integrity）**：三格全身格（正面② / 90°侧面③ / 背面④）= **完整全身**——**头顶到鞋（含鞋袜、含头）全部入画，禁止裁切脚部/头部、禁止画框截断、禁止露白边/露底**（头部必须在画内以保头身比：砍头会让头忽大忽小，见上方面部锚点条）；**鞋必须画在全身格内**——三类特写格（膝盖以下至鞋 / 手部 / 材质）已于 2026-10-10 全部取消，**无处可补**（历史问题：旧版主图只到膝盖以上、鞋只存在于特写格 → 用户拿到的主图上"没有鞋"；**2026-10-12 实测新病灶：提示词同时出现「主图」与「四格纯图板」→ 模型做加法出成 5 格（正面被画两次）**——故「主图」一词**自第六轮起废弃**，一律改称「**正面格**」，并**必须显式声明全图格数**）。

### 立绘提示词
一位约〔年龄〕岁的〔性别/身份〕纯立绘展示，**〔头身比：写实写「真人 6.5~7.5 头身」；3D / 2D 按风格写对应值——主动写头身比是防「头大身小」的第一道锁，与「头部完整入画」配套生效 · 2026-10-13 粉丝反馈〕**，**人物本体 + 身上配饰，不携带、不手持、不放置任何独立道具**。**全图共 4 格，横向并排**：① **面部特写**（全图唯一清晰脸）② **正面全身** ③ **90°侧面全身** ④ **背面全身**——**仅此 4 格，不设独立大主图、不重复任何视角、不出现第 5 格**。②③④三格均为**无脸全身立绘（no pose）**：**头顶至鞋全部入画（含鞋袜、含头，不裁脚、不裁头、不截断、不露底）**，各格人物占该格高度 85%-95%；**面部不刻画任何五官**；**唯一清晰面部只在第①格「面部特写」内**。〔背景描述，如：纯白背景无场景〕。②③④三格为同一人的正面 / 90°侧面 / 背面朝向，端正站立立绘，身体直立、**无任何动作姿态**，整板固定 16:9 横屏画幅，〔焦段，如：50mm〕等效焦距平视无畸变。**四格之下另设一行图底细节条（声纹波形 + 音色标签），不计入格数、不占主视图区。**

**★ 身份外观三件套（必写 · 2026-10-12 新增 · 机检 C26d）**：立绘提示词首句里那个「〔年龄〕岁的〔性别/身份〕」**光有身份词是不够的**——模型会按"这个职业大概穿什么"的统计均值给一套泛化形象（粉丝实测：**外卖员被画成协警**，因为它不知道外卖员该长什么样，就给了个"城市里穿制服的公职人员"）。所以每个 S/A 角色的立绘提示词必须**额外落纸三件套**：

|---|---|---|---|---|
| ① | **职业标识物**（身上配饰，不算独立道具） | 至少 1 个一眼认出行当的硬标识 | `胸前橙色方形外卖箱（保温内胆外露）、平台工牌挂绳` | 无 |
| ② | **服装形制与材质** | 形制 + 材质 + 磨损 + 标志色 | `橙色骑手冲锋衣·尼龙面料·袖口磨白起毛·肩背双反光条掉漆、工装裤沾泥` | `穿制服`、`穿工作服` |
| ③ | **气质体态写进身体** | 长期职业塑造的身体习惯 | `常年骑车致含胸驼背、右肩偏低、手掌粗大、指节发红` | 无 |

**⛔ 反漂移清单（必写，与三件套同段）**：逐条写死这个角色**不能**被画成什么——`禁写成协警警服/公文包/对讲机/肩章`。正向描述禁不住漂移，必须同时给禁止项。

**年龄与体型（必写 · 机检 C26c）**：首句的 `〔年龄〕` 写**年龄段**（`28~32岁`），禁只写"青年/中年"；体型写**数字或明确体型词**（`178cm·精瘦，肩窄腿长`），禁"高大/健壮"这类不可复述的概括。

> ★ **全图唯一清晰面部 = 下表「面部特写」行**；其余三行（正面/侧面/背面全身）**一律无脸——头部完整入画、面部不刻画五官**（完整规则见 **§七**）。

## 四、音色描述撰写规则（**速览标签必须入图 · 渲染于图底部** · 2026-10-10 第四轮 / 2026-10-12 第五轮修正）

### 音色描述撰写规则（三套风格通用）

- 必须为英文，2-4 句，禁止翻译成中文。
- 必含要素：音色特质（音高/质感）、语速语调（可变节奏）、情绪层次（表面与内里的反差）、适用场景（anime dubbing / short drama / 配音）。
- 参考句式：「A female voice, medium pitch, variable speed (soft and gentle shifting to sharp and mocking). Lazy, cold, and dangerous tone with an underlying aura of extreme confidence and controlled madness. Can sound sweet and innocent on the surface, but drops to a low, cutting edge when threatened or when exposing enemies. Ideal for anime dubbing or short drama.」
- 按角色性格改写，不得逐字照抄示例。
- **速览标签（Voice Description Label）**：另写一个 ≤8 词的英文短标签，只保留音色核心词（音高/质感/情绪），如「deep, gravelly, feigned-weak voice, sharp eyes」。**该短标签进图**（渲染于**图底部**，全图唯一入图文字）；完整版反而**不进图**。

### 交付形态（硬性 · 2026-10-12 用户裁定 · 第五轮修正）

| 项 | 内容 | 用途 |
|---|---|---|
| ① 完整版 Voice Description | 英文 2-4 句（音色特质/语速语调/情绪层次/适用场景） | **不进图**：以文本形式留在提示词文档与《素材接线单》，供配音 / TTS / 下游分镜读取 |
| ② 速览标签 Voice Description Label | ≤8 个英文词（音高/质感/情绪核心词） | **入图**：必须渲染于**图底部**（唯一允许入图的文字） |
| ③ 图底声纹锚 | 声纹波形 / 频谱可视化（**非文字图形**） | **入图**：图底横向细节条；**不占入图文字名额**、**不宣称锁声线**；作用 = 视觉一致性锚 + 工作流标记 |

> ✅ **图底横向细节条（现行 · 2026-10-12 第五轮）**：图底部=**① 声纹波形（非文字·视觉一致性锚）＋ ② ≤8 词英文音色速览标签（唯一入图文字）**。用户裁定原话：「**先缩减按 B 方案走吧，那个缩减然后留声纹我觉得还可以。**」——上游用途：下游拿到角色设定图，波形条帮**跨图匹配同一角色**，速览标签帮**一眼读取音色核心**；完整描述回翻文档即可。
> 📌 **为什么从完整版缩写**：生图模型渲染长英文（100+ 字符）易**崩字/缺字/变形**，也会被模型当**字幕 / 水印残留**处理（撞平台合规），有的操作者还会嫌画面脏**手动模糊掉** → 线索直接归零。缩到 ≤8 词后崩字率大幅下降，且**非文字的波形条抗模糊、抗压缩**——两者互补，谁崩了另一个还在。
> ⛔ **仍禁止入图**：「**图中文字标注**」段式的**视角名 / 脸部处理 / 角色名 / 编号 / 边框字**、「**左上角：〔角色名〕**」角标——**一律不得写进提示词**（图面除底部音色速览标签外零文字）。
> 📌 **唯一入图文字 = 图底部英文音色速览标签（≤8 词）**。这是本节的铁律边界，多一个字都算违规；**声纹波形是图案不是文字**，不占这个名额。

⑦ 鞋袜：黑色布面鞋，白底，鞋面干净；白色布袜
⑧ 造型专属配饰：无
```

### 换装执行规则（硬性）

1. **第一套造型为基准**：必须先完成第一套造型的完整立绘提示词（使用「共用骨架」，含完整 Voice Description 文本 + 图底**声纹波形 + 音色速览标签**），后续造型均以第一套为脸型/五官/音色基准。
2. **锁定字段不可改**：脸型、五官、肤色、年龄感必须逐字复用第一套描述，禁止 AI 重新设计或"优化"人脸。
3. **仅服装可变**：除服装、鞋袜、造型专属配饰、（可选）发型外，其余人物特征全部锁定；发型变化时必须写明原因（如梳洗换装），发色和发质不变。
4. **每套造型独立图号**：换装提示词标题必须写明资产图编号（如图2=钱多多B整洁造型），与资产清单编号一一对应。
5. **音色不重复标注（硬性）**：换装造型（第二套及之后）**不写 Voice Description 提示词、图底部不重复渲染音色速览标签**；音色信息统一以第一套造型的**完整音色文本 + 图底速览标签 + 声纹波形**为唯一来源，下游读取该文本，禁止在换装造型中重新编造或修改音色；图底**声纹波形沿用第一套同一条**（同一角色 = 同一波形，换装不改波形）。
6. **立绘纯净与 no pose 规则不变**：换装造型同样禁止手持道具、禁止动作姿态，固定站立立绘+完整全身（含鞋）+膝盖以下细节放大。
7. **单一面部锚点 + 四格纯图 + 全身完整性同样适用（硬性）**：换装造型的**唯一清晰面部同样只落「面部特写」格**，其余三格一律**无脸（无面部细节）**——头部完整入画、面部不刻画五官；三格全身必须**完整全身（头顶至鞋，含头）**；**同样只出四格、同样除图底声纹锚 + 音色速览标签外零文字**。上方「人物锁定」区里的脸型/五官/肤色文字**照写**（用于锁参），但**只在面部特写格渲染成清晰五官**——其余画面出现第二张清晰脸即违反本规则（见 §七）。

## 七、角色资产板图面规则（面部锚点 + 四格纯图 · 除图底声纹锚 + 音色速览标签外零文字 · 硬性 · 2026-10-09/10-10 粉丝反馈纳入 · 2026-10-12 第五轮修正 · 第六轮修正）

> 🔗 **上位权威**：总控 `short-drama-director/references/asset-spatial-ledger.md` §二「角色 4 View 资产参考图」与 `character-lineage-and-sheets.md` §一「标准角色 4 View 资产卡构成」。本节把该口径**落到子技能的实际执行模板**上。

> ⚠️ **2026-10-10 两次口径修正（粉丝实测反馈）**：
> **①（第一轮）** 本包此前用「**无头**」表述，**现予废弃**——**砍头会让生图模型失去头身比参照，导致头部比例失真**。现行口径 = **无脸全身（无面部细节）**：**头部完整保留在画内，只让面部区域不刻画五官**。
> **②（第二轮）** 本包此前的「三联 + 三特写 + 图内文字标注（视角名/脸部处理/角色名/音色）」版式**现予废弃**——**图上字太多且有乱码**。现行口径 = **四格纯图**：**只出四格 + 除图底声纹锚 + 音色速览标签外零文字**。
> **③（第四轮 · 2026-10-10 用户裁定）** 音色描述**属例外**——音色英文本**允许渲染于图底部**（图底是唯一允许入图的文字位）。此前「音色一律禁止入图」的表述**予以纠正**：禁止的是**视角名 / 脸部处理 / 角色名 / 编号**那类文字，**不包含图底音色**。
> **④（第五轮 · 2026-10-12 用户裁定）底部改为「声纹锚 + 缩减版标签」**：图底那行完整英文（2–4 句 / 100+ 字符）**易崩字、易被模型当字幕水印、易被操作者手动模糊**，故**缩减为 ≤8 词速览标签**（完整版转纯文本交付）；同时底部**增设声纹波形 / 频谱可视化**作为**非文字的视觉一致性锚**。现行口径 = **图底横向细节条 = 声纹锚（波形·非文字）＋ 音色速览标签（≤8 词·唯一入图文字）**；**声纹锚不占「唯一入图文字」名额，也不宣称能锁声线**。
> **⑤（第六轮 · 2026-10-12 用户实测）禁止「主图 + 四格板」并列写法**：骨架若同时出现「**主图**」与「**角色四格纯图板**」，生图模型会按 **1 主图 + 4 格 = 5 格**输出（**正面被画两次**，用户实测附图打回）。现行写法 = **总数声明**：开头即写「**全图共 4 格**：① 面部特写 ② 正面全身 ③ 90°侧面全身 ④ 背面全身——**仅此 4 格，不设独立大主图、不重复任何视角、不出现第 5 格**」；「**主图**」一词**废弃**，改称「**正面格**」。

### 7.1 一句话定义

**一张角色资产图 = 四格纯图板**：**面部特写 + 正面 / 90°侧面 / 背面无脸全身**，共四格（**「全图共 4 格」是必须写进提示词的显式总数声明；不设独立大主图、任一视角不得重复出现、不得出现第 5 格**）；**除面部特写格外，其余三格头部完整入画但面部不刻画五官**；**图上文字只有一处 —— 图底部的英文音色速览标签（≤8 词）**（其余一律无字）；**图底另有一条声纹波形（非文字图形）**。

### 7.2 三条独立不变量（各自为什么）

**① 面部锚点唯一 → 脸更准（2026-10-09）**：一张图里出现多张清晰脸时，生图模型会把这些脸**互相平均**（注意力与像素预算被摊薄），脸型/五官相对设定漂移。把全图唯一清晰脸**收束到一格**后，模型对该脸的注意力与像素预算集中，**出图脸部更精准**。

**② 头部完整入画 → 头身比不失真（2026-10-10 第一轮）**：**禁止把头部裁掉、抹掉或"砍头"**。模型靠画面里的头锚定**头身比例**；头部一旦不入画，模型失去参照，**头会忽大忽小、头身比走形**。「无脸」必须是**保头去五官**——头型、发型、颈部、肩线全部保留在画内，只有**面部区域**不做刻画。

**③ 除图底速览标签外零文字 + 只出四格 → 画面干净、模型不分心（2026-10-10 第二轮 / 第四轮修订 · 2026-10-12 第五轮收紧）**：图上每多一行字（视角名、脸部处理、角色名、编号……），模型就要分配一部分像素预算去"画字"，**中文字极易渲染成乱码**，还容易被判成水印/字幕残留；而特写格（膝盖以下至鞋 / 手部 / 材质）会把画布切碎，让四格主视图变小、脸与身体细节反而更糊。**去多余字 + 去特写格 + 缩到 ≤8 词**后画面只留图案 + 一行底部短标签 + 一条波形，模型注意力全部给人物本体。

> 📌 **底部为何是「波形 + 短标签」这对组合**：**波形**是非文字图形 —— 不占模型"画字"的像素预算、不会被渲染成乱码、**抗模糊抗压缩**（形状糊了还是同一条曲线），在参考图序列里形成稳定的可匹配标记；**短标签**是唯一入图文字，纯英文 + ≤8 词 → 崩字率远低于上百字符的长句，且一眼可读。两者互补：**波形兜一致性、标签兜可读性，谁崩了另一个还在**。**这是唯一的例外，不构成「可以在图上随便加字」的先例。**

### 7.3 落位表（**只四格** · 脸部处理列仅供自检，不入图）

| 画面 | 脸部处理（自检用·不入图） | 必写 | 禁止 |
|---|---|---|---|
| **面部特写**（头部近景，头部占该格高度 ≥70%） | **清晰 · 全图唯一** | 五官 10 项 + 皮肤质感 + 性别锚点收尾 | — |
| 正面全身 | **无脸**（无面部细节） | **头部完整入画**（头型/发型/颈部保留）+ 面部不刻画五官；**鞋必须在此格内画完** | 任何五官刻画；**裁头 / 砍头 / 头部出画** |
| 90°侧面全身 | **无脸**（无面部细节） | **头部完整入画** + 面部不刻画五官；完整含鞋 | 同上 |
| 背面全身 | **无脸**（无面部细节） | **后脑完整**（脸天然不在画内）；完整含鞋 | 同上 |

**🥇 只此四格（无独立主图）。** 全图**没有**独立于四格之外的全身主图——正面全身**只在②格出现一次**，不得在四格之外再画一个正面立绘（2026-10-12 实测：提示词写成「主图 + 四格板」→ 模型按 1+4 出成 5 格）。「膝盖以下至鞋」「手部细节」「服饰材质细节」三类特写**已于 2026-10-10 取消**，其内容归并：鞋袜 → 三格全身的描述文字（必须画在全身格内）；手部/配饰 → 「面部特写」行末尾或「配饰」行；服饰材质 → 「服装」行。

**图底横向细节条（唯一入图文字区 + 声纹锚）**：四格之下**另设一行图底细节条**，内含两样东西——**① 声纹波形 / 频谱可视化（非文字图形 · 视觉一致性锚 · 不占入图文字名额）**；**② 该角色的英文音色速览标签 Voice Description Label（≤8 词 · 唯一入图文字 · 清晰正确、无乱码缺字变形、禁止漏标）**。**不渲染** 完整版 Voice Description（**不进图**，转纯文本交付）、角色名、编号。

**逐格「脸部处理」枚举值只允许三种**：`清晰`（仅面部特写格）／`无脸`（无面部细节）／`不适用`（脸部不在画内）。**写出第四种或留空 = 未执行本规则。** ⚠️ 该列**只用于提示词侧自检，不是图上要渲染的文字**。

### 7.4 「无脸」的两种工程实现（**都保留头部** · 二选一）

| 方式 | 写法（英文，可直接进提示词） | 适用 |
|---|---|---|
| **A · 无五官平面**（首选） | `featureless face, no facial features, smooth untextured facial plane, blank face` | 多数情况；保留头型/发型/颈部，面部为平滑无刻画的平面 |
| **B · 柔和失焦**（口语「打马赛克」的工程实现） | `face softly out of focus, blurred featureless face, no facial features` | 需要保留五官位置但不要清晰细节时 |

**❌ 已废弃写法（禁止再用）**：`无头 / headless / cropped head / 头部不入画 / 自颈部截断 / 砍头`——会造成**头身比失真**（见 7.2 ②）。

### 7.5 ⚠️ 禁用词：「马赛克」必须转译

「打马赛克」是**口语别名**，**禁止**把它字面写进提示词。`mosaic / pixelated / censored / 马赛克 / 像素化 / 打码` 会被生图模型渲染成**真实的像素块与审查条纹理**。

> **转译纪律**：凡用户说「脸打马赛克 / 糊掉 / 盖住」，一律转译成 **「无脸（无面部细节）」**（工程实现取 7.4 的 A 或 B），并在交付说明里点明用的是哪一种。

### 7.6 负向词（必写：防第二张脸 + 防砍头 + 防图上出字）

```
duplicate front view panel, extra fifth panel, five-panel layout,

> 📌 **例外（不属禁字范畴）**：图底**声纹波形 / 频谱可视化**（非文字图形）与 **≤8 词英文音色速览标签**（`deep, gravelly, feigned-weak voice, sharp eyes` 一类）**允许入图**，其余文字一律禁。**完整 2–4 句 Voice Description 属于"长文本"**——不入图，写进提示词文档与《素材接线单》。

### 7.7 配套：全身完整性（Full-Body Integrity）

- 三格全身**必须头顶至鞋完整入画**（**头也在画内**）：**禁止裁脚、禁止裁头、禁止画框截断、禁止露白边/露底**；
- **鞋必须画在全身格内**——特写格已取消，**无处可补**（这是 7.3 取消「膝盖以下至鞋」后对鞋的唯一保障）；
- 历史病灶（2026-10-09）：旧版主图写「中景构图至膝盖以上」+ 鞋只存在于特写格 → 用户拿到的主图「鞋没有」。**本规则即为关闭该缺口。**

### 7.8 交付前自检七问（逐角色过）

0. **首句是不是「一名…角色立绘，全身完整入画」，后面又写「四格」？** 是 → **FAIL**：这正是「1 张主图 + 4 格 = 5 格」的触发式写法。首句必须直接进四格语境（「一位约 X 岁的…，**全图共 4 格，横向并排**…」），⛔ 全篇不得出现正向的「主图 / 大主图」（否定用法如「不设独立大主图」可以）。机检 `check_asset_blocks.py` A5 会拦。
1. **全图一共几个人像 / 几格？** 必须**正好 4 个**（1 张清晰脸 + 3 个无脸全身）。出现 5 个（四格之外多一个独立大正面立绘、或某视角重复）→ **FAIL**：删掉多余那一格，并在提示词开头补「**全图共 4 格 · 不设独立大主图 · 不重复任何视角**」。
2. 全图**数一数有几处清晰可辨识的五官**？>1 → FAIL，收敛到面部特写格。
3. **有没有哪一幅画面把头部裁掉 / 抹掉 / 推出画框**？有 → FAIL（改「无脸」：头保留在画内、只去五官）。
4. **图上除图底音色速览标签外，有没有任何其他文字**（视角名 / 脸部处理 / 角色名 / 编号 / 边框字 / 水印 / logo）？有 → FAIL，**只留图案 + 图底一条声纹波形 + 一行 ≤8 词短标签**。
5. **是否只有四格**？出现了「膝盖以下至鞋 / 手部 / 材质」等特写格 → FAIL，删除并把内容并入四格描述文字。
6. 三格全身**有没有完整到鞋**？没有 → FAIL，补「头顶至鞋完整入画、不裁脚」。
7. **图底部有没有「横向细节条」**——内含 ① **声纹波形 / 频谱（非文字）** 与 ② **英文音色速览标签（≤8 词、清晰、无乱码、无缺字）**？缺任一 → FAIL，补上（**速览标签是全图唯一允许出现的文字**；**完整版 Voice Description 不得入图**，只留文本）。

> 「**图底部必须标注以下英文音色速览标签（≤8 词），文字清晰正确、无乱码缺字变形，作为设定图固定组成部分，禁止漏标：〔Voice Description Label 英文原文〕**」
> —— 这是**全图唯一允许入图的文字**（2026-10-10 第四轮 / 2026-10-12 第五轮修正），**删掉即视为漏标违规**。
> ⚠️ **同一区块内另需保留**：「**图底部须设一条声纹波形 / 频谱可视化细节条（非文字图形 · 视觉一致性锚）**」——**声纹锚与速览标签同为图底硬性组成，缺一不可**；但声纹锚**非文字**、**不占「唯一入图文字」名额**、**不得被误当作可删的装饰**。

### 7.11 与「其他格/板」的边界（防混淆）

| 形态 | 是否带文字 | 用途 | 归属 |
|---|---|---|---|
| **角色四格纯图板**（本节） | **图底声纹波形（非文字）＋ ≤8 词英文音色速览标签（唯一文字）；其余零文字** | 锁角色形象（脸 + 体态 + 服装）+ 图底波形锚一致性、短标签读音色 | `character-portrait-templates.md` §七 |
| 九宫格场景图 | 按 `scene-grid-template.md`（含中文降级条款） | 锁场景空间 | `scene-grid-template.md` |
| **道具设定图** | **按 `prop-template.md`（保留「左上角标注：〔道具名〕」）** | 锁道具外观与结构 | `prop-template.md` §二 · **道具图同为 4 格**（正面 / 45° 侧视 / 顶部俯视 / 关键细节特写），但**允许格内标注**且**含细节特写格**——与角色板「零文字 + 不出特写格」**不是同一套纪律**，只是格数碰巧相同 |
| 剧情分镜格 | 可带场次标注 | 固定人物的连续叙事推演 | `sd-storyboard-engine/references/plot-deduction-grid.md` |
| SHOT_TEXT 卡 | 带镜头文字信息 | 分镜交底 | `sd-storyboard-engine/references/storyboard-sheet-template.md` §十一 |

> 本节只管**角色资产板**的图面纪律；其余形态**不受本节约束**，各按自身权威文件执行。
>
> ⚠️ **不要过度外推「零文字」**：2026-10-10 粉丝反馈的原话对象是「**角色资产版**」，故「**除图底声纹锚 + 音色速览标签外**零文字 + 只出四格」**只适用于角色四格纯图板**。道具设定图（`prop-template.md`）仍保留「左上角标注：〔道具名〕」与「关键细节特写」，场景九宫格（`scene-grid-template.md`）仍按其自身标注条款执行——**两者均不得据此节改写**。
>
> ⚠️ **§7.10 负向清单的适用范围**：7.10 表格中所有「**删除**」指令，均只针对**角色资产板的历史写法**（即「左上角：〔角色名〕」角标、视角名 / 脸部处理 / 编号类文字），**不得据此删除道具图 / 场景图中的合法标注条款，也不得删除角色图底部必须保留的声纹波形条与音色速览标签句**。
