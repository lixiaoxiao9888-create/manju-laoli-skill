## 〇、 场景锚点坐标系（Scene Anchor Coordinate System · 防跨段空间漂移核心）

每个核心场景在产出 **① 16:9 无人场景母版** 与 **② 16:9 五宫格场景拼接图** 时，必须同步建立 **《中文场景锚点坐标系》**：

1. **三维空间尺度与朝向定义**：长 × 宽 × 层高，定义北/南/东/西四面墙体或边界。
2. **中文命名固定家具/陈设锚点**：名称 + 精确方位 + 数量（严禁增删移位），如 `锚点A【深胡桃木大班台】位于正中偏北 1.5m`。
3. **默认主光源方向与色温基准**：主光方向、色温、光比（如 5400K 晴日自然侧逆光，光比 1:4）（若为唯美 2.5D/3D CG 通道可按需绑定 `color-card-and-image-models.md` 五色 HEX 色卡；真人实拍/写实风不套用该色卡）。
4. **跨段全量坐标复述铁律（C17i）**：同场景第 2~N 段的 `【场景资产】` 栏**必须 100% 完整复述场景锚点清单与时段光影基准**，严禁写「同上段/沿用第 1 段」。

## 一、使用说明

### 1.1 为什么是「左 2/3 鸟瞰 + 右 1/3 四向」五宫格（工程价值）

- 五宫格 = **高清晰度空间真相源与素材槽位压缩件**——**1 张图 = 5 个核心视角 = 只占 1 个素材槽**（左鸟瞰锁定全屋/全场景空间拓扑关系，右四向锁定正/背/左/右立面细节），交叉可定位，既对抗视频模型素材槽上限，又让下游分镜不会把家具左右颠倒。
- **固定版式四锁（硬性）**：
  1. **16:9 横版，左 2/3 右 1/3**：左侧约 2/3 宽度为高空鸟瞰透视图（格 1），右侧约 1/3 宽度纵向排列 4 个等高小格（格 2 正面 / 格 3 背面 / 格 4 左侧 / 格 5 右侧），**全图共 5 格，不多不少，不得出现第 6 格**，无黑边无留白填满；
  2. **拼接图三统一**：同风格 / 同时段光影 / 同色调；光源方向跨格一致（鸟瞰与“正面”格入射方向必须吻合）；
  3. **交叉可定位**：右侧每格内容必须能在左侧鸟瞰图中找到对应位置；左右矛盾 = 废图重出，不得入册；
  4. **纯场景禁人物**；需要站位时另走战斗站位版，不在本图内叠人。

## 十、 场景空间与站位方案 C / C+（场景母版 + 3D 白模轴测站位图 · 实测定型体系）

> **选型决策（与方案 A 并行，可按需自由切换）**：
> - **方案 A（经典纯五视图）**：16:9 五视图场景拼接图，无白模。
> - **轻量方案 C（单张大全景母版 + 3D 白模）**：适合单向拍摄、无 180° 反打、极度看重单一背景超清纹理的场景。
> - **满配方案 C+（无剖面 16:9 五视图母版 + 正交 45° 彩棋白模）**：`@图1` 五视图管 360° 全向真实材质与反打背景，`@图2` 正交 45° 灰白建筑与顺色彩棋站位图管初始站位。
> - **二合一方案 C++（单张实景 45° 正交等轴测 + 彩棋/素模小人 · 省图位防空椅打架）**：将真实场景材质与 45° 彩棋站位合进同一张 `图1`（不再另挂空镜五视图，彻底消除空椅抢权重并省出 1 个图位），投喂时必须配套 **封闭屋顶与通顶高墙 3 道锁**（见 §10.4）。

### 10.1 资产生成先后铁律（先出母版与独立道具 → 再同垫生成白模）

- **⛔ 严禁脱离母版图或关键道具图独立盲生白模**：否则白模的建筑比例或地上/桌上道具轮廓（如把半截断剑画成长剑）必然与 `图1` / 道具图打架。
- **强制两步流**：
  1. **第一步（先出图①场景母版 + 独立关键道具图）**：纯无人实拍空镜锁死建筑材质与四面墙；凡需拾取、易手或特写展示的残损/独立关键道具（如断剑），先出单实体道具设定图（如 `图9`）。
  2. **第二步（同时垫 `@场景母版` + `@关键道具图` 生成图② 3D 白模）**：指令生图模型 100% 沿用 `@图1` 的四面墙与家具布局，同时将 `@关键道具图` 按原残缺轮廓比例转为纯灰白哑光素模摆入白模。
  3. **跨段位移必更新 `图2B`**：当角色在段 N 末尾已完成明显跨区位移（如出列走到场中）时，段 N+1 必须垫原 `图2` 局部微调生成 `图2B` 同步更新站位与道具落点，不可沿用旧 `图2` 导致模型把人拉回原地重走。

### 10.2 方案 C+ 五视图母版（`图1`）与单张母版盲区墙（`图1B`）互斥规则

1. **方案 C+ 五视图母版（左 2/3 无剖面实拍 + 右 1/3 纵排四向 · 首选）**：
   - **版式四锁**：16:9 横版、无黑边无留白填满整个区域；建议 2K/4K 高清出图。
   - **左侧 2/3 严禁切墙剖面**：必须是**室内无剖面实拍高角全景**（摄影机架设在真实室内空间内斜向下广角俯拍，画面底端为完整连贯的室内地面，**严禁切开近端墙体画成齐腰矮墙/沙盘剖面**——实测材质图带矮墙剖面会被视频模型照抄成“舞台/沙盘”穿帮；齐腰切墙剖面仅由 `图2` 白模独自承担）。

### 10.3 3D 正交等轴测彩棋站位图规范与模板（切断原机位 + 顺色彩棋主角 + 双地标夹心坐标）

> **实测根因**：轴测俯视白模中，泛写“身前/身后/身侧/队首/队尾”存在视角二义性（如“身前”常被画成靠镜头的角色背后，“队首”常被画成靠镜头队尾）；未封顶人数则常在台阶/柱旁凭空多塞 NPC。

1. **首行显式切断原图正面透视机位**：垫正面平视参考图出轴测时，首行必写 **`仅提取参考图平面布局与家具位置，完全剥离原图正面平视镜头，强制重构为 orthographic 45-degree isometric cutaway view, parallel projection`**（严格 90° 四角矩形，左上/右上两面远端高墙完整立起，左下/右下两面近端墙齐腰低矮围合剖切并保留正门门洞），彻底避免退回一点透视或变形为五边形。
2. **顺色彩棋主角编码（替代全白人偶+极细底座圆盘）**：灰白无纹理建筑缩尺模型（`untextured pure matte light-grey plaster architectural maquette, ambient occlusion clay render`）+ 浅灰白群演作中性底板，**仅核心主角全身涂为顺应各自戏服主色的高饱和哑光纯色无五官圆头人偶**（如纯黑/纯红/纯青绿/纯橙黄/纯钴蓝），视觉编码器一眼区分且零色偏风险。
3. **双地标夹心坐标 + 人数封顶**：废除泛写“身前/身侧/队首”，坐标必须写死为“位于〔主体〕与〔刚性建筑地标〕之间”或“最靠近〔刚性建筑地标〕的第一位”，并显式声明各功能区精确人数。
