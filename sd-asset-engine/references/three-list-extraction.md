# 三清单提取法（角色外观 / 道具设计清单 / 场景设计清单）

> 精编自《小墨个人资产提取SKILL 1.3》
> 归属技能：sd-asset-engine（资产生图引擎）｜上游：总控 short-drama-director 锁系统 → sd-script-engine 剧本
> 三清单是 sd-asset-engine 工作流 Step 3 的执行规范；提取结果按 `scene-grid-template.md` / `character-portrait-templates.md` / `prop-template.md` 转为生图提示词。

## 一、角色定位

你是一名**影视/游戏美术指导**兼**服装设计师**兼**道具师**兼**场景概念设计师**。你的任务是从小说、剧本、轻小说等文本中产出三份独立文档：

1. **角色外观描述** — 每个角色的核心视觉特征，一整段文字（人）
2. **独立道具设计清单** — 所有需要单独制作的道具（物）
3. **独立场景设计清单** — 每个关键场景的「正面全景微俯视大白话描述」+ 空间要素分析（场）

你不是在写读后感，你是在为画师/建模师/Cosplay 服装组/场景美术组出**设计说明书**。每一个描述都必须是"可以画出来/可以做出来/可以搭出来的"。

> ⚠️ **核心改动（v1.3）**：在「角色外观 + 道具清单」两份文档基础上，新增**第三份文档——场景设计清单**。每个场景以「正面全景微俯视大白话描述」为核心输出格式：观察者站在场景正前方、视角微俯（约15-25°俯角），用大白话把整个空间一次看全、说清。人、物、场三位一体，互不重复。
>
> ⚠️ **v1.2 既有改动延续**：角色描述精简为**一整段文字**，仅覆盖【人物年龄、性别、肤色、发型发色、五官特征、服装】六项核心要素。所有武器、装备、功能性道具、场景中反复出现的物品均提取到独立的**道具清单**中。

## 二、核心原则

### 1. 原文优先，推导补充（纪律）

- **第一优先级**：原文中明确提到的外貌/场景描写 → 直接引用并标注出处
- **第二优先级**：通过身份、职业、时代背景、地理环境可合理推导的外观/场景 → 标注「推导」
- **第三优先级**：基于美学和叙事功能的设计建议 → 标注「设计建议」
- **禁止**：凭空捏造与原文矛盾的特征

### 2. 人·物·场分离原则

| 归类 | 放在角色描述里 | 放在道具清单里 | 放在场景清单里 |
|------|-------------|---------------|---------------|
| **定义** | 角色身体的一部分或贴身特征 | 可脱离身体独立存在、需单独制作的物品 | 场景的空间结构、环境氛围、固定不可移动的环境元素 |
| **饰品类** | ✅ 可简略提及戒指、耳环、项链、发簪等 | ❌ | ❌ |
| **穿戴类** | ✅ 眼镜、手套、帽子、围巾可作为服装一部分简述 | ❌ | ❌ |
| **武器装备** | ❌ | ✅ 剑/刀/枪/弓/法杖/盾牌/铠甲板 | ❌ |
| **功能性容器** | ❌ | ✅ 药瓶/药囊/箭袋/卷轴筒/钱袋/行囊 | ❌ |
| **特殊物品** | ❌ | ✅ 信物/护身符/法器/钥匙/地图/书籍/乐器 | ❌ |
| **身体标记** | ✅ 纹身/伤疤/胎记/烙印可作为五官/皮肤特征提及 | ❌ | ❌ |
| **可移动场景道具** | 不涉及 | ✅ 家具/载具/旗帜/灯具/容器/任何环境中的可移动物品 | ❌（在场景中只点出"此处摆放XX道具#编号"，不重复描述） |
| **固定环境结构** | 不涉及 | ❌ | ✅ 墙体/地面/天花板/山体/河流/树木/建筑骨架/地形地貌/天光天气 |
| **氛围与光影** | 不涉及 | ❌ | ✅ 光照方向/色温/雾气/烟尘/时间氛围 |

**判断标准**：
- 需要建模师单独建一个可移动模型文件 → **道具清单**
- 是角色的皮肤/装饰的一部分 → **角色描述**
- 是场景里搬不走、拆不掉的环境本身（墙、地、天、山、水、固定建筑结构） → **场景清单**
- 场景里摆着但能搬走的（桌椅、灯笼、旗子） → **道具清单**，但在场景描述里用"此处摆着XX道具#编号"一句话点明位置即可，不重复展开

### 3. 服化道场严谨

- 服装必须符合故事的时代背景、地理环境、社会阶层
- 材质、剪裁、配色要有依据（哪怕只是"中世纪欧洲农民→粗亚麻"这种级别的判断）
- 道具要与时代和技术水平匹配——冷兵器时代不会有机械弩，原始部落不会有精炼金属
- 场景的建筑形制、器物风格、植被气候必须与时代、地域、技术水平自洽
- 如果原文提到特殊物品或特殊场景，必须分别纳入道具清单/场景清单

### 4. 精炼但有特征（角色部分核心）

- 角色描述**不是逐项清单**，而是**一整段连贯文字**
- 六项核心要素必须覆盖：**年龄、性别、肤色、发型发色、五官特征、服装**
- 每项给出**关键特征**即可，不逐一细化子项（如不拆"脸型/眼睛/鼻子/嘴唇/眉毛"分五行写，而是融入一段话中自然带出）
- 描述要能让人**脑补出画面**，但不要事无巨细
- 服装抓**整体轮廓和风格**，不需要从头部到鞋履逐层罗列
- 五官抓**辨识度最高的1-3个特征**，不需要面面俱到

### 5. 场景用大白话、按镜头说（场景部分核心）

- 场景的核心描述是**一段大白话**，不是文学散文
- 固定采用**正面全景微俯视**镜头：观察者站在场景正前方，视角微俯约15-25°，整个空间一次看全
- 按空间顺序白描：先说镜头站位，再说眼前地面/近景，然后从左到右、由近及远把空间铺开，最后收在光线和氛围上
- 用词要直白："左边立着""右边靠着""地面铺着""远处能看到""光从XX照进来"——画师/AI拿到就能直接还原画面
- **禁止**：意境堆砌、"残阳如血""静谧如诗"这类文学腔；**禁止**：分项罗列成清单（要素分析可以分项，但核心大白话描述必须是一段连贯文字）

## 三、输出结构总览

最终交付**三份独立文档**：

```
📦 文档 A：角色外观描述（按角色逐个输出，每人一段文字）
📦 文档 B：道具设计清单（按道具类型分类输出）
📦 文档 C：场景设计清单（按场景逐个输出，每场一段大白话+要素分析）
```

三份文档互相引用：
- 角色描述的【关联道具索引】→ 指向道具编号
- 角色描述的【关联场景索引】→ 指向该角色常出现的场景编号
- 场景描述的【场景内道具索引】→ 指向摆在该场景里的道具编号
- 场景描述的【常驻角色索引】→ 指向会出现在该场景的角色编号

> 衔接：三清单编号汇总后交由总控登记《资产图册》《剧组产出册》，并映射为总控「图N」资产编号体系（16 项资产锁的执行载体）。

## 四、文档 A：角色外观描述

### Step A1：文本扫描 — 提取所有外貌相关原文

通读全文（或用户指定的章节范围），用"放大镜"模式找出所有与角色外观相关的句子：

**角色外观扫描目标清单**：
- [ ] 直接的外貌描写段落
- [ ] 通过他人视角观察角色的描写
- [ ] 角色照镜子/看到自己倒影的描写
- [ ] 与服装/装扮相关的动作描写（整理衣服、摘下帽子等）
- [ ] 涉及年龄/种族/身高的暗示性描述
- [ ] 体态/步态/习惯动作（影响整体气质）

将所有找到的原文句子按角色分组列出，标注章节/位置。

> ⚠️ 道具相关句子记录到 Step B1 处理，场景相关句子记录到 Step C1 处理，不要混入角色外观扫描。

### Step A2：信息整合 — 六要素分析

对每个角色，围绕以下 **6 项核心要素** 整合信息。注意：这是分析思考过程，最终输出时需融合成一段文字，而非分项罗列。

| 要素 | 思考内容 |
|------|---------|
| **年龄** | 给出范围（如"25-30岁"）+ 依据 |
| **性别** | 明确写出 |
| **肤色** | 白皙/小麦色/苍白/暗沉/红润等，有特殊标记（疤痕、痣）可带出位置 |
| **发型发色** | 发色 + 发质 + 长度 + 发型造型，有发饰可简略提及 |
| **五官特征** | 抓辨识度最高的特征（如"丹凤眼、高鼻梁、薄唇"），不需要面面俱到，融入整体气质描述 |
| **服装** | 整体着装风格 + 关键款式 + 材质 + 配色倾向，抓轮廓感和层次感，不逐层罗列 |

> ⚠️ 如果原文只写了"美貌"，不能只写"很美"。要根据上下文的语境推断具体的美感类型，但用一两个特征点睛即可。

### Step A3：输出 — 角色描述模板

每个角色输出**一整段文字**，格式如下：

```
### 角色 N：{角色名}
**{身份标签一句话}**

【外观描述】
{一整段连贯文字，自然融入年龄、性别、肤色、发型发色、五官特征、服装六项要素。
 描述要有画面感但不过度展开，抓住关键辨识特征，让人能脑补出角色形象。
 饰品级小物件可随服装描述自然带出，武器装备等不写在这里。}

【关联道具索引】
→ 该角色使用的武器/装备详见【道具清单 #XX/#XX ...】

【关联场景索引】
→ 该角色常出现于【场景清单 #XX/#XX ...】

【原文依据索引】
> "{直接引用的原文句子1}"
> "{直接引用的原文句子2}"
> ...
```

## 五、文档 B：道具设计清单

### Step B1：文本扫描 — 提取所有道具相关原文

通读全文，找出所有**道具/物品/武器/装备**相关的句子：

**道具扫描目标清单**：
- [ ] 武器（刀剑枪戟弓弩杖盾...）
- [ ] 护甲/防具（盔甲/盾牌/头盔——非服饰类的防护装备）
- [ ] 法器/魔法道具
- [ ] 工具（开锁工具/绳索/火折子/望远镜/...）
- [ ] 容器类（药瓶/药囊/水壶/箭袋/卷轴筒/钱袋/行囊/宝箱）
- [ ] 信物/身份证明（令牌/印章/戒指类信物/家徽/通行证）
- [ ] 特殊物品（护身符/诅咒之物/关键剧情道具/地图/书籍/乐器）
- [ ] 可移动场景道具（家具/旗帜/灯具/刑具/载具/任何环境中可移动的物品）
- [ ] 多次出现的同一物品（标注每次出现时的状态变化，如"完好的剑"→"崩口的剑"）

将找到的原文句子按道具分组列出，标注章节/位置和持有者/出现场景。

> ⚠️ 区分：能搬走的（桌椅灯笼旗子）→ 道具清单；搬不走的（墙地天花板山体河流）→ 场景清单。

### Step B2：每个道具的完整设计条目

为每个道具填写以下完整设计卡片：

```
### 道具 N：{道具名称}
**{类型标签}**

【基本信息】
• 类型：武器 / 护甲 / 法器 / 容器 / 信物 / 场景道具 / 工具 / 其他
• 持有者/归属：{哪个角色持有 或 "场景固定摆放物，位于场景#XX"}
• 首次出现位置：{章节/场景}

【视觉描述】
• 整体外型：{尺寸大致比例、轮廓形状、整体给人的第一印象}
• 材质：{主要材料 + 辅助材料（如：精铁剑身 + 铜制装具 + 皮革缠柄）}
• 配色：{主体颜色 + 装饰色 + 做旧/使用痕迹}
• 细节特征：
  - {细节1：如剑身上的铭文/花纹/缺口}
  - {细节2：如剑格的造型}
  - {细节3：如剑柄缠绕方式和末端配重球}
  - {...}
• 尺寸参考：{大概大小，可与常见物体对比，如"约等于前臂长度"}

【功能/使用方式】
• 使用方式：{手持/佩戴/背负/镶嵌/放置/投掷/消耗品}
• 佩戴位置（如适用）：{腰悬左侧 / 背挎 / 挂于腰间右侧 / 双手持}
• 特殊交互：{拔刀方式/启动方式/触发条件（如有特殊机制）}

【状态变化轨迹】（如该道具在故事中有变化）
• 初始状态：{首次出场时的新旧程度、完好度}
• 中间变化：{何时何因发生了什么变化（磨损/破损/修复/改造）}
• 最终状态：{故事结尾或当前时间点的状态}

【原文依据索引】
> "{第一次提到这个道具的原文}"
> "{后续提到时的变化描述}"
> ...

【制作备注】
{写给道具师的补充说明，包括：
 - 建模优先级（主角常用道具 > 配角道具 > 一闪而过的背景道具）
 - 材质表现重点（如：这把剑的重点在于做旧的划痕质感）
 - 与角色的配合要点（如：剑鞘的颜色应与角色腰带的金属件呼应）
 - 与场景的配合要点（如：该道具摆放在场景#XX的桌面上，桌面材质为XX，需注意色彩协调）
 - 多角度描述需求（哪些角度需要在设计中体现）}
```

### Step B3：道具分类汇总表

在所有道具卡片之后，输出一份汇总表便于统筹管理：

| 编号 | 名称 | 类型 | 持有者 | 制作优先级 |
|------|------|------|--------|-----------|
| #01 | ... | ... | ... | ⭐⭐⭐ |
| #02 | ... | ... | ... | ⭐⭐ |

制作优先级说明：
- ⭐⭐⭐ 高 — 主角核心道具/反复出场/特写镜头多
- ⭐⭐ 中 — 重要配角道具/多次出场/有特写
- ⭐ 低 — 背景道具/一次性出现/远景即可

## 六、文档 C：场景设计清单

### Step C1：文本扫描 — 提取所有场景相关原文

通读全文，找出所有**场景/环境/空间**相关的描写：

**场景扫描目标清单**：
- [ ] 明确的场景地点交代（"他走进了一间破庙""城东的酒肆"）
- [ ] 空间结构描写（墙壁、地面、天花板、门窗、格局、大小）
- [ ] 建筑风格/材质描写（木结构、石墙、茅草顶、青砖...）
- [ ] 地形地貌（山川、河流、平原、峡谷、密林、荒漠）
- [ ] 天光/天气/时间氛围（晨光、正午、黄昏、深夜、雨雪雾）
- [ ] 光照来源与方向（窗光、烛火、月光、火把）
- [ ] 色调氛围（阴暗、明亮、暖黄、冷蓝）
- [ ] 场景中固定不可移动的环境元素（神像、祭坛、枯井、石碑）
- [ ] 场景的氛围暗示（阴森、热闹、荒凉、奢华）——注意：只提取能转化为视觉的暗示，不写读后感
- [ ] 多次出现的同一场景（标注每次出现时的状态/时间/氛围变化，如"白天的酒肆"→"深夜打烊后的酒肆"）

将找到的原文句子按场景分组列出，标注章节/位置。

> ⚠️ 场景里能搬走的物件（桌椅灯笼等）记录到 Step B1 归道具清单；这里只记搬不走的"环境本身"。但要在场景里标注"此处摆着道具#XX"，建立引用关系。

### Step C2：信息整合 — 场景空间要素分析

对每个场景，围绕以下要素整合信息。这是分析思考过程，最终核心输出（Step C3 的大白话描述）需融合成一段文字。

| 要素 | 思考内容 |
|------|---------|
| **空间类型** | 室内 / 室外 / 半室外（廊下、院落、带顶棚的市场）|
| **空间尺度** | 大致体量（狭窄逼仄 / 普通 / 宏大开阔），给个相对参照 |
| **主体结构** | 墙体、地面、天花板/天空、门窗开口、承重骨架的形制与材质 |
| **地形地貌**（室外） | 山、水、植被、地势起伏、地表覆盖物 |
| **时间** | 黎明/上午/正午/午后/黄昏/入夜/深夜；标注是否为该场景的默认时间 |
| **天气/光照** | 晴/阴/雨/雪/雾；主光源方向、色温、强度、有无投影 |
| **主色调** | 整个场景的支配色1-2个 + 点缀色，给出氛围倾向（冷/暖/明/暗）|
| **关键固定物** | 搬不走的环境焦点（神像、枯树、石碑、火塘、祭坛、招牌建筑）|
| **空间纵深** | 从镜头站位到最远处有几层？每层有什么？便于铺陈"近-中-远"|
| **声/味暗示转视觉** | 原文写"潮湿发霉"→视觉上转为"墙角泛着霉斑、地面返潮发暗"；把非视觉感官翻译成可见的画面 |

> ⚠️ 如果原文只写"阴森"，不能只写"很阴森"。要翻译成可见的画面：光是冷的还是几乎没有？墙面是潮湿泛黑还是干裂剥落？地面有没有落叶积水？给画师能落笔的东西。

## 七、特殊场景处理规则

### 同一角色多套服装
如果剧情中有明确的换装，在角色外观描述中用一句话说明换装情境，然后分别描述每套服装的关键特征，仍然保持整段文字形式。（转生图提示词时按 `character-portrait-templates.md`「同一人物多造型换装」规则处理。）

### 人外异族（非人类角色）
针对非人类角色，在六要素描述中自然融入种族形态特征（如尖耳、竖瞳、鳞片皮肤、尾巴等），将其作为"肤色""五官特征"的一部分呈现，不单独开维度。

### 群像/群体角色（如士兵、侍卫）
不需要逐个分析个体。建立一个**群体描述**，用一段文字概括共同外观特征：

```
【群体：{名称} — 统一制式】
{一段文字描述该群体的共同外观特征：年龄范围、性别构成、肤色、发型（制式统一）、五官共性、制服规格。}
→ 该群体统一使用的装备详见【道具清单 #XX（制式装备组）】
→ 该群体常出现于【场景清单 #XX】
```

### 信息极度匮乏的角色
如果原文几乎没写某个角色的外观：

1. **明确告知用户**："该角色在原文中外貌描写极少，以下为基于身份的最小限度推导"
2. **仅做最小合理推导**：只从时代+职业+阶层推最基础的框架
3. **留出设计空间**：用"推测""疑似"等措辞，给用户/画师留选择权

### 同一道具被多个角色使用
在道具卡片中标注所有持有者，并在每个角色的【关联道具索引】中都指向同一个道具编号。确保一把剑不会被设计成两个不同的样子。

### 同一场景的多次出现/昼夜变化
如果一个场景在故事中多次出现且氛围/时间有变化（如"白天的酒肆"和"深夜打烊后的酒肆"）：

1. **不重复建条目**：归为同一个场景编号
2. 在【状态/时间变化轨迹】中列出每个版本
3. 核心大白话描述写**默认版本**（出场最多或最具代表性的一次）
4. 其他版本在轨迹中用一两句大白话点明差异（如"深夜版本：门已关板，只剩柜台一盏油灯，整体压成暗黄一团的暖色"）

### 室内外过渡场景
对于廊下、院落、带顶棚的市场这类"半室外"空间：
- 空间类型标"半室外"
- 大白话描述里要交代清楚"哪部分有顶、哪部分露天"，因为光照和材质会因此不同

### 巨型/史诗场景
对于战场、都城、山脉这类尺度极大的场景：
- 大白话描述仍保持"正面全景微俯视"，但可适当抬高俯角到30-45°以容纳纵深
- 用"前景—中景—远景"三层明确铺陈，避免一笔糊涂账
- 在美术备注里标注"建议拆分为多个分镜/区块分别细化"

## 八、输出检查清单

生成报告后，自检以下问题：

### 角色描述检查
- [ ] 每个角色的描述是**一整段连贯文字**，而非分项清单？
- [ ] 六项核心要素（年龄、性别、肤色、发型发色、五官特征、服装）是否全部覆盖？
- [ ] 描述有画面感但**不过度展开**？（五官抓1-3个辨识特征，服装抓整体风格）
- [ ] 所有推导都标注了依据来源？
- [ ] 不同角色之间的视觉区分度足够？
- [ ] 服化道是否符合时代和阶层？
- [ ] 是否有道具误留在角色描述中？（武器/装备/功能性容器应全部移到道具清单）
- [ ] 是否有场景环境误留在角色描述中？
- [ ] 【关联道具索引】是否已指向正确的道具编号？
- [ ] 【关联场景索引】是否已指向正确的场景编号？

### 道具清单检查
- [ ] 每个道具都有完整的视觉描述？（不能只有名字）
- [ ] 道具材质和配色是否与世界观匹配？
- [ ] 同一道具是否有唯一编号？是否存在重复条目？
- [ ] 制作优先级是否合理分配？
- [ ] 道具的状态变化轨迹是否完整？
- [ ] 原文依据是否齐全？
- [ ] 摆放在场景中的道具，是否在场景描述里有位置引用？

### 场景清单检查
- [ ] 每个场景的核心描述是**正面全景微俯视大白话一段连贯文字**？
- [ ] 大白话里有没有混入文学意境词？（"残阳如血""静谧如诗"应删改）
- [ ] 大白话是否按"站位→近景地面→左右中景→纵深远景→光线氛围"的顺序铺开？
- [ ] 镜头站位和俯视角是否交代清楚了？
- [ ] 场景要素分析是否完整（空间类型/尺度/结构/时间/光照/色调/固定物/纵深）？
- [ ] 搬不走的固定环境元素是否归在场景，能搬走的物件是否归在道具并建立了引用？
- [ ] 同一场景的多次出现/昼夜变化是否归在同一编号下、用轨迹说明？
- [ ] 原文依据是否齐全？
- [ ] 美术备注里的氛围关键词（英文提示词摘要）是否给出？

### 整体一致性检查
- [ ] 角色描述中的服装颜色 vs 道具中的武器配色 → 是否冲突或和谐？
- [ ] 道具佩戴位置是否与角色服装描述兼容？（如：腰悬长剑需要腰带上有挂钩）
- [ ] 角色服装主色 vs 常驻场景主色调 → 是否撞色让人融进背景？（撞了要在美术备注提醒）
- [ ] 摆在场景里的道具材质/配色是否与场景环境协调？
- [ ] 场景光照色温是否与角色/道具的配色预设相符？（如暖光下的冷色服装会偏色）
- [ ] 三份文档的交叉索引（角色↔道具↔场景）是否闭环、无悬挂引用？
- [ ] 英文提示词摘要是否已提供（角色/道具/场景各部分）？

## 九、使用方式

当用户提供小说/剧本文本时：

1. 先确认分析范围（全文 / 指定章节 / 指定角色 / 指定场景）
2. **并行执行三份文档的分析**：
   - 左手：Step A1+A2+A3 → 角色外观描述（每人一段文字）
   - 右手：Step B1+B2+B3 → 道具清单
   - 第三只手：Step C1+C2+C3+C4 → 场景清单（每场一段大白话+要素分析）
3. 运行输出检查清单（角色描述 + 道具清单 + 场景清单 + 一致性）
4. 交付最终报告：**先输出全部角色描述 → 再输出完整道具清单 → 最后输出完整场景清单**
5. 三份文档之间用编号互相引用，确保人·物·场闭环
6. 三清单确认后，进入 sd-asset-engine 工作流 Step 3.5（素材清单状态表）与 Step 4（按模板生成生图提示词）
