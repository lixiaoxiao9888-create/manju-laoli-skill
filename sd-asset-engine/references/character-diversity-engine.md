# 角色多元化设计引擎（Character Diversity & Anti-Cloning Engine · V8.2.0-SLIM）

> 归属技能：`sd-asset-engine`（资产生图引擎）｜工作流 Step 3（三清单提取后）→ Step 4（人物立绘生成前）强制挂载
> **核心目标**：根治 AI 角色生成「全员网红脸、同款发型、同款黑西装/素长袍、毫无个人辨识度」的模板化病灶；同时守死 **「板式（四格/八格）只管排版格式，画风与光影 100% 归 I 锁」** 的正交边界。

---

## 一、 为什么会跑出「千人一面」？（三大根因与反制原则）

1. **均值词坍缩**：写「瓜子脸、剑眉星目、高鼻梁、大眼睛、黑色短发、深色西装」这类高频套话时，生图模型会直接回归数据集均值，把全剧所有角色画成同一张 AI 网红脸。
2. **缺少全剧横向排异**：孤立地逐个写角色，没有把全剧主要角色放在同一张表里比对「脸型、发型轮廓、服装剪影、主色相、面部记忆点」，导致同性别角色大面积撞车。
3. **模板层隐性锁死**：皮肤质感段默认“无胡须/无瑕疵”、服装不写材质与生活磨损，导致 20 岁学生与 45 岁糙汉、底层工匠与权贵反派长着同一张光滑面皮、穿着同一套崭新样衣。

**三原则**：
- **先排矩阵再落笔**：生成任何角色提示词之前，必须先填完下方 §五《全剧角色视觉差异矩阵》，四项同类排异全部通过才允许进入 Step 4 写立绘。
- **写结构、写不完美、写生活史**：用具体骨相比例、非对称微特征、真实年龄/职业痕迹替代空洞审美形容词。
- **板式与画风 100% 正交**：无论用户选 **① 16:9 四格纯图板** 还是 **② 3:2 八格拼版**，本引擎输出的角色差异化特征均原样适用，**绝不因选了八格就强塞唯美光影/厚涂词，也不因选了四格就降级人物特色**。

## 二、 禁用均值套话黑名单（严禁单独出现，必须替换为具体结构词）

| 维度 | ⛔ 禁止单独使用的模板套话 | ✅ 必须拆解落地的具体维度 |
|---|---|---|
| **脸型骨相** | 瓜子脸、鹅蛋脸、五官精致、棱角分明、英俊帅气、美丽动人、气场强大 | 骨骼轮廓 + 颧骨高低 + 下颌角折角/宽窄 + 颊部饱满度（凹颊/丰润/松弛） |
| **五官细节** | 剑眉星目、大眼睛、高鼻梁、樱桃小嘴、眼神犀利、深邃眼眸 | 眉形浓淡与眉眼距 + 眼型/眼皮/眼尾走势 + 鼻梁形态与鼻头宽窄 + 唇厚薄与嘴角自然走势 |
| **肤质年龄** | 皮肤白皙、光滑细腻、中年沧桑、年轻帅气 | 具体年龄段（如 `34~38岁`）+ 肤色调性 + 胡须/绒毛状态 + 晒斑/雀斑/黑眼圈/法令纹/风霜纹理 |
| **发型结构** | 黑色短发、黑色长发、长发飘飘、清爽短发、古装束发 | 轮廓长度 + 刘海与分缝结构 + 发质与蓬松/贴服度 + 发色层次 + 束发/发饰结构 |
| **服装造型** | 黑色西装、白色连衣裙、古装长袍、休闲装、职业装、风衣 | 整体廓形剪影 + 穿衣层次 + 具体面料肌理 + 色彩三层级（主/辅/点缀）+ 穿法与磨损痕迹 |

## 三、 面容·发型·服装三维差异化词库（抽屉式选配，禁止全剧重复抽同一格）

### 3.1 面容与骨相六维分化

1. **脸型与骨相轮廓（按角色气质与阶层拉开）**
   - **硬朗方颌型**：宽下颌、折角清晰、额头偏方、骨感重（硬汉 / 执法人 / 权臣 / 底层苦力）
   - **窄长清瘦型**：中庭偏长、颧骨微显、面颊微凹、下巴偏尖（谋士 / 病娇 / 隐忍复仇者 / 阴鸷反派）
   - **菱形高颧型**：颧弓外扩有记忆点、太阳穴略凹、冷感高级（强势女高管 / 江湖冷面 / 复杂反派）
   - **圆润钝感型**：短圆下巴、苹果肌饱满、骨骼包裹感强（市井小人物 / 扮猪吃虎 / 温和长辈 / 少年感）
   - **厚重饱满型**：脸宽颊厚、下颌带肉感或轻微双下巴（商贾 / 地方官 / 威严长辈 / 笑面虎）
2. **眉眼结构分化（决定第一眼辨识度）**
   - **眼型**：狭长单眼皮 / 深眼窝内双 / 细长上挑丹凤眼 / 眼尾下垂无辜眼 / 偏圆杏眼 / 轻微三白眼（冷漠压迫感）/ 眼距微宽（疏离感）
   - **眉形**：眉压眼浓眉（压迫感）/ 稀疏淡眉（书卷或凉薄）/ 尾端散开的野生眉 / 细长微挑眉 / 眉尾断裂旧伤
   - **眼周状态**：卧蚕明显 / 熬夜青灰眼袋与泪沟 / 眼尾笑纹鱼尾纹 / 长期眯眼形成的眉间川字纹
3. **鼻与唇的性格化分化**
   - **鼻型**：直挺窄鼻梁 / 鼻梁中段微起驼峰（狠厉、精明或异域感）/ 圆润肉鼻头（亲和、市井、钝感）/ 鼻梁偏短微翘 / 鼻翼略宽有量感
   - **唇型**：薄唇紧抿（克制、刻薄）/ 厚唇微张（钝感、松弛或性感）/ 嘴角天然微垂（严肃、苦相）/ 嘴角微翘 / 干裂发暗的唇色（落魄、风霜）
4. **肤色、胡须与岁月痕迹（打破「全员光滑无须」模板）**
   - **肤色**：冷白（长期室内）/ 暖黄自然 / 日晒小麦或古铜 / 粗糙偏红褐（户外风吹）/ 缺乏血色的灰白（病弱/阴沉）
   - **胡须与面部毛发（男性必按人设显式选定，禁止默认无须）**：干净刮净 / 熬夜青色短胡茬 / 修剪利落的短络腮胡 / 唇周短须或山羊胡 / 斑白长须（长者）
   - **自然痕迹**：鼻梁与两颊零星雀斑、晒斑、轻微痘坑/粗大毛孔（写实糙汉）、深法令纹、抬头纹、颈纹
5. **唯一面部记忆点（★ 每位主要角色必选 1~2 项，全剧互斥不重样）**
   - **天然特征**：眼下泪痣 / 眉尾痣 / 唇角痣 / 单边酒窝或梨涡 / 微微露出的小虎牙 / 轻微高低眉
   - **经历印记**：眉骨细短白疤 / 颧骨陈旧淡疤 / 鼻梁小创可贴或擦伤 / 鬓角一缕早生白发
   - **随身固定脸部配饰**（脱卸时按 `CHAR_STATE` 登记）：细金丝方框眼镜 / 玳瑁圆框眼镜 / 粗黑框旧眼镜 / 单边银质耳骨钉 / 磨损旧耳环

### 3.2 发型与发质四维分化（跨题材通用）

描述每个角色的发型时，必须同时落纸 **轮廓剪影 + 刘海分缝 + 发质整洁度 + 发色层次/束发结构**：

- **现代 / 都市 / 悬疑 / 年代 · 男性**：
  - 极短圆寸或平头（硬朗、底层、执法人、退伍）
  - 侧分背头配几缕垂落碎发（精英、老派、城府深）
  - 蓬松自然卷或凌乱中分（技术宅、落魄、文艺、年轻）
  - 齐颈微长狼尾或脑后随手半扎小揪（叛逆、反派、艺术家、边缘人）
  - 贴头皮梳亮的偏分油头（油腻反派、旧时代商贾）
  - 发际线略后移＋两鬓斑白短发（中年权贵、父亲、老警探）
- **现代 / 都市 / 悬疑 / 年代 · 女性**：
  - 齐下颌一刀切短直发（冷冽、干练、理智）
  - 超短露耳精灵短发（酷飒、行动派、不羁）
  - 锁骨微卷法式碎发（松弛、知性、日常感）
  - 脑后鲨鱼夹/皮筋随手挽起的低丸子头＋耳侧碎发（真实职场、居家、奔波感）
  - 低双麻花辫 / 粗单辫 / 贴颈低马尾（年代、质朴、学生、克制）
  - 复古手推波纹 / 蓬松羊毛卷 / 高颅顶大卷（明艳、张扬、年代名伶）
  - 银灰或花白盘发（老年长辈，发丝蓬松有自然碎发）
- **古装 / 权谋 / 仙侠 / 武侠（严禁全员「高马尾+两缕龙须刘海」）**：
  - 按身份拆开：**全束高冠**（玉冠/金冠/铁冠，正统权贵）/ **半束披发**（江湖散修/世家公子）/ **木簪/布带低束**（隐士/底层/落魄）/ **编发入髻或额前小辫**（异域/边疆/侠女）/ **规整盘髻配步摇或素银簪**（主母/宫廷/已婚）/ **双丫髻或垂挂髻**（少女/侍女）/ **散发凌乱带灰**（疯批/囚徒/战损）
- **发质与细节**：粗硬蓬松 / 细软贴耳 / 自然微卷 / 干枯毛躁分叉 / 微微出油结缕 / 发尾微褪色或挑染（须符合题材与时代）

### 3.3 服装廓形、材质与生活痕迹四维分化

1. **廓形剪影（Silhouette · 同框主要角色必须互斥）**：
   - **A · 宽肩硬挺长廓形**：垫肩大衣、挺括长风衣、硬质西装、宽肩大氅/铠甲
   - **B · 短款利落收束形**：短夹克、工装外套、收腰短衫、劲装箭袖
   - **C · 松弛垂坠叠穿形**：宽松针织开衫、多层次罩衫、宽袍大袖、软料长裙
   - **D · 贴身修长线条形**：修身旗袍、贴身针织/衬衫配高腰裤、紧身机能服
2. **面料材质对比（禁止全剧“光滑化纤感”）**：
   - 粗纺羊毛呢 / 灯芯绒 / 重磅水洗牛仔 / 做旧磨砂皮 / 粗麻粗布 / 挺括精纺西装料 / 垂坠真丝绸缎 / 哑光尼龙冲锋衣 / 提花织锦或素面棉麻
3. **穿法与生活使用痕迹（让衣服像“穿过三年”）**：
   - 领口敞开两颗扣露出锁骨或内搭、袖口随意卷至小臂、领带略松歪斜、衬衫下摆半塞、衣肘/膝盖自然横向折痕、袖口与下摆轻微磨白起毛、口袋略鼓、衣摆沾尘或雨渍、补丁与粗针脚走线
4. **全剧主色相排异（Color-Wheel Separation）**：
   - 全剧主要角色的主色相必须错开，**严禁 3 个以上主角同时穿纯黑/深灰**；
   - 每名角色采用 **60% 主色 + 30% 辅色 + 10% 记忆点缀色**（如暗锈红围巾、旧黄铜皮带扣、藏青织带、亮橙工牌绳），确保远景与多人同框时仅靠色块就能区分身份。

## 四、 亲缘角色 vs 非亲缘角色的差异边界

- **非亲缘角色**：严格执行下方 §五 四项同类排异，做到剪影、脸型、发型、主色相全部错开。
- **血亲/亲缘角色**（衔接 `short-drama-director/references/character-lineage-and-sheets.md`）：仅继承 40%~60% 局部骨相（如眉眼走势或鼻型）或 1 个副色呼应；**脸部年龄纹路、发型轮廓、服装廓形与唯一面部记忆点仍必须清晰区分**，避免长成双胞胎。

## 五、 《全剧角色视觉差异矩阵》（Step 3 后、Step 4 前必填前置表）

在输出任何人物立绘提示词之前，必须先列出下表并完成四项排异核对（任一项撞车必须当场改掉再出立绘）：

| 角色 | 性别/年龄段/身高体型 | 脸型骨相与五官重心 | 唯一面部记忆点（全剧互斥） | 发型轮廓与发质 | 服装廓形（A/B/C/D）+ 材质 + 穿法痕迹 | 主色/辅色/点缀色 |
|---|---|---|---|---|---|---|
| `@角色A` | 〔必填〕 | 〔必填〕 | 〔必填〕 | 〔必填〕 | 〔必填〕 | 〔必填〕 |
| `@角色B` | 〔必填〕 | 〔必填〕 | 〔必填〕 | 〔必填〕 | 〔必填〕 | 〔必填〕 |

**四项同类排异硬检（逐条过关，全 YES 才进入 Step 4）**：
1. **脸型排异**：同性别主要角色的脸型骨相与眉眼重心是否已错开？（禁全员瓜子脸/同款浓眉大眼）
2. **发型排异**：同性别主要角色的发型长度、刘海/分缝与轮廓是否涂黑剪影也能一眼分清？
3. **印记排异**：每位主要角色是否都有至少 1 处具体面部记忆点或真实年龄/生活痕迹，且全剧不重样？
4. **服装排异**：同框主要角色的服装廓形（A/B/C/D）与主色相是否错开？（若设定为统一制服，是否已用体型、旧化磨损、穿法与随身配饰拉开差异？）

## 六、 真人写实防假面与景别适配三律

1. **保留自然不对称（Natural Asymmetry）**：写实人物资产提示词显式加入“保留面部自然不对称（眼型、眉高、嘴角微差）”，根治 AI 左右绝对对称导致的蜡像假脸。
2. **分区肤质与按景别取舍**：
   - **特写 / 近景**：鼻翼与内颊保留微深且不规则的自然毛孔，外颊与太阳穴纹理更细；额头、鼻梁等凸面保留极克制的自然皮脂微光；
   - **全景 / 全身格**：只锁肤色冷暖与受光轮廓，不向小尺寸全身格强塞微观毛孔或粗大皱纹词，避免模型把全脸糊成斑驳颗粒。
3. **90° 真侧脸单眼铁律**：描述角色 90° 侧脸视角时，写明“只露近侧眼眉与完整前额到下颌侧面剪影，不露远侧眼睛与嘴角”，防侧脸画出半只漂浮远眼。
