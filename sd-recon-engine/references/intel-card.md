# 对标情报卡（intel-card）

> 本文件回答一个问题：**采回来的东西，按什么格式交出去。**
> 配套：[source-ladder.md](source-ladder.md)（去哪儿找）· [recon-evidence.md](recon-evidence.md)（怎么才不出错）

## 〇 · 这是什么

《对标情报卡》是采风环节的**唯一交付物**。一张卡 = 一部剧（或一个题材）的公开情报全集。

**它不是什么**：不是剧本、不是分集大纲、不是复制粘贴的素材堆。它是**给下一步生产用的结构化输入**。

**一条铁律**：卡里每一栏都要能被**独立核查**——写明"谁在哪一天说的"。写不出来的，写进 ⑫ 未找到项。

## 一 · 十三项字段总表

| # | 字段 | 必填 | 一句话要求 |
|---|---|---|---|
| ① | 剧名 | ✅ | 中文名 / 原文名 / 别名 + 是否改编 |
| ② | 平台与上线 | ✅ | 平台 / 上线日期 / 是否仍在榜 |
| ③ | 体量 | ✅ | 集数 / 单集时长 / 总时长 / 是否分季 |
| ④ | 题材与标签 | ✅ | 题材归类 + 常见标签 + 同题材对比位置 |
| ⑤ | 主创 | ⭕ | 主演 / 导演 / 编剧 / 出品方（公开可见者） |
| ⑥ | **热度证据** | ✅ | 分条列出：指标 / 数值 / 时点 / 来源 / 分级 |
| ⑦ | 故事骨架 | ⭕ | 一句话前提 / 主要冲突 / 结局走向 |
| ⑧ | 爽点结构 | ⭕ | 开局钩子 / 反转点位 / 情绪峰值位置 |
| ⑨ | 观众反馈 | ⭕ | 正面 / 负面分列，各标来源 |
| ⑩ | **可迁移点** | ✅ | ★ 哪些结构能被新项目复用 |
| ⑪ | **不可迁移点** | ✅ | ★ 哪些是它的专属资源，抄不来 |
| ⑫ | 未找到项 | ✅ | 明确列出没查到的字段 |
| ⑬ | 采集记录 | ✅ | 检索词 / 覆盖源 / 采风时点 / 采风者 |

**⭕ = 找不到时写「未找到」并通过，不算失败。** ✅ = 必须有一栏内容，哪怕内容是「未找到」。

## 二 · 逐字段填写口径

### ① 剧名

```
剧名：《禁止闪婚：甜桃烈酒2》
原文名：（不适用 / 英文名：…）
别名：（无 / 平台另名：…）
是否改编：☐ 原创  ☐ 改编自〈作品名〉  ☐ 未找到
```

**口径**：剧名必须**逐字照抄来源原文**（外网检索时尤其重要——模型很容易把剧名"翻译"成看起来很合理的样子）。**分季标记要保留**（《XXX 第八季》不是《XXX》）。

### ② 平台与上线

```
主平台：红果 / 抖音 / ReelShort / DramaBox / …
上线日期：2026-10-03
当前状态：在榜（截至 2026-10-07）/ 已下榜 / 未知
```

**口径**：多平台同发时要**分列**；「在榜」必须带**截至日期**。

### ③ 体量

```
集数：77（若官方标注，照抄官方数字）
单集时长：未找到 / 约 1.5 分钟
总时长：未找到
分季：无 / 有（第 N 季）
```

**口径**：集数**以官方标注为准**；**禁止用"每集 1~2 分钟 × 集数"反推总时长**（那是估算，不是数据）。

### ④ 题材与标签

```
题材：家庭伦理 / 爱情 / 古风 / 系统重生 / …
标签：（照抄来源给出的标签，如 系统、重生、逆袭、打脸虐渣）
同题材位置：据〈来源〉〈日期〉，相对当周同题材中位数 …（有则填，无则写"未找到"）
```

### ⑤ 主创

```
主演：A / B / C          （照抄；不确定的人数不要凑）
导演：
编剧：
出品方：
```

**口径**：**只写来源明确写出的**。不认识的职务不要硬填。

### ⑥ 热度证据（★ 核心栏 · 一行一条，禁止合并）

```
| # | 指标 | 数值 | 时点 | 来源 | 分级 |
|---|---|---|---|---|---|
| 1 | 榜单排名（日榜） | 第 11 名 | 2026-10-07 | 短剧工程单剧页（原始来源标注为抖音官方短剧数据中心） | T1.5 |
| 2 | 历史最高排名 | 第 11 名 | 2026-10-06 | 同上 | T1.5 |
| 3 | 在榜天数 | 3 天 | 2026-10-05~10-07 | 同上 | T1.5 |
| 4 | 当周热播指数 | 911（环比 -1%） | 截至 2026-10-07 | 同上 | T1.5 |
| 5 | 首日排名 | 第 92 名 → 次日第 11 名 | 2026-10-05 → 10-06 | 同上 | T1.5 |
```

**四条硬口径**：

1. **一行一条**，禁把多个指标挤在一行（"热度 911、排名 11、在榜 3 天"= 三条，不是一条）；
2. **每条必须带时点**——没有日期的热度数字**不进卡**；
3. **「热播指数」不是播放量**，照抄指标原名，**禁止改写成"播放量 911 万"**；
4. **平台不同不可比**，跨生态排名禁止并列；外网源的排名单独成表并注明"与国内平台不可比"。

### ⑦ 故事骨架

```
一句话前提：〈主角〉在〈处境〉下，必须〈目标〉，否则〈代价〉。
主要冲突：（2~3 条）
结局走向：〈公开可见者；未知写"未找到"〉
```

**口径**：只写**公开可见**的简介级信息。**禁止**为补全骨架而编造分集情节——分集内部细节通常拿不到，写「未找到」即可。

### ⑧ 爽点结构

```
开局钩子：（前 3 秒 / 前 1 集给出的冲突或反差）
反转点位：（公开讨论中反复被提到的反转处）
情绪峰值位置：（第 N 集附近 / 结局）
```

**口径**：本栏多为**推断**，**必须标注推断依据来源**。拿不到就写「未找到」。

### ⑨ 观众反馈

```
正面：（照抄或转述，标平台 + 时点 + 链接）
负面：（同上；争议点尤其重要——争议往往比好评更有信息量）
```

**口径**：**正反必须都记**。只记好评的卡是**失真**的卡。

### ⑩⑪ 可迁移点 / 不可迁移点（★ 本卡的价值所在）

见 §三 专项方法。

### ⑫ 未找到项

```
- 单集时长：未找到
- 付费卡点位置：未找到（需实际观看）
- 完播率：未找到（平台不公示）
```

**口径**：**主动列**，不要留空。这份清单是**诚实度的证据**，也是下一轮采风的待办。

### ⑬ 采集记录

```
检索词：（逐条列出实际用过的检索词）
覆盖源：（按分级列出：T1 ___ / T1.5 ___ / T2 ___）
采风时点：2026-10-08
预算状态：未用尽 / 已用尽（未覆盖：___）
采风者：（工具/执行者标识）
```

## 三 · 可迁移点 / 不可迁移点：怎么提

**这一步是采风的目的**。做完 ①~⑨ 只是"抄回来了"，做完 ⑩⑪ 才是"能用了"。

### 3.1 可迁移点（问：这个结构换一批人、换一个朝代/地点，还成立吗？）

| 判据 | 例子（写作时替换为实际内容） |
|---|---|
| **冲突结构**能否换壳 | 「被贬妻为妾 → 直接进宫面圣」的**反应模式**可迁移（不哭诉、立刻反制）；换成任何"被压制 → 立刻反制"的处境都成立 |
| **人物关系**能否换壳 | 「表面废人、实则马甲一层层揭」的**反转节奏**可迁移 |
| **钩子位置**能否搬 | 「开局即高能，第一集就决裂」的**时间点**可迁移 |
| **标签组合**能否复配 | 「系统 + 重生 + 打脸」的**组合方式**可迁移 |

### 3.2 不可迁移点（问：这个东西，我新项目里拿得到吗？）

| 类型 | 说明 |
|---|---|
| **演员资源** | 主演自带的流量与表演能力，新项目未必有 |
| **平台流量** | 该剧吃到了平台某次推荐位 / 档期红利，不可复制 |
| **IP 基础** | 改编自已有读者基础的作品，原创项目没有 |
| **档期红利** | 假期档 / 竞品空窗期，属外部条件 |
| **制作规模** | 高成本实景 / 特效投入，短剧项目通常够不到 |
| **运气成分** | 二次传播、意外出圈——**必须承认存在**，不要写成方法论 |

### 3.3 反模式（这样写 = 白采）

- ❌ 「这部剧节奏好、人设好、值得学习」——**空话，不可执行**；
- ❌ 「照它这个来」——**没说清要照什么**；
- ❌ 把 ⑨ 观众讨论里的评价直接搬进 ⑩——**那是别人的判断，不是可迁移结构**；
- ❌ 只写可迁移点、不写不可迁移点——**会误导项目组以为能全盘复刻**。

## 五 · 交付前自检清单

- [ ] ①  剧名**逐字照抄**来源，未被"翻译"或"美化"；
- [ ] ⑥  热度证据**一行一条**，每条带时点，分级标注正确；
- [ ] ⑥  没有把「热播指数」写成「播放量」；
- [ ] ⑥  跨生态排名未并列比较；
- [ ] ⑨  正反面都记了（不是只记好评）；
- [ ] ⑩⑪ **两栏都写了**，且 ⑩ 里没有空话；
- [ ] ⑫  未找到项**主动列出**（哪怕 0 项也要写"无"）；
- [ ] ⑬  检索词、覆盖源、时点、预算状态齐全；
- [ ] 全文**没有任何未标来源的硬信息**。

**任一项不通过 = 卡不合格，返工后重交。**
