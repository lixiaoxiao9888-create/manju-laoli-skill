# 采风证据纪律（recon-evidence）

> 本文件回答一个问题：**怎么才不出错。**
> 配套：[source-ladder.md](source-ladder.md)（去哪儿找）· [intel-card.md](intel-card.md)（按什么格式交）

## 〇 · 为什么单独写一份纪律

采风环节最危险的失败**不是"没找到"，而是"找到了一份看起来很真的错东西"**。

错误在这个环节会被**原样传下去**：情报卡 → 来源登记 → IP 开发 → 全剧圣经 → 剧本。等到剧本阶段再发现"这个榜单是三年前的"，返工成本已经不可控。

**本纪律的全部目的：让错误在采风环节就停下。**

## 一 · 六条铁律

### 铁律 1 · 不编造

**没查到的写「未找到」。禁止用"行业常识"把内容补全。**

这是最重要的一条。模型的默认行为是**补全**——它会用"短剧通常 80~100 集""这类题材一般有个反转"把空缺填满，而且填得非常像真的。

**判据**：这个数字/名字，我能在某一份具体来源里指出来吗？指不出来 = 删掉，写「未找到」。

### 铁律 2 · 时点必标

**任何榜单、热度、排名、在榜状态，必须带日期。**

- 推荐榜单后缀写法：`第 11 名（2026-10-07 日榜）`
- 「在榜」必须写 `截至 <日期>`
- **过期门槛**：日榜距今 > 3 天、周榜距今 > 14 天 → **必须标「已过期」，且不得作为当前热度依据**

**检索词必须带当前年月**——不带年月的检索词会稳定召回任意年份的榜单，这是本引擎最高频的翻车点。

### 铁律 3 · 来源必标

**每条硬信息带：来源名 + 链接 + 分级。**

给不出来源的信息**不进卡**——哪怕它看起来非常对。

「我印象里这部剧挺火」不是来源。**印象不是来源。**

### 铁律 4 · 一手与转述分开

平台公示数据（T1）与媒体转述（T2）**分栏、分开措辞**，禁止混排。

错例：

> ❌ 热度 5559 万，据报道是当周第一

对例：

> ✅ 公示热度 5559 万（据〈数据方〉2026-10-05 榜单，原始来源标注为〈平台〉官方数据中心）
> ✅ 有报道称其为当周第一（T2，未核实原始排名数据）

**判据**：这句话里的数字，是平台给的，还是某个人转述的？两者措辞必须不同。

### 铁律 5 · 事实与推断分开

| 类型 | 措辞 | 例 |
|---|---|---|
| **事实** | 直接陈述 + 来源 | 「2026-10-07 日榜第 11 名（短剧工程，T1.5）」 |
| **推断** | 显式标注「推断」+ 依据 | 「【推断】开局钩子较强，依据：首日第 92 名→次日第 11 名」 |
| **未验证** | 显式标注「未核实」 | 「有讨论称该剧结局留了第二季伏笔（T2，未核实）」 |

**禁止**：把推断写成事实的句式。**"这部剧靠反转取胜"是推断，"该剧 10-06 排第 11 名"是事实。**

### 铁律 6 · 热度只看独立信源数

**轻量版不算热度分。** 若需给参考，只数：

```
独立信源数 = 点名提到该剧的【不同来源主体】个数
```

三条数法：

1. 同一篇文章被转载十次 = **1 个来源**（按原始发布方去重，不按链接）；
2. 同一媒体的多篇文章 = **1 个来源**；
3. 只算**逐字点名**该剧的——合集里罗列、评论里顺带一提的**不算**。

> 这套数法对应外网公开周榜（CherryBowl）的方法论：**用"有几个独立主体在说"替代"某个平台给了多少分"**——前者更难伪造。

## 二 · 分级判定速查（判"这算几手"）

```
问：这个数据是谁产生的？
├─ 平台/官方自己公示的原始数据            → T1
├─ 专业方基于官方数据的加工（指数/榜单）    → T1.5
└─ 媒体/自媒体/观众对上述内容的转述或评论   → T2
```

**两个常见误判**：

| 误判 | 正解 |
|---|---|
| 排版精良的行业周榜 = T1 | 只要**不是平台自己发布的原始数据**，加工过的就是 **T1.5** |
| 我转引了 T1 数据但没拿到原文 = T1 | **经转引必须降级标注**：「经〈数据方〉转引，原始来源标注为〈平台〉」 |

## 三 · 九种常见编造形态（逐条对号）

> 这是本纪律最实用的一节。**交付前逐条扫一遍。**

| # | 形态 | 错例 | 对例 |
|---|---|---|---|
| 1 | **补全数字** | 「热度指数 911，约 911 万播放」 | 「当周热播指数 911（平台综合指标，非播放量）」 |
| 2 | **补全年份** | 来源说"本周"，卡里写"2026-10-06" | 「本周（截至来源发布时点 2026-10-07）」 |
| 3 | **剧名翻译** | 外网剧名被"翻译"成顺口的中文名 | **逐字照抄**原文名，中文名另标并注明"译名待核" |
| 4 | **同名合并 / 分季混淆** | 《XXX》与《XXX 第八季》当同一部 | 保留分季标记，**分季算独立条目** |
| 5 | **强化语气范围** | 来源"有观众认为" → 写成"观众普遍认为" | 照抄原力度：「有观众认为（T2，来源：〈平台〉）」 |
| 6 | **跨平台换算** | 「ReelShort 第 1 ≈ 国内 TOP1 热度」 | **禁止跨生态换算**，两套生态分行列出 |
| 7 | **行业常识补全** | 未标集数时写"通常 80~100 集" | 写「未找到」，或标注【推断·行业惯例】 |
| 8 | **重复计数** | 同一篇稿被转 10 次 = 10 个来源 | 按**原始发布方**去重 = 1 个来源 |
| 9 | **旧榜回填当下** | 拿 3 个月前的榜单写"现在最火" | 带时点 + 超期标「已过期」 |

**自检口诀：这句话，我能指出是谁在哪一天说的吗？**

## 四 · 拿不到时怎么写（话术模板）

| 情况 | 写法 |
|---|---|
| 完全没查到 | `未找到` |
| 只有传闻 | `有讨论称……（T2，来源：〈平台〉〈日期〉，未核实）` |
| 只能推算 | `【推断】……；依据：〈哪条数据〉` |
| 数据过期 | `第 N 名（〈日期〉日榜，已过期 —— 距今 > 3 天）` |
| 来源只给结论不给数据 | `据〈来源〉称其表现优异（T2，未给出具体指标）` |
| 平台不公示 | `平台不公示该项（如精确播放量、完播率）` |

**禁止**用"据了解""业内普遍""大概""应该是"这类词——**它们既不是来源也不是推断标注**。

## 五 · 交付前证据自检（证据部分）

- [ ] 全文**没有任何未标来源的硬信息**；
- [ ] 所有热度/排名/在榜数据**都带时点**；
- [ ] 超期数据（日榜 > 3 天 / 周榜 > 14 天）**已标"已过期"**；
- [ ] 没有把「热播指数」写成「播放量」；
- [ ] 没有跨平台/跨生态换算；
- [ ] T1 / T1.5 / T2 **措辞分栏**，未混排；
- [ ] 推断项**全部显式标注**【推断】+ 依据；
- [ ] 独立信源数**按原始发布方去重**；
- [ ] 未查到项**主动写「未找到」**，未用行业常识补全；
- [ ] 没有"据了解 / 业内普遍 / 大概是"这类无来源措辞。

**任一项不通过 = 返工。**

## 六 · 与套装其他证据纪律的关系

本纪律是**采风环节**的证据口径，与以下既有模块**互引不重复**：

| 模块 | 管什么 | 与本纪律的关系 |
|---|---|---|
| `sd-script-engine` 的「① 来源登记」 | 剧本层的**来源可追溯** | 情报卡进入来源登记时**保留来源与分级**，不得把 T2 讨论当设定依据 |
| `sd-qc-engine` | 成品的**事实核查与连续性** | 采风结论被引用到成品时，若与成品正文冲突，**以可核查的来源为准** |

**一句话**：采风纪律保证"带回来的东西是真的"；下游各层的证据纪律保证"用出去的东西没变形"。**两者缺一，链就断。**
