# 空间导演转换器｜空间参考系统 V3

> 目标：把普通分镜转换成视频模型更容易理解的"连续空间"。
>
> 核心不是单纯生成站位图，而是根据分镜类型，建立：
>
> **静态空间状态** 或 **动态空间关键帧**。
>
> 核心原则：
>
> **先空间，后镜头。**

---

# 一、整体流程

```text
普通分镜
 ↓
分析人物数量
 ↓
分析运动程度
 ↓
分析场景复杂度
 ↓
判断空间模式
 ↓
生成空间参考
 ↓
建立人物关系
 ↓
建立摄影机关系
 ↓
转换原分镜
 ↓
输出视频生成提示词
```

---

# 二、空间模式

目前分成两种核心模式。

```text
A｜静态 / 对话型
B｜动态 / 运动战斗型
```

不要用同一种空间表达方式处理所有场景。

---

# 三、A｜静态 / 对话型

## 适用场景

- 对话
- 课堂
- 审讯
- 会议
- 站立交流
- 坐姿交流
- 少量表演动作

人物基本保持在自己的空间区域。

---

## 空间参考

例如教室：

```text
 【讲台 / 黑板】
 ┌──────────────┐
 │ A 女老师 │
 │ 站立 │
 └──────────────┘
 ↓
 【台阶 / 隔离带】
 ↓

 B 学生A C 男主 D 学生B
 左 中 右
 ● ● ●

 【课桌 / 教室】
```

---

## 静态型重点

锁定：

```text
人物位置
左右关系
前后关系
人物朝向
视线关系
180°轴线
摄影机区域
```

人物可以：

- 说话
- 眨眼
- 呼吸
- 点头
- 转头
- 轻微手势
- 轻微移动重心

但不能：

- 换位
- 跨区
- 瞬移
- 因为切镜重新排列

---

# 四、B｜动态 / 运动战斗型

动态场景不能只生成"一张固定站位图"。

因为人物会真实移动。

所以使用：

> **空间关键帧**

也就是：

```text
初始空间
 ↓
运动 / 动作
 ↓
空间变化
 ↓
新的空间状态
 ↓
继续运动
 ↓
最终空间状态
```

---

# 五、动态空间关键帧

例如三人战斗：

## 0秒｜初始状态

```text
 敌人A

 ↓

 主角 女配
```

空间关系：

- 敌人A位于前方
- 主角位于左后方
- 女配位于右后方
- 主角和女配共同面对敌人

---

## 3秒｜开始交战

```text
 敌人A
 ↑

 主角
 女配
```

空间发生变化：

- 主角向前进入战斗位置
- 敌人发生位移 / 调整位置
- 女配保持自己的相对位置
- 三人的空间关系由平面站位变成动态三角关系

---

## 主角被击退

```text
 敌人A


女配 主角
```

这里必须理解为：

```text
敌人攻击
 ↓
主角受力
 ↓
主角沿击退方向移动
 ↓
主角落到新的空间位置
```

不是：

> 切镜后主角突然出现在右边。

---

## 最终状态

```text
主角 敌人A
 ↑
 女配
```

最终空间关系发生新的变化。

这是人物真实运动产生的新空间状态。

不是摄影机切镜造成的重新排列。

---

# 六、动态型最重要的概念

动态场景不是：

> 固定站位 + 人物做动作。

而是：

> **空间状态随着人物运动持续变化。**

因此必须同时表达：

```text
空间状态
+
运动方向
+
运动路径
+
动作因果
+
运动后的新空间状态
```

---

# 七、运动因果

任何明显的位置变化，都应该有动作原因。

例如：

```text
主角
 ↓
向敌人冲刺
 ↓
与敌人交手
 ↓
敌人攻击
 ↓
主角被击退
 ↓
主角落到右后方
```

而不是：

```text
镜头1：主角左边

切镜

镜头2：主角右边
```

空间变化必须由：

- 行走
- 奔跑
- 攻击
- 闪避
- 击退
- 跳跃
- 坠落
- 追逐
- 包抄
- 旋身

等真实动作产生。

---

# 八、动态场景中的空间锚点

动态场景仍然需要空间锚点。

但锚点不是：

> 人物永远不能移动。

而是：

> **人物的初始区域、运动范围和运动规则。**

例如：

```text
主角：
初始 = 左后区
运动 = 向中央前进
允许 = 战斗中央区
禁止 = 无理由穿越女配

女配：
初始 = 右后区
运动 = 向敌人侧翼移动
允许 = 右侧战斗区

敌人：
初始 = 前方
运动 = 前后 / 横向闪避
目标 = 主角与女配
```

---

# 九、动态空间的"关系"比绝对坐标更重要

运动过程中，人物位置会改变。

因此不能永远使用：

```text
主角 = 左
女配 = 右
敌人 = 中
```

而应该记录：

```text
谁在谁的哪一侧
谁在谁的前方
谁正在接近谁
谁正在远离谁
谁攻击谁
谁被谁击退
谁追谁
```

例如：

```text
初始：

敌人
 ↓
主角 女配


交战：

主角 → 敌人
女配 → 敌人


击退后：

敌人
 ↓
女配 主角
```

重点是：

> **空间关系随动作变化，但变化必须有因果。**

---

# 十、多人运动场景

当人物增加到5～8人，不建议为每个人写大量坐标。

优先使用：

## 区域

```text
左前区
右前区
中央战斗区
左后区
右后区
高台
石阶
```

## 阵营

```text
主角组
敌人组
中立角色
```

## 目标关系

```text
A1 → C1
A2 → C2
A3 掩护 A1
B1 包抄 A2
```

## 运动关系

```text
A1 → 中央
C1 ← 后退
A2 → 侧翼
```

复杂多人场景的核心：

> **区域 + 运动路径 + 目标关系 + 空间关键帧**

---

# 十一、复杂玄幻场景空间参考

例如：

```text
 【山门 / 山峰】
 │
 ┌─────────┐
 │ 高台 C │
 │ 敌人 │
 └─────────┘
 ↓
 石阶
 ↓

 A 女主 B 男主
 左 右
 ● ●

 【战斗广场】

 A活动区 B警戒区

 CAMERA
```

这里同时表达：

- 环境结构
- 高低关系
- 前后关系
- 人物位置
- 活动区域
- 摄影机区域

---

# 十二、动态复杂场景也可以使用关键帧地图

例如：

```text
【0秒｜初始】

 高台
 C
 ↓

 A B

 CAMERA
```

```text
【3秒｜交战】

 C
 ↗

 A →

 B

 CAMERA
```

```text
【6秒｜A被击退】

 C

 B A
 ←

 CAMERA
```

```text
【10秒｜重新定位】

 A C
 ↑
 B

 CAMERA
```

这四张图共同定义：

> **同一个场景在10秒内的空间变化。**

---

# 十三、人物位置 ≠ 画面位置

必须区分：

> **真实场景位置**

和：

> **画面中的左右位置。**

例如男主真实位于场景右侧。

摄影机移动后：

- 男主可以出现在画面左边
- 男主可以出现在画面中央
- 男主可以成为前景
- 男主可以只出现半个身体

只要真实三维关系没有被破坏即可。

---

# 十四、摄影机规则

摄影机负责：

- 景别
- 构图
- 观察角度
- 焦距
- 推拉
- 横移
- 过肩
- 反打

但摄影机不能：

- 无理由改变人物空间
- 因为正脸重新排列人物
- 无理由跨越主要战斗轴线
- 把真实空间镜像
- 让切镜变成场景重置

---

# 十五、过肩镜头

当人物位于场景右侧，而镜头需要拍他看向前方人物时：

优先：

```text
 被观察人物
 C
 ↑
 │

 B男主
 ●
 /肩膀/
 CAMERA
```

即：

> **男主右后侧过肩。**

不要为了拍男主正脸而把摄影机直接放到轴线另一侧。

---

# 十六、180°轴线

主要人物关系形成：

```text
A / B ←→ C
```

摄影机原则上保持在同一侧。

正反打：

> 改变观察角度。

不是：

> 镜像整个空间。

因此：

```text
反打 ≠ 左右交换
反打 ≠ 人物重排
反打 ≠ 空间重置
```

---

# 十七、镜头连续性

每次切镜：

```text
继承上一镜结束时的空间状态
 ↓
继承人物位置
 ↓
继承人物关系
 ↓
继承人物运动结果
 ↓
选择摄影机
 ↓
执行当前镜头
```

特别是动态场景：

> **上一镜人物被击退到哪里，下一镜必须从哪里继续。**

不能：

```text
镜头1
主角被击退到右后方

↓

镜头2
主角又自动回到左侧
```

除非分镜明确表现了：

> 主角移动回去。

---

# 十八、镜头提示词应该简洁

空间参考图负责全局。

镜头文字只负责当前变化。

例如：

```text
【0—3秒】

广角建立。

主角与女配从后方逼近敌人。
主角率先冲入中央战斗区。
女配从右侧跟进。

保持初始空间关系。
```

下一镜：

```text
【3—6秒】

中近景。

继承上一镜空间。

敌人迎击主角。
主角受到攻击，被击退至右后方。

空间位置随动作真实变化。
```

下一镜：

```text
【6—10秒】

宽幅关系镜头。

继承主角被击退后的新位置。

女配向敌人侧翼移动。
最终形成新的三角空间关系。
```

不需要每个镜头重复完整空间规则。

---

# 十九、两种模式的最终区别

## 静态型

```text
一个空间状态
+
人物锚点
+
视线关系
+
摄影机关系
```

核心：

> **位置稳定。**

---

## 动态型

```text
多个连续空间状态
+
运动路径
+
动作因果
+
运动后的新位置
+
摄影机关系
```

核心：

> **位置可以改变，但必须连续。**

# 二十一、最终原则

## 静态场景

> **锁空间状态。**

## 动态场景

> **锁空间变化。**

## 运动不是"人物做动作"。

> **运动是人物从一个空间状态移动到另一个空间状态。**

## 动态空间参考不是一张图。

> **而是一组按时间排列的空间关键帧。**

## 每次位置变化必须有动作因果。

> **攻击 → 受力 → 移动 → 新位置。**

## 摄影机可以改变观察方式。

> **不能改变真实空间。**

## 切镜可以改变画面。

> **不能无理由重置人物位置。**

## 最核心的一句话

> **静态场景描述"人物在哪里"；动态场景描述"人物从哪里移动到哪里，以及为什么移动到那里"。**

# 二十二、专业分镜的标准结构

外部专业分镜通常由两部分组成：

```text
【分段 / 单集标题】（总时长）

● 资产规划：
  角色 (Characters)：[图1]角色名＝稳定外观、发型、服装、气质特征
  场景 (Scenes)：@场景1＝空间布局、门窗位置、固定陈设、主光方向、时间、材质、前中后景关系
  道具 (Props)：@道具1＝材质、颜色、形态、初始状态、重量感、辨识特征
  连续性 (Continuity)：角色服装、身体状态、道具状态、场景状态变化的准确时间节点

● 镜头脚本 (Prompt)：
场景：[场景名称]=@场景N
[开始秒]–[结束秒]s（景别、拍摄距离、方位与角度、运镜方式、剪辑衔接）：画面描述
[开始秒]–[结束秒]s（景别、拍摄距离、方位与角度、运镜方式、剪辑衔接）：画面描述

无字幕，无背景音乐
```

解析要点：

- 场景标记单独占一行，`场景：[名称]=@场景N`，不占用时长。
- 时间轴从 0s 开始，相邻镜头首尾无缝衔接，无重叠、无跳秒、无留白。
- 场景切换不重置时间轴。
- 每个镜头独占一行，直接以时间戳开头，没有"镜头1"编号。

---

# 二十三、场景描述写法（场景 DNA）

外部分镜中场景的规范写法：

```text
@场景1＝空间布局、门窗位置、固定陈设、主光方向、时间、材质与前中后景关系
```

场景 DNA 包含：

```text
空间风格与建筑风格
时代背景与地域文化
色彩体系与明度层级
自然光、人工光与阴影逻辑
建筑和家具材质语言
家具、灯具与装饰元素
房间尺度、层高和空间比例
墙体、门窗、柱、梁、楼梯与高差
主视觉区域、功能分区和人物动线
摄影质感、渲染方式与氛围特征
```

转换器必须从这段描述中锁定：

```text
空间布局
门窗位置
固定陈设
主光方向
时间
材质
前中后景关系
```

参考图或原始描述是唯一视觉标准，禁止改变建筑风格、时代背景、色彩体系和空间气质。

---

# 二十四、不可变空间锚点

无论分镜怎么切，以下锚点必须全场景一致：

```text
相同房间轮廓、开间、进深、层高和地面高差
相同墙体厚度逻辑、柱网、梁、拱、楼梯和天花结构
相同门窗数量、形状、尺寸比例、开启方向和所在墙面
相同主家具、固定家具、灯具、屏风、地毯和装饰物
相同家具位置、朝向、间距和与墙体的相对关系
相同墙面、地面、天花、木作、石材、金属和织物材质
相同主色、辅色、点缀色和材质反射关系
相同时间、天气、自然光方向、人工灯状态和阴影方向
相同磨损、灰尘、潮湿、烟雾或使用痕迹
```

严禁四个机位各自生成不同房间，或在反打中随意移动门窗、家具和灯具。

---

# 二十五、镜头描述写法（镜头行格式）

外部分镜的镜头行括号内固定包含五个要素：

```text
[开始秒]–[结束秒]s（景别、拍摄距离、方位与角度、运镜方式、剪辑衔接）
```

- 景别：大远景、全景、中远景、中景、中近景、近景、特写、大特写、极端特写、环境空镜
- 拍摄距离：镜头与被摄主体的物理距离
- 方位与角度：正面、侧面、背面、三分之二侧面、俯拍、仰拍、平视
- 运镜方式：固定、手持、轨道、斯坦尼康、升降、推拉、摇移
- 剪辑衔接：开场直入、hard cut、match cut、sound bridge cut

画面描述按固定顺序组织：

```text
画面主体与构图 → 进行中的动作 → 重力及碰撞反馈 → 微表情与生理应激 → 光影变化 → 台词 → SFX → 英文标签
```

每个镜头只承载一个主要叙事动作或一个主要人物反应。

---

# 二十六、从分镜提取空间的解析流程

收到外部专业分镜后，按以下顺序提取空间：

```text
1. 读资产规划中的场景字段
2. 提取场景 DNA
3. 锁定不可变空间锚点
4. 读每个镜头行的场景标记
5. 判断场景切换（@场景N 变化）
6. 判断静态 / 动态模式
7. 按镜头顺序重建空间状态
8. 生成空间参考
9. 校验空间连续性
```

---

# 二十七、解析时的连续性校验

外部分镜本身通常已保证连续，但转换器必须逐项校验：

```text
空间连续：门窗、家具、灯具、道具不因换机位而漂移
动作连续：人物移动距离符合相邻镜头时间间隔，动作中间态延续
视线连续：正反打视线高度和方向匹配，看向画外目标的镜头反向合理
轴线连续：遵守一百八十度轴线，越轴必须有中性镜头或运动过渡
资产统一：角色、场景、道具编号跨镜头复用，外观状态不漂移
```

特别校验：

```text
人物从画面一侧移动时，后续镜头保持一致银幕方向
同一人物不得在没有过渡镜头的情况下瞬移到房间另一侧
上一镜人物被击退到哪里，下一镜必须从哪里继续
```

# 二十八、空间资产视图（场景的四类表达）

外部分镜可能附带或引用四类空间视图，解析时按对应规则理解：

## 场景四视图（Turnaround）

```text
Front / Left / Right / Back

同一空间模型旋转九十度
正交投影，平行线保持平行
无近大远小、无鱼眼、无三分之四透视
四个方向只改变观察方位，不改变空间、家具、材质、光照
```

## 场景俯视布局（Top View）

```text
九十度垂直向下的正交投影
移除屋顶天花，开顶切墙
展示房间边界、墙体、门窗、出入口、家具、功能区域
标记摄影机位置、镜头朝向、视野锥、人物动线
```

## 场景布局板（Scene Design Sheet）

```text
上半部：C1 主视觉（24/35mm）、C2 侧面空间（35mm）、C3 材质细节（50mm）、C4 功能区域（24/35mm）
下半部：高位三分之四透视的空间布局图 + 摄影机标记

C1–C4 必须来自同一个空间模型
```

## 视觉分镜九宫格（3×3 Storyboard）

```text
第一行：建立空间与触发事件
第二行：展开关系与推进动作
第三行：细节、结果与悬念

九格连续，空间、动作、视线、轴线全程锁定
```

# 二十九、分镜输入到空间参考的对接规则

1. 外部分镜的"场景字段"就是本系统的输入，直接作为空间状态来源。
2. 分镜中的场景切换 = 空间模式切换，重新建立空间锚点。
3. 分镜中的运镜字段（方位与角度）只改变观察方式，不改变真实空间。
4. 分镜中的剪辑衔接（hard cut 等）不重置空间，只重置摄影机。
5. 分镜中人物位置变化必须能在动作描述里找到因果，否则标记为空间错误。
6. 分镜已锁定资产编号的，转换器沿用编号，不重新分配。

# 三十、总结

> **专业分镜负责"怎么拍"，空间参考系统负责"在哪里"。**
>
> 解析分镜时：先提取场景 DNA，再锁空间锚点，再判断静态 / 动态，最后生成空间参考。
>
> 分镜的每个镜头都建立在同一个连续空间上——这正是本系统存在的意义。
